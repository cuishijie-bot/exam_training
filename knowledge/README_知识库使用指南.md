# 国考 / 辽宁省考知识库｜README 使用指南

## 1. 这套知识库怎么用

不要从头到尾背。

正确顺序：

```text
做题
→ 识别题型
→ 查对应专项
→ 复盘错因
→ 做同母题变式
→ 周复测
```

知识库的作用：

```text
不会时查
做错时归
考前时扫
```

---

## 2. 三种使用模式

### 学习模式

```text
01 总库
→ 02～05 专项
→ 少量专项题
```

### 刷题模式

```text
直接做真题
→ 错题进入06
→ 查对应专项
```

### 考前模式

```text
只看07速查
+
个人错因Top5
+
UPDATE动态知识
```

---

## 3. 每道错题必须回答

```text
这是什么题型？
属于哪个母题？
我错在哪一步？
下次看到什么关键词触发？
```

禁止只记：

```text
答案是C
```

---

## 4. D1 / D3 / D7

```text
D0：
当天归因

D1：
第二天不看解析重做

D3：
同母题变式

D7：
放回混合题组
```

---

## 5. 公交通勤

公交适合：

```text
速查
口诀
母题识别
短题
错题二刷
申论材料提炼
```

公交不适合：

```text
长篇作文
复杂排列组合
长材料精算
大规模抄笔记
```

---

## 6. 晚间学习

优先：

```text
完整真题
错题复盘
申论完整小题
必要时作文提纲
```

不要：

```text
晚上重新抄知识库
```

---

## 7. 行测优先级

日常训练建议：

```text
资料分析
→ 保证稳定高正确率

判断推理
→ 建立模型识别

言语
→ 稳定结构与边界

数量
→ 按投入产出取舍

政治理论
→ 高频 + 动态更新

常识
→ 高频稳、冷门放
```

## 9. 申论特别说明

国考：

```text
中央省级
市地级及以下
行政执法
```

辽宁：

```text
省市级
县乡级
```

使用：

```text
knowledge/02_申论/01_通用/09_国考辽宁申论分类分级专项.md
```

先确认自己的职位类别，再训练答案层级。

## 10. 动态知识

以下不能永久背死：

```text
最新法律
政治会议
重大政策
科技航天
世界遗产
人口GDP
辽宁大连最新定位
```

统一标：

```text
UPDATE
```

考前重新核对。

---

## 11. 一周闭环

```text
周一～周五：
专项 + 真题

周六：
混合限时

周日：
统计错因Top5
只补Top3
```

---

## 12. 知识库停止扩张条件

当某模块：

```text
高频母题覆盖完整
+
连续新题正确率稳定
```

就：

```text
停止继续整理
开始刷题
```

只有遇到：

```text
新母题
重复错因
大纲变化
```

才回库补充。

---

## 13. 最终目标

不是：

```text
拥有最多Markdown
```

而是：

```text
看到题
→ 快速识别
→ 调用正确方法
→ 控制时间
→ 稳定得分
```
