> ```text

# 0. 全科统一状态码

```text
NEW
→ 新错题

R1
→ D1二刷完成

R2
→ D3变式完成

R3
→ D7混合复测完成

DONE
→ 母题稳定
```

# 1. 通用附加标签

```text
GUESS
→ 猜对 / 依据不充分

SLOW
→ 明显超时

REPEAT
→ 同错因重复出现
```
