# 0. 2020—2025辽宁申论最稳定结构

公开整理题本高度稳定：

```text
第1题：15分
→ 归纳概括
→ 通常不超过200字

第2题：20分
→ 综合分析 / 原因 / 启示 / 对策
→ 通常不超过300字

第3题：25分
→ 应用文 / 对策 / 贯彻执行
→ 通常400～500字

第4题：40分
→ 大作文
```

记忆：

```text
15概括
20分析
25执行
40作文
```

# 2. 第一题长期规律

12套2020—2025公开卷中，
第一题几乎稳定为：

```text
归纳概括
```

常见对象：

```text
做法
特点
经验
变化
差异
成效
```

因此：

```text
归纳概括 = 辽宁申论第一基本功
```

```

真正难点：

```

# 4. 第三题长期规律

高频文种：

```text
调研报告提纲
发言提纲
工作汇报
工作建议
经验介绍
案例介绍
短评
推荐材料
```

结论：

```text
贯彻执行 / 应用文
是辽宁申论核心板块
```

---

# 5. 第四题长期规律

大量作文采用：

```text
一句抽象话
→ 深入理解
→ 联系实际
→ 自选角度
```

所以作文第一能力不是：

```text
背范文
```

而是：

```text
解释句子中的概念和关系
```

# 71. 最终20条

```text
1. 辽宁申论长期稳定为4题结构
2. 2020—2025公开题本高度稳定为15+20+25+40
3. 第一题几乎稳定考归纳概括
4. 200字高密度概括必须练熟
5. 第二题重点是综合分析和逻辑组织
6. 词句理解是辽宁高频母题
7. 第三题应用文是绝对核心
8. 调研、发言、汇报提纲必须熟练
9. 短评、经验介绍、案例介绍、推荐材料也要会
10. 作文经常从一句抽象话切入
11. 作文先解释概念，再找关系
12. 辽宁作文不等于政策作文
13. 文化、教育、个人成长同样可能成为主题
14. 历史B卷更常见基层、乡村、公共服务材料
15. 历史A卷更常见综合分析、产业和社会发展材料
16. 当前备考以当年官方分级分类要求为准
17. 2026具体题目必须区分官方信息与回忆版
18. 真题建议倒序刷，从最近年份往前
19. 一套真题必须完成“做题—定位—编码—变式”
20. 真题真正作用是验证母题，而不是背答案
```
