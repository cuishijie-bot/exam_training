>
> 本文件目标：
>
> ```text
> 审题
> ↓
> 找主题
> ↓
> 定立意
> ↓
> 写中心论点
> ↓
> 拆分论点

> 组织论证

>
> ```text
> 看到作文题
> 5分钟内完成：
> 主题
> 中心论点
> 3个分论点
> 每段论据方向
> 结尾落点
> ```

# 1. 大作文最重要的一句话

```text
立意必须来自题干和材料共同指向
```

不能只看：

```text
作文题标题
```

也不能只看：

```text
最后一则材料
```

---

# 2. 第一步：审题

先圈：

```text
主题词
关系词
限定词
身份要求
文体要求
字数要求
```

---

# 3. 主题词

例如：

```text
基层治理
创新
奋斗
民生
文化
数字化
乡村振兴
绿色发展
营商环境
服务
```

---

# 4. 关系词

例如：

```text
与
和
既……又……
不是……而是……
只有……才……
既要……也要……
```

一旦出现：

```text
通常不能只写其中一面
```

---

# 5. 限定词

例如：

```text
新时代
基层
青年
高质量发展
现代化
共同富裕
```

限定词决定：

```text
文章边界
```

---

# 6. 第二步：找材料主线

把每则材料压缩成：

```text
1句话
```

---

# 7. 材料主线提炼

可标：

```text
M1：
讲什么问题

M2：
讲什么做法

M3：
讲什么成效

M4：
讲什么关系/价值
```

---

# 8. 材料主线不是简单目录

要找：

```text
所有材料共同在说明什么
```

---

# 9. 第三步：寻找共同主题

例如材料分别写：

```text
老年人数字服务
企业线上审批
基层数据平台
```

共同主题可能不是：

```text
老龄化
企业服务
基层治理
```

而是：

```text
数字化治理如何更好服务群众
```

---

# 10. 第四步：确定立意层级

立意有三个层级：

```text
现象层
方法层
价值层
```

---

# 11. 现象层

例如：

```text
数字化发展很快
```

过浅。

---

# 12. 方法层

```text
数字化治理要提升服务效率
```

可以。

---

# 13. 价值层

```text
数字化治理应坚持以人为本，在提升效率的同时兼顾公平与温度
```

通常更完整。

---

# 14. 立意不是越高越好

如果材料只讲：

```text
基层垃圾分类
```

不要硬拔到：

```text
中华民族伟大复兴
```

---

# 15. 最佳立意标准

```text
贴材料
有高度
可展开
有边界
```

---

# 16. 第五步：中心论点

中心论点回答：

```text
这篇文章最终要证明什么？
```

---

# 17. 中心论点格式

最稳：

```text
主题 + 判断
```

例如：

```text
推进基层治理现代化，关键在于坚持以人民为中心、完善协同机制、提升治理能力。
```

---

# 18. 中心论点必须可拆

如果中心论点：

```text
基层治理很重要
```

太空。

---

# 19. 可拆中心论点

```text
提升基层治理效能，需要强化群众参与、推动资源下沉、健全协同机制。
```

可以拆成3个分论点。

---

# 20. 第六步：分论点

分论点是：

```text
中心论点的三个支撑点
```

---

# 21. 分论点三种来源

```text
材料主题分块
逻辑关系分块
治理路径分块
```

---

# 22. 第一种：并列分论点

例如：

```text
基层治理要：
强化服务
健全机制
激发参与
```

---

# 23. 第二种：递进分论点

```text
思想认识
→ 制度机制
→ 实践落实
```

---

# 24. 第三种：时间分论点

```text
事前预防
事中治理
事后总结
```

---

# 25. 第四种：主体分论点

```text
政府
企业
社会
群众
```

---

# 26. 第五种：关系分论点

例如题目：

```text
效率与温度
```

可以拆：

```text
提高效率是基础
保持温度是价值
实现二者统一是关键
```

---

# 27. 分论点必须平行

不推荐：

```text
一、提高认识
二、完善制度
三、基层治理很重要
```

第三个不是同层级。

---

# 28. 分论点长度

建议：

```text
一句话说清
```

一般：

```text
15～30字
```

---

# 29. 分论点句式 01

```text
以……夯实……
```

---

# 30. 分论点句式 02

```text
以……提升……
```

---

# 31. 分论点句式 03

```text
以……激发……
```

---

# 32. 分论点句式 04

```text
……是……的重要基础
```

---

# 33. 分论点句式 05

```text
……是破解……的关键
```

---

# 34. 第七步：标题

标题功能：

```text
亮主题
亮观点
```

---

# 35. 标题类型 01｜直接型

```text
以优质服务提升基层治理效能
```

---

# 36. 标题类型 02｜关系型

```text
让效率与温度同行
```

---

# 37. 标题类型 03｜动宾型

```text
激活基层治理新动能
```

---

# 38. 标题类型 04｜比喻型

可用，但风险更高。

例如：

```text
打通治理“最后一公里”
```

前提：

```text
材料确实围绕此意
```

---

# 39. 标题不宜

```text
过空
过大
过花
与材料无关
```

---

# 40. 不推荐标题

```text
新时代新征程新作为
```

如果材料没有明显对应：

```text
太空
```

---

# 41. 第八步：开头

开头目标：

```text
100～150字内
把主题和中心论点立住
```

---

# 42. 开头结构 01｜材料切入

```text
材料现象
→ 提炼问题
→ 提出观点
```

---

# 43. 示例骨架

```text
从……到……，材料中的变化说明……
但与此同时，……仍然存在。
因此，推动……，必须……
```

---

# 44. 开头结构 02｜问题切入

```text
指出现实矛盾
→ 分析必要性
→ 提出中心论点
```

---

# 45. 开头结构 03｜关系切入

```text
A重要
B也重要
真正关键是处理好A与B的关系
```

---

# 46. 不推荐开头

```text
长篇名言
历史铺垫
空洞宏大叙事
```

---

# 47. 高频错误：开头写200多字

问题：

```text
浪费正文篇幅
```

---

# 48. 第九步：正文论证

一个完整分论点段可以：

```text
分论点句
→ 解释
→ 材料/案例
→ 分析
→ 回扣
```

---

# 49. 分论点段万能结构

```text
观点
+
为什么
+
材料证明
+
因此怎么办/意味着什么
```

---

# 50. 但不要机械四句

重点是：

```text
有论证链
```

---

# 51. 第十步：材料论据

材料是第一论据来源。

---

# 52. 材料论据怎么用

不要整段抄。

应：

```text
压缩案例
→ 提炼关键事实
→ 服务论点
```

---

# 53. 示例

材料很长：

```text
某社区通过网格员、志愿者、居民议事会解决停车问题……
```

正文可写：

```text
某社区通过网格化走访和居民协商，引导多元主体共同解决停车难题，说明基层治理只有让群众真正参与，才能形成治理合力。
```

---

# 54. 材料案例结构

```text
主体
+ 做法
+ 结果
+ 说明什么
```

---

# 55. 第十一步：案例论证

案例可以来自：

```text
材料
常识性公共案例
自身积累
```

但最稳：

```text
材料优先
```

---

# 56. 案例不是越多越好

一个分论点：

```text
1个典型案例
+
分析
```

通常足够。

---

# 57. 高频错误：堆案例不分析

例如：

```text
A地……
B地……
C地……
```

没有解释：

```text
为什么能证明观点
```

---

# 58. 正确：

```text
案例
→ 提炼机制
→ 回扣分论点
```

---

# 59. 第十二步：原因论证

结构：

```text
如果没有A
→ 会出现什么问题
→ 因此A必要
```

---

# 60. 示例

分论点：

```text
群众参与是基层治理的重要基础。
```

原因：

```text
基层问题直接关系群众日常生活，仅靠行政力量难以全面掌握需求，也难以形成持续治理合力。
```

---

# 61. 第十三步：意义论证

结构：

```text
做好A
→ 对主体1有什么作用
→ 对主体2有什么作用
→ 长远有什么价值
```

---

# 62. 第十四步：对比论证

```text
有A时怎样
没有A时怎样
```

---

# 63. 示例

```text
只靠突击检查，问题容易反复；建立常态化监管机制，才能推动治理由“治标”转向“治本”。
```

---

# 64. 第十五步：因果论证

```text
A为什么导致B
```

要写：

```text
中间机制
```

---

# 65. 不推荐

```text
加强人才培养，所以高质量发展。
```

中间太跳。

---

# 66. 更好

```text
加强人才培养能够提升专业能力和创新水平，为产业升级提供持续的人才支撑，从而增强高质量发展的内生动力。
```

---

# 67. 第十六步：原理论证

可以用：

```text
一般规律
治理逻辑
公共管理常识
```

但不要脱离材料。

---

# 68. 第十七步：对策论证

策论文中：

```text
为什么这样做
+
具体怎么做
```

---

# 69. 对策段结构

```text
分论点
→ 现实问题
→ 为什么需要
→ 怎么落实
→ 预期效果
```

---

# 70. 第十八步：关系型作文

题干同时给：

```text
A与B
```

最重要：

```text
不能只写A
不能只写B
```

---

# 71. 关系型常见关系

```text
并列
互补
基础与目标
手段与目的
对立统一
相互促进
```

---

# 72. 母题 01｜效率与温度

可立意：

```text
公共服务既要提升效率，也要保留人文温度，在二者协调统一中提升群众获得感。
```

---

# 73. 分论点示例

```text
一、效率是提升服务质量的重要基础。
二、温度是公共服务的价值底色。
三、以制度和技术创新实现效率与温度统一。
```

---

# 74. 母题 02｜发展与保护

不应：

```text
先发展后保护
```

除非材料明确。

通常：

```text
发展与保护相互依存，应在保护中发展、在发展中保护。
```

---

# 75. 第十九步：主题型作文

题目给一个核心主题：

```text
奋斗
服务
治理
创新
```

需要从材料中确定：

```text
这个主题具体指什么
```

---

# 76. 主题型不能只围绕词义写

比如：

```text
“创新”
```

不能写成：

```text
创新很重要
要创新
创新有意义
```

要结合材料：

```text
创新什么
为什么创新
如何创新
```

---

# 77. 第二十步：策论文

策论文核心：

```text
解决问题
```

分论点通常是：

```text
三条对策
```

---

# 78. 策论文结构

```text
开头：
问题+总对策

正文：
对策1
对策2
对策3

结尾：
回扣目标
```

---

# 79. 策论文分论点示例

```text
完善制度机制，夯实治理基础。
强化资源保障，提升治理能力。
激发群众参与，凝聚治理合力。
```

---

# 80. 策论文最大风险

写成：

```text
对策罗列
```

没有论证。

---

# 81. 正确做法

每条对策都要说明：

```text
为什么
怎么做
有什么作用
```

---

# 82. 第二十一步：议论文

议论文更强调：

```text
观点
分析
论证
```

不一定每段都写对策。

---

# 83. 议论文分论点示例

主题：

```text
基层治理
```

可以：

```text
群众参与是治理活力之源
制度建设是治理有序之基
服务温度是治理价值之本
```

---

# 84. 第二十二步：启示型作文

材料讲：

```text
某人/某地的经历
```

题目要求围绕启示写文章。

---

# 85. 启示型写法

```text
案例
→ 抽象精神/原则
→ 转化为社会治理/个人成长逻辑
```

---

# 86. 不要只复述故事

---

```text
当前……

因此，应……
```

---

# 88. 模板 02｜观点—解释—案例—回扣

```text
分论点。
这是因为……
材料中的……正说明……

```

---

# 89. 模板 03｜正反对比

```text
如果……
就会……
反之……
因此……
```

---

# 90. 模板 04｜主体展开

```text
对群众……
对政府……
对社会……
```

---

# 91. 第二十四步：段首句

段首最好：

```text
直接亮分论点
```

---

# 92. 不推荐：

```text
首先，我们应该认识到……
```

过空。

---

# 93. 推荐：

```text
完善协同机制，是提升基层治理效能的重要保障。
```

---

# 94. 第二十五步：段尾句

作用：

```text
回扣分论点
承接下一段
```

---

# 95. 例如：

```text
唯有打破部门壁垒，才能把分散力量真正转化为治理合力。
```

---

# 96. 第二十六步：过渡

段落之间要自然。

可以：

```text
如果说……是基础，那么……则是关键。
```

---

# 97. 但不要每段都写套路过渡

会：

```text
模板感强
```

---

# 98. 第二十七步：结尾

结尾任务：

```text
回扣主题
总结观点
适度升华
```

---

# 99. 结尾结构 01

```text
总结中心论点
→ 展望
```

---

# 100. 结尾结构 02

```text
回扣材料主题
→ 提出行动方向
```

---

# 101. 结尾长度

建议：

```text
80～120字
```

---

# 102. 高频错误：结尾拔太高

如果文章讲：

```text
社区服务
```

结尾突然：

```text
实现中华民族伟大复兴
```

容易失真。

---

# 103. 第二十八步：如何避免模板化

核心：

```text
让每个分论点来自材料
```

---

# 104. 模板化表现 01

不管什么题都写：

```text
提高认识
完善制度
加强监管
```

---

# 105. 模板化表现 02

标题永远：

```text
以……之笔 绘……画卷
```

---

# 106. 模板化表现 03

开头永远：

```text
古人云……
```

---

# 107. 防模板化方法

```text
用材料关键词
用材料逻辑
用材料案例
用具体主题词
```

---

# 108. 第二十九步：防跑题

跑题通常源于：

```text
只看题目一句话
忽略材料
只抓一个关键词
分论点与中心论点无关
```

---

# 109. 防跑题四检

```text
中心论点是否回应题干？
分论点是否支撑中心？
每段是否回扣主题？
结尾是否仍是同一主题？
```

---

# 110. 第三十步：中心论点检测

把标题遮住。

问：

```text
只看中心论点，
能不能知道文章在写什么？
```

---

# 111. 分论点检测

问：

```text
三个分论点是否都能放在中心论点下面？
```

---

# 112. 例子检测

问：

```text
这个案例是在证明本段观点，
还是只是“我会这个案例”？
```

---

# 113. 第三十一步：材料利用率

高分文章不代表：

```text
材料抄得多
```

而是：

```text
材料用得准
```

---

# 114. 材料可以用于

```text

分论点
案例
问题
原因
对策
结尾
```

# 115. 第三十二步：如何使用材料原话

可以保留：

```text

短句

```

不宜：

```text
整段照抄
```

# 116. 第三十三步：如何写论据分析

案例后至少回答一个问题：

```text

说明什么？
反映什么？
```

# 117. 案例分析句式

```text

```

# 118. 第三十四步：理论分析句式

```text

从群众需求看……
从长远发展看……
从制度运行看……
```

# 119. 但不要滥用

每段一个角度即可。

# 126. 第三十九步：题目中的一句话


# 127. 要做：

# 128. 第四十步：关系词“既要……也要……”

中心论点必须包含：

```text
A
B

```

---

# 129. 第四十一步：关系词“不是……而是……”

通常：

```text
后者是核心
```

```text
为什么不能停留在前者
```

# 130. 第四十二步：材料中反复出现的词

高频重复往往是：

```text

```

# 131. 第四十三步：材料尾段

尾段常：

```text
升华主题
提出观点
```

但不能只看尾段。

---

# 132. 第四十四步：标题与中心论点关系

标题可以更凝练。

中心论点要更完整。

---

# 133. 示例

标题：

```text
让数字治理更有温度
```

中心：

```text
推进数字治理，应在提升服务效率的同时保障不同群体平等享受公共服务，实现技术效率与人本价值统一。
```

---

# 134. 第四十五步：分论点不要重复中心

中心：

```text
要提高效率、保障公平、完善机制
```

分论点分别写：

```text
效率
公平
机制
```

---

# 135. 第四十六步：分论点不要交叉

例如：

```text
一、完善制度提高效率
二、提高效率优化服务
```

重叠严重。

---

# 136. 第四十七步：分论点数量

通常：

```text
3个
```

最稳。

不是硬性规定。

---

# 137. 两个分论点

如果材料只支持两个大方面：

```text
也可以
```

但每段要更充分。

---

# 138. 四个分论点

可能导致：

```text
每段展开不足
```

---

# 139. 第四十八步：论证深度

深度不是：

```text
词越大
```

而是：

```text
能解释为什么
能写出机制
能写出关系
```

---

# 140. 第四十九步：避免空话

不推荐：

```text
我们要努力奋斗
我们要久久为功
我们要砥砺前行
```

如果没有主题对象。

# 141. 更好：

```text
要通过完善数据共享机制、保留线下服务渠道，让数字化真正转化为群众可感可及的便利。
```

# 179. 最终20行极简版

```text
1. 大作文立意必须来自题干+材料
2. 先找主题，再找材料共同主线
3. 中心论点要明确且可拆
4. 分论点必须平行
5. 通常3个分论点最稳
6. 标题要亮主题和观点
7. 开头控制在120～150字左右
8. 开头尽快亮中心论点
9. 每个正文段先亮分论点
10. 分论点后必须解释“为什么”
11. 材料案例要压缩使用
12. 案例后必须分析
13. 关系型作文不能只写一面
14. 策论文不能只罗列对策
15. 议论文重点是论证观点
16. 不要堆名言和空泛政策词
17. 材料关键词是防模板化关键
18. 5～10分钟内先列完整提纲
19. 每段都要回扣中心主题
20. 高分关键=立意准+结构清+论证实
```
