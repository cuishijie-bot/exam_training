# 2. 归纳概括母题 01｜概括问题

题目问法：

```text
概括主要问题
指出存在的困难
归纳当前短板
```

找点路径：

```text
负面现象
不足
缺失
不畅
较低
困难
矛盾
风险
```

第一结构：

```text
小标题 + 具体表现
```

---

# 3. 概括问题第一反应

先问：

```text
谁出了什么问题？
```

# 5. 概括问题高频漏点

```text

□ 问题和影响混在一起
```
