# 国考 / 辽宁省考完整版知识库｜申论综合分析题模型库

> 配套文件：
>
> - `01_申论规范词完整版词库.md`
> - `02_申论归纳概括与材料提炼专项.md`
> - `03_申论综合分析题模型库.md`
>
> 本文件目标：
>
> ```text
> 看到“谈理解 / 谈认识 / 请分析 / 解释一句话”
> ↓
> 先判断题型
> ↓
> 再判断材料逻辑
> ↓
> 按“含义 / 分析 / 结论”组织答案
> ```
>
> 核心原则：
>
> ```text
> 综合分析不是自由发挥
> 本质仍然是：
> 从材料中找点
> + 重新组织逻辑
> ```
>
> 不能机械套：
>
> ```text
> 是什么
> 为什么
> 怎么办
> ```
>
> 应根据：
>
> ```text
> 题目问法
> 材料内容
> 句子本身
> ```
>
> 灵活组织。

# 0. 综合分析总地图

```text
综合分析
│
├─ A. 词句理解
│  ├─ 解释关键词
│  ├─ 解释句子
│  └─ 解释观点
│
├─ B. 观点分析
│  ├─ 支持
│  ├─ 反对
│  ├─ 辩证
│  └─ 条件性判断
│
├─ C. 现象分析
│  ├─ 表现
│  ├─ 原因
│  ├─ 影响
│  └─ 对策
│
├─ D. 关系分析
│  ├─ A与B关系
│  ├─ 对立统一
│  ├─ 相互促进
│  └─ 条件关系
│
├─ E. 比较分析
│  ├─ 相同点
│  ├─ 不同点
│  └─ 原因/启示
│
└─ F. 启示分析
   ├─ 有效做法
   ├─ 成功条件
   └─ 可迁移原则
```

---

# 1. 综合分析题本质

综合分析题比归纳概括多了一步：

```text
不仅找点
还要解释点与点之间的逻辑
```

---

# 2. 综合分析题核心能力

```text
概括
+
解释
+
判断
+
组织
```

---

# 3. 最稳答题结构

多数综合分析题可考虑：

```text
第一层：
解释对象/亮明观点

第二层：
展开分析

第三层：
作出结论/简要对策
```

但不是每题必须三段齐全。

---

# 4. 第一大类：词语理解题

题目常问：

```text
谈谈你对“……”的理解
解释“……”的含义
如何理解材料中的“……”
```

---

# 5. 词语理解题核心

不是：

```text
查字典
```

而是：

```text
解释这个词在材料语境中的含义
```

---

# 6. 词语理解固定流程

```text
① 找词所在句
② 看上下文
③ 找词指代对象
④ 找具体表现
⑤ 提炼本质
```

---

# 7. 母题 01｜抽象词解释

材料说：

```text
基层治理要打通“最后一公里”
```

不能只写：

```text
最后一公里就是最后一段路
```

应写：

```text
指政策、服务、治理资源真正落实到基层和群众末端，
解决政策落地、服务到户中的堵点。
```

---

# 8. 抽象词解释结构

```text
表层含义
+
材料中的具体所指
+
本质意义
```

---

# 9. 母题 02｜比喻词理解

例如：

```text
“堵点”
“痛点”
“最后一公里”
“毛细血管”
“蓄水池”
```

都要：

```text
去比喻化
```

---

# 10. 去比喻化方法

例如：

```text
“堵点”
```

材料中可能指：

```text
部门信息不共享
审批环节重复
服务流程不畅
```

最终：

```text
指制约工作顺畅推进的关键障碍。
```

---

# 11. 第二大类：句子理解题

题目：

```text
谈谈你对“……”这句话的理解。
```

---

# 12. 句子理解第一步

拆句：

```text
主语
关键词
逻辑关系
```

---

# 13. 句子常见逻辑

```text
因果
转折
并列
条件
递进
对比
```

---

# 14. 母题 03｜因果句

句子：

```text
“服务向前一步，矛盾就会后退一步。”
```

可拆：

```text
服务更主动
→ 更早发现诉求
→ 更及时解决问题
→ 减少矛盾积累
```

---

# 15. 因果句答法

```text
解释含义
→ 分析为什么
→ 联系材料表现/做法
```

---

# 16. 母题 04｜转折句

例如：

```text
“数字化不是为了让群众适应机器，而是让技术更好适应群众。”
```

核心：

```text
反对技术至上
强调以人为本
```

---

# 17. 转折句重点

通常：

```text
“但是 / 而是 / 更重要的是”
```

后半句是核心。

---

# 18. 母题 05｜并列句

例如：

```text
“既要提高效率，也要保留温度。”
```

要分析：

```text
效率
温度
二者关系
```

不是只解释一个。

---

# 19. 母题 06｜条件句

例如：

```text
“只有让群众参与，基层治理才能真正有活力。”
```

要解释：

```text
群众参与是治理活力的重要条件
```

再找材料依据。

---

# 20. 第三大类：观点分析题

题目常见：

```text
有人认为……
请谈谈你的看法
对此观点进行评析
你是否赞同
```

---

# 21. 观点分析第一步

不要急着：

```text
赞成 / 反对
```

先看材料态度。

---

# 22. 观点分析四种类型

```text
完全正确
完全错误
片面
有条件成立
```

---

# 23. 母题 07｜完全正确

材料整体支持：

```text
观点A
```

结构：

```text
表态支持
→ 给出材料理由
→ 总结意义
```

---

# 24. 母题 08｜完全错误

材料明确否定：

```text
观点A
```

结构：

```text
指出错误
→ 分析错误原因
→ 给出正确认识
```

---

# 25. 母题 09｜片面观点

最常见。

观点：

```text
“只要建平台，就能解决基层治理问题。”
```

材料显示：

```text
平台有用
但还需人才、制度、群众参与
```

应答：

```text
观点具有一定合理性，但过于片面。
```

---

# 26. 片面观点答题结构

```text
合理之处
+
局限之处
+
正确认识
```

---

# 27. 母题 10｜有条件成立

观点：

```text
“数字化可以提升服务效率。”
```

材料可能强调：

```text
前提是平台互通、群众会用、线下渠道保留
```

答案：

```text
数字化能够提升效率，但需要相应制度、能力和服务保障。
```

---

# 28. 观点分析不能脱离材料

不要写：

```text
“我认为……”
```

然后展开个人观点。

应该：

```text
依据材料判断
```

---

# 29. 第四大类：现象分析题

常问：

```text
分析某现象
谈谈对某现象的认识
```

---

# 30. 现象分析要回答什么

通常从材料中找：

```text
是什么
为什么
有什么影响
怎么办
```

但按材料有啥写啥。

---

# 31. 现象分析结构

常见：

```text
概括现象
→ 分析原因
→ 分析影响
→ 提出方向
```

---

# 32. 母题 11｜“办事仍需多头跑”

可分析：

```text
表现：
多部门重复提交材料

原因：
信息共享不足、部门协同不畅

影响：
增加群众办事成本

方向：
推进数据共享、流程再造
```

---

# 33. 现象分析的核心

不是写大作文。

而是：

```text
紧扣材料中的逻辑链
```

---

# 34. 第五大类：关系分析题

题目：

```text
分析A与B的关系
谈谈如何理解A和B
```

---

# 35. 关系题第一步

先判断：

```text
二者是什么关系
```

---

# 36. 常见关系 1｜相互促进

```text
A促进B
B反过来促进A
```

---

# 37. 常见关系 2｜基础与保障

```text
A是B的基础
B是A的保障/目标
```

---

# 38. 常见关系 3｜手段与目的

```text
A是手段
B是目的
```

---

# 39. 常见关系 4｜对立统一

例如：

```text
效率与公平
发展与保护
速度与质量
技术与温度
```

不是：

```text
二选一
```

而是：

```text
统筹兼顾
```

---

# 40. 母题 12｜效率与温度

材料：

```text
线上服务效率高
但老人不会使用
```

可得：

```text
效率与服务温度并非对立，
应通过线上线下结合实现效率与公平兼顾。
```

---

# 41. 关系题结构

```text
先说明关系
→ 分别说明A、B作用
→ 说明如何统一
```

---

# 42. 第六大类：比较分析题

题目：

```text
比较A、B两种做法
比较两地经验
分析二者异同
```

---

# 43. 比较题第一步

建立维度：

```text
主体
目标
方式
对象
资源
效果
```

---

# 44. 比较题不能乱比

必须：

```text
同维度比较
```

例如：

```text
A比做法
B比效果
```

不可比。

---

# 45. 母题 13｜两地治理比较

可按：

```text
主体：
A政府主导
B多元共治

方式：
A行政推动
B居民协商

效果：
A效率高
B参与度高
```

---

# 46. 比较题常见结构

```text
相同点
+
不同点
+
原因/启示
```

---

# 47. 第七大类：启示分析题

题目：

```text
从某地做法中获得哪些启示
```

---

# 48. 启示题本质

不是：

```text
照抄经验
```

而是：

```text
从具体做法中提炼可迁移原则
```

---

# 49. 母题 14｜具体做法转启示

材料：

```text
某村请返乡大学生直播卖农产品
```

启示：

```text
发挥本土人才作用，
运用数字技术拓宽农产品销售渠道。
```

---

# 50. 启示题三步

```text
做法
→ 为什么有效
→ 提炼一般原则
```

---

# 51. 启示题避免两个极端

太具体：

```text
每个村都请返乡大学生直播
```

太空：

```text
要创新
```

更好：

```text
发挥人才和数字技术作用，创新农产品营销方式。
```

---

# 52. 第八大类：“谈理解”题

“谈理解”不是固定题型名称。

它可能是：

```text
词句理解
观点分析
关系分析
现象分析
```

---

# 53. 判断“谈理解”是哪类

看题目对象：

```text
一个词
→ 词语理解

一句话
→ 句子理解

一个观点
→ 观点分析

一个现象
→ 现象分析
```

---

# 54. 第九大类：“谈认识”题

一般比“理解”更偏：

```text
判断 + 分析
```

---

# 55. “谈认识”常见结构

```text
概括判断
→ 分析原因/影响
→ 得出结论/方向
```

---

# 56. 第十大类：“请分析”题

“分析”后面跟什么最重要。

例如：

```text
分析原因
→ 只答原因

分析影响
→ 只答影响

分析意义
→ 只答积极影响

分析问题
→ 只答负面表现
```

---

# 57. 不要看到“分析”就写三段式

题目：

```text
分析造成X的原因
```

如果写：

```text
表现+原因+对策
```

就是偏题。

---

# 58. 第十一大类：词句理解的“是什么”

通常包括：

```text
表层含义
材料语境含义
核心本质
```

---

# 59. “为什么”层

材料若有：

```text
原因
意义
背景
作用
```

都可以写。

---

# 60. “怎么办”层

只有当：

```text
材料有做法
或题意需要结论
```

才写。

---

# 61. 综合分析不是必须完整写“怎么办”

这是高频误区。

---

# 62. 第十二大类：观点的隐藏前提

有些观点表面合理，但忽略条件。

例如：

```text
“线上服务越多越好”
```

隐藏问题：

```text
是否所有群众都能使用
是否存在线下替代
```

---

# 63. 分析隐藏前提

材料若说：

```text
老年人使用困难
```

就应指出：

```text
数字服务要考虑不同群体能力差异。
```

---

# 64. 第十三大类：正面现象分析

材料：

```text
某地治理效果很好
```

问：

```text
如何理解这种变化
```

可写：

```text
做法
→ 成效
→ 成功原因
→ 启示
```

---

# 65. 第十四大类：负面现象分析

材料：

```text
群众对政策不了解
```

可写：

```text
表现
→ 原因
→ 影响
→ 改进方向
```

---

# 66. 第十五大类：矛盾现象分析

题目可能出现：

```text
看起来矛盾
```

例如：

```text
平台更多了，基层反而更忙
```

---

# 67. 矛盾现象分析

应找：

```text
隐藏机制
```

例如：

```text
平台重复建设
数据不互通
造成重复填报
```

---

# 68. 第十六大类：本质分析

题目：

```text
分析这一现象的本质
```

不要只复述表现。

---

# 69. 从现象到本质

```text
具体表现
→ 共性机制
→ 深层矛盾
```

---

# 70. 示例

现象：

```text
不同部门反复要求企业提交相同材料
```

本质：

```text
部门协同不足、数据共享机制不畅，
反映政务服务流程整合不充分。
```

---

# 71. 第十七大类：意义分析

题目：

```text
分析某项工作的意义
```

本质：

```text
积极影响
```

---

# 72. 意义分析常见对象

```text
群众
政府
企业
社会
产业
生态
长远发展
```

---

# 73. 意义题结构

可按：

```text
直接作用
+
间接作用
+
长远价值
```

---

# 74. 母题 15｜数字政务意义

可能：

```text
减少群众跑腿
提升行政效率
促进数据共享
推动治理数字化
```

---

# 75. 第十八大类：危害分析

题目：

```text
分析某问题的危害
```

本质：

```text
消极影响
```

---

# 76. 危害题常见层次

```text
群众利益
行政效率
政府形象
市场环境
社会稳定
长期发展
```

---

# 77. 第十九大类：原因分析

题目：

```text
分析原因
```

只围绕：

```text
为什么发生
```

---

# 78. 原因分析常见维度

```text
思想
制度
执行
资源
能力
协同
环境
```

---

# 79. 但不能机械套维度

材料只有：

```text
产业链
品牌
市场
物流
```

就按产业逻辑写。

---

# 80. 第二十大类：综合分析中的“总括句”

第一句作用：

```text
亮明理解
明确判断
概括本质
```

---

# 81. 总括句示例

题目：

```text
理解“数字化不能落下任何人”
```

总括：

```text
这句话强调数字化转型应坚持以人为本，在提升效率的同时保障不同群体平等享受公共服务。
```

---

# 82. 总括句不要空

不推荐：

```text
这句话很有道理，意义重大。
```

---

# 83. 第二十一大类：分析展开

展开最好：

```text
一层一个逻辑
```

---

# 84. 展开结构 1｜原因型

```text
一是……
二是……
三是……
```

---

# 85. 展开结构 2｜表现型

```text
具体表现为……
```

---

# 86. 展开结构 3｜意义型

```text
对群众……
对政府……
对社会……
```

---

# 87. 展开结构 4｜关系型

```text
A……
B……
二者……
```

---

# 88. 第二十二大类：结尾

结尾可：

```text
总结本质
提出方向
```

但不必每题都单列一段。

---

# 89. 字数紧时

把结论压在最后一点：

```text
因此，应……
```

---

# 90. 第二十三大类：题型判定表

| 问法 | 第一反应 |
|---|---|
| 理解一个词 | 语境含义 |
| 理解一句话 | 拆句+逻辑 |
| 评析观点 | 判断合理性 |
| 分析现象 | 表现/原因/影响 |
| 分析关系 | 明确二者关系 |
| 比较A/B | 同维度对比 |
| 获得启示 | 做法→原则 |
| 分析原因 | 只找原因 |
| 分析意义 | 只找积极影响 |

---

# 91. 第二十四大类：材料逻辑优先

综合分析最重要：

```text
按材料本身逻辑组织
```

不是按背诵模板组织。

---

# 92. 示例

若材料顺序本身是：

```text
问题
→ 原因
→ 改革
```

# 153. 最终20行极简版

```text
1. 综合分析仍然以材料为唯一主要依据
2. 先判断题型，再决定结构
3. 理解一个词先看语境
4. 理解一句话先拆关键词和逻辑
5. 比喻词要去比喻化
6. 转折句重点通常在转折后
7. 观点题先判断材料态度
8. 观点可能正确、错误、片面或条件成立
9. 片面观点要写合理之处和局限
10. 现象题按材料找表现、原因、影响
11. 关系题必须先明确二者关系
12. 比较题必须同维度比较
13. 启示题要从具体做法抽象一般原则
14. “谈理解”不等于固定三段式
15. “请分析原因”就只围绕原因
16. 专家观点通常是高价值信息
17. 案例要提炼其证明的共性
18. 数据要提炼趋势和意义
19. 材料没有的内容不要自己补
20. 综合分析=概括+解释+判断+逻辑重组
```
