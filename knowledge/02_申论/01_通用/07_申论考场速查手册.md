# 1. 申论总口令

```text
先审题
再找点
先材料
后表达

概括题看对象
分析题看逻辑
对策题看问题原因
应用文看身份对象目的
作文看题干+材料主线
```

---

# 2. 5秒题型识别

看到：

```text
概括
归纳
总结
→ 归纳概括
```

看到：

```text
谈理解
谈认识
请分析
如何看待
→ 综合分析
```

看到：

```text
提出建议
提出措施
怎么办
→ 提出对策
```

看到：

```text
拟写
撰写
起草
写一份
提纲
→ 应用文
```

看到：

```text
自拟题目
写一篇文章
围绕……
→ 大作文
```

# 3. 审题四问

```text
① 问什么？
② 材料范围在哪？
③ 有什么身份/对象要求？
④ 字数多少？
```

# 96. 最终20行极简版

```text
1. 申论先审题，再读材料
2. 概括问题找负面事实
3. 概括原因找“为什么”
4. 概括做法找“谁做什么”
5. 概括成效找前后变化
6. 案例要抽象，数据要提趋势
7. 规范词必须有材料依据
8. 同义项要合并，不同主体别乱合
9. 句子理解先拆关键词和逻辑
10. 观点分析先判断材料态度
11. 关系题必须先明确关系
12. 启示题要把具体经验一般化
13. 对策必须对应问题和原因
14. 对策要具体、可行、不越权
15. 应用文先看身份、对象、目的、文种
16. 格式不能压过内容
17. 作文立意=题干+材料共同主线
18. 分论点必须平行且支撑中心
19. 案例后一定要分析
20. 申论高分核心=审题准+找点全+提炼准+结构清
```
