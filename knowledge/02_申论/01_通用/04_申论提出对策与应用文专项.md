# 国考 / 辽宁省考完整版知识库｜申论提出对策与应用文专项

> 配套文件：
>
> - `01_申论规范词完整版词库.md`
> - `02_申论归纳概括与材料提炼专项.md`
> - `03_申论综合分析题模型库.md`
> - `04_申论提出对策与应用文专项.md`
>
> 本文件目标：
>
> ```text
> 找问题
> ↓
> 找原因
> ↓
> 找材料已有措施
> ↓
> 转化为具体对策
> ↓
> 判断是否针对、可行、可操作
> ↓
> 根据文种改造成应用文
> ```
>
> 核心原则：
>
> ```text
> 对策必须来源于材料
> 对策必须对应问题
> 对策不能空
> 对策不能越权
> 应用文先看身份、对象、目的
> ```
>
> 对策题不是：
>
> ```text
> 背万能模板
> ```
>
> 应用文也不是：
>
> ```text
> 背固定格式套所有文种
> ```

# 1. 提出对策题第一步：审题

先圈：

```text
谁来解决
解决什么
面向谁
有无身份限制
字数多少
```

---

# 2. 对策题常见问法

```text
提出解决措施
提出改进建议
提出工作思路
提出对策
提出解决办法
提出整改措施
```

---

# 3. 对策题最关键：先找问题

没有问题：

```text
就没有针对性
```

---

# 4. 对策来源 01｜材料直接给

材料中如果出现：

```text
专家建议……
某地采取……
群众希望……
应当……
需要……
```

优先提炼。

---

# 5. 母题 01｜直接对策

材料：

```text
专家建议，应建立统一的数据共享平台。
```

答案：

```text
建立统一数据共享平台，推动部门间数据互联互通。
```

---

# 6. 对策来源 02｜问题反推

问题：

```text
宣传渠道单一
```

对策：

```text
拓宽宣传渠道，创新宣传方式。
```

---

# 7. 问题转对策公式

```text
问题词
→ 对应解决动作
```

例如：

```text
不完善
→ 完善

不健全
→ 健全

不足
→ 加强 / 加大

不畅
→ 畅通 / 优化

缺乏
→ 补充 / 建设
```

---

# 8. 对策来源 03｜原因反推

原因：

```text
工作人员业务能力不足
```

对策：

```text
加强业务培训，提升专业能力。
```

---

# 9. 原因转对策原则

解决：

```text
根因
```

往往比只处理表面问题更有效。

---

# 10. 母题 02｜问题+原因双转化

问题：

```text
群众办事慢
```

原因：

```text
部门数据不共享
```

对策：

```text
推进部门数据共享，优化跨部门办理流程，提高办事效率。
```

---

# 11. 对策来源 04｜经验转化

材料：

```text
A地实行一窗受理、部门联办后，审批时间明显缩短。
```

若问B地怎么办：

```text
借鉴一窗受理和部门联办机制，优化审批流程。
```

---

# 12. 经验转对策

```text
去地名
去人名
去特殊载体
保留可复制机制
```

---

# 13. 对策来源 05｜反面案例

材料：

```text
某地只重建设、不重维护，设施很快损坏。
```

可反推：

```text
建立设施常态化维护机制，加强后续管理。
```

---

# 14. 对策来源 06｜专家观点

专家往往提供：

```text
方向性对策
制度性对策
本质性对策
```

优先级高。

---

# 15. 对策五大标准

```text
针对性
可行性
操作性
权责匹配
材料依据
```

---

# 16. 第一标准：针对性

每一条对策都应能回答：

```text
它解决哪个问题？
```

---

# 17. 错误示例

问题：

```text
群众不知道政策
```

对策却写：

```text
加大财政投入
```

没有针对性。

---

# 18. 正确示例

```text
加强政策宣传和解读，拓宽信息发布渠道，提高群众知晓率。
```

---

# 19. 第二标准：可行性

对策必须：

```text
能实施
```

不能：

```text
不计成本
不顾现实
```

---

# 20. 错误示例

```text
给每个村配备100名专业人员。
```

通常不现实。

---

# 21. 第三标准：操作性

不推荐：

```text
加强管理
提高认识
完善机制
```

单独出现太空。

---

# 22. 提升操作性

把：

```text
加强管理
```

写成：

```text
明确监管责任，开展常态化巡查，建立问题台账和整改闭环。
```

---

# 23. 对策表达公式

```text
动作
+
对象
+
方式
+
目的
```

---

# 24. 示例

```text
加强基层工作人员培训，
通过专题培训、案例教学等方式，
提升政策执行和群众服务能力。
```

---

# 25. 第四标准：权责匹配

身份是：

```text
社区工作人员
```

不能随便提出：

```text
修改国家法律
```

---

# 26. 身份越基层

越应该提：

```text
协调
宣传
服务
反馈
执行
```

而不是：

```text
宏观立法
全国性改革
```

---

# 27. 第五标准：材料依据

材料没有：

```text
不要凭空补大而全政策
```

---

# 28. 对策题常见维度

如果材料确有依据，可从：

```text
思想
制度
责任
监管
服务
人才
资金
技术
宣传
协同
```

找。

# 29. 高频“问题—对策”对应 01

```text
思想认识不足
→ 加强宣传教育、转变理念

责任不清
→ 明确职责、压实责任

制度不健全
→ 完善制度机制

执行不到位
→ 加强督促检查、推动落实
```

---

# 30. 高频对应 02

```text
部门协同不畅
→ 健全部门联动机制

信息共享不足
→ 建立数据共享机制

监管不到位
→ 加强日常监管、加大执法力度

违法成本低
→ 完善惩戒机制、提高违法成本
```

---

# 31. 高频对应 03

```text
人才不足
→ 引进培养专业人才

能力不足
→ 加强培训

资金不足
→ 加大投入、拓宽资金渠道

设施不足
→ 补齐基础设施短板
```

---

# 32. 高频对应 04

```text
宣传不足
→ 拓宽宣传渠道、加强政策解读

群众参与不足
→ 畅通参与渠道、完善协商机制

服务流程繁琐
→ 优化流程、精简材料

数字鸿沟
→ 完善适老化服务、保留线下渠道
```

---

# 33. 对策题结构

最稳：

```text
① 完善……
② 加强……
③ 优化……
④ 健全……
```

---

# 34. 小标题+展开

例如：

```text
① 强化宣传引导：拓宽线上线下宣传渠道，加强政策解读，提高群众知晓率。
```

---

# 35. 对策数量

不要固定：

```text
一定5条
```

要看材料。

---

# 36. 对策排序

优先：

```text
按材料顺序
```

若需要重组：

```text
先制度
再执行
再保障
再监督
```

---

# 37. 轻重缓急

如果题目强调：

```text
当前
紧急
近期
```

优先写：

```text
短期可落地措施
```

---

# 38. 长效治理

如果题目强调：

```text
长效
根治
机制建设
```

重点：

```text
制度、机制、监督、保障
```

---

```text
只写“加强、完善、提高”
```

# 40. 高频错误 02


---

# 41. 高频错误 03

```text

```

---

# 42. 高频错误 04

```text

```

---

# 43. 高频错误 05

```text

```

---

# 44. 高频错误 06

```text
一条对策塞太多 unrelated 内容
```

---

# 45. 高频错误 07

```text

```

---

# 46. 高频错误 08

```text
基层身份提出中央级政策
```


```text

DC6 = 权责越界
```

# 49. 应用文总原则

应用文第一步不是想格式。

先看：

```text
身份
对象
目的
场景
文种
```

---

# 50. 应用文五问

```text
我是谁？
写给谁？
为什么写？
要达到什么目的？
什么文种？
```

---

# 51. 身份决定什么

决定：

```text
语气
权限
内容重点
```

---

# 52. 对象决定什么

决定：

```text
称谓
语言风格
说服方式
```

---

# 53. 目的决定什么

决定：

```text
正文重点
```

---

# 54. 文种决定什么

决定：

```text
格式
结构
语气
```

---

# 55. 应用文并非都要完整格式

考试中常见：

```text
“写一份提纲”
```

通常：

```text
不需要完整落款日期
```

---

# 56. 题目说“提纲”

重点：

```text
内容结构
```

---

# 57. 题目说“完整文稿”

才更重视：

```text
标题
称谓
正文
落款
日期
```

---

# 58. 应用文通用正文结构

多数可从：

```text
背景/目的
→ 主体内容
→ 号召/结尾
```

选择。

不是所有文种都全要。

# 107. 应用文格式总表

```text
通知
→ 标题+称谓+正文+落款+日期

倡议书
→ 标题+称谓+倡议内容+号召+落款+日期

公开信
→ 标题+称谓+正文+结尾+落款+日期

讲话稿
→ 称谓+开场+主体+结尾

短评
→ 标题+观点+分析+结论

简报
→ 标题+情况/做法/成效等

提纲
→ 标题+分层要点
```

---

# 108. 但格式必须服从题目要求

题目若说：

```text
“不考虑格式”
```

就：

```text
只写正文
```

```text
17. 讲话稿重现场感
18. 短评重观点和分析
```
