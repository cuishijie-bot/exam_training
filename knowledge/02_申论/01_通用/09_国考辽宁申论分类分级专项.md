

# 第一编 2026国考申论三分类

官方分类：

```text
① 中央机关及其省级直属机构综合管理类
② 市（地）级及以下直属机构综合管理类
③ 行政执法类
```

---

# 1. 中央/省级综合管理类

主要测查：

```text
阅读理解
综合分析
提出和解决问题
文字表达
```

---

# 2. 核心能力标签

```text
看得全
想得深
揭示本质
多角度分析
合理推断评价
```

---

# 3. 阅读理解

重点不是只找：

```text
材料表层事实
```

而要：

```text
准确提炼事实包含的观点
揭示所反映的本质问题
```

---

# 4. 综合分析

要求：

```text
多角度
有逻辑
能推断
能评价
```

---

# 5. 提出和解决问题

不是泛泛：

```text
加强宣传
完善制度
```

而是：

```text
理解问题
分析约束
提出针对性办法
```

---

# 6. 作答风格

更强调：

```text
宏观视野
本质分析
关系判断
系统性
政策逻辑
```

# 第七编 同一道材料如何“分级作答”

# 41. 材料

假设：

```text
某地企业办理事项需要跑多个部门，
材料重复提交，
政策咨询答复不一致。
```

---

# 42. 省市级思路

可提炼：

```text
政务服务协同机制不健全
数据共享不足
部门权责衔接不畅
营商环境改革仍需深化
```

分析：

```text
制度
机制
政府职能转变
市场预期
```

---

# 43. 县乡级/市地级思路

优先：

```text
整合窗口
明确一次性告知清单
推进数据共享
统一答复口径
设置帮办代办
```

---

# 44. 行政执法类思路

若涉及执法：

```text
明确检查权限
规范检查程序
推行检查清单
避免多头重复检查
加强政策解释
兼顾规范监管和企业正常经营
```

# 第二十二编 最终20条

```text
1. 国考申论2026按三类职位分别命题
2. 中央省级重点是阅读、综合分析、提出解决问题、文字表达
3. 市地级及以下重点是阅读、贯彻执行、解决问题、文字表达
4. 行政执法重点是阅读、依法办事、公共服务、文字表达
5. 中央省级口诀“深”
6. 市地级口诀“干”
7. 行政执法口诀“法+服”
8. 行政执法不能一罚了之
9. 执法题必须考虑依据、权限、程序、服务
10. 辽宁2026按省市级、县乡级分别命题
11. 辽宁省市级重点综合分析
12. 辽宁县乡级重点贯彻执行
13. 辽宁省市级强调揭示本质、多角度推断评价
14. 辽宁县乡级强调组织意图、依法行政、结合实际完成任务
15. 省市级答案一般层级更高但仍必须贴材料
16. 县乡级答案必须具体可执行但不能脱离材料
17. 分类分级不是题型绝对分割
18. 同一主题应根据职位类别改变分析层级
19. 辽宁主题库要与省市/县乡能力要求结合使用
20. 考前必须先确认自己职位对应哪一类试卷
```
