# 国考 / 辽宁省考完整版知识库｜申论归纳概括与材料提炼专项

> 配套文件：
>
> - `01_申论规范词完整版词库.md`
> - `02_申论归纳概括与材料提炼专项.md`
>
> 本文件目标：
>
> ```text
> 材料很多
> ↓
> 找主体
> ↓
> 找事实
> ↓
> 判断属于问题/原因/影响/做法/成效
> ↓
> 提炼关键词
> ↓
> 合并同类项
> ↓
> 形成“小标题 + 展开”
> ↓
> 控制字数
> ```
>
> 核心原则：
>
> ```text
> 先忠实材料
> 再规范提炼
> 先找事实
> 再抽象概括
> 先分类
> 再合并
> ```
>
> 归纳概括题不是：
>
> ```text
> 背模板
> 猜答案
> 自己补政策
> ```
>
> 而是：
>
> ```text
> 从材料中找答案
> + 用更规范的语言压缩答案
> ```

# 1. 归纳概括题最重要的一句话

```text
答案一定来自材料
```

不是来自：

```text
常识
经验
新闻
政策背诵
```

# 2. 第一步：审题

先圈：

```text
作答对象
```

例如：

```text

概括做法
概括特点
```

# 3. 审题四问

```text
① 问什么？
② 范围在哪？
③ 有几个要求？
④ 字数多少？
```

# 6. “概括原因”在找什么

找：

```text
为什么发生
导致它的因素
背后的根源
```

---

# 7. “概括影响”在找什么

找：

```text
带来什么结果
造成什么后果
产生什么价值
```

---

# 8. “概括做法”在找什么

找：

```text
谁做了什么
采取了什么措施
怎么解决问题
```

---

# 9. “概括成效”在找什么

找：

```text
做完之后发生了什么变化
```

---

# 10. 第二步：锁定材料范围

如果题目说：

```text
根据给定资料2
```

就只用：

```text
资料2
```

不要从资料1、3补答案。

---

# 11. 第三步：逐段找主体

每一段先问：

```text
谁？
```

常见主体：

```text
政府
部门
基层干部
企业
群众
村民
社区
学校
医院
社会组织
平台
专家
市场主体
```

---

# 12. 为什么要找主体

因为很多要点的区别就在：

```text
谁的问题
谁的原因
谁的做法
```

---

# 13. 主体不同不能随便合并

例如：

```text
政府服务不到位
企业创新能力不足
群众参与不积极
```

不能一股脑写：

```text
各方面能力不足
```

会失真。

---

# 14. 第四步：找事实

事实是：

```text
发生了什么
做了什么
造成什么
```

不要一开始就急着套大词。

---

# 15. 找事实时的标记法

可用：

```text
P = 问题 Problem
R = 原因 Reason
I = 影响 Impact
M = 做法 Measure
E = 成效 Effect
```

---

# 16. 示例标记

材料：

```text
村民不知道补贴政策，
主要因为村里通知方式单一，
后来村委会通过微信群和入户讲解，
政策知晓率明显提高。
```

可标：

```text
P：不知道政策
R：通知方式单一
M：微信群+入户讲解
E：知晓率提高
```

# 24. “例如”后面的材料怎么办

案例不是没用。

案例是：

```text
抽象规律的证据
```

---

# 25. 案例提炼原则

不要写：

```text
某某村张大爷办证跑了5次
```

要提炼：

```text
办事流程繁琐
群众办事成本较高
```

---

# 26. 案例提炼四步

```text
人物是谁
→ 做了什么
→ 为什么这样
→ 反映什么共性问题
```

---

# 27. 第六步：判断句子功能

一句话到底是：

```text
问题
原因
影响
做法
成效
```

不能混。

---

# 28. 问题 vs 原因

材料：

```text
办事效率低，
因为部门数据不共享。
```

问题：

```text
办事效率低
```

原因：

```text
部门数据共享不足
```

---

# 29. 问题 vs 影响

材料：

```text
流程繁琐，
导致群众办事成本增加。
```

问题：

```text
流程繁琐
```

影响：

```text
群众办事成本增加
```

---

# 30. 做法 vs 成效

材料：

```text
建立一站式服务中心，
群众跑腿次数明显减少。
```

做法：

```text
建立一站式服务中心
```

成效：

```text
降低群众办事成本
```

---

# 31. 第七步：口语转规范词

材料：

```text
没人管
```

可提炼：

```text
监管不到位
```

# 32. “人不够”

```text
人员力量不足

```

---

# 33. “钱不够”

```text
资金保障不足
投入力度不足
```

---

# 34. “办得慢”

```text
办事效率不高
服务效能不足
```

---

# 35. “大家各干各的”

```text
部门协同不畅
资源整合不足
```

---

# 36. “群众不知道”

```text
政策宣传不到位
群众知晓率不高
```

---

# 37. “政策没人执行”

```text
政策落实不到位
执行力度不足
```

---

# 38. “检查时认真，过后恢复”

```text
治理缺乏常态长效
存在运动式治理
```

---

# 39. 第八步：从现象提炼本质

材料：

```text
三个部门要求重复交同一份材料
```

现象：

```text
重复提交材料
```

本质：

```text
部门信息共享不足
审批流程繁琐
```

---

# 40. “提炼本质”不能过度

材料只说：

```text
重复交材料
```

可以写：

```text
信息共享不足
```

不宜直接写：

```text
政府数字治理体系严重落后
```

---

# 41. 第九步：多句压一个点

材料：

```text
工作人员少，
经费有限，
设备也比较旧。
```

可概括：

```text
基层资源保障不足，
人员、资金、设备均较薄弱。
```

---

# 42. 一点多层表达

标准格式：

```text
小标题：展开
```

例如：

```text
资源保障不足：基层人员少、经费有限、设施设备老化。
```

---

# 43. 第十步：合并同类项

材料多处说：

```text
通知不到位
宣传方式单一
群众不知道政策
```

可合并：

```text
政策宣传不到位，宣传方式单一、覆盖面不足，群众知晓率不高。
```

---

# 44. 同义项一定要合并

例如：

```text
人手少
工作人员不足
基层力量薄弱
```

通常不是3点。

而是：

```text
基层人员力量不足
```

---

# 45. 但不能过度合并

例如：

```text
资金不足
人才不足
宣传不足
```

这三者属于：

```text
不同维度
```

不能全写：

```text
保障不足
```

否则丢信息。

---

# 46. 合并标准

可以合并：

```text
含义近
主体相同
层级相同
```

---

# 47. 不宜合并

如果：

```text
主体不同
逻辑功能不同
层级不同
```

不要硬合。

---

# 53. 第十二步：排序

一般顺序可参考：

```text
材料顺序
```

这是最稳妥的。

---

# 54. 如果需要归类

可按：

```text
思想
制度
执行
保障
协同
```

或：

```text
产业
人才
文化
生态
治理
```

---

# 55. 不要为了“好看”强行重组

只要题目没要求：

```text
优先保持材料顺序
```

避免：

```text
漏点
错位
```

---

# 56. 第十三步：小标题怎么写

小标题最好：

```text
短
准
有概括性
```

例如：

```text
一是服务流程繁琐。
二是部门协同不畅。
三是资源保障不足。
```

---

# 57. 小标题不要太空

不推荐：

```text
一是思想问题。
二是制度问题。
```

如果材料能更具体：

```text
一是服务意识不足。
二是审批机制不完善。
```

---

# 58. 小标题不要太长

不推荐：

```text
一是有关部门在服务群众过程中存在办事效率低下以及流程较为复杂的问题。
```

推荐：

```text
一是服务流程繁琐、效率不高。
```

---

# 59. “总括词 + 展开”结构

最稳：

```text
① 宣传不到位：渠道单一、覆盖面不足，群众知晓率低。
```

---

# 60. 第十四步：控制字数

优先删除：

```text
修饰词
例子
背景
情绪描述
重复主语
```

---

# 61. 可以删的词

例如：

```text
非常
十分
比较
一些
很多
特别
实际上
可以说
```

一般可删。

---

# 62. 不要删掉核心逻辑

例如：

```text
“因为”
“导致”
“通过”
```

有时承载：

```text
原因/影响/做法逻辑
```

不能随便删。

---

# 63. 字数压缩顺序

```text
先删例子
再删修饰
再合并同义
再压缩动词
最后压缩句式
```

# 67. 母题 02｜概括原因

# 68. 原因题不是对策反推

不能看到：

```text

```

```text

```

除非材料明确支持。

# 78. 母题 06｜概括特点

特点不是：

```text

```

而是：

```text

```

---

# 79. 特点题常见角度

```text

频率

```

---

# 80. 示例：服务模式特点

材料：

```text
线上线下结合
24小时开放
覆盖多个事项
```

可概括：

```text
服务渠道多元
服务时间灵活
服务事项综合
```

---

# 81. 母题 07｜概括变化

变化题必须体现：

```text
前后对比
```

---

# 82. 变化表达

```text
由……转向……
从……变为……
由单一向多元转变
由被动服务向主动服务转变
```

---

# 83. 母题 08｜概括经验

经验通常等于：

```text
经过实践验证有效的做法
```

比普通“做法”更强调：

```text
可复制性
```

---

# 84. 经验题固定思路

```text
做了什么
为什么有效
能否推广
```

---

# 85. 母题 09｜概括启示

启示：

```text
从别人做法/教训中
提炼“我们应该怎么办”
```

---

# 86. 启示题不能照抄个性做法

材料：

```text
某村建立“红白理事会”
```

启示可以：

```text
发挥基层自治组织作用
```

而不是必须：

```text
所有地方都建红白理事会
```

---

# 87. 第十五步：案例型材料提炼

案例材料常包含：

```text
人物

```

要抽象。

---

# 88. 案例材料四问

```text
为什么讲这个故事？
这个人遇到了什么？
采取了什么？
反映什么共性？
```

---

# 89. 案例 01

材料：

```text
一位老人不会使用手机，
挂号时反复尝试仍失败。
```

提炼：

```text
线上服务适老化不足，
老年群体面临数字使用障碍。
```

---

# 90. 案例 02

材料：

```text
企业负责人连续跑三个部门，
提交三次相同材料。
```

提炼：

```text
跨部门协同不足，
数据共享不畅，
审批流程繁琐。
```

---

# 91. 案例 03

材料：

```text
年轻人学会直播后，
帮助村里农产品打开销路。
```

提炼：

```text
运用数字营销拓宽农产品销售渠道，
提升市场对接能力。
```

---

# 92. 第十六步：数据型材料提炼

数据不要全抄。

问：

```text
数据说明什么趋势？
```

---

# 93. 示例

材料：

```text
办理时间由5天缩短到1天，
材料由8项压减到3项。
```

提炼：

```text
审批效率明显提升，
办事流程进一步简化。
```

---

# 94. 数据题三种提炼

```text
上升
下降
差距
```

进一步：

```text
效率提升
成本降低
覆盖扩大
发展不均
```

---

# 95. 第十七步：对话型材料提炼

对话中常有：

```text
口语
抱怨
评价
```

不要直接抄引号。

---

# 96. 示例

居民：

```text
“我们想参加，但每次都是活动结束才知道。”
```

提炼：

```text
活动信息发布不及时，
群众参与渠道不畅。
```

---

# 97. 第十八步：领导/专家观点

专家话常是：

```text
高度概括
解释机制
给出评价
```

通常重要。

---

# 98. 专家观点怎么用

如果与题目一致：

```text
可直接提炼
```

但：

```text
不要机械整句抄
```

---

# 99. 第十九步：材料重复点

一个观点：

```text
出现2次、3次
```

往往是：

```text
重点
```

---

# 100. 重复不等于多写几遍

要：

```text
合并成一个更完整要点
```

---

# 101. 第二十步：正反对比

材料有：

```text
过去 vs 现在
A地 vs B地
改革前 vs 改革后
```

常用于：

```text
变化
成效
经验
问题
```

---

# 102. 正反对比提炼

例如：

```text
以前被动等群众上门，
现在干部主动入户。
```

提炼：

```text
服务方式由被动响应向主动服务转变。
```

---

# 103. 第二十一步：隐含问题怎么找

有些材料不说：

```text
“这是问题”
```

但事实本身就是问题。

例如：

```text
老人每次看病要坐2小时公交。
```

可提炼：

```text
基层医疗资源不足，
群众就医不便。
```

---

# 104. 隐含原因怎么找

材料：

```text
村干部不会使用新系统，
系统上线后很多功能闲置。
```

原因：

```text
基层数字化应用能力不足
```

---

# 105. 第二十二步：一句材料多个要点

材料：

```text
平台数量多，但彼此不互通，
基层干部要重复填报同样数据。
```

可提炼两点：

```text
信息系统整合不足、数据共享不畅；
重复填报加重基层工作负担。
```

---

# 106. 不要机械“一句一点”

原则：

```text
按信息点拆
不是按句子拆
```

---

# 107. 第二十三步：一个要点多句材料

多句都围绕：

```text
同一问题
```

就合并。

---

# 108. 第二十四步：分类词怎么选

优先用：

```text
材料本身的维度
```

其次才用：

```text
常见分类框架
```

---

# 109. 不要硬套“思想制度监管宣传”

如果材料全在讲：

```text
产业链
品牌
销售
物流
```

就按：

```text
生产
加工
品牌
销售
物流
```

分类更准。

---

# 110. 第二十五步：概括层级

三个层级：

```text
事实层
规范层
主题层
```

---

# 111. 示例

事实层：

```text
三次提交相同材料
```

规范层：

```text
信息共享不足
```

主题层：

```text
政务服务数字化协同不足
```

---

# 112. 考场优先用哪层

一般：

```text
规范层
```

最稳。

---

# 113. 题目要求“高度概括”

可以：

```text
适当提高一个层级
```

但仍不能：

```text
脱离材料
```

---

# 114. 第二十六步：答案颗粒度

过细：

```text
通知贴在墙上
没发微信群
没打电话
```

可合：

```text
宣传渠道单一
```

---

# 115. 过粗

```text
工作不到位
```

太空。

更好：

```text
政策宣传不到位
```

---

# 116. 最佳颗粒度

```text
一眼能看出材料依据
又有规范概括
```

---

# 117. 第二十七步：小标题是否必须

不是每题都必须。

但在：

```text
字数允许
要点较多
```

时建议：

```text
小标题+展开
```

---

# 118. 字数很紧时

可直接：

```text
①宣传不足，渠道单一、覆盖面窄；
②协同不畅，数据共享不足；
③保障不足，基层人手和经费有限。
```

---

# 119. 第二十八步：字数分配

假设：

```text
200字
预计5个点
```

每点大约：

```text
30～35字
```

留：

```text
标题/连接词空间
```

---

# 120. 第二十九步：要点数量预估

不要迷信：

```text
固定5点
```

要看：

```text
材料信息量
```

---

# 121. 通常判断标准

如果两个点：

```text
主体不同
内容不同
无法互相包含
```

就应分开。

---

# 122. 第三十步：总括句

题目若要求：

```text
简要概括
```

可以直接分点。

不一定要写：

```text
“主要有以下几点”
```

---

# 123. 字数紧张时

删：

```text
“主要表现为”
“具体来说”
“可以看出”
```

---

# 124. 第三十一步：序号

推荐：

```text
①②③④
```

或：

```text
一是、二是、三是
```

---

# 125. 序号作用

```text
层次清楚
便于阅卷
减少长句
```

---

# 126. 第三十二步：规范动词

做法题：

```text
完善
建立
加强
推进
优化
整合
搭建
引进
开展
创新
```

---

# 127. 第三十三步：规范名词

问题题：

```text
机制
能力
意识
资源
保障
服务
监管
协同
渠道
平台
```

---

# 128. 第三十四步：问题题写名词化表达

不推荐：

```text
他们没有好好宣传
```

推荐：

```text
政策宣传不到位
```

---

# 129. 做法题写动作化表达

不推荐：

```text
有一个宣传平台
```

推荐：

```text
搭建政策宣传平台
```

---

# 130. 成效题写结果化表达

不推荐：

```text
大家觉得方便
```

推荐：

```text
群众办事便利度提升
```

---

# 131. 第三十五步：主谓结构

有时保留主体更清晰：

```text
政府优化审批流程；
企业加强技术研发；
群众参与社区治理。
```

---

# 132. 主体可省略的情况

同一主体连续多个措施：

```text
可省略重复主语
```

节省字数。

---

# 133. 第三十六步：避免重复

问题：

```text
宣传不到位，宣传不足，宣传效果差
```

若本质相同：

```text
合成一个点
```

---

# 134. 同义替换库｜问题

```text
不足
→ 不充分 / 不够 / 薄弱

不畅
→ 衔接不顺 / 协同不足

不高
→ 有待提升

缺乏
→ 不足 / 短缺
```

---

# 135. 同义替换库｜对策

```text
加强
→ 强化

完善
→ 健全

提升
→ 提高

推进
→ 推动

整合
→ 统筹
```

注意：

```text
不要为了换词而换词
```

---

# 136. 第三十七步：问题原因对应但不机械

问题：

```text
服务效率低
```

原因可能：

```text
流程繁琐
系统不通
人员不足
```

不是简单：

```text
“因为服务意识不足”
```

必须看材料。

---

# 137. 第三十八步：影响链条

材料：

```text
流程繁琐
→ 企业多跑
→ 成本增加
→ 投资意愿下降
```

可提炼：

```text
增加企业办事成本，
影响市场主体投资信心。
```

---

# 138. 第三十九步：因果链压缩

若字数紧：

```text
流程繁琐、数据共享不足，
增加企业办事成本，影响营商环境。
```

---

# 139. 第四十步：做法链条

材料：

```text
培训干部
→ 干部会用平台
→ 服务效率提高
```

如果问做法：

```text
加强干部数字技能培训
```

如果问成效：

```text
提升基层数字化服务能力和效率
```

---

# 140. 高频错误 01｜整段抄材料

问题：

```text
没有提炼
字数浪费
信息杂乱
```

---

# 141. 高频错误 02｜只写大词

例如：

```text
机制不完善
意识不到位
```

但没有材料对应。

问题：

```text
过空
```

---

# 142. 高频错误 03｜擅自补原因

材料没有：

```text
资金不足
```

不要凭经验补。

---

# 143. 高频错误 04｜把影响当问题

材料：

```text
群众满意度下降
```

如果题目问问题，也可能是：

```text
结果
```

要看逻辑位置。

---

# 144. 高频错误 05｜把做法当成效

```text
建立平台
```

是：

```text
做法
```

不是：

```text
成效
```

---

# 145. 高频错误 06｜分类过度

把3个点硬套成：

```text
思想
制度
执行
```

可能失真。

---

# 146. 高频错误 07｜不看主体

```text
企业的问题
```

写成：

```text
政府服务不足
```

主体错。

---

# 147. 高频错误 08｜只抄例子

案例只是：

```text
证据
```

答案应：

```text
抽象
```

---

# 148. 高频错误 09｜同义重复

一个意思写两遍：

```text
浪费字数
```

---

# 149. 高频错误 10｜概括层级过高

材料：

```text
老人不会手机挂号
```

写：

```text
社会治理体系现代化不足
```

太虚。

---

# 150. 高频错误 11｜概括层级过低

材料：

```text
老人不会手机挂号
```

只写：

```text
老人不会用手机
```

太具体。

更好：

```text
数字服务适老化不足
```

---

# 151. 高频错误 12｜小标题和展开重复

例如：

```text
宣传不到位：宣传工作不到位。
```

没有新增信息。

---

# 152. 正确结构

```text
宣传不到位：渠道单一、覆盖面不足，群众知晓率低。
```

---

# 153. 高频错误 13｜答题对象看错

题目问：

```text
做法
```

却答：

```text
成效
```

这种最致命。

---

# 154. 高频错误 14｜字数失控

前两点写太多：

```text
后面没空间
```

所以：

```text
先预估点数
```

---

# 155. 高频错误 15｜表达不并列

例如：

```text
①资金不足
②加强人才培训
③群众满意度提高
```

三个分别是：

```text
问题 / 对策 / 成效
```

若题目只问问题：

```text
结构错误
```


# 181. 最终20行极简版

```text
1. 先圈作答对象
2. 再锁定材料范围
3. 每段先找主体
4. 再找核心事实
5. 问题找负面表现
6. 原因找“为什么”
7. 做法找“谁做什么”
8. 成效找前后变化
9. 转折后通常是重点
10. 因果词后常有影响
11. 案例要从具体抽象到共性
12. 数据不要全抄，要提炼趋势
13. 口语要转成规范词
14. 同义重复要合并
15. 不同主体不要乱合
16. 优先保留材料顺序
17. 小标题要短、准、具体
18. 字数紧先删例子和修饰
19. 规范词不能脱离材料
20. 最终答案=材料事实+准确概括
```
