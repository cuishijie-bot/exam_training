```text
先找确定关系

```

# 3. 首句判断

适合首句的：

```text
背景
概念
总述
观点
时间起点
```

---

# 4. 不适合首句的

```text
指代词开头
转折后半句
因果结论句
补充句
承接句
明显总结句
```

---

# 5. 首句黑名单

常见：

```text
但是
因此
所以
同时
此外
这
其
上述
由此
总之
```

通常：

```text
不优先做首句
```

---

# 6. 但黑名单不是绝对

若题目语境特殊，

仍需：

```text
结合句义
```

---

# 7. 首句候选怎么比

如果两个句子都像首句，

比较：

```text
谁更总
谁更先
谁更适合引出全文
```

---

# 8. 背景句

例如：

```text
近年来……
随着……
在……背景下……
```

常可做：

```text
首句
```

---

# 9. 概念句

例如：

```text
“所谓X，是指……”
```

常适合：

```text
先提出概念
再解释/展开
```

---

# 10. 总述句

如果一句：

```text
概括后文多个方面
```

常适合首句。

---

# 11. 观点句

若后面都是：

```text
论证该观点
```

观点句可首。

---

# 12. 捆绑句第一类｜指代

常见：

```text
这
这种
这些
其
上述
该
此
```

---

# 13. 指代捆绑

结构：

```text
A先出现具体对象
→ B再用“这/其/该”指代
```

---

# 14. 指代捆绑原则

```text
先有对象
后有指代
```

---

# 15. 指代不能无来源

如果某句开头：

```text
“这种现象……”
```

前面必须：

```text
已经出现一个现象
```

---

# 16. 指代捆绑高频陷阱

前一句虽然有名词，

但：

```text
不是“这种现象”真正指代对象
```

还要看：

```text
语义完整
```

---

# 17. 捆绑第二类｜关联词

例如：

```text
虽然……
但是……
```

通常：

```text
强捆绑
```

---

# 18. 关联词常见

```text
虽然—但是
因为—所以
不仅—而且
如果—那么
只有—才
只要—就
即使—也
```

---

# 19. 关联词捆绑注意

有时：

```text
关联词前后并非紧邻
```

但逻辑顺序不能反。

---

# 20. 捆绑第三类｜重复词

若两句：

```text
围绕同一核心词
```

且后一处继续展开前一处，

可能：

```text
紧密相连
```

# 61. 衔接第一原则｜话题一致

选项必须：

```text
延续当前核心话题
```

---

# 62. 话题偷换

上文谈：

```text
数字技术的风险
```

选项突然谈：

```text
数字经济的发展历史
```

即使相关：

```text
也可能不衔接
```

---

# 63. 衔接第二原则｜对象一致

前文主体：

```text
企业
```

选项突然：

```text
政府
```

除非后文需要：

```text
否则警惕
```

---

# 64. 衔接第三原则｜逻辑一致

前后若：

```text
转折
```

选项也要配合。

---

# 65. 衔接第四原则｜语气一致

前文客观，

选项突然：

```text
强烈批判
```

可能不自然。

# 66. 衔接第五原则｜句式一致

并列结构中：

```text

```

是重要提示。

# 113. 排序题“假会”

如果你只是：

```text
完整读一遍觉得某顺序顺
```

但说不出：

```text
哪两句捆绑
为什么谁在前
```

不算稳定。

---

# 114. 衔接题“假会”

只说：

```text
“这个最顺”
```

不够。

要能说：

```text
它承接了上文哪个词
又引出了下文哪个点
```

---

# 115. 下文题“假会”

不能只说：

```text
“这个和主题相关”
```

必须说：

```text
尾句提出了什么新信息
下一段为什么自然接它
```

# 118. 最终20条极简版

```text
1. 排序题先找确定关系，不从头试到底
2. 首句优先背景、概念、总述、观点
3. 指代词句通常不能做首句
4. 因此、所以、总之通常不优先首句
5. 指代必须先有明确对象
6. 关联词能形成强捆绑
7. 时间顺序按早到晚
8. 概念先提出后解释
9. 观点通常先于例子
10. 排序要找尾句总结/结论/对策
11. 话题应连续推进
12. 段首衔接多总领或引题
13. 段中衔接要承上启下
14. 段尾衔接多总结/对策
15. 衔接题必须保持话题和对象一致
16. 下文推断重点看尾句
17. 尾句提出新概念，下文常解释
18. 尾句提出问题，下文常分析或解决
19. 下文不能只是全文相关，要紧接尾句
20. 三类题核心=确定关系+信息推进
```
