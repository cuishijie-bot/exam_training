>
> 本文件目标：
>
> ```text
> 选项
> → 找定位词
> → 回原文
> → 一一对应
> → 判断是否偷换
> ```

> 核心原则：
>
> ```text
> 细节题不是“我觉得原文大概是这个意思”
> 而是：
> 选项的主体、范围、程度、因果、时间、条件
> 是否都能在原文找到依据。
> ```

# 1. 细节题第一原则

```text
回原文
```

不要凭：

```text
整体印象
```

---

# 2. 第二原则

```text
选项关键词
→ 原文对应词
```

---

# 3. 第三原则

只要一处关键不一致：

```text
选项就可能错
```

---

# 4. 细节题四步法

```text
第一步：
圈选项关键词

第二步：
定位原文

第三步：
逐项比对

第四步：
找偷换点
```

# 5. 高频定位词


---

# 6. 为什么先找定位词

因为细节题：

```text
不需要重新理解全文
```

只需要：

```text

```

# 7. 偷换概念

原文：

```text
A
```

选项：

```text
B
```

A、B虽然相关，

但：

```text
不是同一个概念
```

---

# 8. 偷换概念高频形式

```text
主体偷换
对象偷换
概念范围偷换
近义不等同
上位下位偷换
```

# 119. 最终20条极简版

```text
1. 细节题核心是回原文定位
2. 不凭全文印象作答
3. 选项关键词是定位入口
4. 主体、对象必须一致
5. 部分不能偷换成全部
6. 可能不能偷换成一定
7. 有助于不能偷换成决定
8. 相关不能偷换成因果
9. 先后不能偷换成因果
10. 必要条件不能偷换成充分条件
11. 时间过去现在未来不能混
12. 数量和比较范围不能扩大
13. 原文没依据就是无中生有
14. 指代先就近，再看语义完整
15. 词句理解以语境义为主
16. 比喻义不能无限拔高
17. 引用他人观点不等于作者认同
18. 作者态度要看评价词和结论
19. 二选一要逐词对原文
20. 细节题核心=定位→比对→找偷换
```
