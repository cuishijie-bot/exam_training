# 1. 言语第一原则

```text
题目问什么
就找什么
```

不要把：

```text
主旨题
```

做成：

```text
细节题
```

---

# 2. 第二原则

```text
文段重点
≠
出现次数最多的词
```

---

# 3. 第三原则

```text
重点位置
+
逻辑关系
+
作者态度
```

共同决定答案。

---

# 4. 四步做题法

```text
第一步：
识别题型

第二步：
判断文段结构

第三步：
找重点句/关键词

第四步：
对照选项
```

# 36. 主旨选项三原则


# 37. 不偏


# 38. 不窄

不能只概括：

```text

```

# 39. 不空


# 67. 逻辑填空之转折

```text

```


# 68. 逻辑填空之并列

# 152. 最终20条极简版

```text
1. 言语理解不是语感题，而是结构题
2. 先识别题型，再读材料
3. 主旨题先找文段结构
4. 转折后通常更重要
5. 因果题结论更重要
6. 有明确对策时优先看对策
7. 并列结构必须概括完整
8. 背景和例子通常不是主旨
9. 主旨选项要不偏、不窄、不空
10. 意图题不能过度拔高
11. 细节题必须回原文定位
12. 可能不能偷换成一定
13. 相关不能偷换成因果
14. 指代词优先就近找完整对象
15. 逻辑填空先语境、再搭配、再词义
16. 成语不能望文生义
17. 排序先首句、再捆绑、再尾句
18. 衔接题看承上启下
19. 下文推断重点看尾句
20. 言语核心=题型+结构+重点+选项匹配
```
