# 1. 第一步：先归题型

不要把所有错题都写成：

```text
“言语错题”
```

必须先分：

```text
主旨
细节
逻辑填空
排序
衔接
下文
```

---

# 2. 第二步：归母题

例如：

```text
主旨题
→ ZX-M04 转折重点
```

而不是只记：

```text
“主旨题”
```

---

# 3. 第三步：编错因

言语目前已有几套专项错因：

```text
ZX
→ 中心理解/主旨

XJ
→ 细节/词句

TK
→ 逻辑填空

YJ
→ 排序/衔接/下文
```

---

# 4. 统一原则

不要另起一套冲突编码。

继续沿用：

```text
ZX__
XJ__
TK__
YJ__
```

# 33. 填空二刷要求

```text
我给你错题后，
先不要直接讲答案。

根据题型先问我：

主旨：
结构是什么？重点在哪？

细节：
定位句在哪？哪个词被偷换？

填空：
语境逻辑是什么？最确定空是哪一个？

排序：
首句候选？强捆绑？

衔接：
横线功能？

下文：
尾句新信息是什么？

我回答后再纠正。
```

# 94. Codex填空变式

```text

生成5道新题。

如果错因是固定搭配，
就换不同搭配对象。

如果是程度，
就设计弱→强/强→弱语境。
```

# 115. 最终20条极简版

```text
1. 言语错题必须先分题型
2. 主旨错题要记录结构、重点、主题词
3. 主旨不能只记正确答案
4. 细节错题必须写原文词和偷换词
5. 可能/必然、部分/全部是高频偷换
6. 填空错题要记录语境逻辑
7. 填空必须记录固定搭配或词义差异
8. 成语错题要记核心义、对象、褒贬
9. 多空题要记录最确定空
10. 排序错题要记录首句和强捆绑
11. 衔接错题要记录横线位置功能
12. 下文错题必须记录尾句功能
13. 蒙对题也进入错题库
14. 超时题也进入错题库
15. D1二刷不能只记答案
16. D3必须做同母题变式
17. D7放回混合题组复测
18. 每周只重点打Top3错因
19. 答对但说不清依据属于假会
20. 言语错题闭环=归类→归因→变式→复测→毕业
```
