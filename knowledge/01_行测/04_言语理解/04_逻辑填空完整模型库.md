# 1. 逻辑填空第一原则

```text
先看语境
后看词
```

---

# 2. 第二原则

```text
搭配优先于“感觉”
```

---

# 3. 第三原则

```text
先找最确定的空
```

---

# 4. 第四原则

```text
多空题必须联动
```

---

# 5. 五步法

```text
第一步：
看空前空后

第二步：
判断逻辑关系

第三步：
看固定搭配

第四步：
比较词义侧重

第五步：
回句验证
```

# 6. 语境逻辑01｜转折

关键词：

```text
但是
然而
却
反而
事实上
实际上
不过
```

---

# 7. 转折逻辑

前后通常：

```text
语义方向相反
```

---

# 8. 转折填空

如果前文偏：

```text
积极
```

后文可能要：

```text
消极/限制
```

反之亦然。

---

# 9. 转折例型

```text
看似A，
实际上却____。
```

空格应：

```text
与A形成反向
```

---

# 10. 语境逻辑02｜并列

关键词：

```text
同时
并且
以及
也
还
一方面……另一方面
```

---

# 11. 并列逻辑

并列词通常：

```text
方向一致
层级相当
```

---

# 12. 并列填空

如果前一项：

```text
“提升效率”
```

后一项通常也应：

```text
正向、同层级
```

---

# 13. 语境逻辑03｜递进

关键词：

```text
甚至
更
尤其
不仅……而且
不但……还
```

---

# 14. 递进逻辑

后项通常：

```text
程度更强
范围更深
影响更大
```

---

# 15. 递进填空

若第一空：

```text
“影响”
```

第二空在“甚至”后：

```text
程度应更强
```

# 28. 实词辨析第一维度｜词义侧重


---

# 29. 词义侧重判断

问：

```text
这个词重点强调什么？
```

---

# 30. 例型

```text
“遏制”
“限制”
“控制”
```

都表示：

```text
约束
```

但程度和侧重不同。

---

# 31. 实词第二维度｜程度

例如：

```text
影响
冲击
摧毁
```

程度不同。

---

# 32. 程度必须匹配语境

上下文只是轻度：

```text
不能选极强词
```

---

# 33. 程度词强弱

弱：

```text
影响
干扰
限制
```

强：

```text
冲击
破坏
摧毁
颠覆
```

---

# 34. 实词第三维度｜范围

有的词：

```text
适用范围宽
```

有的：

```text
更具体
```

---

# 35. 范围匹配

不能让：

```text
狭义词
```

去覆盖：

```text
广义对象
```

---

# 36. 实词第四维度｜使用对象

```text

“赡养”
```

# 37. 使用对象判断

# 202. 最终20条极简版

