# 第一编 马原高频陷阱总库

# 3. 物质与意识

错误：

```text
意识决定物质
```

正确：

```text
物质第一性
意识第二性

意识对物质具有能动反作用
但必须通过实践
```

---

# 4. 意识能动作用

错误：

```text
正确意识可以直接改变客观世界
```

正确：

```text
意识必须通过实践
才能反作用于客观世界
```

---

# 5. 规律

错误：

```text
规律可以被创造、改变、消灭
```

正确：

```text
规律具有客观性
人可以认识和利用规律
```

---

# 6. 联系

错误：

```text
任何两个事物之间都存在直接联系
```

正确：

```text
联系具有普遍性
具体联系具有条件性
```

---

# 7. 整体与部分

错误：

```text
任何部分都决定整体
```

正确：

```text
整体居主导地位
关键部分在一定条件下可对整体起决定作用
```

---

# 8. 新事物判断

错误：

```text
新出现的就是新事物
```

正确：

```text
是否符合客观规律和发展趋势
才是判断新事物的根本标准
```

---

# 9. 矛盾普遍性和特殊性

错误：

```text
特殊性寓于普遍性
```

正确：

```text
普遍性寓于特殊性
共性寓于个性
```

---

# 10. 主要矛盾 vs 矛盾主要方面

错误：

```text
主要矛盾直接决定事物性质
```

更准确：

```text
事物性质主要由
主要矛盾的主要方面决定
```

---

# 11. 抓重点题

材料：

```text
牵牛鼻子
抓关键
重点突破
```

先区分：

```text
多个矛盾中的关键
→ 主要矛盾

整体中的关键组成部分
→ 关键部分
```

---

# 12. 量变质变

错误：

```text
任何量变都会立刻引起质变
```

正确：

```text
量变达到一定程度
才会引起质变
```

---

# 13. 辩证否定

```text
否定 = 全盘抛弃
```

```text

既克服又保留
```
