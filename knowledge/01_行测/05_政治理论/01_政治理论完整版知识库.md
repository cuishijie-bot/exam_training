
```text

```

# 25. 新事物

```text

形式新奇

```

```text
符合事物发展规律
具有强大生命力和远大发展前途
```

# 27. 最根本规律

```text
矛盾规律
```

---

# 28. 矛盾

矛盾是：

```text
对立统一
```

两种基本属性：

```text
斗争性
同一性
```

---

# 29. 矛盾同一性

主要指：

```text
相互依存
相互贯通
一定条件下相互转化
```

---

# 30. 矛盾斗争性

指：

```text
矛盾双方相互排斥、相互对立
```

---

# 31. 同一性与斗争性

```text
同一性是相对的
斗争性是绝对的
```

---

# 32. 矛盾普遍性

```text
矛盾存在于一切事物发展过程中
每一事物发展过程始终存在矛盾
```

方法：

```text
承认矛盾
分析矛盾
解决矛盾
```

---

# 33. 矛盾特殊性

不同事物、不同阶段、不同方面：

```text
矛盾特点不同
```

方法论：

```text
具体问题具体分析
```

---

# 34. 具体问题具体分析

是：

```text
马克思主义活的灵魂
```

```text

正确解决矛盾的关键
```


# 38. 次要矛盾
