# 1. 类比推理第一句话

```text
先找一级关系
再看二级关系
```

---

# 2. 什么叫一级关系

例如：

```text
教师：学生
```

一级关系：

```text
职业对象
```

---

# 3. 什么叫二级关系

如果两个选项都是：

```text
职业对象
```

再比：

```text
谁主动
谁被服务
是否一一对应
是否直接作用
```

---

# 4. 类比推理四步法

```text
第一步：
判断题干关系

第二步：
造一句话

第三步：
代入选项

第四步：
二级辨析
```

# 5. 造句法

例如：

```text
医生：病人
```

造句：

```text
医生诊治病人
```

选项也要能：

```text
X对Y实施同类关系
```

---

# 6. 造句法的价值

避免只看：

```text
“这两个词都有关”
```

---

# 7. 高频误区

错误：

```text
题干两个词有关
选项两个词也有关
→ 就选
```

正确：

```text
关系类型
方向
强弱
范围
是否一致
```

# 27. 逻辑关系03｜种属关系

例如：

```text
苹果：水果
```

关系：

```text
苹果是水果的一种
```

---

# 28. 种属判断公式

```text
A是B的一种
```

能成立：

```text
A → B
```

---

# 29. 种属方向不能反

```text
苹果：水果
≠
水果：苹果
```

---

# 30. 种属陷阱

很多题不是问：

```text
有没有包含
```

而是看：

```text
谁包含谁
```

---

# 31. 逻辑关系04｜组成关系

例如：

```text
轮胎：汽车
```

关系：

```text
轮胎是汽车的组成部分
```

---

# 32. 组成判断公式

```text
A是B的一部分
```

---

# 33. 种属 vs 组成

最重要区别：

```text
苹果是水果的一种
轮胎是汽车的一部分
```

口诀：

```text
一种
→ 种属

一部分
→ 组成
```

---

# 34. 种属与组成高频错题

```text
桌腿：桌子
→ 组成

椅子：家具
→ 种属
```

---

# 35. 逻辑关系05｜交叉关系

两个概念：

```text
部分重合
```

例如：

```text
教师：作家
```

有的人：

```text
既是教师又是作家
```

但：

```text
不是所有教师都是作家
也不是所有作家都是教师
```

---

# 36. 交叉判断

```text
有交集
但互不包含
```

# 39. 全异与并列区别


# 160. 最终20条极简版

```text
1. 类比推理不是看“有关”，而是看关系是否最一致
2. 先找一级关系，再找二级关系
3. 第一顺序：语义→逻辑→语法→对应
4. 近义还要看程度、词性、褒贬
5. 反义还要看绝对/相对
6. 并列必须同一分类层级
7. “一种”是种属
8. “一部分”是组成
9. 种属与组成是最高频易错点
10. 功能要看主要功能还是次要功能
11. 原材料与组成部分不要混
12. 工具对象与工具功能不要混
13. 因果与先后不要混
14. 必然因果与或然因果要区分
15. 关系方向不能看反
16. 两个选项都成立时看二级关系
17. 三词题必须建完整链条
18. 填空题必须左右同时匹配
19. 常识对应优先典型关系
20. 类比推理核心=关系类型+方向+二级辨析
```
