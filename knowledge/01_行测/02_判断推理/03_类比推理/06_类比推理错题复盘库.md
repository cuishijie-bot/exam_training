# 1. 第一问：一级关系到底是什么

必须具体。

不要写：

```text
有关
相关
对应
```

要写：

```text
种属
组成
并列
主谓
动宾
功能
原材料
职业对象
因果
先后
```

---

# 2. 第二问：二级关系是什么

例如一级都是：

```text
功能
```

二级可能：

```text
主要功能
vs
次要功能
```

---

# 3. 第三问：方向是否一致

例如：

```text
苹果：水果
```

方向：

```text
下位 → 上位
```

错项若：

```text
交通工具：汽车
```

就是：

```text
上位 → 下位
```

# 12. 错题复盘第一层｜当天

当天只做：

```text
① 定一级关系
② 定二级关系
③ 编LB错因
④ 写一句下次触发
```

---

# 13. 当天不要做什么

不要：

```text
抄长解析
```

---

# 14. 单题复盘长度

建议：

```text
50～120字
```

---

# 15. 单题复盘时间

建议：

```text
1～2分钟
```

---

# 16. 次日二刷

要求：

```text
不看原答案
```

重新做。

---

# 17. 二刷真正通过

不是：

```text
记得答案D
```

而是能说：

```text
题干一级关系是____
二级关系是____
A错在____
B错在____
C错在____
所以D
```

---

# 18. 3日后变式

做：

```text
同母题
不同词汇
不同背景
```

---

# 19. 为什么必须做变式

因为原题答对可能只是：

```text
记住答案
```

变式答对才说明：

```text
会迁移关系模型
```

---

# 20. 7日后混合复测

把弱项混进：

```text
普通类比题组
```

不要提前提示母题。

---

# 21. 推荐复习节奏

```text
当天
→ 归因

次日
→ 二刷

3天后
→ 同母题变式

7天后
→ 混合复测
```

---

# 22. 类比错题毕业标准

单题毕业：

```text
① 5秒说出一级关系
② 能说出二级关系
③ 方向不再错
④ 能解释错误项为什么“也像”
⑤ 同母题新题连续3题正确
⑥ 7日混合复测正确
```

---

# 23. 母题毕业标准

某母题：

```text
最近10题正确率 ≥ 90%
```

且：

```text
二级关系能主动说出
```

才算：

```text
STABLE / DONE
```


```text
记题
而不是会关系
```

# 101. 最终20条极简版

```text
1. 类比错题核心是“把什么关系看成了什么关系”
2. 每题必须写一级关系
3. 有二级关系必须写二级关系
4. 方向单独记录
5. 错题必须归LB-M母题
6. 错因统一用LB1～LB24
7. 种属组成错题强制写“一种/一部分”
8. 材料组成强制写“加工/部件”
9. 功能题记录主要/次要、直接/间接
10. 因果题记录必然/或然、因果/先后
11. 三词题必须写AB、BC、AC
12. 填空题必须双边验证
13. 二选一必须写唯一差异
14. 蒙对题也进错题库
15. 超时题也进错题库
16. 次日二刷不能只记答案
17. 3日后必须做同母题变式
18. 7日后做混合复测
19. 母题最近10题≥90%才算稳定
20. 错题闭环=关系→错因→变式→复测→毕业
```
