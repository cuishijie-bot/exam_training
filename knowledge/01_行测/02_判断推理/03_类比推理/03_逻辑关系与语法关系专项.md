# 1. 逻辑关系第一问

看到两个名词先问：

```text
它们的集合关系是什么？
```

---

# 2. 全同关系

定义：

```text
A和B外延完全一致
```

即：

```text
A就是B
B就是A
```

---

# 3. 全同示例

```text
长江：我国第一长河
```

若题干明确唯一指称，

可视为：

```text
全同
```

---

# 4. 全同判断

试着说：

```text
所有A都是B
所有B也都是A
```

都成立：

```text
全同
```

---

# 5. 全同陷阱

有时两个词：

```text
高度相关
```

但不是同一外延。

例如：

```text
教师：教育工作者
```

可能不是严格全同，

因为：

```text
教育工作者范围更大
```

---

# 6. 并列关系

定义：

```text
A和B同属一个上位概念
且彼此不包含
```

---

# 7. 并列示例

```text
苹果：香蕉
```

共同上位：

```text
水果
```

---

# 8. 并列判断公式

```text
A是X的一种
B也是X的一种
A≠B
```

---

# 9. 并列第一关键：同级

题干：

```text
苹果：香蕉
```

二者都是：

```text
水果的具体种类
```

---

# 10. 并列层级陷阱

选项：

```text
水果：苹果
```

不是并列。

而是：

```text
种属
```

---

# 11. 并列第二关键：同一分类标准

例如：

```text
陆军：海军
```

是按：

```text
军种
```

并列。

若选项：

```text
军人：陆军
```

层级和标准都不一致。

---

# 12. 并列二级辨析

两个选项都并列时，

继续看：

```text
是否同级
是否同一分类维度
是否天然/人工一致
是否具体/抽象一致
```

---

# 13. 种属关系

定义：

```text
A是B的一种
```

---

# 14. 种属公式

```text
A ⊂ B
```

且：

```text
A是一个完整类别
不是B的零件
```

---

# 15. 种属示例

```text
苹果：水果
```

造句：

```text
苹果是一种水果
```

---

# 16. 种属方向

```text
苹果：水果
```

是：

```text
下位：上位
```

---

# 17. 方向看反

```text
水果：苹果
```

是：

```text
上位：下位
```

虽然有关，

但方向不同。

---

# 18. 组成关系

定义：

```text
A是B的一部分
```

---

# 19. 组成示例

```text
轮胎：汽车
```

造句：

```text
轮胎是汽车的一部分
```

---

# 20. 种属 vs 组成

最核心口诀：

```text
一种
→ 种属

一部分
→ 组成
```

---

# 21. 高频对照

```text
苹果：水果
→ 一种
→ 种属

桌腿：桌子
→ 一部分
→ 组成
```

---

# 22. 种属 vs 组成陷阱01

```text
发动机：汽车
```

是：

```text
组成
```

不是：

```text
汽车的一种
```

---

# 23. 陷阱02

```text
汽车：交通工具
```

是：

```text
种属
```

不是：

```text
交通工具的一部分
```

---

# 24. 快速判断法

问：

```text
能不能说“A是一种B”？
```

能：

```text
种属
```

否则再问：

```text
能不能说“A是B的一部分”？
```

能：

```text
组成
```

---

# 25. 材料关系与组成区别

```text
木材：家具
```

不是典型组成，

更接近：

```text
原材料
```

因为：

```text
木材经过加工形成家具
```

---

# 26. 组成要求

通常：

```text
组成部分在整体中仍以部分身份存在
```

---

# 27. 原材料要求

通常：

```text
经过加工转化
形成成品
```

---

# 28. 交叉关系

定义：

```text
A和B有部分重合
但互不包含
```

---

# 29. 交叉示例

```text
教师：作家
```

有的人：

```text
既是教师又是作家
```

但：

```text
不是所有教师都是作家
也不是所有作家都是教师
```

---

# 30. 交叉判断三问

```text
有A不是B吗？
有B不是A吗？
有同时属于A和B的吗？
```

三者都：

```text
有
```

则：

```text
交叉
```

---

# 31. 全异关系

定义：

```text
A和B没有交集
```

---

# 32. 全异示例

若分类边界明确：

```text
植物：哺乳动物
```

---

# 33. 全异 vs 并列

并列：

```text
同一上位概念下
```

全异：

```text
只是无交集
不一定同一分类维度
```

---

# 34. 集合关系速查

```text
A=B
→ 全同

A、B同级且不重合
→ 并列

A是一种B
→ 种属

A是一部分B
→ 组成

部分重合
→ 交叉

完全无交集
→ 全异
```

---

# 35. 逻辑关系方向

方向非常重要。

例如：

```text
苹果：水果
```

不能对应：

```text
交通工具：汽车
```

因为：

```text
一个下位→上位
一个上位→下位
```

---

# 36. 方向检查法

造句必须保持：

```text
A如何作用于B
```

和：

```text
C如何作用于D
```

同方向。

---

# 37. 语法关系总原则

如果集合关系不明显，

尝试：

```text
直接把两个词连成一句话
```

---

# 38. 主谓关系

格式：

```text
谁 + 做什么
```

或：

```text
谁 + 怎么样
```

---

# 39. 主谓示例

```text
鸟：飞翔
```

造句：

```text
鸟飞翔
```

---

# 40. 主谓第二类

```text
花：开放
```

```text
花开放
```

---

# 41. 主谓陷阱

```text
飞翔：鸟
```

顺序变成：

```text
谓语：主语
```

方向不一致。

---

# 42. 动宾关系

格式：

```text
动作 + 对象
```

---

# 43. 动宾示例

```text
阅读：书籍
```

```text
阅读书籍
```

---

# 44. 动宾第二例

```text
驾驶：汽车
```

```text
驾驶汽车
```

---

# 45. 主谓 vs 动宾

```text
鸟：飞翔
→ 鸟做飞翔
→ 主谓

阅读：书籍
→ 阅读书籍
→ 动宾
```

---

# 46. 偏正关系

格式：

```text
修饰语 + 中心词
```

---

# 47. 偏正示例

```text
红色：花朵
```

```text
红色的花朵
```

---

# 48. 偏正第二类

```text
快速：前进
```

可能：

```text
快速地前进
```

---

# 49. 偏正判断法

尝试加入：

```text
的
地
```

自然：

```text
大概率偏正
```

---

# 50. 并列语法关系

例如：

```text
调查：研究
```

可组成：

```text
调查研究
```

两者：

```text
地位平行
```

---

# 51. 并列构词

例如：

```text
山川
风雨
买卖
```

常有：

```text
并列语素
```

---

# 52. 复合词构词关系

高频：

```text
主谓
动宾
偏正
并列
补充
```

---

# 53. 主谓式复合词

例如：

```text
地震
```

可理解：

```text
地在震
```

---

# 54. 动宾式复合词

例如：

```text
读书
```

```text
读 + 书
```

---

# 55. 偏正式复合词

例如：

```text
红花
```

```text
红的花
```

---

# 56. 并列式复合词

例如：

```text
风雨
```

```text
风 + 雨
```

同级。

---

# 57. 补充式关系

例如：

```text
提高
```

可理解：

```text
提 + 高
```

后者补充说明前者结果/程度。

---

# 58. 构词题第一原则

不要只看：

```text
词义
```

还要看：

```text
内部结构
```

---

# 59. 构词题二级辨析

两个选项词义关系都成立时，

可比较：

```text
内部构词结构
```

---

# 60. 语法关系与对应关系区别

例如：

```text
医生：患者
```

不是：

```text
主谓
```

因为不能说：

```text
医生患者
```

自然成句。

它是：

```text
职业对象
```

---

# 61. 动宾与工具对象区别

```text
阅读：书籍
→ 动宾

剪刀：布料
→ 工具对象
```

---

# 62. 动宾与功能区别

```text
裁剪：布料
→ 动宾

剪刀：裁剪
→ 工具功能
```

---

# 63. 逻辑关系与语法关系冲突时

优先选择：

```text
更本质
更稳定
更直接
```

的关系。

---

# 64. 例

```text
苹果：水果
```

虽然可造：

```text
苹果是水果
```

但核心是：

```text

```

不是普通主谓。

# 65. 三词型逻辑

三词题不能只看：

```text
A:B
```

还要看：

```text
B:C
A:C
```

---

# 66. 三词结构01｜层级递进

```text
苹果：水果：食物
```

关系：

```text
苹果属于水果
水果属于食物
```

---

# 67. 层级链

```text
下位
→ 上位
→ 更上位
```

---

# 68. 三词结构02｜组成递进

例如：

```text
零件：机器：生产线
```

可能：

```text
前者组成后者
后者又组成更大整体
```

---

# 69. 三词结构03｜动作链

```text
报名：考试：录取
```

可能：

```text

```

---

# 70. 三词结构04｜原因结果链

```text

```

```text

```

---

# 71. 三词结构05｜主体-行为-对象


```text

→ 行为
→ 对象
```

# 72. 三词结构06｜工具-功能-对象

```text

```

---

# 73. 三词结构07｜原料-成品-用途


```text

→ 成品
→ 功能
```

# 78. 填空型逻辑关系

# 122. 最终20条极简版

```text
1. 名词类比先看集合关系
2. 全同=外延完全一致
3. 并列=同一上位、同级、不互含
4. 种属=一种
5. 组成=一部分
6. 种属和组成是最高频易错点
7. 种属方向不能反
8. 直接上位优于隔级上位
9. 交叉=部分重合、互不包含
10. 全异=无交集
11. 并列和全异区别在是否同一分类体系
12. 主谓=谁做什么
13. 动宾=做什么对象
14. 偏正=什么样的什么
15. 构词结构也可作为二级关系
16. 三词题必须建完整链条
17. 填空题左右两侧必须同时匹配
18. 两个选项都对时看方向、层级、同级性
19. 造句不能只说“有关”
20. 本专项核心=集合关系+造句语法+二级层级
```
