# 1. 常识对应第一原则

先造句。

例如：

```text
剪刀：裁剪
```

造句：

```text
剪刀用于裁剪
```

---

# 2. 造句必须具体

错误：

```text
剪刀和裁剪有关
```

太宽。

正确：

```text
剪刀的主要功能之一是裁剪
```

---

# 3. 典型对应优先

如果两个选项都能勉强说通：

```text
选更典型、更直接、更稳定的
```

---

# 4. 功能关系

格式：

```text
事物
→ 功能
```

---

# 5. 功能示例

```text
剪刀：裁剪
钥匙：开锁
雨伞：遮雨
温度计：测温
```

---

# 6. 功能判断

问：

```text
“这个东西主要用来做什么？”
```

---

# 7. 主要功能 vs 次要功能

例如：

```text
手机：通信
```

比：

```text
手机：照明
```

更典型。

---

# 8. 次要功能陷阱

选项虽然：

```text
客观能实现
```

但不是：

```text
主要功能
```

通常匹配度低。

---

# 9. 直接功能 vs 间接功能

例如：

```text
空调：调节温度
```

是直接功能。

若说：

```text
空调：提高工作效率
```

可能只是：

```text
间接效果
```

---

# 10. 功能二级辨析

两个选项都是功能时，

看：

```text
主要/次要
直接/间接
专用/通用
核心/附加
```

# 60. 原因—结果


# 62. 因果二级辨析

看：

```text
必然/或然
直接/间接
单因/多因
```

---

# 63. 必然因果

严格来说：

```text
A发生
→ B必然发生
```

---

# 64. 或然因果

```text
A发生
→ B可能发生
```

---

# 65. 高频现实因果多为或然

例如：

```text
下雨
→ 路滑
```

通常：

```text
并非绝对必然
```

---

# 66. 因果方向

```text
原因：结果
```

不能反。

---

# 67. 先后 vs 因果

```text
报名：考试
```

是：

```text
先后
```

不是：

```text
报名必然导致考试
```

# 136. 最终20条极简版

```text
1. 常识对应不是“有关”，而是对应方式一致
2. 功能要优先看主要功能
3. 直接功能优于间接效果
4. 工具对象与工具功能不要混
5. 行为工具与工具功能方向不同
6. 原材料要经过加工形成成品
7. 组成部分作为部件存在于整体中
8. 原材料与组成是高频易错点
9. 职业可对应对象、工具、场所
10. 三类职业关系必须分清
11. 作者作品注意方向
12. 人物成就与作者作品不是同一关系
13. 属性要看固有/典型还是偶然
14. 地点关系要看层级
15. 时间对应要看固定性
16. 因果与先后不能混
17. 条件与因果不能混
18. 两个选项都成立时比典型性
19. 常识不熟先靠结构和排除
20. 常识对应核心=造句+方向+典型性+二级关系
```
