# 1. 陷阱01｜把“有关”当关系

题干：

```text
医生：患者
```

错误概括：

```text
两者有关
```

正确：

```text
职业
→ 工作对象
```

---

# 2. 为什么“有关”没有用

因为：

```text
医生和医院有关
医生和听诊器有关
医生和患者也有关
```

但三者关系完全不同。

---

# 3. 触发动作

一旦脑中出现：

```text
“有关”
“相关”
“配套”
```

立即继续问：

```text
到底是什么具体关系？
```

---

# 4. 陷阱02｜把上下位当近义

```text
苹果：水果
```

不是：

```text
近义
```

而是：

```text
种属
```

---

# 5. 快速检查

如果能说：

```text
A是一种B
```

优先：

```text
种属
```

---

# 6. 陷阱03｜种属/组成混淆

最高频。

```text
苹果：水果
→ 一种
→ 种属

轮胎：汽车
→ 一部分
→ 组成
```

---

# 7. 种属/组成强制口诀

```text
一种 = 种属
一部分 = 组成
```

---

# 8. 陷阱04｜材料/组成混淆

```text
木材：家具
→ 原材料

发动机：汽车
→ 组成
```

---

# 9. 判断关键

原材料：

```text
加工转化后形成成品
```

组成：

```text
作为部件存在于整体
```

---

# 10. 陷阱05｜并列/全异混淆

并列：

```text
同一上位概念
+
同级
+
互不包含
```

全异：

```text
只是没有交集
```

---

# 11. 并列必须检查

```text
是否同级
是否同一分类标准
```

---

# 12. 并列层级陷阱

```text
苹果：香蕉
```

是同级。

```text
水果：苹果
```

不是并列。

---

# 13. 陷阱06｜交叉/并列混淆

```text
教师：作家
```

有部分人：

```text
既是教师又是作家
```

因此：

```text
交叉
```

不是并列。

---

# 14. 交叉三问

```text
有A不是B？
有B不是A？
有同时属于A和B？
```

都“有”：

```text
交叉
```

---

# 15. 陷阱07｜方向看反

这是第二大高频。

题干：

```text
苹果：水果
```

是：

```text
下位→上位
```

选项：

```text
交通工具：汽车
```

是：

```text
上位→下位
```

排。

---

# 16. 高频方向关系

```text
下位 → 上位
部分 → 整体
材料 → 成品
工具 → 功能
职业 → 对象
作者 → 作品
原因 → 结果
事件 → 时间
事物 → 地点
```

---

# 17. 方向检查法

把题干关系写成一句：

```text
A如何对应B
```

再检查选项是否：

```text
C以同样方向对应D
```

---

# 18. 陷阱08｜主谓/动宾混淆

```text
鸟：飞翔
→ 鸟飞翔
→ 主谓

阅读：书籍
→ 阅读书籍
→ 动宾
```

---

# 19. 秒判

第一个词如果是：

```text
动作
```

更可能：

```text
动宾
```

---

# 20. 陷阱09｜偏正/普通对应混淆

```text
红色：花朵
```

可说：

```text
红色的花朵
```

是：

```text
偏正
```

---

# 21. 偏正速判

尝试加：

```text
的
地
```

自然：

```text
考虑偏正
```

---

# 22. 陷阱10｜工具对象/工具功能混淆

```text
剪刀：布料
→ 工具→对象

剪刀：裁剪
→ 工具→功能
```

---

# 23. 陷阱11｜行为工具/工具功能方向混淆

```text
写字：笔
→ 行为→工具

笔：写字
→ 工具→功能
```

---

# 24. 陷阱12｜职业对象/工具/场所混淆

```text
医生：患者
→ 对象

医生：听诊器
→ 工具

医生：医院
→ 场所
```

---

# 25. 职业三分法

看到职业：

```text
先问后一个词是：
谁？
用什么？
在哪里？
```

---

# 26. 陷阱13｜作者作品/人物成就混淆

```text
曹雪芹：《红楼梦》
→ 作者作品

袁隆平：杂交水稻
→ 人物成就
```

不是同一关系。

# 27. 陷阱14｜功能主次

题干：

```text
钥匙：开锁
```

选项：

```text
手机：照明
```

虽然手机能照明，

但：

```text
不是核心功能
```

---

# 28. 功能二级关系

```text
主要/次要
核心/附加
直接/间接
```

---

# 29. 陷阱15｜直接/间接

题干：

```text
医生：患者
```

是：

```text
直接作用
```

若选项是：

```text
通过第三方间接影响
```

关系不够精确。

---

# 30. 陷阱16｜专用/通用

```text
医生：听诊器
```

专业性较强。

```text
医生：电脑
```

虽能用，

但：

```text
太通用
```

---

# 31. 陷阱17｜典型/偶然

```text
雪：白
```

是典型属性。

```text
汽车：红
```

只是偶然属性。

---

# 32. 陷阱18｜必然/或然

两个都因果时，

可能还要比：

```text
必然
vs
可能
```

---

# 33. 因果关系现实判断

例如：

```text
降雨：积水
```

通常：

```text
或然
```

而非绝对必然。

---

# 34. 陷阱19｜因果/先后

```text
报名：考试
```

有：

```text
先后
```

但：

```text
报名不是考试发生的充分因果
```

---

# 35. 秒判

问：

```text
A是否“导致”B？
```

若只是：

```text
A通常在B之前
```

则：

```text
先后
```

---

# 36. 陷阱20｜条件/因果

```text
氧气：燃烧
```

更适合：

```text
条件
```

而不是：

```text
氧气导致燃烧
```

---

# 37. 条件判断

问：

```text
没有A，
B是否可能无法发生？
```

---

# 38. 陷阱21｜近义程度没看

```text
喜欢：热爱
```

除了近义，

还有：

```text
弱→强
```

---

# 39. 陷阱22｜程度方向看反

题干：

```text
弱→强
```

选项：

```text
强→弱
```

排。

---

# 40. 陷阱23｜褒贬漏看

```text
坚持
```

和：

```text
固执
```

存在一定语义关联，

但：

```text
感情色彩不同
```

---

# 41. 陷阱24｜词性漏看

一级关系都一样时，

词性可能决定答案。

---

# 42. 陷阱25｜象征/比喻混淆

```text
鸽子：和平
→ 象征
→ 代表

老师：园丁
→ 比喻
→ 像
```

---

# 43. 速判

```text
“代表”
→ 象征

“像”
→ 比喻
```

---

# 44. 陷阱26｜成语拆字

成语必须：

```text
看整体义
```

不要：

```text
只抓其中一个字
```

---

# 45. 陷阱27｜成语对象差异

意思相近，

但可能：

```text
一个形容人
一个形容事情
```

# 46. 陷阱28｜三词只看前两个

三词题必须检查：

```text
A-B
B-C
A-C
```

---

# 47. 三词链断裂

常见错项：

```text
A-B非常像
B-C却不一致
```

---

# 48. 三词强制动作

草稿：

```text
AB：
BC：
AC：
```

---

# 49. 陷阱29｜填空只看左侧

形式：

```text
A对于X
相当于
B对于Y
```

必须：

```text
左边 + 右边
同时精确成立
```

---

# 50. 填空题常见错项

```text
左边特别自然
右边只是有关
```

排。

# 51. 陷阱30｜生僻常识卡死

```text

```

---

# 52. 生僻题策略

先用：

```text
方向
结构
词性
其他选项
```

排除。

---

# 53. 陷阱31｜一级关系对了就停

比如：

```text
两个选项都是功能
```

这时必须继续：

```text
哪一个是主要功能？
```

---

# 54. 陷阱32｜横向关系漏看

如果：

```text
A:B
C:D
```

纵向都一样，

再看：

```text
A与C是否同类
B与D是否同类
```

---

# 55. 横向二级关系

可看：

```text
词性
自然/人工
具体/抽象
人物/事物
古代/现代
中国/外国
```

---

# 56. 陷阱33｜关系概括层级过低

例如：

```text
钥匙：开锁
```

若概括为：

```text
“物体和动作”
```

太宽。

正确：

```text
工具→主要功能
```

---

# 57. 陷阱34｜关系概括过细

也不要无依据加：

```text
“金属工具通过旋转实现主要功能”
```

题干没体现的：

```text
不要过度细化
```

---

# 58. 最佳关系粒度

应该：

```text
既能区分选项
又不超出题干
```

---

# 59. 陷阱35｜多个关系只看一个

词对可能同时存在：

```text
一级关系
+
二级关系
```

例如：

```text
喜欢：热爱
```

有：

```text
近义
+
弱→强
```

---

# 60. 陷阱36｜常识关系不准确

如果事实基础错：

```text
再完美的关系也没用
```

所以常识型题需要：

```text
基本事实准确
```

---

# 61. 但不要无限背常识

最有效：

```text
只积累真题和错题里的常识
```

# 127. 最终20条极简版

```text
1. 类比推理最怕把关系概括成“有关”
2. 一级关系必须具体
3. “一种”是种属
4. “一部分”是组成
5. 加工形成是原材料
6. 并列要同级、同一分类标准
7. 方向反转是高频陷阱
8. 主谓与动宾要用造句法
9. 工具对象与工具功能不能混
10. 职业对象、工具、场所必须分清
11. 功能题要比主要/次要
12. 对应题要比直接/间接
13. 近义题还要看程度、褒贬、词性
14. 因果与先后不能混
15. 条件与因果不能混
16. 三词题必须建立完整链条
17. 填空题必须左右双边验证
18. 两个选项都成立时必须比二级关系
19. 生僻常识不要死磕
20. 类比母题核心=一级关系+方向+二级精确匹配
```
