# 0. 类比推理一句话本质

```text
类比推理
=
找“最一致”的关系
```

不是：

```text
看两个词有没有关系
```

---

# 1. 第一原则

```text
先找一级关系
再比二级关系
```

---

# 2. 第二原则

```text
关系具体
>
“有关”
```

---

# 3. 第三原则

两个选项都能说通：

```text
选关系更精确的
```

---

# 4. 总识别顺序

```text
先语义
→ 再逻辑
→ 再语法
→ 后对应
```

---

# 5. 语义关系速查


# 6. 近义二级辨析

都近义时看：

```text

```

---

# 7. 程度

例如：

```text
喜欢 → 热爱
```

是：

```text
弱 → 强
```

方向必须一致。

---

# 8. 反义

继续区分：

```text
绝对反义
相对反义
状态反义
方向反义
```

---

# 9. 象征 vs 比喻

```text
代表
→ 象征

像
→ 比喻
```

---

# 10. 成语

只看：

```text
整体义
```

不要拆字。

# 11. 成语二级关系

```text

```

---

# 12. 逻辑关系速查

```text
全同
并列
种属
组成
交叉

```

---

# 13. 种属秒判

```text
A是B的一种
→ 种属
```

例如：

```text
苹果：水果
```

---

# 14. 组成秒判

```text
A是B的一部分
→ 组成
```

例如：

```text
轮胎：汽车
```

---

# 15. 种属 vs 组成

最重要口诀：

```text
一种
→ 种属

一部分
→ 组成
```

---

# 16. 原材料 vs 组成

```text
木材：家具
→ 加工形成
→ 原材料

轮胎：汽车
→ 部件存在
→ 组成
```

---

# 17. 并列

要求：

```text
同一上位
同级
同一分类标准
```

---

# 18. 交叉

```text
部分重合
互不包含
```

---

# 19. 全异

```text
完全无交集
```

---

# 20. 并列 vs 全异

```text
并列：
同一分类体系

全异：
仅无交集
```

---

# 21. 语法关系速查

```text

```

---

# 22. 主谓

```text
谁做什么
```

例如：

```text
鸟：飞翔
```

---

# 23. 动宾

```text
做什么对象
```

例如：

```text
阅读：书籍
```

---

# 24. 偏正

```text
什么样的什么
```

例如：

```text
红色：花朵
```

---

# 25. 偏正判断

```text

地
```

# 74. 错题触发词

```text

→ 种属

“一部分”
→ 组成

“用于”
→ 功能

“导致”
→ 因果

→ 象征
```

# 82. 最终10条

```text
1. 先语义，再逻辑，再语法，后对应
2. 一种=种属
3. 一部分=组成
4. 加工形成=原材料
5. 关系方向不能反
6. 功能题比主次和直接性
7. 两个选项都对时必须比二级关系
8. 三词题建AB/BC/AC
9. 填空题左右双边验证
10. 类比推理不是“有关”，而是“最一致”
```
