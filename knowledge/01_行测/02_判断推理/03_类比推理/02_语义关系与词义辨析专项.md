# 1. 语义题第一原则

不要只问：

```text
这两个词意思像不像
```

还要问：

```text
像到什么程度
```

---

# 2. 近义关系

近义：

```text
词义相近
但未必完全相同
```

---

# 3. 完全近义

例如：

```text
美丽：漂亮
```

在多数语境：

```text
可以互换
```

---

# 4. 语境近义

两个词：

```text
并非所有场景都可互换
```

但在某类语境中：

```text
意义相近
```

---

# 5. 近义题二级辨析顺序

```text
1. 词性
2. 褒贬
3. 程度
4. 使用对象
5. 语体
6. 搭配
```

---

# 6. 词性

例如：

```text
美丽：漂亮
```

都是：

```text
形容词
```

若选项：

```text
奔跑：快速
```

是：

```text
动词：形容词
```

二级不一致。

---

# 7. 褒贬色彩

例如：

```text
果断：坚决
```

都偏：

```text
褒义
```

---

# 8. 褒贬陷阱

```text
固执：坚持
```

虽然有：

```text
“持续不改变”
```

共同点，

但：

```text
固执多贬义
坚持多褒义
```

---

# 9. 程度

例如：

```text
喜欢：热爱
```

一级：

```text
近义
```

二级：

```text
弱→强
```

---

# 10. 程度必须看方向

题干：

```text
喜欢：热爱
```

选项：

```text
愤怒：生气
```

若：

```text
愤怒 > 生气
```

方向：

```text
强→弱
```

不一致。

---

```text
害怕
→ 恐惧

损坏
→ 摧毁

批评
→ 谴责

困难
→ 艰巨
```

# 12. 使用对象

有些近义词：

```text
对象不同
```

例如：

```text
赡养
抚养
扶养
```

字面相近，

使用关系不同。

# 14. 语体色彩

```text

口语
正式
```


```text
固定不同
```

# 22. 绝对反义


# 23. 相对反义


选项：


```text
反义
```

二级：

```text
绝对
vs
相对
```

# 27. 行为反义

# 29. 程度关系专项

```text

```

而是：


# 30. 程度递进公式

```text

```

```text

```

# 31. 程度递减

题干若：

```text

```

选项也要：

```text
强→弱
```

# 32. 程度关系常见错法


没看：

```text

```

# 33. 象征关系

象征：

```text
具体事物
→ 抽象意义
```

---

# 34. 常见象征

例如：

```text
鸽子：和平
```

```text
橄榄枝：和平
```

---

# 35. 象征核心

不是：

```text
A和B经常一起出现
```

而是：

```text
A代表B
```

---

# 36. 象征二级辨析


# 37. 比喻关系

```text

```

# 38. 比喻示例

```text

```

---

# 39. 比喻核心

```text

```

---

# 40. 象征 vs 比喻

象征：

```text
A代表B
```

比喻：

```text
A像B
```

---

# 41. 象征/比喻速判

问：

```text

“A象征B”
还是
“A像B”
```

# 42. 比喻陷阱

两个词：

```text
关系密切
```

不等于：

```text
比喻
```

# 43. 词性关系

语义题非常高频二级条件。

常见：

```text
名词
动词
形容词
副词
```

---

# 44. 词性一致优先

如果题干：

```text
两个都是形容词
```

选项也最好：

```text
两个都是形容词
```

---

# 45. 词性并非永远优先

只有在：

```text
一级关系都相同
```

时才用于二级区分。

---

# 46. 褒贬关系

词语常分：

```text
褒义
贬义
中性
```

---

# 47. 褒贬判断

不要机械。

应看：

```text
通常语境
```

---

# 48. 中性词

很多词：

```text
本身中性
```

不要硬贴褒贬。

---

# 49. 感情色彩方向

题干：

```text
褒义：褒义
```

选项：

```text
贬义：贬义
```

一级近义可能成立，

但二级色彩不同。

---

# 50. 语义范围

近义词可能：

```text
一个范围更大
一个更具体
```

---

# 51. 范围大小

例如：

```text
车辆
汽车
```

不是近义，

更接近：

```text
种属
```

所以：

```text
不要把“意思有关”当近义
```

---

# 52. 近义判断标准

能否在多数相同语境：

```text
近似替换
```

---

# 53. 上下位概念不能当近义

```text
水果：苹果
```

不是：

```text
近义
```

而是：

```text
种属
```

---

# 54. 行为结果也不能当近义

```text
学习：进步
```

不是：

```text
近义
```

# 70. 同音/近形词不是语义关系

# 119. 最终20条极简版

```text
1. 语义题先判断近义、反义、程度、象征、比喻
2. 近义不等于完全相同
3. 一级近义都成立时看二级关系
4. 二级优先看程度、褒贬、词性、对象、语体
5. 喜欢→热爱属于弱→强
6. 程度方向必须一致
7. 绝对反义和相对反义要区分
8. 生死更偏绝对反义
9. 大小属于相对反义
10. 象征是“代表”
11. 比喻是“像”
12. 上下位概念不是近义
13. 有关不等于近义
14. 成语必须看整体义
15. 成语还可看褒贬、对象和结构
16. 一词多义要结合另一词确定义项
17. 书面和口语可作为二级差异
18. 两个选项都像时必须说出具体差异
19. 生僻词先利用结构和排除
20. 语义题核心=一级词义关系+二级细微差别
```
