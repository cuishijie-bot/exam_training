# 0. 分析推理总原则

分析推理不是靠“脑内硬推”。

固定流程：

```text
① 判断模型
② 画结构
③ 找确定信息
④ 找限制最强条件
⑤ 落位 / 排除
⑥ 看选项
```

口诀：

```text
先建模
再强条件
能落位先落位
能排除先排除
```

---

# 1. 第一大类：顺序排列

典型题干：

```text
5人参加比赛
安排先后顺序
从周一排到周五
按名次排列
按出场顺序排列
```

---

# 2. 顺序题基础模型

直接画：

```text
1  2  3  4  5
```

或：

```text
周一 周二 周三 周四 周五
```

不要只在脑中记。

---

# 3. 母题 01｜确定位置

题干：

```text
A排第3
```

直接：

```text
1 2 A 4 5
```

这是最优先的信息。

---

# 4. 母题 02｜A在B之前

题干：

```text
A在B之前
```

只表示：

```text
A < B
```

不表示：

```text
A紧挨B
```

---

# 5. 母题 03｜A紧挨B之前

题干：

```text
A紧挨着排在B之前
```

表示：

```text
AB
```

作为整体捆绑。

---

# 6. 母题 04｜A与B相邻

可能：

```text
AB
或
BA
```

---

# 7. 母题 05｜A与B不相邻

若A已确定位置：

```text
直接排除A左右位置
```

---

# 8. 母题 06｜A、B之间隔1人

位置差：

```text
2
```

例如：

```text
A _ B
```

---

# 9. 母题 07｜A、B之间隔2人

位置差：

```text
3
```

---

# 10. 固定间隔通用公式

若：

```text
A和B之间隔k人
```

则：

```text
位置差 = k+1
```

---

# 11. 母题 08｜A在B前且不相邻

需要同时满足：

```text
A < B
且
位置差≥2
```

---

# 12. 母题 09｜A最早 / 最晚

例如：

```text
A不早于第3
```

表示：

```text
A ∈ {3,4,5}
```

---

# 13. “不早于 / 不晚于”

```text
不早于第3
→ 第3及以后

不晚于第3
→ 第3及以前
```

---

# 14. “至少第3”

通常表示：

```text
第3及以后
```

但要结合具体语境确认。

---

# 15. 顺序题优先条件

优先级通常：

```text
确定位置
> 唯一范围
> 相邻/紧邻
> 固定间隔
> 先后关系
> 单纯排除
```

---

# 16. 第二大类：座位安排

常见：

```text
一排座位
圆桌座位
会议座次
相邻座位
左右关系
```

---

# 17. 一排座位

可直接编号：

```text
1 2 3 4 5 6
```

---

# 18. 母题 10｜A在B左边

表示：

```text
A位置 < B位置
```

---

# 19. 母题 11｜A紧邻B左侧

表示：

```text
AB
```

且：

```text
A在左
B在右
```

---

# 20. 圆桌题核心

圆桌中：

```text
没有绝对第1位
```

通常先固定：

```text
任意一个人
```

作为参照。

---

# 21. 母题 12｜圆桌固定参照

若6人围桌：

```text
先把A固定在任一位置
```

再排其他人。

---

# 22. 圆桌左右判断

必须确认：

```text
面向圆心
还是背向圆心
```

通常题目默认：

```text
面向圆心
```

时左右关系与纸面方向可能需要注意。

---

# 23. 第三大类：分组题

典型：

```text
6人分成两组
若干人分到不同部门
项目分成若干组
```

---

# 24. 分组题基础表示

若两组：

```text
甲组：
乙组：
```

或：

```text
G1 / G2
```

---

# 25. 母题 13｜A和B同组

直接捆绑：

```text
AB
```

作为一个单位考虑。

---

# 26. 母题 14｜A和B不同组

如果只有两组：

```text
A在甲
→ B必在乙
```

---

# 27. 母题 15｜A、B至少一人进甲组

表示：

```text
A甲 或 B甲
```

允许：

```text
两人都进甲
```

---

# 28. 母题 16｜A、B恰有一人进甲组

表示：

```text
一个进甲
一个不进甲
```

---

# 29. 母题 17｜A若进甲，则B进乙

翻译：

```text
A甲 → B乙
```

可做逆否：

```text
B不乙 → A不甲
```

---

# 30. 分组题高频条件

```text
同组
不同组
至少一个
恰好一个
最多一个
如果……那么……
```

---

# 31. 分组题强条件

如果某人：

```text
和多个对象都有关系
```

优先分析。

例如：

```text
A不能和B同组
A必须和C同组
A若进甲则D进乙
```

A就是：

```text
信息中心
```

---

# 32. 第四大类：匹配题

常见：

```text
人—岗位
人—项目
人—城市
人—时间
产品—产地
```

---

# 33. 匹配题最佳工具：二维表

例如：

| 人员 | 项目1 | 项目2 | 项目3 |
|---|---|---|---|
| A |  |  |  |
| B |  |  |  |
| C |  |  |  |

标：

```text
√ = 可以/确定
× = 不可以
```

---

# 34. 母题 18｜唯一匹配

若A：

```text
不能1
不能2
```

且只有：

```text
1、2、3
```

三个项目。

则：

```text
A只能3
```

---

# 35. 母题 19｜反向唯一

如果项目1：

```text
只能A或B
```

而A已匹配项目2：

```text
项目1只能B
```

---

# 36. 母题 20｜一一对应

题干说：

```text
每人一个项目
每项目恰好一人
```

则表格中：

```text
每行一个√
每列一个√
```

---

# 37. 匹配题连锁排除

确定一个：

```text
A→项目2
```

若一一对应：

```text
其他人项目2全部×
```

然后继续看：

```text
谁只剩唯一项目
```

---

# 38. 第五大类：时间安排题

典型：

```text
周一至周五安排5个活动
5个项目分时段
每天一个会议
```

本质：

```text
顺序 + 匹配
```

---

# 39. 时间题模型

直接画：

```text
周一：
周二：
周三：
周四：
周五：
```

---

# 40. 母题 21｜活动A早于B

```text
A在B之前
```

---

# 41. 母题 22｜活动A与B不连续

```text
两者不相邻
```

---

# 42. 母题 23｜活动A只能周一或周二

这是强条件：

```text
优先使用
```

---

# 43. 第六大类：可能 / 一定题

题干常见：

```text
以下哪项一定成立
以下哪项可能成立
以下哪项不可能成立
```

不同问法：

```text
方法不同
```

---

# 44. “一定成立”

目标：

```text
找所有合法情况都成立的项
```

适合：

```text
推必然
```

---

# 45. “可能成立”

只需：

```text
构造一种合法情况
```

选项代入特别好用。

---

# 46. “不可能成立”

只需证明：

```text
该选项一代入就矛盾
```

---

# 47. 母题 24｜可能成立用代入

选项具体时：

```text
直接把A项当真
```

检查是否能完成全部安排。

如果：

```text
能完成
```

A即可。

---

# 48. 母题 25｜不可能成立用代入排除

逐项代入：

```text
哪个立即冲突
```

即答案。

---

# 49. 第七大类：最大信息法

分析推理最核心技巧之一。

所谓最大信息：

```text
涉及对象最多
限制最强
最容易锁定位置
```

---

# 50. 信息强度示例

强：

```text
A只能第2或第3
```

弱：

```text
A不在第5
```

---

# 51. 信息强度示例 2

强：

```text
A紧挨B且在B前
```

弱：

```text
A在B前
```

---

# 52. 母题 26｜多对象条件优先

例如：

```text
A在B前
B紧邻C
D不与A相邻
```

通常：

```text
B紧邻C
```

优先形成：

```text
BC / CB
```

再结合A关系。

---

# 53. 第八大类：确定信息法

一旦有：

```text
确定位置
确定组
确定匹配
```

立即落位。

不要继续：

```text
悬着不用
```

---

# 54. 母题 27｜唯一剩余位置

若：

```text
1、2、3、4、5
```

已有：

```text
A=1
B=3
C=5
D只能2或4
```

若另一个位置被限制：

```text
可快速落位
```

---

# 55. 第九大类：捆绑法

适合：

```text
相邻
同组
连续安排
```

---

# 56. 母题 28｜AB相邻

把：

```text
AB
```

视为一个整体。

但内部可能：

```text
AB
BA
```

---

# 57. 母题 29｜ABC连续

若三者连续但顺序未知：

```text
ABC整体
```

内部再排列。

---

# 58. 第十大类：间隔法

典型：

```text
A和B之间隔k人
```

先列可能位置对。

---

# 59. 母题 30｜5位置中隔1人

位置对：

```text
(1,3)
(2,4)
(3,5)
```

---

# 60. 第十一大类：列表法

当多个对象、多个条件互相交叉：

```text
列表比脑推稳定
```

---

# 61. 适合列表法的题

```text
人—项目
人—城市
人—时间
部门—负责人
产品—地区
```

---

# 62. 第十二大类：代入排除法

适合：

```text
选项信息很具体
完整推理成本高
```

---

# 63. 代入优先的题型

```text
可能成立
不可能成立
可以推出
不能推出
```

尤其：

```text
选项直接给完整顺序/分组
```

---

# 64. 代入法流程

```text
① 假设选项成立
② 看是否违反任何条件
③ 若不违反，尝试完成剩余安排
④ 能完成 → 可能
⑤ 必冲突 → 不可能
```

---

# 65. 第十三大类：假设法

当：

```text
两种情况都可能
```

可分支：

```text
若A……
若非A……
```

---

# 66. 假设法原则

分支尽量少。

优先选择：

```text
只有2种可能
```

的变量。

---

# 67. 母题 31｜二选一假设

若：

```text
A只能第1或第5
```

可分：

```text
情况1：A=1
情况2：A=5
```

---

# 68. 第十四大类：排除法

有些条件本身难正推，但很容易：

```text
排错误位置
```

---

# 69. 母题 32｜连续排除

例如：

```text
A不在1
A不在2
A不在4
A不在5
```

则：

```text
A=3
```

---

# 70. 第十五大类：占位法

如果：

```text
位置有限
对象有限
```

可通过已占位置推剩余。

---

# 71. 母题 33｜剩余唯一

若：

```text
5个位置
已有4个确定
```

最后一个：

```text
自动确定
```

---

# 72. 第十六大类：容量约束

分组题常见：

```text
每组3人
每房间最多2人
每项目至少1人
```

这些是：

```text
硬约束
```

优先使用。

---

# 73. 母题 34｜组容量

若：

```text
甲组只能3人
```

已确定：

```text
A、B、C在甲
```

则其他人：

```text
不能再进甲
```

---

# 74. 母题 35｜至少 / 至多

```text
至少2人
→ 2、3、4……

至多2人
→ 0、1、2
```

---

# 75. “恰好”最强

```text
恰好2人
```

比：

```text
至少2人
至多2人
```

限制更强。

---

# 76. 第十七大类：条件联动

例如：

```text
A若第1 → B第3
B第3 → C不第5
```

可串成：

```text
A第1 → B第3 → C不第5
```

---

# 77. 分析推理中的翻译关系

如果有：

```text
如果A，则B
只有A，才B
```

仍要调用翻译推理：

```text
箭头 + 逆否
```

---

# 78. 母题 36｜条件链 + 排列

```text
A第1 → B第3
B第3 → C第5
```

可得：

```text
A第1 → C第5
```

---

# 79. 第十八大类：条件矛盾检查

若某分支推出：

```text
A必须第2
又必须第4
```

说明：

```text
该分支不成立
```

---

# 80. 母题 37｜假设后矛盾

假设：

```text
A第1
```

推出：

```text
B第2
C第2
```

但一位置只能一人。

则：

```text
A不能第1
```

---

# 81. 第十九大类：排序相邻组合

高频组合：

```text
A在B前
B与C相邻
A不与C相邻
```

---

# 82. 处理组合条件

不要逐条孤立看。

尝试：

```text
把最强结构先拼出来
```

例如：

```text
BC / CB
```

再放A。

---

# 83. 第二十大类：多人排序中的局部顺序

如果：

```text
A<B<C
```

只说明：

```text
A在B前
B在C前
```

三者未必连续。

---

# 84. 母题 38｜相对顺序

```text
A在B前
B在C前
```

可得：

```text
A在C前
```

---

# 85. 第二十一大类：首尾限制

例如：

```text
A不能首位
B不能末位
C必须首尾之一
```

首尾位置：

```text
信息密度很高
```

应优先利用。

---

# 86. 母题 39｜首尾二选一

若：

```text
C只能第1或第5
```

适合：

```text
假设分支
```

---

# 87. 第二十二大类：颜色 / 类别安排

例如：

```text
红蓝绿三类项目
每人选一类
```

本质：

```text
分组 / 匹配
```

---

# 88. 第二十三大类：多维匹配

有时同时：

```text
人
时间
地点
```

三维。

不要画三维表。

更稳：

```text
先解决约束最强的一维
再把结果带入另一维
```

---

# 89. 母题 40｜先时间后地点

如果：

```text
A只能周一
B只能北京
```

先分别锁定：

```text
确定信息
```

再关联。

---

# 90. 第二十四大类：多人多任务

例如：

```text
每人可承担多个任务
每任务至少1人
```

先看题干是否：

```text
一一对应
```


# 91. 高频陷阱 01｜默认一一对应

题目没说：

```text
每人一个

```

就不要自动假设。

# 92. 高频陷阱 02｜“在前”理解成“紧前”

```text

```

只代表：


# 93. 高频陷阱 03｜“相邻”漏掉两个方向


包括：


# 94. 高频陷阱 04｜“至少”理解成“恰好”

# 95. 高频陷阱 05｜“至多”理解错

# 97. 高频陷阱 07｜脑内记太多

# 98. 高频陷阱 08｜过早固定

如果：


不能直接定：


还可能：

```text
BA
```

# 99. 高频陷阱 09｜分支太多

假设法如果一上来分：

```text
4、5种情况
```


# 100. 高频陷阱 10｜可能题试图证明必然

```text

```

```text

```

# 101. 高频陷阱 11｜一定题只找到一个例子

“一定成立”需要：

```text
所有合法情况都成立
```

```text
不够
```

---

# 102. 高频陷阱 12｜不可能题完整推理

选项具体时：

```text
直接代入
```

通常更快。

---

# 103. 高频母题组 A｜顺序

## A1

5人：

```text
A在B前
B与C相邻
C不在第5
```

先做：

```text
B/C相邻捆绑
```

再结合：

```text
A在B前
```

---

## A2

```text
A只能1或2
B不能1
A在B前
```

如果：

```text
A=2
```

B必须在3以后。

若其他条件冲突：

```text
可锁A=1
```

---

# 104. 高频母题组 B｜分组

## B1

两组各3人：

```text
A和B同组
```
