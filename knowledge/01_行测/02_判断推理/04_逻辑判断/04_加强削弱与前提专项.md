# 0. 论证题总框架

任何论证题都先拆成：

```text
论据
↓
论证过程
↓
论点
```

真正的考点往往在：

```text
论据和论点之间
```

也就是：

```text
缺口
```

---

# 1. 第一步：找论点

## 高频标志词

```text
因此
所以
由此可知
可见
说明
表明
这意味着
研究者认为
专家认为
作者认为
```

---

# 2. 没有标志词时怎么找论点

问自己：

```text
作者最想让你相信哪句话？
```

通常是：

```text
最需要被证明
最具结论性
最有争议性
```

的那句。

---

# 3. 论点常见位置

```text
开头
中间
结尾
```

不要默认：

```text
一定在最后一句
```

---

# 4. 第二步：找论据

论据通常是：

```text
事实
数据
调查
实验
案例
研究结果
统计
现象
```

作用：

```text
用来支持论点
```

---

# 5. 第三步：找论证缺口

高频缺口：

```text
A与B相关
→ A导致B

部分样本
→ 整体结论

短期有效
→ 长期有效

动物有效
→ 人也有效

某指标上升
→ 某结论成立

A像B
→ A和B结论相同

某措施实施
→ 一定达到目标
```

---

# 6. 加强题本质

加强：

```text
让论点更可信
```

常见方式：

```text
直接支持
搭桥
排除他因
补充机制
提高样本代表性
提高实验可信度
```

---

# 7. 削弱题本质

削弱：

```text
让论点更不可信
```

常见方式：

```text
直接否定
拆桥
另有他因
因果倒置
共同原因
样本偏差
实验缺陷
反例
概念偷换
```

---

# 8. 前提题本质

前提：

```text
论证成立不可缺少的条件
```

判断标准：

```text
没它不行
```

---

# 9. 加强 vs 前提

```text
加强：
有它更好

前提：
没有它不行
```

---

# 10. 削弱 vs 反驳

削弱不一定要：

```text
证明论点完全错误
```

只要：

```text
降低可信度
```

即可。

---

# 11. 母题 01｜直接支持论点

论点：

```text
A能提高B
```

选项：

```text
研究发现使用A后B显著提高
```

属于：

```text
直接加强
```

---

# 12. 母题 02｜直接否定论点

论点：

```text
A能提高B
```

选项：

```text
多项研究发现A并不能提高B
```

属于：

```text
直接削弱
```

---

# 13. 母题 03｜搭桥

论据：

```text
A增加
```

论点：

```text
B会上升
```

缺口：

```text
A和B之间存在正向关系
```

加强项若说明：

```text
A增加会导致B上升
```

就是：

```text
搭桥
```

---

# 14. 搭桥题识别

题干：

```text
论据和论点使用了不同概念
```

例如：

```text
阅读量增加
→ 学习成绩提高
```

缺：

```text
阅读量与学习成绩之间的关系
```

---

# 15. 母题 04｜拆桥

若选项指出：

```text
A和B之间并没有题干假定的关系
```

就是：

```text
拆桥削弱
```

---

# 16. 搭桥 / 拆桥口诀

```text
加强补关系
削弱断关系
```

---

# 17. 母题 05｜排除他因加强

论点：

```text
A导致B
```

加强选项：

```text
其他可能导致B的因素基本不存在
```

作用：

```text
排除替代解释
```

---

# 18. 母题 06｜另有他因削弱

论点：

```text
A导致B
```

选项：

```text
C更可能导致B
```

这是：

```text
另有他因
```

---

# 19. 另有他因的强弱

强他因：

```text
能完整解释B
且与A独立
```

弱他因：

```text
只是可能有一点影响
```

---

# 20. 母题 07｜因果倒置

论点：

```text
A导致B
```

选项：

```text
实际上B可能导致A
```

削弱：

```text
因果方向可能反了
```

---

# 21. 母题 08｜共同原因

观察到：

```text
A与B同时变化
```

论点：

```text
A导致B
```

选项：

```text
C同时导致A和B
```

说明：

```text
A、B相关
但未必有直接因果
```

---

# 22. 因果论证三大削弱

```text
因果倒置
另有他因
共同原因
```

看到：

```text
“相关”“同时出现”“随着……增加”
```

就优先检查。

---

# 23. 因果论证三大加强

```text
A先于B
排除其他原因
存在明确机制
```

---

# 24. 母题 09｜时间先后加强

如果：

```text
A先发生
B后发生
```

至少可以削弱：

```text
B导致A
```

从而加强：

```text
A→B
```

但注意：

```text
先后关系本身仍不能完全证明因果
```

---

# 25. 母题 10｜机制加强

论点：

```text
A导致B
```

选项解释：

```text
A通过机制M作用于B
```

通常属于：

```text
较强加强
```

---

# 26. 母题 11｜剂量效应

若：

```text
A越多
B越明显
```

可加强：

```text
A与B存在因果关系
```

---

# 27. 母题 12｜干预实验

如果人为：

```text
改变A
```

随后：

```text
B相应变化
```

比单纯相关性更能支持：

```text
因果关系
```

---

# 28. 第四大类：样本与总体

高频论证：

```text
对样本的调查
→ 推总体结论
```

重点看：

```text
样本是否有代表性
```

---

# 29. 母题 13｜样本代表性加强

加强：

```text
随机抽样
样本量足够
覆盖不同地区/年龄/职业
```

---

# 30. 母题 14｜样本偏差削弱

削弱：

```text
样本来自特殊群体
不能代表总体
```

---

# 31. 母题 15｜自愿者偏差

自愿参加调查的人：

```text
可能与普通人系统性不同
```

因此：

```text
样本不一定代表总体
```

---

# 32. 母题 16｜非回应偏差

只统计：

```text
愿意回答的人
```

忽略：

```text
未回答者
```

如果两者差异大：

```text
调查结论可能偏差
```

---

# 33. 母题 17｜幸存者偏差

只看：

```text
成功者
留下者
能被观察到的人
```

忽略：

```text
失败者
退出者
未被观察到的人
```

---

# 34. 样本题固定排查

```text
样本量够吗？
随机吗？
覆盖广吗？
有选择偏差吗？
回应者有偏吗？
```

---

# 35. 第五大类：实验论证

实验题重点：

```text
实验组
对照组
变量控制
随机分组
样本量
测量方式
```

---

# 36. 母题 18｜有对照组加强

如果题干实验原本：

```text
有实验组
但对照关系不清
```

选项若说明：

```text
存在合理对照组
```

可加强可靠性。

---

# 37. 母题 19｜无对照组削弱

若只看到：

```text
使用A后B提高
```

没有：

```text
未使用A的人作比较
```

就难排除：

```text
自然变化
时间因素
其他变化
```

---

# 38. 母题 20｜控制变量加强

实验组与对照组：

```text
除核心变量A外
其他条件基本一致
```

可加强：

```text
差异由A造成
```

---

# 39. 母题 21｜混杂变量削弱

如果两组除了A：

```text
还在年龄、环境、基础水平等方面不同
```

则：

```text
无法确定结果由A引起
```

---

# 40. 母题 22｜随机分组加强

随机分组作用：

```text
减少两组初始系统差异
```

---

# 41. 母题 23｜安慰剂效应削弱

药物/治疗实验中：

```text
改善可能来自心理预期
```

不一定来自：

```text
药物本身
```

---

# 42. 母题 24｜双盲加强

双盲可降低：

```text
受试者期待
研究者主观影响
```

---

# 43. 实验论证固定排查

```text
有无对照
是否随机
是否控制变量
样本是否足够
测量是否客观
是否有安慰剂/期待效应
```

---

# 44. 第六大类：反例削弱

论点：

```text
所有A都有B
```

只要找到：

```text
一个A没有B
```

就能：

```text
直接反驳
```

---

# 45. 母题 25｜全称结论的反例

论点：

```text
所有采取措施A的城市都能降低污染
```

若选项指出：

```text
某城市采取A后污染并未下降
```

削弱很强。

---

# 46. 反例的强弱

若论点是：

```text
“通常”“大多数”
```

一个个例：

```text
削弱有限
```

若论点是：

```text
“所有”“一定”
```

一个反例：

```text
非常强
```

---

# 47. 第七大类：概念偷换

论据讲：

```text
A指标
```

论点变成：

```text
B概念
```

如果：

```text
A不能代表B
```

论证就有问题。

---

# 48. 母题 26｜指标替代

例如：

```text
网店评分高
→ 商品质量一定高
```

缺口：

```text
评分是否能可靠代表质量
```

---

# 49. 母题 27｜概念范围扩大

论据：

```text
部分消费者
```

论点：

```text
所有消费者
```

属于：

```text
以偏概全
```

---

# 50. 母题 28｜局部推整体

论据：

```text
某几个城市
```

论点：

```text
全国
```

需要：

```text
代表性
```

---

# 51. 第八大类：时间范围外推

论据：

```text
短期有效
```

论点：

```text
长期有效
```

---

# 52. 母题 29｜短期推长期

加强需要：

```text
短期效果能持续
```

削弱可指出：

```text
长期会出现适应、反弹、衰减
```

---

# 53. 第九大类：对象外推

论据：

```text
动物实验
```

论点：

```text
人类有效
```

---

# 54. 母题 30｜动物推人

加强：

```text
动物与人在关键机制上相似
已有初步人体证据
```

削弱：

```text
两者代谢/机制存在关键差异
```

---

# 55. 第十大类：类比论证中的加强削弱

结构：

```text
A有特征X
B与A相似
→ B也有X
```

---

# 56. 母题 31｜关键相似点加强

加强：

```text
A和B在与结论X直接相关的方面相似
```

---

# 57. 母题 32｜关键差异削弱

削弱：

```text
A和B在影响X的关键机制上不同
```

---

# 58. 第十一大类：措施—目标论证

常见：

```text
实施措施A
→ 达到目标B
```

---

# 59. 措施题三大检查

```text
措施能实施吗？
措施能触达问题原因吗？
会不会产生副作用？
```

---

# 60. 母题 33｜可行性加强

选项：

```text
实施成本可控
相关主体能执行
资源足够
```

加强：

```text
措施可实施
```

---

# 61. 母题 34｜不可行削弱

选项：

```text
成本过高
缺资源
无法执行
```

削弱措施效果。

---

# 62. 母题 35｜副作用削弱

即使措施能解决A：

```text
却引发更严重B
```

可能削弱：

```text
“总体有效”
```

---

# 63. 母题 36｜措施没打中原因

问题由：

```text
C造成
```

措施却只处理：

```text
A
```

则：

```text
措施难有效
```

---

# 64. 第十二大类：前提题

题干常见：

```text
上述论证成立必须基于哪项假设
以下哪项是上述论证的前提
要使上述结论成立，需要补充
```

---

# 65. 前提题第一原则

```text
必要性
```

不是：

```text
支持力度最大
```

---

# 66. 否定代入法

选项：

```text
X
```

改成：

```text
非X
```

如果论证：

```text
彻底无法成立
```

则：

```text
X很可能是前提
```

---

# 67. 母题 37｜搭桥型前提

论据：

```text
A
```

论点：

```text
B
```

必须假设：

```text
A和B存在必要联系
```

---

# 68. 母题 38｜排除型前提

论点：

```text
A导致B
```

可能必须假设：

```text
没有其他因素足以完整解释B
```

---

# 69. 母题 39｜可行性前提

结论：

```text
实施A可以达到B
```

必须至少有：

```text
A能被实施
```

---

# 70. 母题 40｜样本代表性前提

如果论点：

```text
样本结果可推广总体
```

必须假设：

```text
样本具有一定代表性
```

---

# 71. 母题 41｜指标有效性前提

论据用：

```text
指标X
```

论点谈：

```text
概念Y
```

必须假设：

```text
X能有效反映Y
```

---

# 72. 前提题高频错误

错误选项可能：

```text
很能加强
但不是必须
```

所以一定要：

```text
否定代入
```

---

# 73. 第十三大类：加强削弱强弱比较

不是所有加强/削弱都一样强。

---

# 74. 加强强度参考

通常：

```text
直接建立核心桥梁
> 直接证明论点
> 排除关键他因
> 补充机制
> 一般正向信息
> 背景信息
```

具体题目：

```text
以“打中论证核心”为准
```

---

# 75. 削弱强度参考

通常：

```text
直接否定核心结论
> 拆掉必要桥梁
> 强他因/因果倒置
> 重大实验/样本缺陷
> 一般反例
> 边缘质疑
```

---

# 76. “直接否定”未必永远最强

如果选项只是：

```text
重复结论相反观点
```

但没有证据。

而另一个选项：

```text
给出强事实拆掉核心论证
```

后者可能更强。

因此：

```text
看证据力度
```

---

# 77. 第十四大类：无关项

高频干扰项：

```text
说的是别的主体
说的是别的时间
说的是别的指标
只重复背景
与论点方向无关
```

---

# 78. 母题 42｜主体偷换

论点：

```text
大学生
```

选项：

```text
中学生
```

若无法迁移：

```text
无关
```

---

# 79. 母题 43｜时间偷换

论点：

```text
长期效果
```

选项：

```text
只说短期变化
```

若无法连接：

```text
力度弱或无关
```

---

# 80. 母题 44｜指标偷换

论点：

```text
幸福感
```

选项：

```text
收入
```

若没有说明：

```text
收入与幸福感关系
```

不能直接支持。

---

# 81. 母题 45｜背景项

选项只是：

```text
介绍相关背景
```

但不影响：

```text
论点真假
```

属于：

```text
无关项
```

---

# 82. 第十五大类：对比实验型加强削弱

如果论证来自：

```text
两组比较
```

重点问：

```text
两组是否真正可比
```

---

# 83. 母题 46｜基线不同

实验组初始：

```text
本来就更高
```

即使结果更高：

```text
也不能归因于实验
```

---

# 84. 母题 47｜回归均值

如果选了：

```text
极端高/低的人群
```

后续即使自然回归：

```text
也可能改善
```

不能全归因于干预。

---

# 85. 第十六大类：前后对比型论证

结构：

```text
实施A前B低
实施A后B高
→ A导致B提高
```

---

# 86. 前后对比三大漏洞

```text
同期其他变化
自然趋势
测量方式变化
```

---

# 87. 母题 48｜同期政策变化

A实施同时：

```text
还有C政策
```

则B改善：

```text
可能由C导致
```

---

# 88. 母题 49｜自然趋势

即使不实施A：

```text
B本来就在上升
```

则：

```text
前后对比不足以证明A有效
```

---

# 89. 第十七大类：选择进入偏差

结构：

```text
选择参加A的人表现更好
→ A导致表现好
```

漏洞：

```text
参加者本来就更优秀/更积极
```

---

# 90. 母题 50｜自我选择偏差

例如：

```text
参加培训的人升职率更高
```

可能：

```text
主动参训的人本来更上进
```

---

# 91. 第十八大类：预测型论证

结构：

```text
过去趋势
→ 未来仍然如此
```

---

# 92. 母题 51｜趋势延续前提

必须假设：

```text
未来关键条件没有根本变化
```

---

# 93. 母题 52｜结构变化削弱

若未来：

```text
政策、技术、环境发生重大变化
```

过去趋势：

```text
可能无法外推
```

---

# 94. 第十九大类：成本收益论证

结构：

```text
A带来收益
→ 应该实施A
```

缺口：

```text
成本是否可接受
收益是否大于代价
```

---

# 95. 母题 53｜忽略成本削弱

如果A：

```text
收益100
成本1000
```

则：

```text
“值得实施”
```

结论被削弱。

---

# 96. 母题 54｜净收益加强

若选项说明：

```text
收益显著大于成本
```

加强：

```text
实施建议
```

---

# 97. 第二十大类：必要条件型论证

论点：

```text
A是B必不可少的条件
```

削弱最直接：

```text
没有A也能B
```

---

# 98. 母题 55｜否定必要性

论点：

```text
A是成功必要条件
```

反例：

```text
有人没A也成功
```

直接削弱。

---

# 99. 第二十一大类：充分条件型论证

论点：

```text
有A就一定B
```

削弱：

```text
有A但不B
```

---

# 100. 母题 56｜否定充分性

```text
A成立
但B未发生
```

直接构成反例。

---

# 101. 高频错误母型 01｜没先找论点

结果：

```text
选项看着相关就选
```

正确：

```text
先定位论点
```

---

# 102. 高频错误母型 02｜只看主题相关

选项和题干：

```text
主题一样
```

不等于：

```text
能加强/削弱
```

---

# 103. 高频错误母型 03｜他因方向判断错

另有他因：

```text
削弱“A导致B”
```

但如果选项只是：

```text
C也能促进B
```

不一定完全削弱A。

要看：

```text
是否替代题干因果解释
```

---

# 104. 高频错误母型 04｜因果倒置力度没看懂

如果题干只是：

```text
相关
```

而论点直接说：

```text
A导致B
```

指出：

```text
B导致A
```

通常是强削弱。

---

# 105. 高频错误母型 05｜前提当加强做

前提题不是找：

```text
最支持
```

而是找：

```text
不能缺
```

---

# 106. 高频错误母型 06｜反例力度误判

论点：

```text
多数
通常
倾向于
```

一个反例：

```text
未必强
```

---

# 107. 高频错误母型 07｜样本量大就一定有代表性

错误。

```text
样本量大
```

不等于：

```text
抽样方式合理
```

---

# 108. 高频错误母型 08｜有对照组就一定可靠

还要看：

```text
两组是否可比
是否随机
是否控制变量
```

---

# 109. 高频错误母型 09｜无关背景项误选

选项只是：

```text
介绍A很重要
```

但没影响：

```text
论证核心
```

就是无关。

---

# 110. 高频错误母型 10｜削弱结论对象错位

论点：

```text
A能提高B
```

选项：

```text
A价格较高
```

如果题目不是：

```text
“是否值得使用A”
```

则价格：

```text
通常无关
```

