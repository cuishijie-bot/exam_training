# 1. 逻辑判断总口令

```text
翻译题先写箭头
真假题先找矛盾
分析题先建模
论证题先找论点
加强补桥
削弱拆桥
前提否定代入
因果先查倒置他因
实验先看对照随机控制
调查看样本代表性
```

# 2. 5秒题型识别

看到：

```text
如果 / 只要
→ 翻译推理

只有 / 才 / 除非
→ 必要条件

只有一句真/假
→ 真假推理

排序 / 座位 / 分组 / 匹配
→ 分析推理

最能支持
→ 加强

最能削弱 / 质疑
→ 削弱

必须假设 / 前提
→ 前提题

最能解释
→ 解释题

最有助于评价
→ 评价题

实验 / 调查 / 相关
→ 特殊论证
```

# 3. 翻译推理核心

```text
只要A就B
→ A→B

只有A才B
→ B→A

除非A否则不B
→ B→A
```

---

# 4. 逆否命题

```text
A→B
```

等价：

```text
非B→非A
```

---

# 5. 四种方向

```text
A→B

A成立
→ B成立
√

非B
→ 非A
√

B
→ A
×

非A
→ 非B
×
```

口诀：

```text
肯前必肯后
否后必否前
肯后不能肯前
否前不能否后
```

---

# 6. 且 / 或

```text
A且B
→ 两者都真

A或B
→ 至少一个真
```

---

# 7. 德摩根律

```text
非(A且B)
= 非A或非B

非(A或B)
= 非A且非B
```

---

# 8. 不都 vs 都不

```text
不都
= 至少一个不

都不
= 两个都不
```

---

# 9. 条件命题否定

```text
A→B
```

其否定：

```text
A且非B
```

# 10. 集合推理

```text
所有A是B
→ A→B

所有A不是B
→ A→非B

有的A是B
→ A∩B存在

有的A不是B
→ A∩非B存在
```

# 11. 集合高频陷阱

```text

> 紧邻

> 容量
```

# 27. 同组 / 异组

# 44. 因果题总口令

看到：

```text
A和B相关
→ A导致B
```

立刻查：

```text
① B会不会导致A
② 有没有C导致B
③ 有没有C同时导致A和B
```

---

# 45. 因果倒置

```text
A→B
```

可能：

```text
B→A
```

---

# 46. 另有他因

```text
C→B
```

若C足以替代A解释：

```text
削弱强
```

---

# 47. 共同原因

```text
C→A
C→B
```

所以：

```text
A、B相关
不一定直接因果
```

---

# 48. 因果加强

```text
A先于B
排除他因
存在机制
剂量效应
干预实验
```

---

# 49. 相关≠因果

即使：

```text
相关很强
```

也不能自动推出：

```text

```

# 55. 双盲

# 56. 随机抽样 vs 随机分组

```text
随机抽样

→ 看两组可比性
```

# 76. 高频陷阱一页版

```text
□ 只要/只有别翻反
□ 逆否才等价
□ 肯后不能肯前
□ 否前不能否后
□ 不都≠都不
□ 所有不能反向推
□ 真假题先找矛盾
□ 分析题先抓强条件
□ 可能题只需一个合法情况
□ 论证题先找论点
□ 加强看是否打中缺口
□ 削弱看是否打中缺口
□ 前提题用否定代入
□ 相关不等于因果
□ 他因要看能否替代原解释
□ 样本量大不等于代表性好
□ 有对照不等于实验一定可靠
□ 随机抽样≠随机分组
□ 解释题要同时解释两边
□ 评价题看正反答案
```

```text

6. 肯后不能肯前

8. 真假题先找矛盾
```
