# 0. 翻译推理总口令

```text
只要A就B
→ A→B

只有A才B
→ B→A

A→B
→ 非B→非A

肯前必肯后
否后必否前
肯后不能肯前
否前不能否后
```

看到：

```text

只要
一旦
若
凡是
所有……都……
```

优先翻译：

```text
前 → 后
```

# 2. 母题 01｜如果A那么B

```text
如果下雨，那么路湿。
```

翻译：

```text
下雨 → 路湿
```

可推出：

```text
非路湿 → 非下雨
```

不能推出：

```text
路湿 → 下雨
```

# 10. “只要”与“只有”对照

```text
只要A，就B
→ A→B

只有A，才B
→ B→A
```

口诀：

```text
只要：前推后
只有：后推前
```

# 11. 高频陷阱：把必要条件当充分条件

题干：

```text
只有努力才能成功
```

正确：

```text
成功 → 努力
```

错误：

```text
努力 → 成功
```

为什么错：

```text
努力只是成功的必要条件
不是充分条件
```



# 38. 翻译推理专项：条件关系组合

若：

```text
A→B
C→非B
```

```text
会推出B和非B
```

矛盾。

因此：

```text
A和C不能同时成立
```

# 50. “有的”可以换位

```text

```

可换成：

```text
有的B是A
```


# 51. “所有”不能随便换位


不能换成：


# 52. 集合推理图示思维

```text

→ A在B里面

→ A和B有交叉

所有A不是B
→ A和B完全分离
```

# 63. 母题 22｜只有一句真 + 一对矛盾

若4句话中：

```text
甲与乙矛盾
```

则：

```text
甲乙必一真一假
```

题干说：

```text
只有一句真
```

所以：

```text
其他所有话都假
```

---

# 64. 母题 23｜只有一句假 + 一对矛盾

同理：

```text
矛盾对中一真一假
```

既然全题只有一句假：

```text
其余全部真
```

# 65. 母题 24｜两真一假

```text
真
```

# 66. 母题 25｜一真两假

找到矛盾对：

```text
占一真一假
```

第三句必须：


# 67. 没有明显矛盾怎么办

用：

```text

```

# 68. 假设法

步骤：

```text
① 假设某句话真
② 推其余关系
③ 检查真话数量
④ 若冲突则排除
```

---

# 69. 母题 26｜假设某人说真话

题干：

```text
只有一个人说真话
```

假设：

```text
甲真
```

则：

```text
乙、丙、丁都假
```

检查是否矛盾。

---

# 70. 真假推理中的反对关系

有些命题：

```text
不能同时真
但可以同时假
```

叫：

```text
反对关系
```

例如：

```text
所有A是B
所有A不是B
```

若A存在：

```text
不能同时真
```

但可能：

```text
都假
```

---

# 71. 真假推理中的下反对

有些命题：

```text
不能同时假
但可以同时真
```

例如：

```text
有的A是B
有的A不是B
```

在A有多个成员时：

```text
可同时真
```

---

# 72. 公考真假题优先级

一般优先：

```text
矛盾
> 反对
> 下反对
> 假设法
```

```text

```

国考省考通常按题干具体对象处理，优先遵循：

```text

```

# 111. 最终 20 行极简版

```text
1. 只要A就B：A→B
2. 只有A才B：B→A
3. 除非A否则不B：B→A
4. A→B 的逆否：非B→非A

6. 否后必否前
7. 肯后不能肯前
8. 否前不能否后
9. A且B：两者都真

11. 非(A且B)=非A或非B

15. 有的A是B：交集存在
16. 真假题先找矛盾
17. 矛盾必一真一假
18. A→B的否定=A且非B
```
