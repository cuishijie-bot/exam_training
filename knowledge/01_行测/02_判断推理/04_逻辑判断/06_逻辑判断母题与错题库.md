# 1. 第一眼题型识别

看到：

```text
如果 / 只要
→ 翻译推理
```

看到：

```text
只有 / 才 / 除非
→ 必要条件
```

看到：

```text
只有一句真 / 假
→ 真假推理
```

看到：

```text
排序 / 座位 / 分组 / 匹配
→ 分析推理
```

看到：

```text
最能支持
→ 加强
```

看到：

```text
最能削弱 / 质疑
→ 削弱
```

看到：

```text
必须假设 / 前提
→ 前提题
```

看到：

```text
最能解释
→ 解释题
```

看到：

```text
最有助于评价
→ 评价题
```

# 2. 翻译母题 01｜只要A就B

## 题干信号

```text

如果
一旦
```

```text
A → B
```


```text
B → A
```

# 95. 错题总编码

## 翻译

```text
FT1 只要/只有翻反
FT2 逆否错误
FT3 肯后肯前
FT4 否前否后
FT5 且或错误
FT6 集合错误
```

---

## 真假

```text
TT1 矛盾没找到
TT2 矛盾认错
TT3 真话数没利用
TT4 假设混乱
```

---

## 分析

```text
AP1 建模错误
AP2 强条件没抓
AP3 相邻/先后混
AP4 代入没想到
AP5 假设分支过多
AP6 可能/一定混
```

---

## 加强削弱

```text
AS1 论点找错
AS2 论据找错
AS3 缺口没找到
AS4 搭桥/拆桥错
AS5 他因误判
AS6 倒置漏看
AS7 样本漏洞漏看
AS8 实验漏洞漏看
AS9 无关项误选
AS10 强弱比较错
```

---

## 前提

```text
PR1 把加强当前提
PR2 否定代入不会
PR3 必要桥梁漏看
PR4 可行性漏看
```

---

## 特殊论证

```text
CE1 相关当因果
CE2 倒置漏看
CE3 共同原因漏看
EX1 对照漏看
EX2 随机漏看
EX3 控制变量漏看
SV1 样本代表性漏看
AN1 关键相似判断错
IN1 解释只解释一边
```

# 114. 高频条件反射总表

```text
只要
→ 前推后

只有
→ 后推前

A→B
→ 非B→非A

只有一句真/假
→ 找矛盾

排序/座位
→ 画位置线

匹配
→ 二维表

可能成立
→ 代入构造

加强
→ 补桥

削弱
→ 拆桥

前提
→ 否定代入

相关推因果
→ 倒置/他因/共同原因

实验
→ 对照/随机/控制

调查
→ 样本代表性

类比
→ 关键相似/关键差异

解释
→ 同时解释两边

评价
→ 正反答案测试
```

# 115. 高频陷阱一页版

```text
□ 只要/只有别翻反
□ 逆否才等价
□ 肯后不能肯前
□ 否前不能否后
□ 不都≠都不
□ 所有不能反向推
□ 真假题先找矛盾
□ 分析题先抓强条件
□ 可能题只需一个合法情况
□ 加强削弱先找论点
□ 两个选项都相关时看谁打中缺口
□ 前提不是“最能加强”
□ 相关不等于因果
□ 有他因不等于A一定无效
□ 样本量大不等于代表性好
□ 有对照不等于实验一定可靠
□ 随机抽样≠随机分组
□ 类比看关键机制
□ 解释题必须兼顾两边
□ 评价题检查正反答案
```
