# 1. 第一大类：因果论证

典型结构：

```text
A和B相关
↓
所以A导致B
```

或：

```text
A出现后
B出现
↓
所以A导致B
```

---

# 2. 因果题第一反应

看到：

```text
导致
造成
引起
使得
促成
影响
由于
原因是
```

立刻问：

```text
① 会不会是B导致A？
② 会不会是C导致B？
③ 会不会是C同时导致A和B？
```

---

# 3. 母题 01｜相关不等于因果

题干：

```text
经常运动的人更健康
→ 运动导致健康
```

漏洞：

```text
健康的人本来就更愿意运动
```

或者：

```text
生活方式C同时导致运动和健康
```

---

# 4. 母题 02｜因果倒置

原论点：

```text
A → B
```

削弱：

```text
可能是 B → A
```

---

# 5. 因果倒置强弱

如果题干只有：

```text
相关性数据
```

因果倒置通常：

```text
很强
```

如果题干已有：

```text
随机实验
干预结果
明确时间先后
```

因果倒置力度：

```text
下降
```

---

# 6. 母题 03｜另有他因

原论点：

```text
A导致B
```

削弱：

```text
C也能导致B
```

更强的版本：

```text
C比A更能完整解释B
```

---

# 7. 他因削弱的关键

不是只要出现：

```text
C也有影响
```

就一定很强。

要看：

```text
C是否足以替代A
```

---

# 8. 母题 04｜共同原因

观察：

```text
A升高
B也升高
```

可能：

```text
C同时导致A和B
```

这说明：

```text
A和B相关
但不一定直接因果
```

---

# 9. 母题 05｜时间先后

若：

```text
A先发生
B后发生
```

可支持：

```text
A可能导致B
```

同时削弱：

```text
B导致A
```

但：

```text
时间先后本身仍不能证明因果
```

---

# 10. 母题 06｜剂量效应

如果：

```text
A越多
B越明显
```

通常加强：

```text
A与B存在因果关系
```

例如：

```text
暴露量越大
风险越高
```

---

# 11. 母题 07｜干预效应

如果人为：

```text
改变A
```

结果：

```text
B随之变化
```

比单纯观察相关：

```text
因果证据更强
```

---

# 12. 因果加强五问

```text
① A是否先于B？
② 是否排除关键他因？
③ 是否存在作用机制？
④ 是否有剂量效应？
⑤ 是否有干预实验？
```

---

# 13. 因果削弱五问

```text
① B会不会导致A？
② 是否有其他原因C？
③ 是否有共同原因C？
④ 是否只是偶然相关？
⑤ 是否样本/测量有偏差？
```

---

# 14. 高频陷阱：相关强≠因果强

即使：

```text
相关系数很高
```

也不能自动证明：

```text
A导致B
```

---

# 15. 高频陷阱：时间先后≠因果证明

```text
A先B后
```

只能说明：

```text
B不太可能先导致A
```

不能排除：

```text
C导致B
```

---

# 16. 高频陷阱：机制解释≠直接证明

如果只是提出：

```text
一个可能机制
```

而没有证据验证：

```text
加强有限
```

---

# 17. 第二大类：实验论证

实验题固定看：

```text
实验组
对照组
随机分组
控制变量
样本量
测量方式
安慰剂
双盲
重复验证
```

---

# 18. 实验题第一问：有没有对照组

没有对照组时：

```text
实验后发生变化
```

不能确定：

```text
变化由实验变量造成
```

---

# 19. 母题 08｜设置对照组

实验组：

```text
接受A
```

对照组：

```text
不接受A
```

如果其余条件一致：

```text
两组差异更可归因于A
```

---

# 20. 母题 09｜无对照组

只观察：

```text
使用A前
使用A后
```

问题：

```text
自然趋势
时间变化
同期事件
```

都可能影响结果。

---

# 21. 第二问：是否随机分组

随机分组作用：

```text
让两组初始特征尽量可比
```

降低：

```text
选择偏差
```

---

# 22. 母题 10｜随机分组加强

若实验对象：

```text
随机进入实验组/对照组
```

通常加强：

```text
因果解释
```

---

# 23. 母题 11｜自行选择分组

如果：

```text
愿意接受治疗的人进入实验组
不愿意者进入对照组
```

两组可能本来就不同。

这是：

```text
自我选择偏差
```

---

# 24. 第三问：是否控制变量

理想实验：

```text
两组只在核心变量A上不同
```

---

# 25. 母题 12｜混杂变量

实验组：

```text
年龄更低
收入更高
基础水平更好
```

若这些因素也影响结果：

```text
不能把差异全归因于A
```

---

# 26. 第四问：是否存在安慰剂效应

尤其：

```text
药物
心理
疼痛
主观感受
```

类实验。

---

# 27. 母题 13｜安慰剂效应

受试者因为：

```text
相信自己接受了有效治疗
```

而主观改善。

削弱：

```text
“药物本身导致改善”
```

---

# 28. 母题 14｜安慰剂对照

对照组接受：

```text
外观相同但无有效成分的处理
```

可以区分：

```text
心理期待
vs
真实药效
```

---

# 29. 第五问：是否双盲

双盲：

```text
受试者不知道分组
研究人员也不知道分组
```

目的：

```text
减少期待和观察者偏差
```

---

# 30. 母题 15｜双盲加强

可降低：

```text
受试者期待
研究者主观评分
```

---

# 31. 第六问：样本量

样本量太小：

```text
偶然性更大
```

但要注意：

```text
样本量大 ≠ 设计一定科学
```

---

# 32. 母题 16｜小样本削弱

如果：

```text
只测5人
```

却得出：

```text
普遍结论
```

力度较弱。

---

# 33. 第七问：测量方式

如果结果依赖：

```text
主观自评
```

可能有：

```text
测量偏差
```

---

# 34. 母题 17｜客观指标加强

例如：

```text
血液指标
设备记录
标准化考试
```

通常比：

```text
个人感觉
```

更可靠。

---

# 35. 第八问：是否重复

一次实验：

```text
可能偶然
```

多个独立实验重复得到类似结果：

```text
加强
```

---

# 36. 实验论证 8 项清单

```text
□ 对照组
□ 随机分组
□ 控制变量
□ 安慰剂
□ 双盲
□ 样本量
□ 客观测量
□ 重复验证
```

---

# 37. 实验高频陷阱：有对照≠好实验

还要看：

```text
两组是否可比
```

---

# 38. 实验高频陷阱：随机抽样≠随机分组

```text
随机抽样
→ 影响样本代表性

随机分组
→ 影响实验组/对照组可比性
```

这两个概念不要混。

---

# 39. 实验高频陷阱：相关研究冒充实验

如果研究者只是：

```text
观察已有差异
```

没有人为干预：

```text
属于观察研究
```

因果证据通常较弱。

---

# 40. 第三大类：调查论证

调查题重点：

```text
谁被调查
怎么抽
谁没回答
问题怎么问
结论推广到谁
```

---

# 41. 调查题第一问：样本来自哪里

如果总体：

```text
全国居民
```

却只调查：

```text
某大学学生
```

代表性：

```text
不足
```

---

# 42. 母题 18｜样本代表性

正确加强：

```text
样本覆盖不同地区、年龄、职业
```

---

# 43. 母题 19｜便利抽样

例如只调查：

```text
商场门口路人
网络平台用户
某小区居民
```

若推广总体：

```text
可能偏
```

---

# 44. 母题 20｜自愿者偏差

主动愿意参与的人：

```text
往往更关心该议题
```

所以：

```text
不一定代表普通人
```

---

# 45. 母题 21｜非回应偏差

如果：

```text
大量人不回答
```

而未回答者与回答者差异明显：

```text
结论可能偏
```

---

# 46. 母题 22｜幸存者偏差

只调查：

```text
仍留在行业的人
```

忽略：

```text
已经退出的人
```

结论会偏向：

```text
幸存者特征
```

---

# 47. 母题 23｜问卷措辞诱导

例如：

```text
“你是否支持这项明显有利于公众的政策？”
```

题目本身：

```text
带有倾向
```

可能影响回答。

---

# 48. 母题 24｜社会期许偏差

涉及：

```text
道德
收入
违法
健康习惯
```

受访者可能：

```text
不愿如实回答
```

---

# 49. 母题 25｜回忆偏差

如果要求：

```text
回忆多年前行为
```

数据可能：

```text
不准确
```

---

# 50. 调查题固定排查

```text
① 总体是谁？
② 样本是谁？
③ 抽样是否随机？
④ 样本是否覆盖总体？
⑤ 是否有大量未回应？
⑥ 问题是否诱导？
⑦ 回答是否可靠？
```

---

# 51. 调查高频陷阱：样本量大≠代表性好

```text
100万网络投票
```

也可能不如：

```text
1000人的随机抽样
```

---

# 52. 调查高频陷阱：回应率低

即使样本最初随机：

```text
如果只有少数人回答
```

最终样本仍可能：

```text
失去代表性
```

---

# 53. 第四大类：类比论证

结构：

```text
A具有X
B和A相似
→ B也具有X
```

---

# 54. 类比题核心

不是看：

```text
像不像
```

而是看：

```text
相似点是否和结论X有关
```

---

# 55. 母题 26｜关键相似点加强

例如：

```text
某药对动物A有效
动物B在相关代谢机制上与A高度相似
```

加强：

```text
B也可能有效
```

---

# 56. 母题 27｜关键差异削弱

如果：

```text
A和B在影响结论的核心机制上不同
```

即使外表很像：

```text
类比仍弱
```

---

# 57. 母题 28｜无关相似点

例如：

```text
两城市面积相近
```

但结论谈：

```text
人口政策效果
```

面积相近：

```text
未必相关
```

---

# 58. 类比加强三问

```text
① 相似点够多吗？
② 相似点与结论相关吗？
③ 是否存在关键差异？
```

---

# 59. 类比削弱三问

```text
① 有无关键不同？
② 结论依赖的机制是否不同？
③ 类比范围是否被过度扩大？
```

---

# 60. 类比高频陷阱：表面相似

表面：

```text
规模
颜色
形式
```

相似，不代表：

```text
关键机制相似
```

---

# 61. 第五大类：解释题

题干常见：

```text
以下哪项最能解释上述现象
以下哪项最有助于解释这一矛盾
```

---

# 62. 解释题本质

不是：

```text
加强某个结论
```

而是：

```text
让两个看似矛盾现象同时合理
```

---

# 63. 母题 29｜A下降但总量上升

例如：

```text
单价下降
但总销售额上升
```

解释可能：

```text
销量大幅增加
```

---

# 64. 母题 30｜措施实施但问题反而增加

可能：

```text
检测更充分
统计口径改变
暴露增加
延迟效应
```

---

# 65. 解释题正确项特征

必须：

```text
同时照顾题干两边
```

不能只解释：

```text
其中一个现象
```

---

# 66. 解释题高频模型 1｜分母变化

例如：

```text
占比下降
绝对数量却上升
```

可能：

```text
总体增长更快
```

---

# 67. 解释题高频模型 2｜统计口径变化

看似：

```text
问题增加
```

可能：

```text
检测/报告更充分
```

---

# 68. 解释题高频模型 3｜时间滞后

措施现在实施：

```text
效果尚未体现
```

短期数据：

```text
仍可能恶化
```

---

# 69. 解释题高频模型 4｜群体结构变化

总体变化可能来自：

```text
不同子群体占比变化
```

---

# 70. 解释题高频模型 5｜基数效应

同样增加：

```text
百分比变化
```

可能因基数不同而不同。

---

# 71. 解释题做题流程

```text
① 找两边现象
② 明确哪里“看起来矛盾”
③ 找一个机制同时解释两边
④ 排除只解释单边的选项
```

---

# 72. 第六大类：评价题

题干：

```text
以下哪项最有助于评价上述论证？
```

---

# 73. 评价题本质

一个好问题应该：

```text
如果答案“是”
→ 加强

如果答案“否”
→ 削弱
```

或者反过来：

```text
正反答案都会显著影响论证
```

---

# 74. 母题 31｜评价因果关系

论点：

```text
A导致B
```

评价问题：

```text
是否存在其他因素C也能导致B？
```

如果：

```text
有 → 削弱
无 → 加强
```

所以：

```text
有评价价值
```

---

# 75. 母题 32｜评价样本代表性

论点由样本推总体。

问：

```text
样本是否能代表总体？
```

正反答案：

```text
都会改变论证强弱
```

---

# 76. 母题 33｜评价实验可比性

问：

```text
实验组和对照组初始是否相似？
```

非常关键。

---

# 77. 评价题排除法

如果某问题：

```text
无论回答是/否
都不影响结论
```

则：

```text
没有评价价值
```

---

# 78. 第七大类：原因解释 vs 因果证明

注意区分：

```text
解释题
```

和：

```text
因果加强题
```

解释题：

```text
只要让现象合理
```

不一定要证明：

```text
严格因果
```

---

# 79. 第八大类：前后对比型因果

结构：

```text
政策前 B低
政策后 B高
→ 政策导致B提高
```

---

# 80. 前后对比漏洞 1｜同期变化

政策实施期间：

```text
还有其他政策C
```

可能：

```text
C导致B
```

---

# 81. 前后对比漏洞 2｜自然趋势

即使没有政策：

```text
B本来就在增长
```

---

# 82. 前后对比漏洞 3｜测量改变

前后使用：

```text
不同统计口径
不同设备
不同标准
```

结果：

```text
不可直接比较
```

---

# 83. 第九大类：横向比较型因果

结构：

```text
使用A的人B更高
未使用A的人B更低
→ A导致B
```

---

# 84. 横向比较漏洞｜初始差异

两组人：

```text
本来就不同
```

例如：

```text
年龄
收入
教育
健康基础
```

---

# 85. 第十大类：筛选极端样本

例如选：

```text
表现特别差的人
```

实施干预后：

```text
表现改善
```

可能只是：

```text
回归均值
```

---

# 86. 母题 34｜回归均值

极端值下一次测量：

```text
自然更接近平均水平
```

所以：

```text
改善不一定由干预造成
```

---

# 87. 第十一大类：选择进入偏差

结构：

```text
参加培训者表现更好
→ 培训有效
```

可能：

```text
更上进的人更愿意参加
```

---

# 88. 母题 35｜自我选择

削弱：

```text
参与者和未参与者起点不同
```

---

# 89. 第十二大类：观察者效应

受试者知道：

```text
自己正在被观察
```

可能：

```text
改变行为
```

---

# 90. 母题 36｜霍桑效应

参与实验本身：

```text
可能改变表现
```

所以变化：

```text
不一定来自核心处理
```

---

# 91. 第十三大类：测量工具变化

如果两组或前后：

```text
使用不同量表/仪器
```

则：

```text
差异可能来自测量工具
```

---

# 92. 第十四大类：选择性报告

只报告：

```text
支持结论的实验
```

忽略：

```text
不支持的实验
```

会导致：

```text
结果看起来更强
```

---

# 93. 母题 37｜发表偏差

成功显著的研究：

```text
更容易发表
```

失败研究：

```text
可能被忽视
```

---

# 94. 第十五大类：多个指标比较

如果研究同时测：

```text
很多指标
```

只挑一个显著结果：

```text
可能偶然
```

---

# 95. 第十六大类：中介机制

结构：

```text
A
→ M
→ B
```

如果选项证明：

```text
A影响M
M影响B
```

可加强：

```text
A→B
```

---

# 96. 母题 38｜机制链

例如：

```text
运动
→ 改善睡眠
→ 提高认知
```

如果两段机制都有证据：

```text
整体因果更可信
```

---

# 97. 第十七大类：调节变量

有时A对B的影响：

```text
只在特定群体成立
```

例如：

```text
年轻人有效
老年人无效
```

这可能削弱：

```text
“对所有人都有效”
```

但未必削弱：

```text
“对年轻人有效”
```

---

# 98. 第十八大类：总体与子群体

总体平均可能：

```text
掩盖子群体差异
```

---

# 99. 母题 39｜辛普森悖论意识

整体数据趋势：

```text
A优于B
```

但分组后：

```text
各组可能相反
```

公考中不一定要求专业名词，但要有意识：

```text
总体关系可能受群体构成影响
```

---

# 100. 第十九大类：比例与绝对量混淆

题干可能：

```text
比例下降
```

却推出：

```text
人数下降
```

错误。

---

# 101. 母题 40｜比例下降≠数量下降

如果总量增长足够快：

```text
比例下降
绝对数量仍可上升
```

---

# 102. 第二十大类：基数效应

例如：

```text
A增长50%
B增长20%
```

不能直接推出：

```text
A增长量更大
```

因为：

```text
基期不同
```

这种逻辑在论证题中也可能出现。

---

# 103. 高频陷阱 01｜实验与调查混淆

实验：

```text
研究者主动干预
```

调查/观察：

```text
只观察已有差异
```

因果证据强度通常：

```text
实验 > 观察相关
```

---

# 104. 高频陷阱 02｜随机抽样和随机分组混淆

```text
随机抽样
→ 总体代表性

随机分组
→ 组间可比性
```

---

# 105. 高频陷阱 03｜样本量大就代表性好

错。

```text
抽样方式
```

比单纯：

```text
人数多
```

更关键。

---

# 106. 高频陷阱 04｜有他因就必然击倒原因

错。

如果：

```text
A和C都能导致B
```

A仍可能：

```text
是真实原因之一
```

只有当C：

```text
足以替代题干解释
```

削弱才强。

---

# 107. 高频陷阱 05｜机制说得通就当证明

```text
理论上可能
```

不等于：

```text
现实中确实发生
```

---

# 108. 高频陷阱 06｜类比只看相似数量

不是相似点越多越强。

关键：

```text
是否与结论相关
```

---

# 109. 高频陷阱 07｜解释题只支持一边

解释必须：

```text
同时兼容两边现象
```

---

# 110. 高频陷阱 08｜评价题找“重要问题”

“重要”不等于：

```text
能评价论证
```

必须：

```text
正反答案都能改变论证强弱
```

---

# 111. 高频母题组 A｜因果

题干：

```text
经常喝咖啡的人工作效率更高
→ 咖啡提高效率
```

削弱方向：

```text
高强度工作者本来就更常喝咖啡
```

= 因果倒置/选择差异。

# 112. 高频母题组 B｜实验

```text

```

优先质疑：

```text

样本小
安慰剂效应
```

# 113. 高频母题组 C｜调查

题干：

```text

80%支持政策A
→ 全国80%的人支持
```

主要问题：

```text
平台用户不代表全国人口
自愿投票存在选择偏差
```

# 114. 高频母题组 D｜类比

题干：

```text
A城市实施措施X成功
B城市与A城市人口规模相近
→ B也会成功
```

关键：

```text
人口规模是否是影响措施效果的核心条件？
```

# 115. 高频母题组 E｜解释

题干：

```text
价格下降
总收入却上升
```

解释：

```text
销量增长幅度超过价格下降幅度
```

---

# 116. 高频母题组 F｜评价

论点：

```text
培训A提高员工绩效
```

评价问题：

```text
参加培训者在培训前是否已比未参加者绩效更高？
```

若：

```text
是 → 削弱
否 → 加强
```

所以：

```text
评价价值高
```
