> 定位：国考、辽宁省考判断推理中的 **逻辑判断总模型库**。
>
> 目标不是背答案，而是形成：
>
> ```text

> → 识别题型
> → 调用固定模型
> → 排除干扰项
> ```
>
> 本文件重点覆盖：
>
> ```text
> 翻译推理
> 真假推理
> 集合推理
> 分析推理

# 1. 第一大类：翻译推理

翻译推理本质：

```text
把自然语言
翻译成逻辑关系
```

核心不是算，而是：

```text
准确翻译
```

---

# 2. 充分条件

## 关键词

```text
如果……那么……
只要……就……
若……则……
凡是……都……
一旦……就……
```

翻译：

```text
A → B
```

含义：

```text
A发生
一定推出B
```

---

# 3. 必要条件

## 关键词

```text
只有……才……
除非……否则不……
必须……才……
没有……就不能……
```

翻译：

```text
B → A
```

例如：

```text
只有努力，才能成功
```

翻译：

```text
成功 → 努力
```

---

# 4. “只要”与“只有”

```text
只要A，就B
→ A → B

只有A，才B
→ B → A
```

这是最常见易错点之一。

---

# 5. 逆否命题

若：

```text
A → B
```

则必然：

```text
非B → 非A
```

这叫：

```text
逆否
```

---

# 6. 不能推出的两个方向

由：

```text
A → B
```

不能推出：

```text
B → A
```

也不能推出：

```text
非A → 非B
```

---

# 7. 充分条件四种关系速查

若：

```text
A → B
```

则：

```text
A       → B       √
非B     → 非A     √
B       → A       ×
非A     → 非B     ×
```

口诀：

```text
肯前必肯后
否后必否前
否前不确定
肯后不确定
```

---

# 8. 母题 01｜如果A那么B

看到：

```text
如果
只要
一旦
```

第一反应：

```text
前 → 后
```

---

# 9. 母题 02｜只有A才B

看到：

```text
只有
才
```

第一反应：

```text
后 → 前
```

---

# 10. 母题 03｜除非A否则不B

常见等价：

```text
B → A
```

例如：

```text
除非努力，否则不能成功
```

等价：

```text
成功 → 努力
```

---

# 11. “除非”题快速理解

```text
除非A，否则不B
```

可理解为：

```text
没有A，就没有B
```

所以：

```text
B → A
```

---

# 12. 且关系

关键词：

```text
并且
而且
同时
既……又……
```

表示：

```text
A 且 B
```

要为真：

```text
A真
B也真
```

---

# 13. 或关系

关键词：

```text
或者
至少一个
二者至少其一
```

通常逻辑“或”表示：

```text
A或B
```

可包含：

```text
A真B假
A假B真
A真B真
```

只有：

```text
A假B假
```

时为假。

---

# 14. “要么A要么B”

若题干明确表达：

```text
二选一
不能同时
```

则是：

```text
不相容或
```

即：

```text
只能一个成立
```

---

# 15. 否定“且”

```text
非(A且B)
```

等价：

```text
非A 或 非B
```

---

# 16. 否定“或”

```text
非(A或B)
```

等价：

```text
非A 且 非B
```

---

# 17. 德摩根律

```text
非(A且B)
= 非A 或 非B

非(A或B)
= 非A 且 非B
```

---

# 18. 母题 04｜“并非A且B”

翻译：

```text
非A 或 非B
```

---

# 19. 母题 05｜“并非A或B”

翻译：

```text
非A 且 非B
```

---

# 20. 充分条件链条

若：

```text
A → B
B → C
```

则：

```text
A → C
```

---

# 21. 多条件传递

```text
A → B
B → C
C → D
```

可得：

```text
A → D
```

---

# 22. 逆否链

若：

```text
A → B → C
```

则：

```text
非C → 非B → 非A
```

# 23. 翻译推理做题顺序

```text
① 找逻辑词
② 写箭头
③ 做逆否
④ 找能传递的链
⑤ 看选项
```

# 24. 翻译推理高频陷阱

```text
只要/只有翻反
肯后误推肯前
否前误推否后
除非翻译错误
或关系理解过窄
且/或否定搞反
```

# 25. 第二大类：集合推理

常见词：

```text
所有
有的
没有
```

---

# 26. “所有A都是B”

翻译：

```text
A → B
```

集合关系：

```text
A包含于B
```

---

# 27. “所有A都不是B”

翻译：

```text
A → 非B
```

即：

```text
A与B不相交
```

---

# 28. “有的A是B”

表示：

```text
至少存在一个
A且B
```

不能推出：

```text
所有A都是B
```

---

# 29. “有的A不是B”

表示：

```text
至少存在一个A
不属于B
```

---

# 30. 母题 06｜所有A都是B + 所有B都是C

可推出：

```text
所有A都是C
```

---

# 31. 母题 07｜有的A是B + 所有B都是C

可推出：

```text
有的A是C
```

---

# 32. 母题 08｜所有A都是B + 有的B是C

不能必然推出：

```text
有的A是C
```

因为：

```text
那个B∩C中的元素
不一定属于A
```

---

# 33. “有的”不可逆滥推

```text
有的A是B
```

可理解为：

```text
A∩B非空
```

因此也可说：

```text
有的B是A
```

但不能扩展为：

```text
所有B都是A
```

---

# 34. 集合推理高频陷阱

```text
所有 + 有的
方向混淆

有的
被误当成所有

部分重合
被误判为包含
```

如果找到一对矛盾：


```text
其余全部为假
```

# 44. 母题 10｜只有一句假

# 46. 第四大类：分析推理

分析推理常见：


---

# 47. 分析推理总原则

```text
信息最大化
```

先用限制最强的信息。

---

# 48. 什么叫限制最强

例如：

```text
A只能在第1或第2
B必须紧挨C
D不能和E同组
```

这类比：

```text
A不在第5
```

限制更强。

---

# 49. 母题 11｜确定信息优先

如：

```text
A一定第3
```

先固定。

---

# 50. 母题 12｜唯一位置

若某人：

```text
只能放一个位置
```

优先落位。

---

# 51. 母题 13｜相邻关系

```text
A和B相邻
```

可捆绑为：

```text
AB
或
BA
```

# 52. 母题 14｜不相邻

重点排：

```text

```

# 53. 母题 15｜前后关系

```text
A在B前
```

```text
顺序在前
```

# 54. 母题 16｜固定间隔

# 59. 分析推理技巧：代入排除

如果题目问：

```text
以下哪项可能成立
```

```text
优先代入选项
```

有时比完整推理更快。

# 60. 分析推理技巧：最大信息法

优先使用：

```text
同时涉及多个对象
限制范围最小
最容易锁定位置
```

的条件。

# 62. 第五大类：加强论证

加强题本质：

```text
让论点更可信
```

---

# 63. 加强题结构

通常：

```text
论据
→ 论点
```

加强就是：

```text
补桥
支持
排除反对
```

---

# 64. 找论点

常见标志：

```text
因此
所以
可见
说明
由此可知
这表明
研究人员认为
专家指出
```

---

# 65. 母题 21｜补充正向论据

原论点：

```text
A有利于B
```

选项：

```text
研究发现A确实提高B
```

属于：

```text
直接支持
```

---

# 66. 母题 22｜建立联系

论据：

```text
A
```

论点：

```text
B
```

中间缺：

```text
A→B
```

加强选项：

```text
把A和B连起来
```

叫：

```text
搭桥
```

---

# 67. 母题 23｜排除他因

如果论点认为：

```text
A导致B
```

加强可说：

```text
没有其他重要因素导致B
```

---

# 68. 母题 24｜增加样本代表性

调查论证中，加强可：

```text
样本随机
样本量大
覆盖全面
```

---

# 69. 母题 25｜实验设计更可靠

加强：

```text

随机分组

重复实验
```

---

# 70. 加强强弱排序

通常：

```text
建立必要联系
直接证明
排除关键他因
```

强于：

```text

```

# 71. 第六大类：削弱论证

削弱题本质：

# 72. 削弱母题总类


# 73. 母题 26｜直接否定论点

论点：


选项：


# 74. 母题 27｜拆桥

论据：

```text
A
```

论点：

```text
B
```

```text

```

---

# 75. 母题 28｜另有他因

论点：

```text

```

选项：


---

# 76. 母题 29｜因果倒置

论点：

```text
A导致B
```

选项：

```text

```

---

# 77. 母题 30｜共同原因

A和B相关：

```text
不一定A导致B
```

可能：

```text
C同时导致A和B
```

---

# 78. 母题 31｜样本偏差

调查结论：

```text
抽样人群不代表总体
```

削弱很强。

---

# 79. 母题 32｜幸存者偏差

只观察：

```text
成功者
留下者
可见者
```

忽略：

```text
失败者
未进入样本者
```

---

# 80. 母题 33｜实验变量未控制

若实验组和对照组除了A：

```text
还有其他差异
```

则不能说明：

```text
结果由A造成
```

---

# 81. 母题 34｜没有对照组

仅观察：

```text
使用A后B提高
```

若无：

```text
未使用A的对照
```

因果结论弱。

---

# 82. 母题 35｜时间先后不等于因果

```text
A发生后
B发生
```

不代表：

```text
A导致B
```

---

# 83. 削弱强弱常见原则

一般：

```text
直接否定核心关系
拆掉必要桥梁
提出强有力他因
```

比：

```text
轻微例外
边缘信息
```

更强。




# 90. 第八大类：解释题

题干常见：



# 92. 解释题原则

```text

```



---

# 96. 母题 40｜A先B后

```text
A发生在B之前
```

```text

```

---

# 97. 母题 41｜剂量效应

```text

```

```text
A与B之间因果关系
```

# 98. 母题 42｜干预实验

如果人为改变：

```text
A
```

导致：

```text
B随之变化
```

# 99. 第十大类：实验论证

# 100. 实验题固定排查

```text

⑤ 测量是否客观？
⑥ 是否重复验证？
```

# 101. 母题 43｜控制变量

```text
只在核心变量A上不同
```

---

# 102. 母题 44｜随机分组

随机：

```text
减少初始差异
```

# 103. 母题 45｜双盲

# 106. 母题 47｜样本代表性

如果调查：

```text
只调查某一特殊群体
```

却推广到：

```text
整个总体
```

结论弱。

主动参与调查的人：

```text
可能与普通人不同
```

```text
可能与回答者系统性不同
```

# 109. 第十二大类：类比论证

结构：

```text
A具有X
B与A相似
所以B也具有X
```

---

# 110. 类比论证关键

看：

```text
相似点是否与结论相关
```

---

# 111. 母题 50｜增加关键相似点

加强：

```text
A和B在与结论直接相关方面相似
```

---

# 112. 母题 51｜指出关键差异

削弱：

```text
A和B在关键机制上不同
```

---

# 113. 第十三大类：评价论证

题干：

```text
以下哪项最有助于评价上述论证？
```

核心：

```text
无论答案是“是”还是“否”
都会显著影响论证强弱
```

---

# 114. 母题 52｜评价关键桥梁

问：

```text
A与B之间是否真的存在关系？
```

如果：

```text
是 → 加强
否 → 削弱
```

则是好评价问题。

---

# 115. 第十四大类：原因解释

有时题目问：

```text
造成现象的原因是什么
```

注意：

```text
解释原因
≠ 加强原论点
```

要直接解决：

```text
为什么出现这个现象
```

---

# 116. 加强 / 削弱 / 前提 / 解释辨析

```text
加强：
让结论更可信

削弱：
让结论更不可信

前提：
论证成立不可缺

解释：
让矛盾现象变得合理
```

# 117. 论证题总解题顺序

```text
① 找论点
② 找论据
③ 找论据到论点的缺口
④ 判断问加强/削弱/前提/解释
⑤ 比较选项作用位置
```

```text
作者认为
```

# 121. 论证缺口

高频缺口：

```text
A相关 → A导致B
局部样本 → 总体结论
个别案例 → 普遍规律
指标X → 概念Y
短期效果 → 长期效果
动物实验 → 人类结论
相关群体 → 目标群体
```

---

# 122. 高频论证错误 01｜相关当因果

```text
A与B同时变化
```

不能直接推出：

```text
A导致B
```

---

# 123. 高频论证错误 02｜因果倒置

可能：

```text
B导致A
```

---

# 124. 高频论证错误 03｜另有他因

可能：

```text
C导致B
```

---

# 125. 高频论证错误 04｜共同原因

可能：

```text
C同时导致A和B
```

---

# 126. 高频论证错误 05｜以偏概全

小样本：

```text
推整个总体
```

---

# 127. 高频论证错误 06｜样本偏差

样本：

```text
不是随机
不具代表性
```

---

# 128. 高频论证错误 07｜概念偷换

论据讲：

```text
满意度
```

论点变成：

```text
工作效率
```

中间缺桥。

---

# 129. 高频论证错误 08｜指标替代

用：

```text
某个代理指标
```

直接代表：

```text
目标概念
```

要检查代理是否可靠。

# 130. 高频论证错误 09｜实验无对照

只看到：

```text
实验后变化
```

不能确定：

```text
是实验变量造成
```

---

# 131. 高频论证错误 10｜短期推长期

短期：

```text
有效
```

不代表：

```text
长期也有效
```

---

# 132. 高频论证错误 11｜动物推人

动物实验：

```text
不能直接无条件推广到人
```

需要：

```text
机制相似
或人类验证
```

---

# 133. 高频论证错误 12｜个例推普遍

```text
一个成功案例
```

不能直接证明：

```text
所有情况下都有效
```

# 134. 高频论证错误 13｜幸存者偏差

只看：

```text
留下来的成功者
```

忽略：

```text
失败者
```

---

# 135. 高频论证错误 14｜选择性数据

只选：

```text
支持结论的数据
```

忽略：

```text
反例
```

---

# 136. 高频论证错误 15｜自我选择

例如：

```text
主动健身的人更健康
```

不能直接说明：

```text
健身项目本身造成全部差异
```

因为主动选择者可能本来就不同。

# 137. 加强选项强度排序参考

通常：

```text
直接建立论据-论点联系
> 排除关键他因
> 补充正向证据
> 弱相关背景
```

---

# 138. 削弱选项强度排序参考

通常：

```text
直接否定核心关系
> 拆桥
> 强有力另有他因/因果倒置
> 样本实验重大缺陷
> 一般反例
> 无关信息
```

---

# 139. 前提题否定代入法

看到选项：

```text
X
```

把它改成：

```text
非X
```

如果论证：

```text
完全无法成立
```

则：

```text
X很可能是必要前提
```

# 144. 逻辑判断高频陷阱一页版

```text
□ 只要A就B：A→B
□ 只有A才B：B→A
□ A→B只能推出非B→非A
□ 肯后不能肯前
□ 否前不能否后
□ 所有A是B不等于所有B是A
□ 有的不能扩大成所有
□ 真假题先找矛盾
□ 分析题先用限制最强条件
□ 加强看是否真正支持论点
□ 削弱看是否打到核心
□ 相关不等于因果
□ 前提题用否定代入
□ 调查看样本代表性
□ 实验看对照和控制变量
□ 类比看关键相似点
```
