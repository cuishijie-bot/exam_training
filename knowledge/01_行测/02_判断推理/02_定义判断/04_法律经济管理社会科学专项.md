# 1. 专业定义第一原则

```text
题干定义
>
你原本知道的知识
```

即使现实中：

```text
某专业概念定义更复杂
```

考试仍然：

```text
以题干为准
```

---

# 2. 专业定义第二原则

看到陌生术语：

```text
先删术语名称
```

把定义当成：

```text
一个“谁在什么条件下做什么”的普通文本
```

---

# 3. 陌生术语消除法

题目：

```text
“X效应是指……”
```

脑中改成：

```text
“某现象是指……”
```

只看后面。

---

# 4. 专业定义第三原则

不要先问：

```text
“这个概念我学没学过？”
```

先问：

```text
“定义给了哪些必要条件？”
```


# 48. 心理学定义总模型

```text

→ 心理机制
→ 认知/情绪变化
→ 行为结果
```

---

# 49. 心理题第一原则

不要看：

```text
“行为像不像”
```

要看：

```text
“为什么发生”
```

---

# 50. 心理题第二原则

很多错误项会：

```text
复制同样表面行为
```

但：

```text
触发机制不同
```

---

# 51. 心理类母题01｜从众

结构：

```text
群体多数意见
→ 个体受到压力/认同影响
→ 改变原判断/行为
```

---

# 52. 从众错误项

```text
因为新证据更充分而改变观点
```

不属于从众。

---

# 53. 心理类母题02｜锚定

结构：

```text
先接触某初始信息
→ 后续判断受初始信息影响
```

---

# 54. 锚定错误项

```text
经过完整重新计算得出结论
```

```text
不符合
```

# 146. 最终20条极简版

```text
1. 专业定义不等于专业知识题
2. 陌生术语先把名称删掉再看定义
3. 题干定义优先于现实专业知识
4. 法律类先看主体资格
5. 法律类再看权限、主观状态和后果
6. 严重结果不能反推故意
7. 经济类先看市场主体
8. 同样降价可能对应完全不同经济目的
9. 管理类先看组织关系
10. 管理类重点看手段与目标
11. 心理类最重要的是机制，不是表面行为
12. 从众必须有群体影响
13. 锚定必须有初始信息影响后续判断
14. 社会类要看角色、规范和群体关系
15. 传播类用“谁说啥、通过啥、给谁、影响啥”
16. 生态类重点看双方得失关系
17. 科技类重点看流程顺序和结果
18. 专业题错项常常“表面像、机制不同”
19. 不要用背景知识自行补条件
20. 专业定义核心=翻译术语+拆机制+核必要要件
```
