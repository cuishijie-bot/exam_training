# 0. 八大要件专项总地图

```text
定义判断
│
├─ 1. 主体
├─ 2. 客体
├─ 3. 行为
├─ 4. 条件
├─ 5. 目的
├─ 6. 动机
├─ 7. 结果
└─ 8. 性质
```

优先级通常：

```text
强主体
>
强条件
>
目的/结果
>
行为方式
>
性质
```

不是绝对，
但考场可作为第一排查顺序。

```text
谁做
```

# 3. 主体最强判断法

定义若写：

```text
“由某类主体实施”
```

先扫四个选项：

```text
谁不是这个主体
```

通常能快速排除。

---

# 4. 主体偷换母题

定义：

```text
消费者……
```

选项：

```text
商家……
```

即使行为形式一致：

```text
主体不同
→ 排
```

---

# 5. 主体资格陷阱

定义：

```text
国家工作人员利用职务便利……
```

选项：

```text
普通公司职员利用工作便利……
```

“工作便利”：

```text
≠ 职务便利
```

“普通公司职员”：

```text
≠ 国家工作人员
```

---

# 6. 主体范围扩大

定义：

```text
特定行业从业人员
```

选项：

```text
任何社会公众
```

通常：

```text
范围扩大
```

---

# 7. 主体范围缩小

定义：

```text
自然人或法人
```

选项仅出现：

```text
自然人
```

不一定错。

关键：

```text
是否仍属于定义允许范围
```

---

# 8. 主体身份与行为能力

有些定义不仅看：

```text
是不是某类人
```

还看：

```text
是否具备相应资格/权限
```

---

# 9. 权限型主体

例如：

```text
“有权作出行政决定的机关”
```

选项：

```text
无决定权的内部部门
```

可能不符。



```text

```

# 15. 客体属性

有些定义要求对象具有：

```text
特定属性
```

```text
“尚未公开的信息”
```

若选项对象已经公开：

```text
客体属性不符
```

# 16. 客体状态


# 17. 客体数量

定义可能限定：

```text

```

数量也是客体条件。

# 18. 客体与结果不要混

例如：

```text
对他人财产实施行为
→ 客体是“财产”

导致财产损失
→ 结果是“损失”
```

# 21. 行为方式偷换

定义：

```text
通过欺骗方式
```

```text
通过公开协商
```

行为结果类似也不行。

---

# 22. 行为“主动/被动”

定义：

```text
主动实施
```

选项：

```text
被迫接受
```

性质与行为方向不符。

---

# 23. 行为“直接/间接”

定义：

```text
直接影响
```

选项：

```text
先影响第三方
再间接产生结果
```

要警惕。

---

# 24. 行为“作为/不作为”

法律类高频：

```text
主动做了什么
```

和：

```text
本应做但没有做
```

是不同机制。

---

# 25. 行为“单次/持续”

定义要求：

```text
持续实施
反复出现
```

选项：

```text
一次偶发
```

可能不符。

---

# 26. 行为顺序

定义：

```text
先A后B
```

选项：

```text
先B后A
```

即使都有A、B：

```text
也可能不符
```

---

# 27. 行为数量

定义：

```text
反复实施3次以上
```

选项：

```text
只发生一次
```

直接排。

---

# 28. 行为与目的关系

同一行为：

```text
可能服务不同目的
```

所以不能：

```text
只看动作一样
```

---

# 39. 条件和原因区别

条件：

```text
概念成立的前提
```

原因：

```text
行为为什么发生
```

---

# 40. 示例

定义：

```text
在高压力环境下，
个体因为害怕失败而放弃尝试。
```

可以拆：

```text
条件：
高压力环境

动机/原因：
害怕失败

行为：
放弃尝试
```

---

# 41. 条件和方式区别

条件：

```text
在什么情况下
```

方式：

```text
通过什么手段
```

---

# 42. 示例

```text
在未经授权情况下
通过复制方式
获取利益
```

对应：

```text
条件 = 未经授权
方式 = 复制
目的 = 获利
```

---

# 43. 目的：想实现什么结果

目的回答：

```text
“为了什么”
```

---

# 44. 目的信号词

```text
为了
旨在
以……为目的
意图
企图
用于
试图
```

---

# 45. 目的偷换

定义：

```text
为了排挤竞争对手
```

选项：

```text
为了清理库存
```

即使都：

```text
低价销售
```

也不一定属于同一概念。

---

# 46. 目的与结果不同

目的：

```text
行为发生前想实现什么
```

结果：

```text
行为之后实际发生什么
```

---

# 47. 示例

某人：

```text
为了提升销量降价
```

结果：

```text
竞争对手退出市场
```

不能反推：

```text
其目的必然是排挤竞争对手
```

---

# 48. 目的不可由结果强推

这是高频陷阱。

---

# 49. 目的可以从材料推断吗

可以，

但前提：

```text
语境明确
```

---

# 50. 目的不可脑补

如果选项只是：

```text
“某人做了A”
```

却没写：

```text
为什么做
```

除非语境唯一，

否则：

```text
不要擅自补目的
```

---

# 51. 动机：为什么想这么做

动机回答：

```text
“为什么产生这个目的”
```

---

# 52. 目的和动机关系

例：

```text
动机：
害怕失去市场

目的：
排挤竞争对手

行为：
低价销售
```

# 53. 动机常见于

# 55. 动机偷换

定义：

```text
因为追求群体认同而改变行为
```

选项：

```text
因为掌握了新证据而改变行为
```

表面都是：

```text
改变行为
```

机制不同。

# 56. 结果：最后发生了什么

```text

```

# 58. 实际结果 vs 可能结果

定义：

```text
造成损害
```

选项：

```text
存在损害风险
```

不一定符合。

---

# 59. 可能结果型定义

如果定义说：

```text
“可能导致……”
```

那：

```text
无需实际造成
```

---

# 60. 结果程度

定义可能要求：

```text

严重
明显
持续
```

这些词不能删。

---

# 61. 结果对象

有时结果针对：

```text
个人
组织
市场
社会
生态
```

结果对象也要核对。

---

# 62. 结果与目的相反

有人：

```text
为了帮助别人
```

却：

```text
造成损失
```

仍不能因此说：

```text
目的就是造成损失
```

```text

```

```text
自愿

```

# 79. 主体+条件组合题

定义：

```text
特定工作人员
在利用职务便利情况下

```

```text

再职务便利
```

---

# 80. 主体+目的组合题

定义：

```text
经营者
为了排挤竞争者
实施……
```

先看：

```text
经营者？
```

再看：

```text
排挤目的？
```

---

# 81. 条件+行为组合题

定义：

```text

```

先看：

```text
是否未经同意
```

再看：

```text
是否公开
```

---

# 82. 行为+结果组合题

定义：

```text

造成B结果
```

```text

```

---

# 83. 目的+结果组合题

定义：

```text

并造成B结果
```

不能：

```text
只有目的
没有结果
```

---

# 84. 条件+目的+行为三要件

压成：

```text

+ 目的
+ 行为
```

# 85. 一票否决法

所谓：

```text
一票否决
```

```text

```

# 86. 最适合一票否决的要件

# 87. 不宜直接一票否决的词


# 88. 一票否决顺序建议


# 89. 为什么先看否定词

因为：

```text

与
“经同意”
```

可能直接决定生死。

# 90. 为什么主体优先

主体错：

```text
后面全不用看
```

---

# 91. 为什么目的靠前

目的往往是：

```text
相似行为之间最核心区分点
```

---

# 92. 为什么行为不一定第一

因为四个选项常常：

```text
都在做类似行为
```

真正区别藏在：

```text
条件/目的/性质
```

---

# 93. “行为像”陷阱

这是定义判断第一大错觉：

```text
“看起来很像”
```

但可能：

```text
主体错
目的错
条件错
```

---

# 94. “结果像”陷阱

同样结果：

```text
可能由不同机制产生
```

所以：

```text
结果相同
≠ 定义相同
```

---

# 95. “目的像”陷阱

目的相同：

```text
行为方式可能不满足定义
```

---

# 96. “主体像”陷阱

同样是企业，

但定义可能只限：

```text
生产企业
```

选项是：

```text
销售平台
```

仍可能不符。


# 101. 示例02｜客体秒杀

定义：

```text
保护的是尚未公开的商业信息。
```

# 158. 最终20条极简版

```text
1. 主体回答“谁做”
2. 客体回答“对谁/对什么做”
3. 行为回答“做什么”
4. 条件回答“什么情况下”
5. 目的回答“为了什么”
6. 动机回答“为什么想这么做”
7. 结果回答“最后发生什么”
8. 性质看自愿/强制、直接/间接等属性
9. 主体资格错可以直接排
10. 客体属性错也可直接排
11. “未经授权”与“已获授权”是典型一票否决
12. 行为相似不等于概念相同
13. 目的不同可区分相似行为
14. 严重结果不能反推主观故意
15. 实际结果和可能风险要区分
16. 自愿与被迫不能混
17. 直接与间接不能混
18. 故意与过失要看主观状态
19. 难题最后往往只差一个隐藏要件
20. 本专项核心=找到那个“一票否决”的边界条件
```
