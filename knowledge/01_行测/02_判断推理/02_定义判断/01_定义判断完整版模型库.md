# 国考 / 辽宁省考完整版知识库｜定义判断完整版模型库

> 所属模块：
>
> ```text
> 行测
> → 判断推理
> → 定义判断
> ```
>
> 本文件定位：
>
> ```text
> 建立定义判断总框架
> ```
>
> 目标：
>
> ```text
> 看到定义
> ↓
> 抓核心要件
> ↓
> 判断必要条件
> ↓
> 对照选项
> ↓
> 用最小排除法快速锁定
> ```
>
> 核心原则：
>
> ```text
> 定义判断不是“凭感觉像不像”
> 而是：
> 看选项是否满足定义要件
> ```

# 0. 定义判断总地图

```text
定义判断
│
├─ A. 单定义
│  ├─ 主体
│  ├─ 客体
│  ├─ 行为
│  ├─ 条件
│  ├─ 目的
│  ├─ 结果
│  └─ 性质
│
├─ B. 多定义
│  ├─ 定义A
│  ├─ 定义B
│  ├─ 定义C
│  └─ 分类匹配
│
├─ C. 常见学科
│  ├─ 法律
│  ├─ 经济
│  ├─ 管理
│  ├─ 社会学
│  ├─ 心理学
│  ├─ 传播学
│  └─ 生态/科技
│
└─ D. 常见陷阱
   ├─ 主体偷换
   ├─ 条件缺失
   ├─ 目的不符
   ├─ 结果不符
   ├─ 范围扩大
   ├─ 因果倒置
   └─ 相似概念混淆
```

---

# 1. 定义判断第一句话

```text
先拆定义
再看选项
```

不要反过来。

---

# 2. 为什么不能先看选项

先看选项容易：

```text
被故事带着走
```

定义判断真正考的是：

```text
概念边界
```

---

# 3. 定义判断四步法

```text
第一步：
标关键词

第二步：
拆要件

第三步：
找必要条件

第四步：
对照排除
```

---

# 4. 最核心的“要件模型”

任何定义都优先拆：

```text
谁
→ 主体

对谁/对什么
→ 客体

做什么
→ 行为

在什么情况下
→ 条件

为什么做
→ 目的

产生什么
→ 结果

具有何种性质
→ 性质
```

---

# 5. 七要件口诀

```text
主
客
行
条
目
果
性
```

即：

```text
主体
客体
行为
条件
目的
结果
性质
```

---

# 6. 并不是每道题都有七个要件

有的定义只有：

```text
主体 + 行为
```

有的只有：

```text
条件 + 结果
```

所以：

```text
只抓题目真正限制范围的要件
```

---

# 7. 主体

主体回答：

```text
谁可以实施这个行为？
```

例如：

```text
行政机关
消费者
劳动者
企业
国家机关
组织成员
个人
```

---

# 8. 主体陷阱

定义要求：

```text
国家机关工作人员
```

选项却是：

```text
普通企业员工
```

直接排除。

```text

是指……主体
```

# 10. 客体


```text

```

```text
针对消费者个人信息
```

```text
针对企业商业秘密
```

即使行为类似：

```text
也不符合
```

# 13. 行为陷阱

```text
主动实施
```

```text

```

可能直接不符。

---

# 14. 条件

条件通常是：

```text
在……情况下
当……
基于……
未经……
通过……
由于……
```

---

# 15. 条件是高频必要要件

例如：

```text
“在未经本人同意的情况下公开其个人信息”
```

如果选项中：

```text
本人已明确同意
```

就不符合。

---

# 16. 目的

目的信号：

```text
为了……
以……为目的
旨在……
意图……
用于……
```

---

# 17. 目的陷阱

定义：

```text
为了获得不正当利益
```

选项：

```text
为了公益救助
```

行为形式可能相似，

但：

```text
目的不同
```

---

# 18. 结果

结果信号：

```text
导致……
造成……
从而……
使……
结果是……
```

---

# 19. 结果陷阱

定义要求：

```text
造成实际损害
```

选项只有：

```text
存在风险
但尚未造成后果
```

是否符合：

```text
取决于定义是否要求“实际结果”
```

# 25. “只要像”不够

选项可能：

```text
很像这个概念
```

但缺一个关键必要条件，

仍然：

```text
不符合
```

# 26. 定义判断的底层逻辑

可以理解为：

```text
定义
=
若干条件的交集
```

例如：

```text
A
且
B
且
C
```

选项要：

```text
至少满足所有必要条件
```

---

# 27. 形式化表达

若定义要求：

```text
主体A
+
条件B
+
行为C
```

那么：

```text
A ∧ B ∧ C
```

才成立。

# 28. 选项排除逻辑

```text
缺A
→ 排

缺B
→ 排

缺C
→ 排
```

# 29. 定义判断最优策略

不是：

```text
证明正确项多正确
```

而是：

```text
快速找错误项缺哪个要件
```


# 32. 多定义题

题干给：

```text
定义1
定义2
定义3
```

再问：

```text
哪个选项对应哪个定义
```

---

# 33. 多定义第一原则

不要一次记全部定义。

先：

```text
抓每个定义最有区分度的关键词
```

---

# 34. 多定义压缩法

例如：

```text
A：
强调“内部”
B：
强调“外部”
C：
强调“双方”
```

只记：

```text
内
外
双
```

---

# 35. 多定义第二原则

先看：

```text
差异点
```

不是共同点。

---

# 36. 多定义高频陷阱

三个定义可能都有：

```text
“影响他人”
```

但真正区别是：

```text
是否有直接接触
是否有利益交换
是否经过第三方
```

---

# 37. 正向题


```text
找全符合
```

# 38. 反向题

# 39. 反向题最大陷阱

```text

```

# 40. 反向题操作

```text

```

```text

```

# 41. 题干很长怎么办

# 43. 定义判断里的“属概念”

有些定义：

```text

```



```text

```

```text
法律行为
```

# 147. 最终20条极简版

```text
1. 定义判断不是凭感觉，而是核对要件
2. 先拆定义，再看选项
3. 七要件：主客行条目果性
4. 不必每题都凑齐七要件
5. 先抓最限制范围的条件
6. 主体限制强时优先看主体
7. “未经、必须、只有”是强条件
8. “为了、旨在”抓目的
9. “导致、造成、形成”抓结果
10. 自愿/强制、有偿/无偿是高频性质
11. 缺一个必要条件就可以排除
12. 正确项不必最典型，只要满足定义
13. 多定义先找差异点，不找共同点
14. 心理题看机制，不只看表面现象
15. 法律题按题干定义，不凭生活常识
16. 经济题抓主体、交易和效果
17. 反向题一定圈“不属于”
18. 错题要写“错误项缺哪个要件”
19. 1分钟仍抓不到区分点就先跳
20. 定义判断核心=关键词+必要条件+快速排除
```
