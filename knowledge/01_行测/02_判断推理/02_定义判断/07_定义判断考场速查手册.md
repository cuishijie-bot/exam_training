# 0. 定义判断一句话本质

```text
定义判断
=
要件匹配
```

不是：

```text
生活常识判断
```

---

# 1. 第一原则

```text
先读定义
再看选项
```

---

# 2. 第二原则

```text
题干定义
>
你自己的常识
```

---

# 3. 第三原则

```text
缺一个关键必要条件
→ 直接排除
```

# 5. 5秒识别

看到：

```text
“根据上述定义”
“属于”
“不属于”
“最符合”
“最不符合”
```

立刻进入：

```text
定义判断模式
```

---

# 6. 10秒拆定义

只问：

```text
谁
对谁
在什么情况下
做什么
为了什么
产生什么结果
有什么性质
```

---

# 7. 最常用压缩模板

```text
主体
+
条件
+
行为
+
目的
+
结果
```

没有的：

```text
不硬补
```

---

# 8. 长定义压缩

看到100字定义：

```text
先删：
背景
出处
评价
举例

再留：
限制词
必要条件
```

---

# 9. 强限制词

优先圈：

```text
必须
只有
未经
仅
不得
至少
长期
持续
特定
直接
自愿
故意
```

---

# 10. 弱限制词

谨慎：

```text
通常
往往
一般
可能
例如
常见
```

它们通常：

```text
不是硬门槛
```

---

# 11. 否定词

必圈：

```text
不
未
未经
非
无
不得
不包括
除外
```

---

# 12. 反向题

题干问：

```text
“不属于”
```

草稿写：

```text
NOT
```

防选反。

---

# 13. 一票否决顺序

优先看：

```text
否定
→ 主体
→ 数量/时间
→ 条件
→ 目的
→ 结果
→ 行为
→ 性质
```

---

# 14. 为什么主体优先

主体不对：

```text
后面都不用看
```

---

# 15. 为什么条件优先

定义判断最爱藏：

```text
未经
必须
至少
长期
特定情况下
```

---

# 16. 为什么目的重要

四个选项行为可能：

```text
都很像
```

真正区别可能只是：

```text
为什么做
```

---

# 17. 行为像 ≠ 定义相同

例如：

```text
都是低价销售
```

但目的可能：

```text
清库存
促销
回笼资金
排挤竞争对手
```

---

# 18. 结果严重 ≠ 故意

必须记：

```text
严重后果
不能反推故意
```

要看：

```text
明知
希望
放任
```

---

# 19. 实际结果 vs 可能结果

```text
造成
≠
可能造成
```

```text
已经形成
≠
有形成风险
```

---

# 20. 自愿 vs 强制

定义：

```text
自主选择
```

选项：

```text
被要求
被迫
不得不
```

通常不符。

---

# 21. 主动 vs 被动

定义：

```text
主动搜集
```

选项：

```text
被动收到
```

不同。

---

# 22. 直接 vs 间接

定义：

```text
直接影响
```

选项：

```text
先影响第三方
再产生影响
```

警惕。

---

# 23. 有偿 vs 无偿

定义：

```text
无偿
```

选项：

```text
获得对价
交换利益
```

不符。

---

# 24. 故意 vs 过失

故意：

```text
明知
希望
放任
```

过失：

```text
疏忽
大意
轻信能够避免
```

---

# 25. 且 / 或

```text
A且B
→ 都要满足

A或B
→ 满足一个即可
```

---

# 26. 并列词

看到：

```text
同时
并且
以及
```

检查：

```text
是否全部必要
```

---

# 27. 因果

```text
A导致B
≠
B导致A
```

---

# 28. 时间顺序

```text
先A后B
≠
先B后A
```

---

# 29. 数量条件

看到：

```text
至少
超过
两个以上
多次
```

不要漏。

---

# 30. 时间条件

看到：

```text
长期
持续
反复
短期
事前
事后
```

不要删。

---

# 31. 程度条件

看到：

```text
显著
严重
明显
持续
```

可能是必要条件。

---

# 32. “包括”与“仅包括”

```text
包括
→ 未必穷尽

仅包括
→ 范围封闭
```

---

# 33. “等”

```text
A、B、C等
```

说明：

```text
列举未穷尽
```

---

# 34. “例如”

只是：

```text
举例
```

不是：

```text
全部定义
```

---

# 35. “不包括”

即使前面都符合：

```text
落入排除项
→ 仍不属于
```

---

# 36. 多定义题

不要全背。

只记：

```text
每个定义最有区分度的词
```

---

# 37. 多定义标签法

例如：

```text
A = 主动
B = 被动
C = 双向
```

脑中只留：

```text
主 / 被 / 双
```

# 83. 最终10条

```text
1. 定义判断=要件匹配
2. 七要件：主客行条目果性
3. 先抓强限制，不必全文死记
4. 未经/必须/只有是高价值词
5. 行为像不代表定义相同
6. 二选一只找唯一差异要件
7. 心理题看机制，法律题看主体权限
8. 多定义只记差异标签
9. 反向题一定圈“不”
10. 缺一个关键必要条件就排
```
