>
> ```text

> ↓

# 0. 定义拆解总地图

```text
定义文本
│
├─ 1. 大类/属概念
├─ 2. 主体
├─ 3. 客体
├─ 4. 行为
├─ 5. 条件
├─ 6. 目的
├─ 7. 结果
├─ 8. 性质
├─ 9. 排除项
└─ 10. 修饰信息
```

最终不是全记。

而是压成：

```text
最小充分识别框架
```

---

# 1. 最终目标：把定义压成“判定式”

例如长定义：

```text
某行为是指特定主体在未经权利人许可的情况下，
以获取利益为目的，
通过复制、传播等方式使用特定内容的行为。
```

不要记整句。

压成：

```text
特定主体
+ 未经许可
+ 复制/传播
+ 获利目的
```

---

# 2. 什么叫“判定式”

判定式就是：

```text
这个概念成立
最少需要哪些关键条件
```

例如：

```text
A主体
∧ B条件
∧ C行为
∧ D目的
```

---

# 3. 定义拆解三步

```text
第一步：
删掉解释性、背景性内容

第二步：
圈限制词

第三步：
重写成短要件
```

---

# 4. 第一步：先找中心句

定义中最核心通常在：

```text
“是指……”
“是……的一种……”
“指的是……”
“所谓……是……”
```

---

# 5. 中心句前面的内容

有时是：

```text
背景
来源
学者观点
现象说明
```

不一定是定义要件。

---

# 6. 中心句后面的内容

可能包含：

```text
定义本体
举例
补充说明
例外
```

必须分清。

---

# 7. 高频“不是核心要件”的信息

```text
历史背景
学术来源
提出者
概念产生年代
研究意义
现象举例
评价性描述
```

---

# 8. 例子不能代替定义

题干：

```text
例如……
比如……
典型表现是……
```

这些用于：

```text
帮助理解
```

不是：

```text
全部边界
```

---

# 9. 举例陷阱

定义说：

```text
可通过A、B、C等方式实现
```

选项用：

```text
D方式
```

只要：

```text
仍满足本质要件
```

可能仍符合。

---

# 10. 第二步：圈“强限制词”

强限制词通常决定：

```text
选项生死
```

---

# 11. 强限制词01｜主体限制

```text
由……
主体是……
特定主体……
仅限于……
```

---

# 12. 强限制词02｜条件限制

```text
在……情况下
未经……
基于……
必须……
只有……
当……
```

---

# 13. 强限制词03｜目的限制

```text
为了……
旨在……
以……为目的
意图……
```

---

# 14. 强限制词04｜结果限制

```text
造成……
导致……
形成……
使……
从而……
```

---

# 15. 强限制词05｜范围限制

```text
仅
只
特定
一定范围内
非……
不包括……
除……外
```

---

# 16. 强限制词06｜性质限制

```text
主动
被动
自愿
强制
有偿
无偿
公开
秘密
直接
间接
持续
临时
```

---

# 17. 第三步：判断“必要条件”

问自己：

```text
如果这个条件没有，
概念还成立吗？
```

如果：

```text
不成立
```

就是：

```text
必要条件
```

---

# 18. 必要条件测试

例如：

```text
“未经本人同意”
```

问：

```text
如果本人同意了，
还能叫这个定义吗？
```

如果不能：

```text
这是必要条件
```

---

# 19. 非必要条件测试

定义举例：

```text
常见于网络平台
```

问：

```text
发生在线下还能成立吗？
```

如果能：

```text
“网络平台”不是必要条件
```

---

# 20. “常见”不是“必须”

高频词：

```text
通常
常见
往往
一般
多见
主要
```

往往只是：

```text
倾向
```

不是绝对限制。

---

# 21. “必须”才是强条件

```text
必须
只能
仅限
不得
只有
未经
```

优先级很高。

---

# 22. “可以”与“必须”区别

```text
可以
→ 允许，不代表必要

必须
→ 缺失即不成立
```

---

# 23. “包括”与“仅包括”

```text
包括A、B
```

可能：

```text
还有其他
```

---

# 24. “仅包括”

```text
范围封闭
```

不能扩展。

---

# 25. “等”字判断

```text
A、B、C等
```

说明：

```text
列举未穷尽
```

---

# 26. “即”字判断

```text
即……
```

往往是：

```text
解释/同义改写
```

注意不要重复记两遍。

---

# 27. “也就是说”

通常：

```text
换句话解释
```

不是新增要件。

---

# 28. “同时”

高频：

```text
A，同时B
```

通常：

```text
A和B都要满足
```

---

# 29. “或者”

```text
A或者B
```

通常：

```text
满足其一即可
```

---

# 30. “以及”

通常：

```text
并列
```

但要看语义是否都必须。

---

# 31. 并列关系

定义：

```text
A、B、C
```

可能有两种：

```text
① 三个都必须
② 三种类型任选其一
```

必须看连接词。

---

# 32. 并列全部必要

例：

```text
主体具有A、B、C特征
```

往往：

```text
A∧B∧C
```

---

# 33. 并列任选

例：

```text
通过购买、租赁、交换等方式
```

这里：

```text
方式任选
```

---

# 34. 如何判断并列是“且”还是“或”

看它描述的是：

```text
同一对象的多个属性
→ 常为“且”

多个实现方式
→ 常为“或”
```

---

# 35. 递进关系

```text
不仅A
而且B
```

通常：

```text
A+B
```

B往往更关键。

---

# 36. 转折关系

```text
虽然A
但是B
```

定义核心常在：

```text
B
```

---

# 37. 条件关系

```text
只有A才B
```

说明：

```text
A是必要条件
```

---

# 38. 条件关系02

```text
只要A就B
```

说明：

```text
A是充分条件
```

在定义判断中：

```text
仍要严格按题干语义
```

---

# 39. 因果关系

```text
由于A
导致B
```

要保留：

```text
A→B
```

---

# 40. 因果陷阱

选项：

```text
B导致A
```

即使A、B都出现：

```text
仍不符
```

---

# 41. 时间顺序

```text
先A
后B
```

也可能是定义要件。

---

# 42. 高频时间词

```text
先……
再……
之后……
事前……
事后……
持续……
短期……
长期……
```

---

# 43. 过程型定义

有些定义强调：

```text
过程
```

例如：

```text
A
→ B
→ C
```

不能只看：

```text
最终结果
```

---

# 44. 过程型题拆法

压成：

```text
起点
→ 关键行为
→ 结果
```

---

# 45. 状态型定义

有些定义不是行为，

而是：

```text
一种状态/关系
```

---

# 46. 状态型要件

重点：

```text
对象
关系
程度
持续性
```

---

# 47. 关系型定义

例如：

```text
两个主体之间
形成某种稳定关系
```

重点：

```text
双方是谁
关系怎么形成
是否稳定
```

---

# 48. 行为型定义

重点：

```text
谁
做什么
为什么
在什么情况下
```

---

# 49. 结果型定义

重点：

```text
什么原因
造成什么结果
```

---

# 50. 机制型定义

常见于：

```text
心理学
管理学
传播学
```

重点：

```text
为什么会出现这个现象
```

---

# 51. 机制型拆法

不要压成：

```text
“表现像”
```

要压：

```text
触发条件
→ 心理/组织机制
→ 行为结果
```

---

# 52. 心理效应例

长定义可能说：

```text
个体因先接收到某信息，
使后续判断受到该初始信息影响……
```

压成：

```text
先有信息
→ 形成锚点
→ 后续判断受影响
```

---

# 53. 法律定义拆法

通常优先：

```text
主体资格
行为对象
主观状态
行为方式
法律后果
```

---

# 54. 法律题强限制词

```text
故意
过失
明知
未经
非法
无权
依法
应当
不得
```

---

# 55. 经济定义拆法

优先：

```text
谁交易
交易什么
通过什么机制
产生什么经济结果
```

---

# 56. 管理学定义拆法

优先：

```text
组织主体
管理对象
管理手段
管理目标
```

---

# 57. 传播学定义拆法

优先：

```text
传播者
信息
媒介
受众
效果
```

---

# 58. 社会学定义拆法

优先：

```text
群体
关系
规则
互动
认同
```

---

# 59. 科技定义拆法

优先：

```text
条件
过程
结果
```

不用提前懂术语。

---

# 60. 生态定义拆法

优先：

```text
对象
环境条件
相互作用
结果
```

---

# 61. 长定义压缩法01｜删除修饰语

原句：

```text
在现代复杂社会关系背景下，
部分组织为了提高自身管理效率，
会通过……
```

先删：

```text
在现代复杂社会关系背景下
```

如果它不限制定义边界。

---

# 62. 压缩法02｜同义合并

原文：

```text
主动、自觉、自发地
```

如果三者表达同一核心：

```text
主动
```

即可。

---

# 63. 压缩法03｜动作名词化

```text
“通过不断收集、分析并使用相关信息”
```

压：

```text
收集并利用信息
```

---

# 64. 压缩法04｜例子抽象化

原文：

```text
如短信、邮件、社交软件等
```

压：

```text
信息媒介
```

---

# 65. 压缩法05｜程度词保留

如果定义强调：

```text
严重
持续
明显
反复
```

不要删。

这些可能是：

```text
程度要件
```

---

# 66. 压缩法06｜否定词绝不删

```text
不
未
未经
非
无
不得
```

一律保留。

---

# 67. 压缩法07｜时间词不要误删

例如：

```text
持续6个月以上
```

如果定义明确：

```text
时间是必要条件
```

必须保留。

---

# 68. 压缩法08｜数量条件

例如：

```text
两个以上
超过50%
至少三次
```

属于：

```text
硬条件
```

必须保留。

---

# 69. 数量条件陷阱

定义：

```text
至少3次
```

选项：

```text
2次
```

直接排。

---

# 70. 程度条件陷阱

定义：

```text
显著影响
```

选项：

```text
几乎没有影响
```

可能不符。

---

# 71. 频率条件

```text
反复
持续
经常
长期
```

与：

```text
一次
偶发
短暂
```

要区分。

---

# 72. 空间范围条件

```text
同一区域
跨区域
组织内部
公开场所
特定市场
```

都可能是必要条件。

---

# 73. 身份范围条件

```text
未成年人
消费者
劳动者
管理人员
国家工作人员
```

不能偷换。

---

# 74. “普通人也能做”陷阱

即使普通人也能实施相同行为，

如果定义主体要求：

```text
特定身份
```

仍不属于。

---

# 75. 目的要件怎么判断真假

有些选项：

```text
没有直接写目的
```

但从行为可推。

---

# 76. 可以推断目的的情况

选项明确：

```text
行为和语境唯一指向某目的
```

可以合理推断。

---

# 77. 不可强推目的

如果：

```text
存在多个可能目的
```

不要自己脑补。

---

# 78. 结果要件怎么判断

区分：

```text
实际发生
vs
可能发生
```

---

# 79. 高频词

实际：

```text
造成
导致
已经
形成
```

可能：

```text
可能
容易
存在风险
可能导致
```

---

# 80. 定义要求“可能”时

选项不必：

```text
真的造成结果
```

---

# 81. 定义要求“实际结果”时

仅有风险：

```text
通常不够
```

---

# 82. 主观状态要件

法律/心理题常见：

```text
明知
故意
希望
放任
误以为
疏忽
```

---

# 83. 主观状态不能用结果代替

造成严重结果：

```text
不等于一定故意
```

---

# 84. 目的与动机区别

```text
目的
= 想实现什么结果

动机
= 为什么想这么做
```

题干写哪个：

```text
就看哪个
```

---

# 85. 行为与结果区别

```text
行为
= 做了什么

结果
= 做完后发生什么
```

---

# 86. 条件与原因区别

```text
条件
= 概念成立的前提

原因
= 事情为什么发生
```

不完全等同。

---

# 87. 条件与方式区别

```text
条件
= 在什么情况下

方式
= 通过什么手段
```

---

# 88. 客体与对象区别

考试中可以近似理解。

核心：

```text
行为指向谁/什么
```

---

# 89. 定义拆解错误01｜抓太多

把100字定义压成：

```text
80字
```

没有意义。

---

# 90. 错误02｜抓太少

只记：

```text
“某种行为”
```

失去区分度。

---

# 91. 最佳压缩长度

一般：

```text
10～25字
```

能满足：

```text
快速比选项
```

即可。

---

# 92. 错误03｜只抓名词不抓关系

例如：

```text
企业
市场
价格
消费者
```

不够。

应该：

```text
企业通过降价影响消费者购买
```

---

# 93. 错误04｜忽略逻辑词

```text
因为
所以
但
同时
只有
未经
```

往往比名词更重要。

---

# 94. 错误05｜把背景当要件

题干前半段说：

```text
随着互联网发展……
```

若只是背景：

```text
不要硬记
```

---

# 95. 错误06｜把评价当定义

例如：

```text
“这种现象危害很大”
```

这可能只是：

```text
评价
```

不是成立条件。

---

# 96. 错误07｜把典型表现当唯一表现

定义举：

```text
“例如……”
```

不能理解成：

```text
只有例子里的情况才符合
```

---

# 97. 错误08｜删掉否定词

最致命。

---

# 98. 错误09｜把“或”看成“且”

```text
A或B
```

不是：

```text
A且B
```

---

# 99. 错误10｜把“且”看成“或”

同理。

---

# 100. 错误11｜程度条件忽略

```text
持续
显著
严重
反复
```

可能是关键。

---

# 101. 错误12｜自己补常识条件

题干没有：

```text
不要自行增加
```

---

# 102. 压缩母题01｜主体+行为

原定义结构：

```text
某类主体
实施某行为
```

压：

```text
谁 + 做什么
```

---

# 103. 压缩母题02｜条件+行为

压：

```text
什么情况下 + 做什么
```

---

# 104. 压缩母题03｜行为+目的

压：

```text
做什么 + 为了什么
```

---

# 105. 压缩母题04｜条件+结果

压：

```text
什么前提
→ 产生什么结果
```

---

# 106. 压缩母题05｜机制链

压：

```text
触发
→ 机制
→ 表现
```

---

# 107. 压缩母题06｜多主体关系

压：

```text
谁与谁
→ 形成什么关系
```

---

# 108. 压缩母题07｜分类定义

压：

```text
A类 = 区分词1
B类 = 区分词2

```

---

# 109. 压缩母题08｜排除性定义

定义常写：

```text
但不包括……
```

压缩时：

```text
“排除项”必须单列
```

---

# 110. 排除项模板

```text
属于：
A+B+C

不包括：
D
```

---

# 111. 选项如果满足A+B+C但落入D

仍然：

```text
不属于
```

---

# 112. 压缩母题09｜双层条件

例如：

```text
只有在A情况下，
主体B实施C行为
```

压：

```text
A条件
+ B主体
+ C行为
```

---

# 113. 压缩母题10｜结果反推

定义：

```text
某行为导致特定结果
```

# 115. 一个完整示范

# 155. 最终20条极简版

```text
1. 长定义不是全文背，要压成判定式
2. 先找“是指”类中心句
3. 背景、出处、评价通常不是核心要件
4. 举例不是定义全部范围
5. 先圈强限制词
6. “必须、只有、未经、仅”优先级最高
7. “通常、往往、例如”通常不是硬条件
8. 否定词绝不能删
9. 数量、时间、程度条件要保留
10. 主体限制强时先保留主体
11. 目的明确时必须保留目的
12. 实际结果和可能结果要区分
13. 行为和结果不要混
14. 条件和方式不要混
15. 并列要判断是“且”还是“或”
16. 因果和时间顺序不能看反
17. 心理管理题重点压“机制”
18. 多定义先压差异词
19. 最佳压缩通常10～25字
20. 定义拆解核心=删背景+圈强词+留必要条件
```
