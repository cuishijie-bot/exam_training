# 0. 高频陷阱总地图

```text

│  ├─ 行为

│  ├─ 结果

├─ B. 逻辑偷换

│
├─ C. 范围偷换

│
```

# 1. 陷阱01｜主体偷换

定义要求：

```text
A类主体
```

错项：

```text
B类主体
```

即使：

```text
行为完全相同
```

也可排。

# 2. 主体偷换高频形式

```text
消费者 ↔ 经营者
劳动者 ↔ 用人单位
行政机关 ↔ 普通组织
国家工作人员 ↔ 普通员工
未成年人 ↔ 成年人
上级 ↔ 同级
内部成员 ↔ 外部人员
```

# 10. 陷阱05｜目的偷换

最常见的“看起来很像”。

定义：

```text
为了A
```

错项：

```text
行为一样
但为了B
```

---

# 11. 目的偷换示例

```text
低价销售
```

可能是：

```text
清库存
促销
回笼资金
排挤竞争对手
```

若定义只认：

```text
排挤竞争对手
```

其他都不符。

# 12. 陷阱06｜动机偷换

尤其心理题。

定义：

```text
因为群体压力改变判断
```

错项：

```text
因为新证据充分改变判断
```

行为一样：

```text
都改观点
```

机制不同。

# 17. 且/或检查

看到：

```text
同时
并且
以及
```

警惕：

```text
是否要求同时满足
```

看到：

```text
或者
任一
```

警惕：

```text
是否满足其一即可
```

# 27. 陷阱18｜表面像、机制不同

```text

```

完全不同。

# 72. 相似概念辨析01｜从众 vs 信息更新

从众：

```text
多数人影响
→ 改变判断
```

信息更新：

```text
新证据更充分
→ 改变判断
```

---

# 73. 从众 vs 服从

从众：

```text
群体影响
```

服从：

```text
权威/命令压力
```

---

# 74. 从众 vs 模仿

从众：

```text
因群体意见压力/认同
```

模仿：

```text
复制他人行为
不一定存在群体压力
```

---

# 75. 锚定 vs 先入为主

若题干定义：

```text
初始数值/信息影响后续判断
```

重点：

```text
后续判断围绕初始信息偏移
```

不要只因：

```text
“先看到某信息”
```

就选。

---

# 76. 晕轮效应 vs 刻板印象

晕轮：

```text
一个人的某一突出特征
→ 推及整体评价
```

刻板印象：

```text
群体标签
→ 推断个体
```

---

# 77. 沉没成本 vs 损失厌恶

沉没成本：

```text
过去不可收回投入
→ 影响当前决策
```

损失厌恶：

```text
同等金额损失痛苦
>
收益快乐
```

---

# 78. 确认偏误 vs 从众

确认偏误：

```text
寻找支持已有观点的信息
```

从众：

```text
受多数意见影响改变观点
```

---

# 79. 角色冲突 vs 一般工作冲突

角色冲突：

```text
同一个人的多个社会角色要求矛盾
```

一般工作冲突：

```text
任务冲突
不一定涉及不同角色
```

---

# 80. 授权 vs 分工

授权：

```text

```

分工：

```text

不一定交权限
```

---

# 81. 激励 vs 控制

```text

```

```text

```

# 82. 参与管理 vs 普通讨论

参与管理：

```text

```

普通讨论：

```text

```

# 83. 大众传播 vs 人际传播

大众传播：

# 137. 最终20条极简版

```text
1. 定义判断错项不是随机，基本都在偷换要件
2. 主体资格错可直接排
3. 客体属性错可直接排
4. 未经/必须/只有是高频强条件
5. 行为一样不代表定义一样
6. 目的往往是相似行为的区分点
7. 动机不同可排心理题相似项
8. 实际结果与可能结果要区分
9. 自愿/强制、直接/间接是高频性质陷阱
10. 且和或不能看反
11. 因果和时间顺序不能看反
12. “通常”不能当“必须”
13. 举例不能当全部定义
14. 排除项必须单独看
15. 严重结果不能反推故意
16. 多定义只记差异点
17. 反向题一定圈“不属于”
18. 二选一只找唯一差异要件
19. 错题要记录“错项怎么骗我”
20. 母题库核心=识别陷阱位置+一票否决+二选一决策
```
