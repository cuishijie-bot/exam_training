# 1. 定义判断错题真正记录什么

不要只写：

```text
正确答案：C
```

要写：

```text
我为什么会被错误项骗
```

优先回答：

```text
错在哪个要件？
错项偷换了什么？
下次看到什么词要触发什么动作？
```

# 2. 错题归因四大类

```text
A类：审题错误
B类：要件错误
C类：逻辑错误
D类：决策错误
```

---

# 3. A类｜审题错误编码

```text
F1 = 反向题选反
F2 = 否定词漏看
F3 = 排除项漏看
F4 = 长定义没读完
F5 = 专业术语先入为主
```

---

# 4. B类｜要件错误编码

```text
F6 = 主体偷换没发现
F7 = 客体偷换没发现
F8 = 行为方式没看
F9 = 前提条件漏看
F10 = 目的漏看
F11 = 动机机制看错
F12 = 实际/可能结果混淆
F13 = 性质条件漏看
```

---

# 5. C类｜逻辑错误编码

```text
F14 = 且/或看反
F15 = 因果看反
F16 = 时间顺序看反
F17 = 范围扩大/缩小
F18 = 举例当全部定义
F19 = 通常当必须
```

---

# 6. D类｜决策错误编码

```text
F20 = 二选一凭感觉
F21 = 一票否决使用过晚
F22 = 过度纠结边缘细节
F23 = 常识覆盖题干
F24 = 明知不确定仍硬选
```

```text

```

# 11. 当天复盘

当天只做三件事：

```text
① 找最强限制
② 写错因编码
③ 写一句下次触发
```

不要抄长解析。

# 13. 次日二刷

要求：

```text
不看答案
重新做原题
```

重点不是：

```text
是否记得C
```

而是：

```text
能否主动抓到上次漏掉的要件
```

---

# 14. 二刷真正通过标准

必须能说明：

```text
A错在哪
B错在哪
D错在哪
为什么C满足全部必要条件
```

只记住答案：

```text
不算通过
```

---

# 15. 3天后变式

不要继续重复原题。

做：

```text
同母题
不同主题
```

目的：

```text
检验模型迁移
而不是答案记忆
```

---

# 16. 7天后混合复测

把该母题混进：

```text
普通定义判断题组
```

不提前提示：

```text
这是哪个母题
```

检验：

```text
真实考试条件下能否自动识别
```

---

# 17. 推荐复习节奏

```text
当天
→ 归因

次日
→ 原题二刷

3天后
→ 同母题变式

7天后
→ 混合复测
```

# 18. 错题毕业标准

一题毕业必须满足：

```text
① 5秒说出母题
② 10秒说出最强限制
③ 能解释错误项分别错哪
④ 同母题新题连续3道正确
⑤ 7天混合复测仍正确
```

---

# 19. 母题毕业标准

某母题可进入维护阶段：

```text
最近10道同母题
正确率 ≥ 90%
```

且：

```text
没有连续重复同一F错因
```

# 25. 为什么不推荐按日期建文件

例如：



```text
按母题分类
日期做字段
```

# 43. 每个判断必须回到定义证据

不接受：

```text
“感觉C更像”
```

接受：

```text
定义要求“未经授权”，
C已经明确获得授权，
所以C缺少必要条件。
```

# 80. 最终20条极简版

```text
1. 错题核心不是答案，而是错误模式
2. 每道错题必须归母题
3. 每道错题必须有个人错因编码
4. DX记录错项骗法，F记录个人失误

6. 次日不看答案二刷
7. 3天后做同母题变式
8. 7天后混合复测
9. 原题答对不等于掌握

11. 二选一错题复盘价值很高
12. 蒙对题也进入错题库
13. 超时题也进入错题库
14. 每周统计错因Top5
15. 只重点打最高频3类错因
16. 错题按母题归档优于按日期归档
17. 错题卡要短，不抄长解析
18. 母题最近10题≥90%才考虑毕业
19. 整个模块目标是快+稳
```
