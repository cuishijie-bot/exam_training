# 0. 空间重构总做题顺序

拿到空间题，按：

```text
① 先看是不是立方体展开图
② 找相对面
③ 找相邻面
④ 看公共边
⑤ 看公共点
⑥ 看图案方向
⑦ 必要时用时针法
⑧ 最后才做空间想象
```

---

# 1. 第一大类：立方体展开图

立方体有：

```text
6个面
```

任意一个面：

```text
有4个相邻面
1个相对面
```

---

# 2. 立方体最核心原则

## 相对面

折叠后：

```text
永远不相邻
```

所以如果某选项让：

```text
一对相对面同时出现在同一顶点周围
```

直接排除。

---

# 3. 相邻面

两个面如果折叠后：

```text
共享一条棱
```

就是相邻面。

---

# 4. 母题 01｜直接共边面

如果展开图中两个面：

```text
直接共用一条边
```

折叠后一定：

```text
相邻
```

这是最稳定判断之一。

---

# 5. 母题 02｜隔一面相对

在某些标准“十字型”展开图中，若三面排成一条直线：

```text
A - B - C
```

则：

```text
A 与 C
```

往往会折成：

```text
相对面
```

但注意：

```text
不要死背所有展开图都适用
```

最好结合整体结构判断。

---

# 6. 母题 03｜四连排中的相对关系

若四个面排成一条直线：

```text
A - B - C - D
```

折成立方体后常见：

```text
A 与 C 相对
B 与 D 相对
```

但仍建议：

```text
结合另外两个面的位置验证
```

---

# 7. 相对面判断优先级

建议：

```text
① 直接用展开结构找明显相对面
② 用“折过去”的方式判断
③ 实在不行再编号模拟
```

---

# 8. 编号模拟法

给6个面编号：

```text
1 2 3 4 5 6
```

选一个中央面作为：

```text
正面
```

周围依次折成：

```text
上
下
左
右
```

剩下最后一个：

```text
通常与中央面相对
```

---

# 9. 高频陷阱一：相对面同时出现

如果选项中的立方体视图中：

```text
两个相对面相邻
```

一定错误。

---

# 10. 第二大类：公共边

## 什么是公共边

两个相邻面折叠后：

```text
共享一条棱
```

这条棱就是：

```text
公共边
```

---

# 11. 母题 04｜图案贴边

若某面上的图案：

```text
靠近某条边
```

折叠后它应：

```text
仍靠近与该边相接的相邻面
```

---

# 12. 公共边方向法

假设面 A 和面 B 共边。

如果 A 面上的箭头：

```text
箭头尖端指向公共边
```

折叠后仍应表现为：

```text
箭头尖端靠近 B 面
```

不会凭空跑到对侧。

---

# 13. 母题 05｜线段跨公共边

如果两个相邻面上的线段在展开图中：

```text
正好在公共边处衔接
```

折叠后可能：

```text
形成连续折线
```

---

# 14. 高频陷阱二：图案与边的相对位置被改变

折叠只改变：

```text
空间方向
```

不会改变图案在本面中的：

```text
相对位置
```

---

# 15. 第三大类：公共点

三个面若在立方体某个顶点相交：

```text
这三个面两两相邻
```

并共享：

```text
一个顶点
```

---

# 16. 母题 06｜三面共点

展开图中三个面围绕某个角形成关系时，折叠后可能：

```text
三面在同一顶点相交
```

---

# 17. 公共点验证法

如果选项显示三个面：

```text
A、B、C
```

在一个顶点汇聚。

则必须满足：

```text
A 与 B 相邻
B 与 C 相邻
A 与 C 相邻
```

任何一对是相对面：

```text
该选项必错
```

---

# 18. 第四大类：时针法

时针法用于判断：

```text
三个相邻面的位置顺序
```

尤其适合：

```text
三面组合选项
```

---

# 19. 时针法基本思想

在展开图中选择：

```text
A、B、C
```

三个彼此相邻并共点的面。

观察它们围绕公共点的顺序：

```text
A → B → C
```

若为：

```text
顺时针
```

折叠后该相对顺序保持。

---

# 20. 时针法重点

折叠后：

```text
顺时针顺序不能变成逆时针
```

若选项中出现：

```text
镜像反转
```

通常错误。

---

# 21. 高频陷阱三：旋转整体不影响时针关系

一个立方体可以：

```text
整体旋转
```

所以：

```text
哪个面在上
哪个面在左
```

可能变化。

但三个面围绕公共点的：

```text
顺逆时针关系
```

不会被整体旋转改变。

---

# 22. 母题 07｜三个面顺序判断

若展开图中：

```text
A → B → C
```

围绕公共点为顺时针。

选项出现：

```text
A → C → B
```

则：

```text
顺序反了
```

可排除。

---

# 23. 第五大类：箭头法

如果面上有：

```text
箭头
三角尖头
不对称线段
字母
```

重点考：

```text
方向
```

---

# 24. 母题 08｜箭头指向公共边

若箭头：

```text
朝公共边
```

折叠后：

```text
仍朝向相邻面
```

---

# 25. 母题 09｜两个箭头相对方向

两个相邻面都有箭头。

可以比较：

```text
箭头尖端是否靠近公共棱
箭尾是否远离公共棱
```

---

# 26. 图案方向判断的核心

不要只记：

```text
上、下、左、右
```

因为折叠后视角会变。

更稳定的是：

```text
相对公共边的位置
```

---

# 27. 高频陷阱四：把二维上下直接带进三维

展开图里的：

```text
上
下
左
右
```

折叠后会改变。

但：

```text
图案离哪条边近
图案朝哪条公共边
```

是稳定关系。

---

# 28. 第六大类：特殊图案方向

常见：

```text
斜线
字母
数字
箭头
三角形
半黑半白
```

---

# 29. 母题 10｜斜线方向

一个面中的斜线：

```text
连接哪两个角
```

折叠后仍连接：

```text
该面的对应两个顶点
```

---

# 30. 母题 11｜字母方向

字母在面上：

```text
不能镜像翻转
```

折叠是空间旋转：

```text
不是镜像
```

所以若选项中字母出现：

```text
左右镜像
```

通常错误。

---

# 31. 母题 12｜半黑半白方向

如果一个面：

```text
左黑右白
```

折叠后不能随意变成：

```text
左右镜像
```

必须结合：

```text
公共边
```

判断。

---

# 32. 第七大类：立方体展开图常见错误选项

高频错误来源：

```text
① 相对面被放成相邻
② 三面时针顺序反
③ 图案镜像
④ 箭头方向反
⑤ 公共边对应错
⑥ 公共点不存在
```

---

# 33. 立方体题做题模板

```text
第一步：
找相对面

第二步：
看选项是否出现相对面相邻
→ 有则排

第三步：
看三面是否能共点

第四步：
看时针顺序

第五步：
看图案与公共边关系
```

# 34. 第八大类：立方体展开图有效性

有时题目问：

```text
哪个展开图能折成立方体
```

---

# 35. 母题 13｜六面展开图合法判断

核心：

```text
折叠后不能有两个面重叠
也不能缺面
```

---

# 36. 非法展开常见原因

```text
某两面折叠后占据同一位置
```

即：

```text
重叠
```

---

# 37. 快速判断思路

优先找：

```text
过于集中在同一侧
```

导致折叠冲突的结构。

---

# 38. 第九大类：截面图

截面题问：

```text
用一个平面切某立体
可能得到什么图形
```

核心不是画切面，而是：

```text
切平面能经过哪些面
```

---

# 39. 截面题总原则

截面边数通常对应：

```text
切平面经过的面数
```

例如：

```text
切过3个面
→ 常得到三角形

切过4个面
→ 常得到四边形
```

---

# 40. 母题 14｜立方体三角形截面

一个平面切过立方体：

```text
3个相邻面
```

可形成：

```text
三角形
```

---

# 41. 母题 15｜立方体四边形截面

切过：

```text
4个面
```

可得到：

```text
四边形
```

包括：

```text
矩形
平行四边形
梯形等
```

视切法而定。

---

# 42. 母题 16｜立方体五边形截面

若切平面经过：

```text
5个面
```

可形成：

```text
五边形
```

---

# 43. 母题 17｜立方体六边形截面

若切平面同时经过：

```text
6个面
```

可形成：

```text
六边形
```

这是立方体截面的常见最大边数。

---

# 44. 高频陷阱五：立方体截面不可能出现圆

立方体全部是：

```text
平面多边形
```

平面切割后：

```text
截面边界为线段
```

所以不可能：

```text
圆
椭圆
```

---

# 45. 第十大类：长方体截面

与立方体类似。

可能得到：

```text
三角形
四边形
五边形
六边形
```

---

# 46. 第十一大类：圆柱截面

## 母题 18｜平行底面切

得到：

```text
圆
```

---

# 47. 母题 19｜垂直底面切

若切平面经过圆柱轴线方向：

```text
常得到长方形
```

---

# 48. 母题 20｜斜切圆柱

可得到：

```text
椭圆
```

---

# 49. 圆柱截面速查

```text
横切 → 圆
竖切 → 长方形
斜切 → 椭圆
```

---

# 50. 第十二大类：圆锥截面

## 母题 21｜平行底面切

得到：

```text
圆
```

---

# 51. 母题 22｜经过顶点切

可得到：

```text
三角形
```

---

# 52. 母题 23｜斜切圆锥

可能得到：

```text
椭圆
```

公考中通常只需：

```text
判断可能性
```

不必深究圆锥曲线理论。

---

# 53. 第十三大类：球体截面

任意平面切球体：

```text
截面都是圆
```

只是：

```text
半径不同
```

---

# 54. 母题 24｜球截面

如果选项出现：

```text
三角形
矩形
椭圆
```

作为球的平面截面：

```text
直接排除
```

严格几何中球与平面的交线为圆（相切时退化为点）。

# 55. 第十四大类：组合立体截面

# 56. 组合截面做法

# 57. 第十五大类：三视图

三视图通常包括：

```text
主视图
俯视图
左视图
```

# 58. 三视图基本含义

## 主视图

从：

```text
正面
```

看。

---

## 俯视图

从：

```text
上方
```

看。

---

## 左视图

从：

```text
左侧
```

看。

# 59. 三视图核心原则

单一视图：

```text
信息不完整
```

必须：

```text
多个视角交叉限制
```

# 60. 母题 25｜主视图判断高度

主视图能反映：

```text
宽度
高度
```

# 61. 母题 26｜俯视图判断前后结构

俯视图能反映：

```text
左右
前后
```

---

# 62. 母题 27｜左视图判断深度与高度

左视图反映：

```text
前后
高度
```

---

# 63. 三视图对应关系

可记：

```text
主视图：宽 + 高
俯视图：宽 + 深
左视图：深 + 高
```

# 64. 高频陷阱六：只凭一个视图确定立体


# 67. 层数法

# 68. 柱高法

从俯视图每个位置记录：

```text

```

```text
各位置高度之和
```

# 69. 高频陷阱七：把遮挡块漏掉


# 70. 第十七大类：表面涂色

经典模型：

```text
大立方体由小立方体拼成
外表面涂色
```

问：

```text
3面涂色
2面涂色
1面涂色
0面涂色
```

---

# 71. n×n×n 大立方体涂色公式

若每条棱分成：

```text
n个小立方体
```

---

# 72. 三面涂色

位于：

```text
8个顶点
```

所以：

```text
8个
```

前提：

```text
n≥2
```

---

# 73. 两面涂色

位于：

```text
12条棱上
除去顶点
```

每条棱有：

```text
n-2
```

个。

总数：

```text
12(n-2)
```

---

# 74. 一面涂色

位于：

```text
6个面的内部
```

每面：

```text
(n-2)^2
```

总数：

```text
6(n-2)^2
```

---

# 75. 零面涂色

内部小立方体：

```text
(n-2)^3
```

---

# 76. 涂色题速查

```text
3面：8
2面：12(n-2)
1面：6(n-2)^2
0面：(n-2)^3
```

---

# 77. 高频陷阱八：n 表示每条棱小块数

不是：

```text
总小立方体数量
```

总数：

```text
n^3
```

---

# 78. 第十八大类：纸张折叠 / 打孔

有时空间题还考：

```text
纸张折叠
```

# 79. 折纸打孔核心原则

```text
展开时做镜像复制
```

# 80. 母题 29｜一次折叠打孔

```text
展开通常得到2个对称孔
```

# 81. 母题 30｜两次折叠打孔


# 82. 折纸打孔做法

从最后状态开始：

```text
逆序展开
```

```text
关于折痕镜像一次
```

---

# 83. 高频陷阱九：折纸孔位跨过折痕

镜像后孔到折痕距离：

```text
相等
```

---

# 84. 第十九大类：空间旋转

有些题给立体：

```text
旋转后判断视图
```

---

# 85. 空间旋转核心

整体旋转改变：

```text
上下左右前后
```

但不改变：

```text
面之间相邻关系
图案本身镜像关系
```

---

# 86. 空间题高频陷阱总表

```text
① 相对面被当相邻
② 公共边找错
③ 三面时针顺序反
④ 图案被镜像
⑤ 箭头与公共边方向错
⑥ 截面边数想当然
⑦ 球截面判断错
⑧ 三视图只看一个视角
⑨ 小立方体遮挡漏数
⑩ 涂色公式中的n理解错
⑪ 折纸展开顺序错
```

---

# 87. 空间题“先排除”原则

多数空间题：

```text
不需要完整构造答案
```

先找：

```text
明显违反相对面
明显时针反转
明显镜像
```

常可快速排除2～3项。

```text
0～5秒：
找相对面

5～10秒：
排相对面冲突选项

10～15秒：
看三面共点/时针

15～20秒：
看图案方向
```
