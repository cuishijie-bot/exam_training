# 国考 / 辽宁省考完整版知识库｜图形推理位置与样式专项

> 配套文件：
>
> - `01_图形推理完整版规律库.md`
> - `02_图形推理位置与样式专项.md`
>
> 本文件只解决一类核心问题：
>
> ```text
> 图形看起来很像
> ↓
> 到底是在“动”
> 还是在“叠”
> ```
>
> 核心口令：
>
> ```text
> 元素没变，只是位置变 → 位置规律
> 元素在组合、删除、保留 → 样式规律
> ```

---

# 0. 位置与样式总识别

看到一组图先问：

```text
① 元素种类一样吗？
② 元素个数一样吗？
③ 只是位置变化吗？
④ 是否发生了重合、删除、保留？
```

判断：

```text
元素完全相同，只换位置
→ 位置

前两图组合成第三图
→ 样式
```

---

# 1. 位置规律总框架

高频：

```text
平移
旋转
翻转
循环移动
内外移动
顺逆时针
多元素分别移动
相邻/间隔移动
```

---

# 2. 母题 01｜单元素横向平移

## 第一眼特征

```text
同一个小图形
在左、中、右之间变化
```

## 固定排查

```text
移动方向？
每次几格？
是否循环？
```

## 常见规律

```text
左 → 中 → 右
```

或：

```text
每次向右1格
```

---

# 3. 母题 02｜单元素纵向平移

## 特征

```text
元素形状不变
只在上中下变化
```

## 规律

```text
上 → 中 → 下
```

或循环：

```text
上 → 中 → 下 → 上
```

---

# 4. 母题 03｜斜向平移

## 特征

```text
位置沿对角线变化
```

常见：

```text
左上 → 中 → 右下
```

或：

```text
右上 → 中 → 左下
```

---

# 5. 母题 04｜固定步长循环移动

例如：

```text
1 → 3 → 5 → 2 → 4
```

说明：

```text
每次移动2格
```

到边界后：

```text
循环
```

---

# 6. 母题 05｜顺时针移动

## 触发

```text
元素围绕中心周边位置变化
```

第一反应：

```text
顺时针 / 逆时针
```

常见：

```text
每次1格
每次2格
每次90°
```

---

# 7. 母题 06｜逆时针移动

与顺时针同理。

关键不要只看：

```text
当前位置
```

要看：

```text
连续三图移动方向是否一致
```

---

# 8. 母题 07｜顺逆时针交替

例如：

```text
+1格
-1格
+1格
-1格
```

或：

```text
顺时针90°
逆时针90°
```

---

# 9. 母题 08｜步长递增

例如：

```text
移动1格
移动2格
移动3格
```

这类题常让人误判为：

```text
位置无规律
```

实际要看：

```text
位移量
```

而不只是位置。

---

# 10. 母题 09｜整体旋转

## 触发

```text
图形轮廓完全一致
方向逐步变化
```

优先看：

```text
固定角度旋转
```

常见：

```text
45°
90°
180°
```

---

# 11. 母题 10｜旋转角度递增

例如：

```text
45°
90°
135°
180°
```

本质：

```text
每次比上一次多转45°
```

---

# 12. 母题 11｜顺逆旋转交替

例如：

```text
+90°
-90°
+90°
-90°
```

不要误判成：

```text
来回翻转
```

---

# 13. 母题 12｜水平翻转

## 特征

```text
上下关系交换
左右关系不变
```

镜像轴：

```text
水平线
```

---

# 14. 母题 13｜垂直翻转

## 特征

```text
左右关系交换
上下关系不变
```

镜像轴：

```text
竖直线
```

---

# 15. 母题 14｜斜轴翻转

常见：

```text
沿左上—右下对角线
```

或：

```text
沿右上—左下对角线
```

---

# 16. 旋转 vs 翻转

## 判断方法

看一个明显的非对称细节。

例如：

```text
箭头
缺口
黑点
字母
```

如果经过：

```text
旋转
```

左右关系不会产生镜像。

如果经过：

```text
翻转
```

会出现镜像关系。

---

# 17. 高频错题点：180°旋转与双翻转

某些图形：

```text
水平翻转 + 垂直翻转
```

等价于：

```text
旋转180°
```

如果只看最终图形：

```text
可能无法区分
```

需要结合整组变化。

---

# 18. 母题 15｜内外移动

## 触发

小元素在：

```text
大图形内部
边界
外部
```

变化。

常见：

```text
内 → 边 → 外
```

或循环。

---

# 19. 母题 16｜内外 + 方向联合

例如：

```text
位置：内 → 外 → 内 → 外
方向：每次旋转90°
```

说明：

```text
可能有两条规律并行
```

---

# 20. 多元素位置总原则

如果图中有：

```text
黑点
白点
三角形
小方块
```

不要整体看。

正确：

```text
逐个追踪
```

---

# 21. 母题 17｜两元素同向移动

例如：

```text
黑点每次顺时针1格
白点每次顺时针2格
```

两者方向相同：

```text
步长不同
```

---

# 22. 母题 18｜两元素反向移动

例如：

```text
黑点顺时针1格
白点逆时针1格
```

这是极高频。

---

# 23. 母题 19｜一快一慢

例如：

```text
黑点每次1格
白点每次2格
```

容易产生：

```text
相遇
错位
循环
```

---

# 24. 母题 20｜相邻与间隔移动

有时不关心绝对位置。

规律可能是：

```text
始终相邻
始终隔1格
相邻/不相邻交替
```

---

# 25. 母题 21｜奇偶位规律

例如：

```text
奇数项按一种移动
偶数项按另一种移动
```

当连续规律不明显时：

```text
尝试拆奇偶项
```

---

# 26. 母题 22｜分组移动

例如：

```text
第1、3、5图一组
第2、4、6图一组
```

各自内部有规律。

---

# 27. 位置规律固定排查表

```text
单元素？
→ 平移 / 旋转 / 翻转

多元素？
→ 分别追踪

移动是否固定步长？
→ 若否，看递增/交替

是否到边界回到起点？
→ 循环

是否内外变化？
→ 内/边/外

连续看不出？
→ 奇偶分组
```

---

# 28. 样式规律总框架

高频：

```text
相加
相减
求同
求异
黑白叠加
覆盖
保留特定部分
```

常出现在：

```text
九宫格
两组图
```

---

# 29. 母题 23｜图形相加

## 触发

前两图：

```text
元素不同
```

第三图：

```text
同时拥有前两图元素
```

第一反应：

```text
相加
```

---

# 30. 母题 24｜图形相减

## 触发

第三图比前图：

```text
少了一部分
```

可能：

```text
图1 - 图2 = 图3
```

---

# 31. 母题 25｜求同

## 规则

```text
相同部分保留
不同部分删除
```

---

# 32. 母题 26｜求异

## 规则

```text
相同部分删除
不同部分保留
```

也就是：

```text
去同存异
```

---

# 33. 求同求异快速判断

先找：

```text
图1和图2完全重合的线/块
```

观察图3：

```text
重合部分留下了？
→ 求同

重合部分消失了？
→ 求异
```

---

# 34. 母题 27｜黑白叠加

## 高频结构

前两格黑白图：

```text
叠加
```

得到第三格。

需要建立：

```text
黑+黑
黑+白
白+黑
白+白
```

的结果表。

---

# 35. 黑白叠加标准做法

不要猜。

先找至少：

```text
2～3个已知对应格
```

记录：

```text
黑+黑 → ?
黑+白 → ?
白+黑 → ?
白+白 → ?
```

再预测未知格。

---

# 36. 母题 28｜黑白异或

常见：

```text
同色变白
异色变黑
```

即：

```text
相同去掉
不同保留
```

本质：

```text
求异
```

---

# 37. 母题 29｜黑白同或

常见：

```text
同色保留
异色去掉
```

本质：

```text
求同
```

---

# 38. 母题 30｜覆盖

## 触发

叠加后：

```text
一部分线条消失
但不像求同求异
```

可能：

```text
后图覆盖前图
```

---

# 39. 覆盖判断

如果同一位置：

```text
图1有A
图2有B
图3只显示B
```

可能说明：

```text
图2覆盖图1
```

反之亦然。

---

# 40. 母题 31｜颜色替换

例如：

```text
黑 → 白
白 → 黑
```

或：

```text
实线 → 虚线
```

可能按：

```text
周期
位置
叠加结果
```

变化。

---

# 41. 母题 32｜线型替换

如：

```text
实线
虚线
粗线
细线
```

样式发生切换。

---

# 42. 母题 33｜元素替换

例如：

```text
圆 → 三角 → 方形
```

位置不变，元素类型按周期变化。

---

# 43. 母题 34｜部分保留

有时不是纯求同求异，而是：

```text
只保留外框
只保留内部
只保留奇数位元素
```

需要结合：

```text
每组三图整体关系
```

判断。

---

# 44. 九宫格样式规律

优先：

```text
横向：1+2=3
```

若不成立：

```text
纵向：1+4=7
```

再看：

```text
对角线
```

---

# 45. 两组图样式规律

前组：

```text
图1 ○ 图2 = 图3
```

后组：

```text
图4 ○ 图5 = ?
```

中间的运算符可能是：

```text
相加
相减
求同
求异
叠加
覆盖
```

---

# 46. 样式规律排查顺序

```text
① 相加
② 相减
③ 求同
④ 求异
⑤ 黑白叠加
⑥ 覆盖
```

---

# 47. 高频陷阱一：把位置题看成数量题

如果元素：

```text
形状相同
数量相同
```

第一反应应该是：

```text
位置
```

而不是乱数。

---

# 48. 高频陷阱二：把旋转看成翻转

检查：

```text
非对称细节
```

例如：

```text
箭头朝向
缺口位置
黑点相对位置
```

---

# 49. 高频陷阱三：只追踪一个元素

多元素题必须：

```text
全部追踪
```

一个元素符合：

```text
不代表规律完整
```

---

# 50. 高频陷阱四：忽略循环

如果元素走到：

```text
边界
```

下一步可能：

```text
回到起点
```

---

# 51. 高频陷阱五：移动步长不固定

不要默认：

```text
每次1格
```

可能：

```text
1、2、3格
```

或：

```text
1、2、1、2
```

---

# 52. 高频陷阱六：奇偶项没拆开

连续看不懂：

```text
1→2→3→4
```

尝试：

```text
1→3→5
2→4→6
```

---

# 53. 高频陷阱七：求同求异搞反

记：

```text
求同 = 相同留下
求异 = 不同留下
```

---

# 54. 高频陷阱八：黑白叠加靠视觉猜

必须：

```text
列运算表
```

否则非常容易错。

---

# 55. 高频陷阱九：叠加顺序有方向

有些题：

```text
黑+白
```

和：

```text
白+黑
```

结果不一定相同。

所以：

```text
不要默认交换律
```

---

# 56. 高频陷阱十：找到一个局部规律就停止

必须验证：

```text
每一组都成立
```

并且：

```text
能唯一确定选项
```

# 69. 位置与样式混合题

有些题同时存在：

```text
位置变化
+
样式变化
```

例如：

```text
黑点移动
箭头同时旋转
```

或：

```text
元素先移动
再黑白互换
```

正确做法：

```text
拆开分析
```

---

# 70. 双规律题固定流程

```text
① 先找最明显的主规律
② 再看选项是否唯一
③ 若不唯一，再找第二规律
```

不要一开始就：

```text
强行找两个规律
```

---

# 71. 九宫格混合题

可能：

```text
横向做样式叠加
纵向做位置移动
```

若单一方向解释不全：

```text
考虑行列分别存在不同规律
```

# 72. 分类题中的位置与样式

```text
旋转类 vs 翻转类
```

或：

```text
求同结构 vs 求异结构
```

但这类频率低于：

```text
属性 / 数量二分类
```


```text
P4高频
```

说明：

```text
多元素追踪能力弱
```

专项练：

```text
双点/三元素移动
```

```text
S2高频
```

说明：

```text
求同求异混淆
```

只练：

```text
重合部分保留/删除
```

```text
S3高频
```
