# 国考 / 辽宁省考完整版知识库｜图形推理属性与数量专项

> 配套文件：
>
> - `01_图形推理完整版规律库.md`
> - `02_图形推理位置与样式专项.md`
> - `03_图形推理属性与数量专项.md`
>
> 本文件解决的是：
>
> ```text
> 图形不像
> ↓
> 先看“性质”
> ↓
> 再看“数量”
> ```
>
> 核心口令：
>
> ```text
> 属性先扫：对称、曲直、开闭
> 数量再数：点、线、角、面、素
> ```

---

# 0. 属性与数量总识别顺序

当图形之间：

```text
不像
但又有明显共同结构
```

先查：

```text
对称
曲直
开闭
```

如果仍不成立，再进入：

```text
点
线
角
面
素
```

不要一上来就：

```text
乱数所有东西
```

---

# 1. 第一大类：属性规律

属性规律主要看：

```text
图形“是什么性质”
```

而不是：

```text
“有几个”
```

高频：

```text
对称性
曲直性
开闭性
```

---

# 2. 母题 01｜轴对称

## 第一眼特征

图形视觉上：

```text
左右很规整
上下很规整
```

优先想：

```text
轴对称
```

---

# 3. 轴对称判断

若沿某条直线折叠：

```text
两侧完全重合
```

则为：

```text
轴对称图形
```

常见对称轴：

```text
竖直
水平
左上—右下
右上—左下
```

---

# 4. 母题 02｜对称轴方向变化

常见：

```text
竖 → 斜 → 横 → 斜
```

或：

```text
每次旋转45°
```

重点不是：

```text
图形朝向
```

而是：

```text
对称轴朝向
```

---

# 5. 母题 03｜对称轴数量

可能规律：

```text
1、2、3、4
```

或：

```text
1、1、2、2、3、3
```

或：

```text
奇数 / 偶数
```

---

# 6. 母题 04｜中心对称

定义：

```text
图形旋转180°
后与原图重合
```

注意：

```text
中心对称 ≠ 轴对称
```

---

# 7. 轴对称 vs 中心对称

可能：

```text
只有轴对称
只有中心对称
两者都有
两者都没有
```

分类题很常考。

---

# 8. 高频示例判断

常见：

```text
正方形
→ 轴对称 + 中心对称

普通等腰三角形
→ 轴对称
但通常不是中心对称

平行四边形
→ 中心对称
但一般不是轴对称
```

---

# 9. 母题 05｜对称轴与图中特殊元素关系

图中如果有：

```text
黑点
箭头
小圆
```

可能规律不是单纯有无对称，而是：

```text
小元素位于对称轴上
```

或：

```text
小元素分布在对称轴两侧
```

---

# 10. 对称题排查模板

```text
① 有无轴对称？
② 有无中心对称？
③ 对称轴几条？
④ 对称轴方向？
⑤ 特殊元素与对称轴关系？
```

---

# 11. 母题 06｜全直线图形

图形全部由：

```text
直线
```

组成。

例如：

```text
三角形
正方形
折线
字母A
```

---

# 12. 母题 07｜全曲线图形

图形全部由：

```text
曲线
```

组成。

例如：

```text
圆
椭圆
弧线组合
```

---

# 13. 母题 08｜曲直混合

同时存在：

```text
直线
+
曲线
```

---

# 14. 曲直分类

常见三分类：

```text
全直
全曲
曲直混合
```

在六图分类题里非常高频。

---

# 15. 曲直交替

一组图可能：

```text
直 → 曲 → 直 → 曲
```

或者：

```text
直 → 混 → 曲
```

---

# 16. 母题 09｜封闭图形

图形所有边界闭合：

```text
没有开口
```

优先考虑：

```text
封闭性
```

---

# 17. 母题 10｜开放图形

图形存在：

```text
开口
端点
```

属于：

```text
开放图形
```

---

# 18. 开闭交替

常见：

```text
闭 → 开 → 闭 → 开
```

---

# 19. 开口方向

有时开闭不只是：

```text
有/无
```

还考：

```text
开口朝上
朝下
朝左
朝右
```

这时可能属于：

```text
属性 + 位置
```

---

# 20. 属性规律快速卡

```text
视觉规整
→ 对称

只有直线/曲线差异
→ 曲直

有无开口
→ 开闭
```

---

# 21. 属性规律高频陷阱一

看到：

```text
有多个封闭面
```

容易误判成：

```text
开闭性
```

但：

```text
开闭性只看整体是否有开口
```

封闭区域数量属于：

```text
数量规律
```

---

# 22. 属性规律高频陷阱二

轴对称图形：

```text
不一定只有1条对称轴
```

要注意：

```text
对称轴数量
```

---

# 23. 属性规律高频陷阱三

图形旋转后方向变了：

```text
仍可能保持轴对称
```

考的可能是：

```text
对称轴方向变化
```

---

# 24. 第二大类：数量规律

数量规律总口诀：

```text
点
线
角
面
素
```

---

# 25. 数量规律的正确思路

不是：

```text
所有都数一遍
```

而是：

```text
根据图形特征选择最可能对象
```

---

# 26. 视觉触发器

看到：

```text
大量交叉
→ 先数点

大量线段
→ 先数线

折角明显
→ 先数角

很多封闭小格
→ 先数面

很多独立小图形
→ 先数素
```

---

# 27. 点规律总览

常见：

```text
交点
顶点
端点
切点
特殊连接点
```

---

# 28. 母题 11｜交点数

## 触发

图形中：

```text
线条频繁相交
```

第一反应：

```text
数交点
```

---

# 29. 交点计数规则

一个位置即使：

```text
多条线经过
```

通常仍算：

```text
1个交点
```

除非题目明显按其他口径。

---

# 30. 交点常见数列

```text
1、2、3、4
```

或：

```text
2、4、6
```

或：

```text
3、3、3
```

---

# 31. 母题 12｜顶点数

多边形或折线明显时：

```text
顶点数量
```

可能成为规律。

---

# 32. 母题 13｜端点数

开放线条图形：

```text
线段末端
```

是端点。

常见于：

```text
一笔画
折线
非封闭图形
```

---

# 33. 母题 14｜切点数

直线与曲线：

```text
相接但不穿过
```

属于：

```text
相切
```

切点可能被单独计数。

---

# 34. 母题 15｜交点 + 端点运算

有时规律是：

```text
交点数 + 端点数 = 常数
```

或者：

```text
交点数 - 端点数
```

---

# 35. 线规律总览

常见：

```text
直线数
曲线数
总线条数
横线
竖线
斜线
内部线
外部线
长线
短线
```

---

# 36. 母题 16｜直线数

图形主要由直线组成时：

```text
数直线
```

---

# 37. 线段 vs 整条线

如果一条长线被交点分割：

```text
是否算成多段
```

要看题目整体规律。

公考图推中：

```text
“线段数”常按被交点分割后的每一段计
```

但不能机械套。

---

# 38. 母题 17｜曲线数

例如：

```text
1条弧
2条弧
3条弧
```

可能递增。

---

# 39. 母题 18｜直线 + 曲线

可能考：

```text
直线数 + 曲线数 = 固定值
```

或：

```text
直线数 : 曲线数
```

---

# 40. 母题 19｜横竖斜分类

尤其是：

```text
汉字
字母
几何图形
```

可能分别数：

```text
横线
竖线
斜线
```

---

# 41. 角规律总览

常见：

```text
总角数
锐角
直角
钝角
内部角
外部角
```

---

# 42. 母题 20｜直角数

非常高频。

第一眼看到：

```text
大量方折结构
```

优先考虑：

```text
直角
```

---

# 43. 母题 21｜锐角数

三角形、折线很多时：

```text
锐角数量
```

可能成为规律。

---

# 44. 母题 22｜角数量递增

例如：

```text
2、3、4、5
```

---

# 45. 角与线关系

有时规律：

```text
角数 = 线数
```

或：

```text
角数 - 线数 = 常数
```

---

# 46. 面规律总览

“面”通常指：

```text
封闭区域
```

是数量规律最高频考点之一。

---

# 47. 母题 23｜封闭区域数

看到：

```text
格子
圆环
多边形嵌套
交叉线形成小区域
```

优先：

```text
数面
```

---

# 48. 面的计数原则

通常数：

```text
图形内部被线条围成的封闭区域
```

不把：

```text
图形外部无限区域
```

算进去。

---

# 49. 母题 24｜面数递增

例如：

```text
1、2、3、4
```

---

# 50. 母题 25｜面数奇偶

例如：

```text
奇、偶、奇、偶
```

---

# 51. 母题 26｜面数相加

九宫格中：

```text
图1面数 + 图2面数 = 图3面数
```

---

# 52. 母题 27｜面与线组合

可能：

```text
面数 + 线数 = 常数
```

或：

```text
面数 = 某类线数
```

---

# 53. 素规律总览

“素”指：

```text
独立的小图形元素
```

如：

```text
圆
三角形
方形
五角星
```

---

# 54. 母题 28｜元素总个数

例如：

```text
1个
2个
3个
4个
```

---

# 55. 母题 29｜元素种类数

例如：

```text
圆、三角、方形
```

共：

```text
3种
```

---

# 56. 母题 30｜相同元素数量

可能只数：

```text
相同图形有几个
```

---

# 57. 母题 31｜不同元素数量

例如：

```text
每幅图都有3种不同元素
```

---

# 58. 母题 32｜最大元素 / 最小元素

有时规律不是总数量，而是：

```text
最大图形的位置
最小图形的位置
```

或者：

```text
最大元素数量
```

---

# 59. 母题 33｜元素内外分类

可分别数：

```text
内部元素
外部元素
边界元素
```

---

# 60. 数量规律中的恒定

并不是一定递增。

常见：

```text
每幅图交点都4个
每幅图面数都3
每幅图元素种类都2种
```

# 61. 数量规律中的递增递减

常见：

# 62. 数量规律中的交替

例如：


或：


---

# 63. 数量规律中的周期

例如：

```text
1,2,3,1,2,3
```

# 64. 数量规律中的加法


# 65. 数量规律中的减法

例如：

# 66. 数量规律中的倍数

# 67. 数量规律中的差值

# 68. 高频母题 34｜奇偶分类

六图分类中：

```text
一组数量为奇数
一组数量为偶数
```

非常高频。

# 69. 高频母题 35｜数量相等分类

例如：

```text
①③⑤面数=2
②④⑥面数=3
```

---

# 70. 高频母题 36｜点线关系分类

例如：

```text
交点数 = 线数
```

一组成立，另一组不成立。

---

# 71. 高频母题 37｜面素关系分类

例如：

```text
封闭面数 = 元素个数
```

---

# 72. 分类题固定排查顺序

六图分两组：

```text
① 先看属性二分类
   对称/不对称
   开/闭
   直/曲

② 再看数量奇偶

③ 再看数量恒等关系

④ 最后看特殊结构
```

---

# 73. 分类题为什么先看属性

因为：

```text
属性二分类通常最直观
```

比数：

```text
7条线、8个角
```

更快。

---

# 74. 九宫格数量题

优先：

```text
横向
```

例如：

```text
1 + 2 = 3
```

若横向不成立：

```text
看纵向
```

---

# 75. 九宫格数量运算

可能：

```text
加
减
倍数
平均
差值
```

---

# 76. 九宫格组合规律

也可能：

```text
第一行数点
第二行数线
第三行数面
```

但这种较少。

优先找：

```text
统一指标
```

---

# 77. 数量题排查陷阱一：一上来数太多

看到复杂图：

```text
不代表要全部数
```

应先问：

```text
哪个特征最突出？
```

---

# 78. 数量题排查陷阱二：数错“面”

面是：

```text
封闭区域
```

不是：

```text
独立部分
```

---

# 79. 面 vs 部分

例如两个相离圆：

```text
面数 = 2
部分数 = 2
```

但复杂图中二者可能不同。

---

# 80. 数量题陷阱三：交点重复计算

一个位置：

```text
三条线交汇
```

通常：

```text
算1个交点
```

---

# 81. 数量题陷阱四：边界点算不算交点

如果两条线：

```text
只在端点连接
```

有些题可能把其视为：

```text
连接点
```

是否计入要看整组规律。

不要机械。

---

# 82. 数量题陷阱五：线段被切开

如果题目在数：

```text
线段
```

交点会增加线段数量。

---

# 83. 数量题陷阱六：角的口径混乱

不要同时混：

```text
所有角
直角
锐角
```

先看哪类角最突出。

---

# 84. 数量题陷阱七：只数元素个数，不看种类

多元素图：

```text
总数一样
```

但：

```text
种类数不同
```

可能才是规律。

---

# 85. 数量题陷阱八：找到递增就停

如果：

```text
1,2,3,4
```

看似成立，但多个指标都能递增。

必须用：

```text
选项唯一性
```

验证。

---

# 86. 属性与数量混合题

有些题：

```text
属性 + 数量
```

同时存在。

例如：

```text
每幅图都轴对称
且对称轴数量依次1、2、3
```

---

# 87. 双规律判断原则

如果一个规律：

```text
能解释全部
并唯一选答案
```

不用强求第二规律。

如果：

```text
多个选项都符合
```

再找第二层。

---

# 96. 5秒识别卡：属性

```text
规整镜像感
→ 对称

全直/全曲
→ 曲直

有无开口
→ 开闭
```

---

# 97. 5秒识别卡：数量

```text
交叉多
→ 点

线条多
→ 线

折角多
→ 角

封闭区多
→ 面

小图形多
→ 素
```

---

# 98. 点线角面素的优先级

不要死背固定顺序。

更实用：

```text
哪个最显眼
先数哪个
```

但没思路时可用：

```text
面
→ 线
→ 点
→ 角
→ 素
```

---

# 99. 为什么面常优先

因为封闭区域：

```text
视觉特征强
计数稳定
```

相比：

```text
线段数
角数
```

更不容易产生口径歧义。

---

# 100. 为什么交点多时点优先

大量交叉图如果去数：

```text
线
角
```

容易非常复杂。

交点往往：

