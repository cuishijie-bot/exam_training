# 国考 / 辽宁省考完整版知识库｜图形推理完整版规律库

> 定位：国考、辽宁省考图形推理 **规律总库 + 识别顺序 + 高频母题 + 易错点 + 考场排查法**。
>
> 核心目标不是“记住所有花样”，而是：
>
> ```text
> 看到图形
> → 先判断是哪一大类
> → 按固定顺序排查
> → 找到稳定规律
> → 排除干扰项
> ```

---

# 0. 图形推理总识别顺序

拿到一道图推题，优先按下面顺序排查：

```text
① 图形是否相似？
↓
相似 → 位置规律 / 样式规律

② 图形是否整体结构相近但细节不同？
↓
看属性规律

③ 图形差异较大、元素很多？
↓
看数量规律

④ 是否存在汉字、字母、生活图形、特殊结构？
↓
看特殊规律

⑤ 是否是立方体、展开图、截面图？
↓
看空间重构
```

建议形成固定口令：

```text
相似看位置样式
不同看属性数量
特殊图形找特殊规律
立体图形看空间
```

---

# 1. 第一大类：位置规律

位置规律常见于：

```text
图形组成元素基本相同
只是位置发生变化
```

高频形式：

- 平移
- 旋转
- 翻转
- 循环移动
- 顺逆时针移动
- 内外移动
- 相邻 / 间隔移动
- 多元素分别移动

---

# 2. 位置规律一：平移

## 识别特征

图形元素：

```text
形状不变
数量不变
方向基本不变
只是位置变化
```

优先考虑平移。

---

## 2.1 横向平移

例如：

```text
左 → 中 → 右
```

或：

```text
每次向右移动1格
```

---

## 2.2 纵向平移

```text
上 → 中 → 下
```

---

## 2.3 斜向平移

例如：

```text
左上 → 中 → 右下
```

---

## 2.4 循环平移

到边界后重新回到起点。

例如：

```text
1 → 2 → 3 → 1
```

---

# 3. 位置规律二：旋转

## 识别特征

图形整体或某一部分：

```text
绕中心转动
```

常见角度：

```text
45°
90°
135°
180°
```

---

## 3.1 固定角度旋转

例如：

```text
每次顺时针90°
```

---

## 3.2 顺逆时针交替

例如：

```text
+90°
-90°
+90°
-90°
```

---

## 3.3 角度递增

例如：

```text
45°
90°
135°
180°
```

即每次增加：

```text
45°
```

---

# 4. 位置规律三：翻转

常见：

```text
左右翻转
上下翻转
沿斜线翻转
```

---

## 4.1 左右翻转

镜像轴：

```text
竖直方向
```

---

## 4.2 上下翻转

镜像轴：

```text
水平方向
```

---

## 4.3 旋转与翻转区别

旋转：

```text
方向随角度整体变化
```

翻转：

```text
镜像关系
```

判断时重点看：

```text
左右关系是否交换
```

---

# 5. 多元素位置规律

如果图中有多个元素：

```text
黑点
白点
箭头
小方块
```

不要默认所有元素一起动。

可能：

```text
黑点顺时针1格
白点逆时针2格
箭头隔格移动
```

---

# 6. 位置规律排查模板

看到相似图形先问：

```text
① 元素个数是否一样？
② 元素形状是否一样？
③ 是否只是位置变？
④ 每次移动几格？
⑤ 顺时针还是逆时针？
⑥ 是否循环？
⑦ 不同元素是否分别移动？
```

---

# 7. 第二大类：样式规律

样式规律通常出现在：

```text
图形轮廓相似
元素之间发生叠加或变化
```

高频：

- 加法
- 减法
- 求同
- 求异
- 黑白叠加
- 去同存异
- 去异存同
- 覆盖
- 复合叠加

---

# 8. 样式规律一：相加

两个图形叠加：

```text
所有元素都保留
```

即：

```text
图1 + 图2 = 图3
```

---

# 9. 样式规律二：相减

图1中：

```text
去掉图2已有部分
```

得到图3。

---

# 10. 样式规律三：求同

两个图形共同拥有的部分保留。

```text
相同 → 留
不同 → 去
```

---

# 11. 样式规律四：求异

两个图形不同的部分保留。

```text
相同 → 去
不同 → 留
```

也叫：

```text
去同存异
```

---

# 12. 样式规律五：去异存同

```text
相同 → 留
不同 → 去
```

与求同本质一致。

---

# 13. 样式规律六：黑白叠加

高频于：

```text
九宫格
黑白块
圆点
阴影图形
```

需要观察：

```text
黑+黑
黑+白
白+黑
白+白
```

分别对应什么结果。

例如可能：

```text
黑+黑=白
黑+白=黑
白+黑=黑
白+白=白
```

---

# 14. 黑白叠加做法

先找至少两组对应位置：

```text
图1格子
图2格子
图3格子
```

列规则：

```text
黑+黑 → ?
黑+白 → ?
白+黑 → ?
白+白 → ?
```

若规律唯一，再预测答案。

---

# 15. 样式规律七：覆盖

两个图形叠加时：

```text
某一图形优先显示
```

例如：

```text
后出现图形覆盖前图
```

常见于：

- 箭头
- 黑白区域
- 线段
- 小图标

---

# 16. 样式规律排查模板

```text
① 图1和图2叠加能否得到图3？
② 是全部保留？
③ 是相同保留？
④ 是不同保留？
⑤ 是某些部分覆盖？
⑥ 黑白是否存在运算？
```

---

# 17. 第三大类：属性规律

属性规律常见于：

```text
图形整体差异存在
但某种性质保持一致或交替
```

高频三大属性：

```text
对称性
曲直性
开闭性
```

---

# 18. 属性一：对称性

## 18.1 轴对称

图形沿某条直线折叠后：

```text
两边重合
```

常见：

```text
竖轴
横轴
斜轴
多条对称轴
```

---

## 18.2 中心对称

图形旋转：

```text
180°
```

后与原图重合。

---

## 18.3 对称轴方向

常考：

```text
对称轴每次旋转45°
对称轴方向依次横、竖、斜
```

---

## 18.4 对称轴数量

可能规律：

```text
1、2、3、4……
```

或：

```text
奇数 / 偶数
```

---

# 19. 属性二：曲直性

分类：

```text
全直线
全曲线
曲直混合
```

常见排列：

```text
直 → 曲 → 混
```

或：

```text
直、曲交替
```

---

# 20. 属性三：开闭性

分类：

```text
全封闭
全开放
半开放 / 有开口
```

常见考法：

```text
封闭、开放交替
```

---

# 21. 属性规律其他常见点

还可能考：

```text
是否有直角
是否有锐角
是否有圆弧
是否含三角形
是否含封闭区域
是否能一笔画
是否为轴对称
是否为中心对称
```

---

# 22. 属性排查口诀

```text
对称
曲直
开闭
```

图形差异大时先扫这三个。

---

# 23. 第四大类：数量规律

数量规律是图形推理最重要的大类之一。

常考对象：

```text
点
线
角
面
素
```

口诀：

```text
点线角面素
```

---

# 24. 数量规律一：点

可能数：

- 交点
- 顶点
- 切点
- 端点
- 特殊点

---

# 25. 交点

## 识别

多条线：

```text
互相相交
```

可能规律：

```text
交点数递增
交点数相等
奇偶变化
```

---

# 26. 顶点

多边形：

```text
角的位置
```

可能数顶点。

---

# 27. 切点

曲线和直线：

```text
恰好接触
```

而不是穿过。

---

# 28. 端点

开放线条：

```text
起点
终点
```

尤其常见于：

```text
一笔画
线段组合
```

---

# 29. 数量规律二：线

常见：

```text
直线数
曲线数
总线条数
横线数
竖线数
斜线数
长线短线
内部线 / 外部线
```

---

# 30. 数直线

注意：

```text
被交点分割后是否算多段
```

要根据题目规律判断。

如果明显在数：

```text
线段
```

交点会把一条长线分成多个线段。

---

# 31. 曲线数

例如：

```text
圆
弧线
波浪线
```

可能单独计数。

---

# 32. 数量规律三：角

常见：

```text
总角数
锐角
直角
钝角
内部角
外部角
```

---

# 33. 直角

特别高频于：

```text
方形
折线
字母
汉字
```

---

# 34. 数量规律四：面

“面”一般指：

```text
封闭区域
```

高频。

---

# 35. 封闭区域数

例如：

```text
日 → 2个封闭区域
田 → 4个封闭区域
```

注意：

```text
外围封闭空间是否计入
```

通常只数图形内部形成的封闭区域。

---

# 36. 面数量规律

可能：

```text
1、2、3、4递增
```

或：

```text
2、4、6
```

或：

```text
相邻两图之和等于第三图
```

---

# 37. 数量规律五：素

“素”指：

```text
独立的小图形元素
```

例如：

```text
3个圆
2个三角形
4个小方块
```

---

# 38. 素的种类

不仅可以数：

```text
元素总个数
```

还可数：

```text
元素种类数
```

例如：

```text
圆、三角形、正方形
```

共有：

```text
3种元素
```

---

# 39. 相同元素 / 不同元素

可考：

```text
相同图形个数
不同图形个数
最大元素
最小元素
```

---

# 40. 数量规律常见数列

高频：

```text
1,2,3,4
2,4,6,8
1,3,5,7
2,3,5,8
1,2,4,8
```

也可能：

```text
前两图相加=第三图
前两图相减=第三图
```

---

# 41. 数量规律中的奇偶

例如：

```text
1,3,5
```

都是奇数。

```text
2,4,6
```

都是偶数。

有时不是精确相等，而是：

```text
奇偶交替
```

---

# 42. 数量规律中的恒等

例如每幅图：

```text
交点数=4
封闭面数=2
线条数=6
```

也可能成为规律。

---

# 43. 数量规律中的运算

九宫格常见：

```text
第一格数量 + 第二格数量 = 第三格数量
```

或：

```text
第一格 - 第二格 = 第三格
```

或：

```text
第一格 + 第三格 = 第二格
```

---

# 44. 数量规律排查模板

```text
点：
交点？顶点？端点？

线：
直线？曲线？线段？

角：
锐角？直角？总角数？

面：
封闭区域？

素：
元素个数？元素种类？
```

口诀：

```text
点线角面素
```

---

# 45. 第五大类：特殊规律

当普通：

```text
位置
样式
属性
数量
```

都难解释时，考虑特殊规律。

高频：

- 一笔画
- 多笔画
- 汉字
- 字母
- 图形部分数
- 连接性
- 黑白块
- 重心
- 内外关系
- 相离相交
- 嵌套
- 相邻关系
- 公共边
- 最大最小元素

---

# 46. 一笔画规律

## 判断基础

图形可否：

```text
一笔画完
且不重复走线
```

重点看：

```text
奇点数
```

---

# 47. 奇点

一个点连接的线条数为：

```text
奇数
```

则为奇点。

---

# 48. 一笔画判断

连通图中：

```text
奇点数 = 0 或 2
```

可以一笔画。

---

# 49. 多笔画

最少笔画数与奇点有关。

通常：

```text
奇点数/2
```

但前提：

```text
图形整体连通
```

若存在多个互不相连部分，还要考虑连通分支。

---

# 50. 汉字规律

汉字常考：

- 笔画数
- 封闭面
- 交点
- 对称性
- 部分数
- 横竖撇捺数量
- 是否含某结构

---

# 51. 汉字笔画

不要按书法复杂规则过度纠结。

公务员图推更常看：

```text
明显视觉笔画
结构
封闭面
交点
对称
```

---

# 52. 字母规律

字母常考：

```text
直线数
曲线数
封闭面
对称轴
笔画数
开闭性
```

例如：

```text
A
H
O
B
C
```

---

# 53. 图形部分数

所谓“部分”：

```text
彼此不连接的独立区域
```

例如：

```text
两个分离圆
→ 2部分
```

---

# 54. 连接性

可考：

```text
是否连通
连通部分数量
元素是否相接
```

---

# 55. 相交 / 相切 / 相离

三个图形之间可能按：

```text
相离
相切
相交
```

形成规律。

---

# 56. 内外关系

常见：

```text
小图形在大图形内部
外部
边界上
```

位置可循环：

```text
内 → 边 → 外
```

---

# 57. 相邻关系

多个小元素：

```text
是否相邻
是否间隔
是否对角
```

高频于：

```text
黑白格
九宫格
圆点阵
```

---

# 58. 公共边

多个图形拼接：

```text
公共边数量
```

可能递增或保持一致。

---

# 59. 黑白块规律

除了叠加，还可能考：

```text
黑块数量
黑块位置
黑块连通
黑块移动
黑白交替
对称性
```

---

# 60. 黑块数量

可能：

```text
1,2,3,4
```

或：

```text
始终4个
```

---

# 61. 黑块移动

可能：

```text
每次顺时针移动1格
```

或：

```text
两组黑块分别移动
```

---

# 62. 黑块连通性

例如：

```text
黑块始终相邻
始终不相邻
始终形成一条直线
```

---

# 63. 重心 / 平衡

偶尔会考：

```text
黑块分布左右平衡
上下平衡
重心移动
```

这类频率较低，放在后面考虑。

---

# 64. 第六大类：空间重构

主要包括：

```text
立方体展开图
折叠关系
相邻面
相对面
截面图
三视图
```

---

# 65. 立方体展开图核心

六个面折成立方体后：

```text
相对面不可能相邻
相邻面可以同时出现
```

---

# 66. 相对面判断

常见方法：

```text
同行/同列隔一个面
```

某些标准展开图中：

```text
隔一面相对
```

但不要死背单一版式。

更稳的方法是：

```text
标记公共边
模拟折叠
```

---

# 67. 公共边法

如果两个面在展开图中：

```text
直接共边
```

折叠后：

```text
一定相邻
```

---

# 68. 公共点法

三个面如果在展开图中：

```text
围绕同一顶点
```

折叠后可能共同汇聚到：

```text
同一立方体顶点
```

这是判断选项的重要方法。

---

# 69. 箭头法

如果面上有：

```text
箭头
线段
图案
```

重点看：

```text
相对方向
```

折叠后方向不能随意变化。

---

# 70. 时针法

对三个相邻面：

```text
按照一定顺序观察图案
```

折叠后顺序应保持。

镜像反向的选项：

```text
通常错误
```

---

# 71. 空间题常见错误

```text
只看面是否出现
不看图案方向
```

或：

```text
相对面被放在同一视图中
```

---

# 72. 截面图

常见立体：

```text
立方体
长方体
圆柱
圆锥
球
```

题目问：

```text
某切法能否得到某截面
```

---

# 73. 立方体截面

可能得到：

```text
三角形
四边形
五边形
六边形
```

但最大边数有限。

重点：

```text
切平面能同时经过多少个面
```

---

# 74. 圆柱截面

可能：

```text
圆
椭圆
长方形
```

---

# 75. 圆锥截面

可能：

```text
圆
椭圆
三角形
```

---

# 76. 球截面

任意平面切球：

```text
截面都是圆
```

---

# 77. 三视图

可能给：

```text
主视图
俯视图
左视图
```

要求判断立体结构。

核心：

```text
不同视角的信息要交叉限制
```

---

# 78. 图形分类题

常见：

```text
6幅图分成两组
```

要求：

```text
每组三幅有共同规律
```

---

# 79. 分类题做法

先寻找：

```text
明显二分类属性
```

例如：

- 有无对称
- 奇偶
- 曲直
- 开闭
- 面数
- 一笔画
- 元素种类

---

# 80. 分类题常见结构

例如：

```text
①③⑤一组
②④⑥一组
```

或者：


# 110. 图推高频陷阱一：过度数数量

看到复杂图形，很多人第一反应：

```text
乱数线、角、点
```

正确：

```text
先看属性
再看数量
```

如果图形明显相似：

```text
先看位置和样式
```

---

# 111. 图推高频陷阱二：找到一个规律就停

一个规律必须：

```text
能解释所有图
```

并：

```text
能唯一确定答案
```

如果多个选项都符合：

```text
说明规律不够完整
```

---

# 112. 图推高频陷阱三：只看局部

有时局部满足规律，但整体不满足。

必须验证：

```text
整组图
```

---

# 113. 图推高频陷阱四：旋转与翻转混淆

判断镜像时：

```text
看左右关系有没有互换
```

---

# 114. 图推高频陷阱五：重复计数交点

一个交叉位置：

```text
一般算1个交点
```

不是按穿过几条线重复计算。

---

# 115. 图推高频陷阱六：面和部分混淆

面：

```text
封闭区域数
```

部分：

```text
独立连通块数
```

二者不是一回事。

---

# 116. 图推高频陷阱七：一笔画只看复杂程度

是否一笔画：

```text
不取决于看起来复杂不复杂
```

只看：

```text
连通性
奇点数
```

# 117. 图推高频陷阱八：九宫格只横向找


不要死磕。

# 121. 数量规律排查优先级

一般：

```text
面
→ 线
→ 点
→ 角
→ 素
```

但如果图形明显：

```text
线条交叉很多
```

先数交点。

如果：

```text
封闭区域特别突出
```

先数面。

# 122. 图形特征触发器

看到：

```text
很多交叉
→ 交点
```

看到：

```text
很多小封闭区
→ 面
```

看到：

```text
很多小元素
→ 素
```

看到：

```text
明显镜像
→ 对称
```

看到：

```text
黑白块
→ 黑白数量/位置/叠加
```

看到：

```text
线条复杂连通
→ 一笔画
```

看到：

```text
汉字字母
→ 笔画/面/交点/对称
```

# 123. 分类题快速法

6幅图分两组时，优先尝试：

```text
有/无
奇/偶
对称/不对称
封闭/开放
直/曲
一笔画/非一笔画
```

二分类属性通常更高效。
