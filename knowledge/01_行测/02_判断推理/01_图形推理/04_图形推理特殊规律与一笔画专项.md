```text

→ 数量

```

但如果一眼出现以下特征，可提前触发特殊规律：

```text

→ 一笔画

→ 部分数

→ 公共边

英文字母
→ 字母结构

```

# 1. 第一大类：一笔画

## 1.1 什么是一笔画

在图形推理中通常指：

```text
一笔连续画完整个图形
不中断
不抬笔
不重复走同一条线
```

本质是：

```text
欧拉路径问题
```

---

# 2. 一笔画判断的两个前提

## 前提 1：图形要连通

所有线条必须属于：

```text
同一个连通整体
```

如果图形分成：

```text
两个完全不相连部分
```

不可能一笔完成整个图。

---

## 前提 2：看奇点数量

连通图中：

```text
奇点数 = 0 或 2
```

即可一笔画。

---

# 3. 什么是“点的度数”

一个点连接出去的线条数量叫：

```text
度数
```

例如：

```text
连接2条线 → 度数2
连接3条线 → 度数3
连接4条线 → 度数4
```

---

# 4. 奇点与偶点

## 奇点

连接线条数为奇数：

```text
1
3
5
...
```

---

## 偶点

连接线条数为偶数：

```text
2
4
6
...
```

---

# 5. 一笔画核心结论

对于一个连通图：

```text
奇点数 = 0
→ 可以一笔画
→ 起点终点可以相同

奇点数 = 2
→ 可以一笔画
→ 两个奇点分别是起点和终点

奇点数 > 2
→ 不能一笔画
```

---

# 6. 母题 01｜0 个奇点

## 特征

所有关键点：

```text
连接线条数均为偶数
```

结论：

```text
可以一笔画
```

并可：

```text
从某点出发再回到起点
```

---

# 7. 母题 02｜2 个奇点

结论：

```text
可以一笔画
```

但：

```text
必须从一个奇点出发
在另一个奇点结束
```

---

# 8. 母题 03｜4 个奇点

结论：

```text
不能一笔画
```

若问最少几笔：

```text
通常需要2笔
```

前提：

```text
整体连通
```

---

# 9. 母题 04｜6 个奇点

连通图中：

```text
最少3笔
```

---

# 10. 最少笔画数公式

对于一个连通图：

若奇点数为：

```text
2n
```

则最少笔画数：

```text
n
```

即：

```text
奇点数 / 2
```

特殊情况：

```text
奇点数 = 0
```

最少仍需：

```text
1笔
```

因此：

```text
最少笔画数
= max(1, 奇点数/2)
```

---

# 11. 非连通图的最少笔画

如果图形存在多个：

```text
互不相连的连通部分
```

要对每个部分分别判断。

总最少笔画数：

```text
= 各连通部分最少笔画数之和
```

---

# 12. 一笔画找奇点的正确方法

不要数：

```text
所有视觉顶点
```

只看：

```text
真正有线连接关系变化的点
```

重点：

```text
端点
交点
连接点
```

---

# 13. 一笔画中的端点

开放线条末端：

```text
度数 = 1
```

因此必为：

```text
奇点
```

---

# 14. 一笔画中的普通拐点

一条线只是弯折：

```text
进入1条
出去1条
```

度数：

```text
2
```

属于：

```text
偶点
```

通常无需重点标记。

---

# 15. 一笔画中的十字交叉

如果两条线真正相交并连接：

```text
度数 = 4
```

是：

```text
偶点
```

---

# 16. 一笔画中的 T 形交点

三条线汇合：

```text
度数 = 3
```

属于：

```text
奇点
```

---

# 17. 一笔画中的多线汇合

例如：

```text
5条线汇合
```

度数5：

```text
奇点
```

---

# 18. 高频陷阱一：交叉但“不连接”

部分图形中可能有：

```text
跨线
桥形
明显上下穿过
```

若表示：

```text
不连接
```

就不能把交叉处当节点。

图推一般以图示关系为准。

---

# 19. 高频陷阱二：所有拐角都当奇点

错误。

普通多边形顶点：

```text
连接2条边
```

度数2：

```text
偶点
```

---

# 20. 高频陷阱三：只数端点

复杂一笔画题里：

```text
T形交点
三线交汇
```

也可能产生奇点。

---

# 21. 高频陷阱四：不先检查连通性

即使：

```text
总奇点数为0
```

但图形分成两个不相连部分：

```text
也不能整图一笔完成
```

---

# 22. 一笔画 10 秒法

```text
① 先看是否连通
② 标出端点
③ 标出三线/五线等奇数连接点
④ 数奇点
⑤ 0或2 → 一笔画
```

---

# 23. 一笔画高频母题识别

看到：

```text

但图形整体连着
```

第一反应：

```text
别急着数线
先看奇点
```

# 24. 第二大类：部分数

## 什么是“部分”

彼此完全不连接的：

```text
独立连通块
```

每一块算：

```text
1部分
```

---

# 25. 母题 05｜独立部分数量

例如：

```text
两个互不接触的圆
```

部分数：

```text
2
```

---

# 26. 部分数 vs 元素数

三个小圆都互不连接：

```text
元素数 = 3
部分数 = 3
```

但如果三个图形相互连在一起：

```text
元素数可能仍是3
部分数却是1
```

---

# 27. 部分数 vs 面数

不要混淆。

```text
部分数
= 连通块数量

面数
= 封闭区域数量
```

---

任意有限图中：

```text
奇度顶点数量一定为偶数
```

所以如果你数出：

```text
1、3、5个奇点
```

通常说明：

```text
你数错了
```

这是非常实用的自检规则。

# 96. 高频陷阱三：相切与相交混

```text
接触1点
→ 相切

边界穿过
→ 相交
```

# 97. 高频陷阱四：相邻和公共边混淆

两个方格：

```text
共边
→ 相邻

只共顶点
→ 对角接触
通常不算共边相邻
```

具体按题型口径。

# 98. 高频陷阱五：黑块连通看“边”还是“角”

通常格点图中的连通：

```text
优先按共边连接
```

若题目有特殊定义，以题图规律为准。
