# 1. 图推总口令

```text
相似看位置样式
规整看属性
杂乱看数量
复杂线看一笔画
汉字字母看结构
黑白格看数量位置连通
立体先看相对相邻
```

---

# 2. 15 秒大类判断

## 0～3 秒

问：

```text
图形像不像？
```

如果：

```text
很像
```

先看：

```text
位置
样式
```

---

## 3～6 秒

如果：

```text
图形整体很规整
```

先看：

```text
对称
曲直
开闭
```

---

## 6～10 秒

如果：

```text
图形差异大
元素复杂
```

看：

```text
点
线
角
面
素
```

---

## 10～15 秒

若仍没结果：

```text
复杂线 → 一笔画
分散块 → 部分数
汉字字母 → 特殊结构
黑白块 → 数量/移动/连通
立体 → 空间重构
```

---

# 3. 第一眼触发表

| 第一眼看到 | 第一排查 |
|---|---|
| 图形几乎一样 | 位置 |
| 元素在增减/叠加 | 样式 |
| 很规整 | 对称 |
| 全直/全曲差异 | 曲直 |
| 有无开口 | 开闭 |
| 交叉很多 | 交点 |
| 小封闭区很多 | 面 |
| 小图形很多 | 素 |
| 方折很多 | 直角 |
| 复杂连通线条 | 一笔画 |
| 多个互不连接图形 | 部分数 |
| 多图接触 | 相离/相切/相交 |
| 图形拼接明显 | 公共边 |
| 汉字 | 对称/面/部分/点 |
| 字母 | 曲直/对称/面 |
| 黑白格 | 数量/位置/连通/叠加 |
| 立方体展开图 | 相对面 |
| 三面同时出现 | 公共点/时针 |
| 箭头/斜线/字母在立方体面上 | 公共边方向 |
| 截面 | 经过哪些面 |
| 三视图 | 宽高深约束 |

# 4. 位置规律速查

```text
元素没变
→ 位置
```

高频：

```text
平移
旋转
翻转
循环
顺逆时针
多元素分别移动
```

---

# 5. 平移

先看：

```text
方向
步长
循环
```

常见：

```text
每次1格
每次2格
1、2、3格递增
```

---

# 6. 旋转

常见：

```text
45°
90°
180°
```

也可能：

```text
旋转角递增
顺逆交替
```

---

# 7. 翻转

```text
左右交换
→ 垂直翻转

上下交换
→ 水平翻转
```

---

# 8. 旋转 vs 翻转

看：

```text
非对称细节
```

例如：

```text
箭头
缺口
黑点
```

镜像关系明显：

```text
翻转
```

---

# 9. 多元素移动

不要整体追。

必须：

```text
黑点单独追
白点单独追
箭头单独追
```

常见：

```text
同向不同速
反向移动
一快一慢
```

---

# 10. 连续规律看不出

尝试：

```text
奇数项一组
偶数项一组
```

即：

```text
1→3→5
2→4→6
```

---

# 11. 样式规律速查

前两图像在生成第三图：

```text
样式
```

优先：

```text
相加

求异
黑白叠加
覆盖
```

# 14. 求异

```text

总角
```

# 30. 九宫格数量题

优先：

```text
横向
```

不行：

```text
纵向
```

常见：

```text
1+2=3
1-2=3
```

# 31. 一笔画速查

先看：

```text
是否连通
```

再看：

```text
奇点数
```

---

# 32. 奇点

一个点连接出去的线条数为：

```text
奇数
```

就是奇点。

常见：

```text
端点：度数1
T形点：度数3
```

---

# 33. 一笔画结论

连通图：

```text
0个奇点
→ 一笔画

2个奇点
→ 一笔画

4个奇点
→ 最少2笔

6个奇点
→ 最少3笔
```

---

# 34. 最少笔画数

连通图：

```text
max(1, 奇点数/2)
```

多个不连通部分：

```text
分别计算后相加
```

---

# 35. 一笔画自检

奇点总数：

```text
一定为偶数
```

如果数出：

```text
1
3
5
```

大概率：

```text
数错
```

---

# 36. 部分数

```text
部分数 = 独立连通块数量
```

不要和：

```text
面数
```

混。

---

# 37. 相离 / 相切 / 相交

```text
不接触 → 相离
接触1点 → 相切
穿过/多个交点 → 相交
```

---

# 38. 公共边

两个图形：

```text
共用完整边
```

才叫：

```text
公共边
```

只共顶点：

```text
不算公共边
```

---

# 39. 汉字题速查

顺序：

```text
对称
→ 封闭面
→ 部分数
→ 交点
→ 直角
→ 笔画
```

不要一上来：

```text
数笔画
```

---

# 40. 字母题速查

顺序：

```text
曲直
→ 对称
→ 封闭面
→ 开闭
→ 线条
```

按：

```text
题图字体
```

判断。

---

# 41. 黑白块速查

顺序：

```text
数量
→ 位置
→ 移动
→ 连通
→ 相邻
→ 对称
→ 叠加
```

若明显是：

```text
前两图生成第三图
```

则叠加提前。

# 44. 九宫格速查

```text
先横
再纵
最后斜
```

常见：

```text
位置
样式叠加

```

# 45. 立方体总口令

```text
先相对
再相邻
三面共点看时针
图案方向看公共边
```

---

# 46. 相对面

```text
相对面永远不相邻
```

选项若让相对面：

```text
共边
共点
```

直接排。

---

# 47. 相邻面

展开图中：

```text
直接共边
```

折叠后：

```text
一定相邻
```

---

# 48. 三面共点

三个面若在立方体一个顶点相交：

```text
必须两两相邻
```

---

# 49. 时针法

三个面围绕公共点：

```text
顺逆时针顺序不能镜像反转
```

整体旋转：

```text
不影响这一顺序
```

---

# 50. 箭头法

不要死记二维上下左右。

看：

```text
箭头相对公共边的位置
```

---

# 51. 图案镜像

折叠：

```text
是空间旋转
```

不是：

```text
镜像翻转
```

字母、数字出现镜像：

```text
优先排除
```

---

## 立方体 / 长方体

常见：

```text
三角形
四边形
五边形

```

不会出现：

```text
圆

```


# 54. 圆锥截面

```text
平行底面 → 圆

斜切 → 椭圆
```

# 55. 球截面

```text
圆
```

# 56. 三视图

```text
主视图 = 宽 + 高
俯视图 = 宽 + 深
左视图 = 深 + 高
```

必须：

```text
多个视角交叉限制
```

---

# 57. 小立方体

数数量：

```text
分层法
柱高法
```

注意：

```text
遮挡块
支撑块
```

---

# 58. 表面涂色

n×n×n：

```text
3面涂色 = 8

2面涂色 = 12(n-2)

1面涂色 = 6(n-2)^2

0面涂色 = (n-2)^3
```

# 60. 高频陷阱一页版

```text
□ 图形相似时别先乱数
□ 找规律必须解释全部图
□ 多个选项符合说明规律不完整
□ 旋转 ≠ 翻转
□ 多元素要分别追踪
□ 黑白叠加必须建表
□ 求同 = 相同留
□ 求异 = 不同留
□ 面 ≠ 部分
□ 交点不要重复算
□ 一笔画先看连通
□ 奇点数量一定为偶数
□ 汉字别先数笔画
□ 字母按题图字体
□ 黑白块不一定考叠加
□ 相对面永不相邻
□ 三面共点必须两两相邻
□ 折叠不是镜像
□ 空间题别只靠脑补
```

# 61. 最容易错的 10 个点

## ① 图形相似还去数线

正确：

```text
先位置 / 样式
```

---

## ② 旋转翻转分不清

正确：

```text
盯非对称细节
```

---

## ③ 多元素只追一个

正确：

```text
逐个追踪
```

---

## ④ 黑白叠加靠猜

正确：

```text
列四种组合
```

---

## ⑤ 面和部分混

```text
面 = 封闭区域
部分 = 连通块
```

---

## ⑥ 乱数点线角面素

正确：

```text
哪个视觉特征最突出先数哪个
```

---

## ⑦ 一笔画忘记连通

正确：

```text
连通 → 奇点
```

---

## ⑧ 汉字先数笔画

正确：

```text
对称/面/部分/点优先
```

---

## ⑨ 相对面出现在一起还没排除

正确：

```text
相对面永不相邻
```

---

## ⑩ 立体题凭感觉

正确：

```text
相对面
公共边
公共点
时针
```

# 66. 最终 20 行极简版

如果只能背一页：

```text
1. 相似看位置样式
2. 规整看对称曲直开闭
3. 杂乱看点线角面素
4. 交叉多先数点
5. 封闭多先数面
6. 小图多先数素
7. 方折多看直角
8. 复杂连通线先看一笔画
9. 一笔画先连通后奇点
10. 奇点0或2可一笔画
11. 求同=共同留
12. 求异=不同留
13. 黑白叠加必须建表
14. 多元素必须分别追踪
15. 面=封闭区，部分=连通块
16. 汉字先看对称/面/部分/点
17. 立方体先排相对面
18. 三面共点必须两两相邻
19. 图案方向看公共边
20. 找到规律后必须验证全部图
```

# 70. 图形推理最终使用方式

```text
不知道规律有哪些
→ 看01

相似图形做不出
→ 看02

图形不相似、乱数
→ 看03

特殊结构不会
→ 看04

立体空间不会
→ 看05

做错题要归类
→ 看06

考前 / 公交
→ 只看07
```

图形推理最终目标：

```text
不是“想到所有可能规律”
而是
“按固定顺序快速缩小范围”
```
