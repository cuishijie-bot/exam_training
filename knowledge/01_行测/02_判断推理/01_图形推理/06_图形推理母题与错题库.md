>
> ```text
> 新题
> ↓
> 看视觉特征
> ↓
> 匹配母题
> ↓
> 按固定顺序排查
> ↓
> 归档错题

>
> ```text
> “这题没见过”
> ↓
> “但它属于我见过的母题”
> ```

# 92. 视觉触发词总表

| 第一眼看到 | 第一排查 |
|---|---|
| 图形几乎一样 | 位置 |
| 前两图像在合成第三图 | 样式 |
| 很规整 | 对称 |
| 全直/全曲差异 | 曲直 |
| 有无开口 | 开闭 |
| 交叉很多 | 交点 |
| 小封闭区很多 | 面 |
| 小图形很多 | 素 |
| 方折很多 | 直角 |
| 复杂连通线条 | 一笔画 |
| 图形彼此分离 | 部分数 |
| 多图接触 | 相交/相切 |
| 小图拼接 | 公共边 |
| 汉字 | 对称/面/部分/点 |
| 字母 | 曲直/对称/面 |
| 黑白格 | 数量/位置/连通/叠加 |
| 立方体展开图 | 相对面 |
| 三面同时出现 | 公共点/时针 |
| 图案有箭头 | 公共边方向 |
| 截面 | 经过哪些面 |
| 三视图 | 宽高深约束 |

# 94. “最小充分规律”原则

正确规律必须：

```text
① 能解释全部图
② 能唯一选答案
③ 尽量简单
```

不要追求：

```text
复杂但花哨
```

# 117. 陌生题处理法

如果完全没见过：

```text
先不要问“规律是什么”
```

先问：

```text
图形相似吗？
是否规整？
是否交叉多？
是否封闭多？
是否小元素多？
是否复杂连通？
是否立体？
```

先确定：

```text
大类
```

再缩小。

# 118. 15 秒大类判断

```text
0～3秒：
相似吗？

相似

3～6秒：
规整吗？

规整
→ 属性

6～10秒：
数量特征明显吗？

明显
→ 点线角面素

10～15秒：
特殊结构？

复杂线 → 一笔画
汉字字母 → 特殊
立体 → 空间
```
