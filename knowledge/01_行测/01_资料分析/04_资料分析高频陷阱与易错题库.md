# 0. 易错题总原则

每道资料分析题先问自己：

```text
① 问的是哪一年？
② 问的是谁？
③ 问的是哪个指标？
④ 单位是什么？
⑤ 问的是量还是率？
⑥ 问的是百分数还是百分点？
⑦ 是现期还是基期？
⑧ 分子是谁，分母是谁？
⑨ 有没有“约”“至少”“超过”等限定词？
⑩ 能不能先排除？
```

---

# 1. 陷阱一：时间口径偷换

## 常见形式

材料给：

```text
2025年全年
2025年1—6月
2025年6月
```

题目可能故意混：

```text
全年
累计
单月
```

---

## 易错例题 1

材料：

```text
2025年1—6月某省出口额为600亿元，同比增长20%。
2025年6月出口额为120亿元，同比增长10%。
```

题目：

> 2024年6月出口额约为多少？

### 正确

必须用：

```text
120 / 1.10
```

不能用：

```text
600 / 1.20
```

### 错因

```text
T-累计值与单月值混淆
```

---

# 2. 陷阱二：同比和环比偷换

## 同比

```text
2026年6月
vs
2025年6月
```

## 环比

```text
2026年6月
vs
2026年5月
```

---

## 易错例题 2

2026 年 6 月某商品销量为 110 万件，同比增长 10%，环比下降 5%。

问：

> 2025 年 6 月销量约为多少？

### 正确

```text
110/1.10 = 100
```

环比数据：

```text
-5%
```

是干扰项。

---

# 3. 陷阱三：累计同比偷换

“1—6 月同比增长”：

```text
今年1—6月
vs
去年1—6月
```

不是：

```text
6月 vs 5月
```

也不是：

```text
上半年 vs 全年
```

---

# 4. 陷阱四：主体偷换

材料可能同时有：

```text
全省
全市
规模以上企业
全部企业
国有企业
民营企业
```

题目可能只换一个词。

---

## 易错例题 3

材料：

```text
全省规模以上工业企业利润增长12%。
其中民营企业利润增长18%。
```

题目：

> 全省工业企业利润增长12%。

### 判断

不能直接推出。

因为材料是：

```text
规模以上工业企业
```

不是：

```text
全部工业企业
```

### 错因

```text
R-统计口径偷换
```

---

# 5. 陷阱五：单位偷换

常见：

```text
元
万元
亿元
万人
人
万吨
吨
万平方米
平方米
```

---

## 易错例题 4

GDP：

```text
6000亿元
```

人口：

```text
300万人
```

人均 GDP：

```text
6000亿元 / 300万人
= 2万元/人
```

不是：

```text
20万元
```

---

# 6. 单位速查

```text
1亿元 = 10000万元
1亿元 = 100000000元

1万人 = 10000人

1万吨 = 10000吨

1万平方米 = 10000平方米
```

# 7. 陷阱六：增长量和增长率偷换

## 关键词

```text
增长多少
```

通常：

```text
增长量
```

```text
增长百分之多少
```

通常：

```text
增长率
```

---

## 易错例题 5

某指标：

```text
上年100
今年120
```

### 增长量

```text
20
```

### 增长率

```text
20%
```

这两个答案不能互换。

---

# 8. 陷阱七：现期量乘增长率

这是资料分析最经典错误之一。

现期：

```text
A
```

同比增长：

```text
r
```

增长量不是：

```text
A×r
```

而是：

```text
A×r/(1+r)
```

---

## 易错例题 6

现期：

```text
120
```

同比增长：

```text
20%
```

错误：

```text
增长24
```

正确：

```text
120×20%/120%
=20
```

---

# 9. 陷阱八：下降量公式方向错误

现期 A，同比下降 r。

减少量：

```text
A×r/(1-r)
```

不是：

```text
A×r
```

---

## 易错例题 7

现期：

```text
80
```

同比下降：

```text
20%
```

基期：

```text
80/0.8=100
```

减少量：

```text
20
```

而：

```text
80×20%=16
```

错误。

---

# 10. 陷阱九：基期量直接减增长率

增长后求原值：

```text
A/(1+r)
```

不是：

```text
A×(1-r)
```

---

## 易错例题 8

现期：

```text
150
```

增长：

```text
50%
```

基期：

```text
150/1.5=100
```

错误：

```text
150×50%=75
```

---

# 11. 陷阱十：百分数与百分点

## 百分点

两个百分率直接作差。

例如：

```text
20% → 25%
```

提高：

```text
5个百分点
```

---

## 相对增长率

```text
(25%-20%)/20%
=25%
```

---

# 12. 易错例题 9

某产业占 GDP 比重：

```text
上年20%
本年24%
```

题目：

> 比重提高了多少？

若选项：

A. 4%  
B. 4个百分点  
C. 20%  
D. 24%

正确：

```text
B
```

---

# 13. 陷阱十一：增速提高 ≠ 增长率本身

去年：

```text
10%
```

今年：

```text
15%
```

增速提高：

```text
5个百分点
```

不是：

```text
15%
```

---

# 14. 陷阱十二：降幅扩大 / 收窄

去年：

```text
下降12%
```

今年：

```text
下降8%
```

说明：

```text
降幅收窄4个百分点
```

不是：

```text
增长4个百分点
```

---

# 15. 陷阱十三：负增长率作差

去年：

```text
-5%
```

今年：

```text
8%
```

增速提高：

```text
8%-(-5%)
=13个百分点
```

---

# 16. 陷阱十四：比重升降直接看现期量

比重变化：

```text
部分增速 vs 整体增速
```

不能只看：

```text
部分量变大了
```

---

## 易错例题 10

某产业增加值：

```text
从100增长到105
```

GDP：

```text
从500增长到550
```

虽然产业增加值增加了，但：

```text
产业增速5%
GDP增速10%
```

所以：

```text
产业占比下降
```

---

# 17. 陷阱十五：比重变化直接用增速差

部分增速：

```text
20%
```

整体增速：

```text
10%
```

不能说：

```text
比重提高10个百分点
```

只能先说：

```text
比重上升
```

变化量还需要：

```text
现期比重
```

---

# 18. 易错例题 11

现期比重：

```text
30%
```

部分增速：

```text
20%
```

整体增速：

```text
10%
```

比重变化：

```text
30%×10%/120%
=2.5个百分点
```

不是：

```text
10个百分点
```

---

# 19. 陷阱十六：基期比重公式方向反

正确：

```text
基期比重
= 现期比重 × (1+整体增速)/(1+部分增速)
```

记忆：

```text
整体在上
部分在下
```

---

# 20. 易错例题 12

现期比重 20%。

部分增速：

```text
20%
```

整体增速：

```text
10%
```

基期比重：

```text
20%×1.10/1.20
≈18.33%
```

如果写成：

```text
20%×1.20/1.10
```

方向就反了。

---

# 21. 陷阱十七：平均数增长率只算增速差

正确：

```text
(a-b)/(1+b)
```

不是：

```text
a-b
```

---

## 易错例题 13

收入增长：

```text
10%
```

人数增长：

```text
5%
```

人均收入增长：

```text
5%/1.05
≈4.76%
```

---

# 22. 陷阱十八：平均数升降其实不用算

如果：

```text
总量增速 > 份数增速
```

平均数上升。

如果：

```text
总量增速 < 份数增速
```

平均数下降。

---

## 易错例题 14

旅游收入增长：

```text
12%
```

游客增长：

```text
15%
```

人均消费：

```text
下降
```

无需计算。

---

# 23. 陷阱十九：把“平均数增长量”和“平均数增长率”混

### 增长率

```text
(a-b)/(1+b)
```

### 增长量

```text
现期平均数 × (a-b)/(1+a)
```

---

# 24. 陷阱二十：倍数表述

### A 是 B 的几倍

```text
A/B
```

### A 比 B 多几倍

```text
A/B-1
```

---

## 易错例题 15

A=400，B=100。

```text
A是B的4倍
A比B多3倍
A比B多300%
```

---

# 25. 陷阱二十一：翻番

```text
翻1番 = 2倍 = 增长100%
翻2番 = 4倍 = 增长300%
翻3番 = 8倍 = 增长700%
```

不要把：

```text
翻2番
```

理解为：

```text
增长200%
```

---

# 26. 陷阱二十二：先涨后跌同幅不回原值

```text
+20%
再-20%
```

结果：

```text
1.2×0.8=0.96
```

即：

```text
下降4%
```

---

# 27. 陷阱二十三：隔年增长率只相加

正确：

```text
r1+r2+r1r2
```

---

## 易错例题 16

去年：

```text
10%
```

今年：

```text
20%
```

两年：

```text
32%
```

不是：

```text
30%
```

---

# 28. 陷阱二十四：一增一降忽略乘积项

去年：

```text
+20%
```

今年：

```text
-10%
```

累计：

```text
20%-10%-2%
=8%
```

不是：

```text
10%
```

---

# 29. 陷阱二十五：年均增长次数

2020 到 2025：

```text
增长次数 = 5
```

不是：

```text
6
```

---

# 30. 年均增长的特殊时间口径

如果题目明确说：

```text
“2019—2023五年间平均每年……”
```

要根据题意判断是：

- 首末期比较
- 五个年度平均
- 还是四次增长

不要机械套年份差。

# 31. 陷阱二十六：年均增长率与年均增长量

### 年均增长率

答案单位：

```text
%
```

### 年均增长量

答案单位：

```text
亿元、万吨、万人……
```

---

# 32. 陷阱二十七：混合增长率简单平均

A 增长：

```text
5%
```

B 增长：

```text
15%
```

总体不一定：

```text
10%
```

除非：

```text
A、B基期量相等
```

---

# 33. 陷阱二十八：混合增长用现期量作权重

精确权重应为：

```text
基期量
```

不是：

```text
现期量
```

---

# 34. 易错例题 17

A：

```text
现期120，增长20%
```

B：

```text
现期110，增长10%
```

基期：

```text
A基期=100
B基期=100
```

所以总体增速：

```text
(20%+10%)/2
=15%
```

若直接按现期量加权：

```text
会产生误差
```

---

# 35. 陷阱二十九：混合增长率超范围

如果两个部分：

```text
5%
15%
```

总体增长率不可能：

```text
18%
```

这是最容易秒杀的判断。

---

# 36. 陷阱三十：十字交叉比例方向反

如果：

```text
低速 r1
高速 r2
总体 r
```

则：

```text
低速部分基期量 : 高速部分基期量
=
(r2-r):(r-r1)
```

---

# 37. 易错例题 18

```text
甲5%
乙15%
总体8%
```

甲乙基期比：

```text
(15-8):(8-5)
=7:3
```

不是：

```text
3:7
```

---

# 38. 陷阱三十一：拉动与贡献混淆

### 拉动

```text
部分增长量 / 整体基期量
```

### 贡献

```text
部分增长量 / 整体增长量
```

---

# 39. 易错例题 19

某产业增长量：

```text
200
```

整体基期：

```text
5000
```

整体增长量：

```text
500
```

拉动：

```text
200/5000=4%
```

贡献：

```text
200/500=40%
```

---

# 40. 陷阱三十二：贡献率超过100%就认为错

贡献率可以：

```text
>100%
```

前提可能是：

```text
其他部分负增长
```

导致：

```text
某部分增长量 > 总体增长量
```

---

# 41. 陷阱三十三：贡献率可以为负

若某部分下降：

```text
部分增长量<0
```

整体却增长：

```text
整体增长量>0
```

则贡献率：

```text
<0
```

表示：

```text
拖累增长
```

---

# 42. 陷阱三十四：顺差逆差符号

出口 > 进口：

```text
顺差
```

进口 > 出口：

```text
逆差
```

题目有时会问：

```text
贸易差额
```

要看正负方向。

---

# 43. 陷阱三十五：顺差扩大不等于出口增速更高就直接结束

如果：

```text
出口增速 > 进口增速
```

通常有利于顺差扩大，但如果基期结构不同，最好在需要精确判断时计算基期出口、进口及差额。

---

# 44. 易错例题 20

现期：

```text
出口900，增长20%
进口800，增长5%
```

基期：

```text
出口750
进口≈762
```

基期其实：

```text
逆差约12
```

现期：

```text
顺差100
```

贸易差额明显改善。

---

# 45. 陷阱三十六：部分量最大 ≠ 占比最大

占比：

```text
部分/整体
```

若不同地区整体不同：

```text
部分量最大
```

不代表：

```text
占比最大
```

---

# 46. 陷阱三十七：增长率最大 ≠ 增长量最大

增长量：

```text
A×r/(1+r)
```

必须同时看：

```text
规模
+
增长率
```

---

# 47. 易错例题 21

甲：

```text
现期1000，增长10%
```

乙：

```text
现期300，增长30%
```

增长量：

```text
甲≈91
乙≈69
```

虽然乙增速更高：

```text
增长量仍是甲更大
```

---

# 48. 陷阱三十八：现期最大 ≠ 基期最大

基期：

```text
A/(1+r)
```

高增长率可能显著拉低基期值。

---

# 49. 陷阱三十九：平均数高低与总量高低混

某地区：

```text
总收入更高
```

不代表：

```text
人均收入更高
```

因为：

```text
还要除以人数
```

---

# 50. 陷阱四十：阈值题不必要地做除法

判断：

```text
A/B > 20%
```

直接：

```text
A > B/5
```

通常比除法快。

---

# 51. 陷阱四十一：排序题四项全算

正确策略：

```text
先找最大
先找最小
排除错误选项
只算临界项
```

---

# 52. 陷阱四十二：综合判断题从 A 开始硬算到底

更优：

```text
优先验证简单项
```

通常顺序：

```text
读取
→ 大小判断
→ 比重升降
→ 混合范围
→ 简单除法
→ 多步计算
```

---

看到：

```text

全部
均

至多

```


# 56. 综合判断陷阱四：增长快慢与规模大小偷换

```text
A增长最快
```

# 57. 综合判断陷阱五：同比增长与占比增长偷换


# 58. 综合判断陷阱六：增速高于总体就一定贡献最大

错误。

贡献率还受：

```text
基期规模
```

影响。

# 59. 图表陷阱一：纵轴不从0开始

折线图、柱状图的纵轴可能：

```text
从80开始
```

导致视觉差距被放大。

必须看：

```text
刻度
```

---

# 60. 图表陷阱二：双坐标轴

一个图可能：

```text
左轴表示总量
右轴表示增速
```

不要拿：

```text
柱高
```

去读：

```text
折线刻度
```

---

# 61. 图表陷阱三：图例颜色/线型

考试中要注意：

```text
实线
虚线
柱状颜色
年份
指标
```

一旦图例看反，整题都错。

---

# 62. 图表陷阱四：同比折线与总量柱混

高总量：

```text
不等于高增速
```

高折线点：

```text
不等于高柱
```

# 63. 表格陷阱一：错行错列

做表格题时建议：

```text
先定位行
再定位列
最后看单位
```

不要边读题边扫整张表。

---

# 64. 表格陷阱二：合计值重复计算

表格可能同时列：

```text
总计
甲
乙
丙
```

若问部分和：

```text
不要把总计再次加进去
```

---

# 65. 表格陷阱三：脚注

常见脚注：

```text
不含某地区
按可比价格计算
以上数据未包括……
```

综合判断题很爱利用脚注出陷阱。

# 66. 文字材料陷阱一：多个百分率扎堆

题目会故意放：

```text
同比
占比
增速
贡献率
```

连续出现。

正确做法：

```text
先明确每个百分率的含义
```

---

# 67. 文字材料陷阱二：同一段多个主体

例如：

```text
全省增长5%，其中A增长8%，B下降2%，C增长10%
```

题目问 A 时：

```text
不要误拿全省5%
```

---

# 68. 文字材料陷阱三：同比增速与增速变化同时出现

例如：

```text
同比增长12%，增速比上年提高3个百分点
```

则上年增速：

```text
9%
```

不是：

```text
3%
```

---

# 69. 易错例题 22

今年增长率：

```text
12%
```

比上年提高：

```text
3个百分点
```

上年增长率：

```text
12%-3%=9%
```

---

# 70. 文字材料陷阱四：增速回落

今年：

```text
增长8%
```

增速回落：

```text
2个百分点
```

上年：

```text
10%
```

---

# 71. 文字材料陷阱五：降幅收窄

今年：

```text
下降5%
```

降幅比上年收窄：

```text
3个百分点
```

上年：

```text
下降8%
```

---

# 72. 易错题：基期增长率反推

题目：

```text
今年增长10%，增速比去年提高4个百分点
```

去年增长率：

```text
6%
```

---

# 73. 易错题：隔年增长叠加

若：

```text
去年增长6%
今年增长10%
```

两年累计：

```text
6%+10%+0.6%
=16.6%
```

---

# 74. 易错题：两期比重方向

部分增速：

```text
-5%
```

整体增速：

```text
-10%
```

注意：

```text
-5% > -10%
```

所以部分下降得更慢：

```text
比重上升
```

---

# 75. 易错题：平均数方向

总量增速：

```text
-3%
```

份数增速：

```text
-8%
```

由于：

```text
-3% > -8%
```

所以平均数：

```text
上升
```

---

# 76. 易错题：增长率为负时公式照用

平均数增长率：

```text
(a-b)/(1+b)
```

只要：

```text
1+b > 0
```

仍可直接使用。

---

# 77. 易错题：比重变化中 a 为负

两期比重差：

```text
现期比重×(a-b)/(1+a)
```

方向仍看：

```text
a-b
```

---

# 78. 陷阱：百分点变化可能超过增速差吗

一般常见正增长情形下：

```text
比重变化量
= 现期比重×(a-b)/(1+a)
```

因为现期比重 < 1：

```text
通常小于 |a-b|
```

可用于排除明显离谱选项。

---

# 79. 陷阱：增长量近似方向

增长时：

```text
Δ = A×r/(1+r)
```

所以：

```text
A×r
```

是：

```text
偏大的估算
```

---

# 80. 陷阱：下降量近似方向

下降时：

```text
D = A×r/(1-r)
```

所以：

```text
A×r
```

是：

```text
偏小的估算
```

---

# 81. 截位陷阱：误差方向不清

如果：

```text
分子截小
分母截大
```

结果：

```text
必偏小
```

如果：

```text
分子截大
分母截小
```

结果：

```text
必偏大
```

---

# 82. 截位陷阱：选项接近仍大幅截位

选项：

```text
20.3%
20.7%
21.0%
21.4%
```

不能只截：

```text
前1～2位
```

---

# 83. 百化分陷阱：近似分数不是完全等于

```text
33.3% ≈ 1/3
16.7% ≈ 1/6
14.3% ≈ 1/7
```

如果选项非常接近：

```text
不能把近似当精确
```

---

# 84. 差分法陷阱

差分法只适合：

```text
两个分数接近
且
分子分母同方向变化
```

不要见两个分数就用。

---

# 85. 交叉相乘陷阱

交叉相乘适合：

```text
比较两个分数大小
```

若数字巨大且明显可估：

```text
截位直除可能更快
```

---

# 86. 年均增长率陷阱：直接平均每年增速

如果每年增速不同：

```text
不能简单算算术平均
```

严格年均增长率应满足：

```text
末期 = 初期×(1+r)^n
```

---

# 87. 年均增长量陷阱：除以年份个数

2020 到 2025：

```text
年份差 = 5
```

年均增长量：

```text
(末-初)/5
```

不是除以：

```text
6
```

---

# 88. 贸易题陷阱：总额与差额

```text
进出口总额 = 出口+进口
贸易差额 = 出口-进口
```

一加一减。

---

# 89. 贸易题陷阱：顺差率/逆差率

如果题目出现：

```text
顺差占进出口总额比重
```

则：

```text
顺差 / 进出口总额
```

不是：

```text
顺差 / 出口
```

---

# 90. 陷阱：比例和比值混

```text
A:B = 2:3
```

则：

A 占 A+B：

```text
2/5
```

B 占：

```text
3/5
```

不是：

```text
2/3
```

---

# 91. 易错例题 23

男女比例：

```text
2:3
```

男性占总人数：

```text
2/(2+3)=40%
```

# 92. 陷阱：部分占其余部分

A 占总体：

```text
40%
```

A 占“其他部分”的比：

```text
40%/60%
=2/3
```

不是：

```text
40%
```

---

# 93. 陷阱：增长率由现期增长量反推

现期：

```text
120
```

增长量：

```text
20
```

增长率：

```text
20/(120-20)
=20%
```

不是：

```text
20/120
```

---

# 94. 陷阱：下降率由现期与减少量反推

现期：

```text
80
```

减少量：

```text
20
```

基期：

```text
100
```

下降率：

```text
20%
```

不是：

```text
20/80=25%
```

# 95. 陷阱：现期是基期几倍与增长率

如果：

```text
现期/基期 = 1.5
```

则增长率：

```text
50%
```

不是：

```text
150%
```

# 96. 陷阱：增长100%与“增加1倍”

增长：

```text
100%
```

等于：

```text
增加1倍
```

最终变成：

```text
原来的2倍
```

# 97. 陷阱：多几倍与多百分比

```text
多2倍
= 多200%
```

最终：

```text
是原来的3倍
```

# 98. 陷阱：问“最接近”还追求精确

“约为”“最接近”：

```text
允许估算
```

不要为小数点后第三位浪费时间。

# 99. 陷阱：问“正确的是”算完三个错项还继续

且题目为：

```text
正确的是
```

一般可以停止。

# 100. 陷阱：问“错误的是”找到错误项还继续

如果两个选项：

```text

```

通常至少可快速排掉一个。

先利用：


# 102. 陷阱：数量级判断没先做


先判断数量级：


# 103. 陷阱：单位换算后数量级错一位

常见：

```text
亿元/万人
```

正确结果通常是：

```text
万元/人
```

建议记：

```text
亿元 ÷ 万人
```

# 104. 陷阱：万人/平方公里

```text
人口/面积
```

如果人口单位万人：

```text

```

或者最后统一数量级。

# 110. 错题升级成模型


# 125. 最终易错清单

考试前只看这一页即可：

```text
□ 去年 = 现期/(1+r)
□ 增长量 ≠ 现期×增长率
□ 下降量分母是1-r
□ 百分数 ≠ 百分点
□ 增速提高看百分点
□ 占比升降只比两个增速
□ 比重变化 ≠ 两增速之差
□ 平均数增长率 ≠ a-b
□ 是几倍 ≠ 多几倍
□ 隔年别忘乘积项
□ 年均增长次数看年份差
□ 混合增长率在部分之间
□ 混合权重看基期量
□ 拉动 ≠ 贡献
□ 增速大 ≠ 增长量大
□ 总量大 ≠ 平均数大
□ 部分量大 ≠ 占比大
□ 同比 ≠ 环比
□ 累计 ≠ 单月
□ 亿元/万人 = 万元/人
□ 综合判断先验证简单项
```
