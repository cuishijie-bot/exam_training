# 国考 / 辽宁省考完整版知识库｜资料分析速算技巧库 + 典型题型模型

> 配套文件：`01_资料分析完整版知识库.md`  
> 本文件定位：**把公式转化为“看到题干就会做”的解题模板**。  
> 核心目标：不是“会公式”，而是做到：
>
> ```text
> 看到题干关键词
> → 立刻识别题型
> → 立刻写出固定模型
> → 判断能否不算 / 少算 / 估算
> → 只保留足够选出答案的精度
> ```
>
> 适用：国考、辽宁省考、事业单位及其他常见公考资料分析。

---

# 0. 资料分析总作战流程

每道题统一执行：

```text
① 看问题，不先通读材料
↓
② 圈时间
↓
③ 圈主体
↓
④ 圈指标
↓
⑤ 圈问法
↓
⑥ 判断题型
↓
⑦ 写公式
↓
⑧ 看选项差距
↓
⑨ 决定：判断 / 估算 / 精算
↓
⑩ 检查单位
```

真正需要练成条件反射的是：

```text
题干翻译能力
```

即把中文题干翻译成数学关系。

---

# 1. 题干翻译总表

| 看到题干 | 第一反应 |
|---|---|
| 去年、上年、基期 | 基期量 |
| 比上年增加多少 | 增长量 |
| 同比增长多少 | 增长率 |
| 占、占比、比重 | 部分 ÷ 整体 |
| 去年占比 | 基期比重 |
| 占比提高多少 | 两期比重差 |
| 人均、户均、平均、每 | 平均数 |
| 平均数增长率 | `(a-b)/(1+b)` |
| 是……的几倍 | `A/B` |
| 比……多几倍 | `A/B-1` |
| 两年累计增长 | 隔年增长率 |
| 年均增长率 | 开 n 次方 |
| 年均增加 | `(末-初)/年份差` |
| 总体由两部分组成 | 混合增长 |
| 拉动增长 | 部分增长量 ÷ 整体基期量 |
| 贡献率 | 部分增长量 ÷ 整体增长量 |
| 提高几个百分点 | 两个百分率直接作差 |
| 顺差 | 出口 - 进口 |
| 逆差 | 进口 - 出口 |
| 排名第几 | 先粗比，再精比临界项 |
| 哪项正确 | 先算简单项，后算复杂项 |

# 2. 做题前：先看选项

资料分析很多题的计算方法由选项决定。

## 2.1 选项差距很大

例如：

```text
A. 12.3%
B. 18.7%
C. 26.4%
D. 41.8%
```

可以：

```text
大幅截位
```

甚至只算前两位。

---

## 2.2 选项差距较小

例如：

```text
A. 12.3%
B. 12.8%
C. 13.2%
D. 13.7%
```

需要：

```text
少截位
或
交叉相乘
或
精确到前三位有效数字
```

---

## 2.3 选项是范围

例如：

```text
A. 低于10%
B. 10%～15%
C. 15%～20%
D. 20%以上
```

只需要算到：

```text
落在哪个区间
```

不需要精算。

---

# 3. 三种计算等级

资料分析每题都先判断属于哪一级。

## 一级：不算

直接判断：

- 比重升降
- 平均数升降
- 混合增长率范围
- 明显大小关系
- 单位数量级

---

## 二级：估算

使用：

- 截位直除
- 百化分
- 放缩
- 化同
- 分数比较

---

## 三级：精算

仅用于：

- 选项极接近
- 判断题临界项
- 连续复合增长
- 小数差异敏感
- 题目明确要求精确关系

原则：

```text
能一级解决，不进二级；
能二级解决，不进三级。
```

---

# 4. 速算技巧一：截位直除

## 4.1 适用

看到：

```text
A/B
```

优先考虑。

例如：

```text
比重
平均数
倍数
增长率
基期量
```

---

## 4.2 基本规则

```text
选项差距大 → 截前2位
选项差距中 → 截前3位
选项差距小 → 少截或不截
```

---

## 4.3 示例

```text
123456 / 456789
```

粗算：

```text
123 / 457 ≈ 0.27
```

如果选项：

```text
A. 18%
B. 27%
C. 36%
D. 45%
```

直接选：

```text
27%
```

无需精算。

---

# 5. 截位的“同方向误差”

如果：

```text
分子截小
分母截大
```

则结果一定：

```text
偏小
```

如果：

```text
分子截大
分母截小
```

则结果：

```text
偏大
```

这可以用来判断：

```text
真实值在估算值哪一侧
```

---

# 6. 速算技巧二：百化分

必须熟记：

```text
50%   = 1/2
33.3% ≈ 1/3
25%   = 1/4
20%   = 1/5
16.7% ≈ 1/6
14.3% ≈ 1/7
12.5% = 1/8
11.1% ≈ 1/9
10%   = 1/10
9.1%  ≈ 1/11
8.33% ≈ 1/12
7.14% ≈ 1/14
6.67% ≈ 1/15
6.25% = 1/16
5%    = 1/20
4%    = 1/25
3.33% ≈ 1/30
2.5%  = 1/40
2%    = 1/50
1%    = 1/100
```

---

# 7. 百化分：增长量秒杀模型

增长量：

```text
Δ = A × r/(1+r)
```

若：

```text
r = 1/n
```

则：

```text
Δ = A/(n+1)
```

所以：

```text
增长50%   → 增长量 = 现期/3
增长33.3% → 增长量 ≈ 现期/4
增长25%   → 增长量 = 现期/5
增长20%   → 增长量 = 现期/6
增长16.7% → 增长量 ≈ 现期/7
增长12.5% → 增长量 = 现期/9
增长10%   → 增长量 = 现期/11
```

看到这些增长率：

```text
优先秒算
```

---

# 8. 百化分：基期量秒杀模型

若：

```text
r = 1/n
```

则：

```text
基期量
= A/(1+1/n)
= A×n/(n+1)
```

例如：

```text
增长25%
```

则：

```text
基期量 = 现期×4/5
```

---

# 9. 百化分：下降模型

下降率：

```text
r = 1/n
```

减少量：

```text
D = A/(n-1)
```

基期量：

```text
B = A×n/(n-1)
```

例如：

```text
下降20% = 1/5
```

则：

```text
减少量 = 现期/4

基期量 = 现期×5/4
```

---

# 10. 速算技巧三：放缩法

## 10.1 增长量

```text
Δ = A×r/(1+r)
```

所以增长时：

```text
Δ < A×r
```

如果选项中：

```text
只有一个选项小于 A×r 且接近
```

很可能直接选。

---

## 10.2 基期量

增长时：

```text
B = A/(1+r)
```

所以：

```text
B < A
```

如果选项中只有一个小于现期量：

```text
直接排除其余
```

---

## 10.3 下降时

```text
B = A/(1-r)
```

所以：

```text
B > A
```

---

# 11. 速算技巧四：化同法

比较：

```text
A/B
C/D
```

若分母接近，可以主动化成相近分母。

例如：

```text
432/810
451/840
```

不用分别算小数。

可观察：

```text
810 → 840约增加3.7%
432 → 451约增加4.4%
```

分子增幅更大，所以：

```text
451/840 更大
```

---

# 12. 速算技巧五：交叉相乘

比较：

```text
A/B 与 C/D
```

看：

```text
A×D
与
C×B
```

谁大谁对应的分数大。

适合：

- 两个分数很接近
- 选项要求排序
- 直接除法不方便

---

# 13. 速算技巧六：差分法

适合：

```text
A/B
C/D
```

且：

```text
A>C
B>D
```

两个分数非常接近。

差分数：

```text
(A-C)/(B-D)
```

然后比较：

```text
差分数
与
较小那个原分数
```

### 使用原则

差分法不是必用技巧。

只有：

```text
两个分数非常接近
且
交叉乘法很大
```

才考虑。

---

# 14. 速算技巧七：增长率近似

如果：

```text
r 较小
```

则：

```text
1/(1+r) ≈ 1-r
```

所以：

```text
基期量
= A/(1+r)
≈ A(1-r)
```

注意：

```text
这是近似
不是正式公式
```

适合：

- r 很小
- 选项差距大

---

# 15. 增长量近似

增长量：

```text
Δ
= A×r/(1+r)
```

当 `r` 较小时：

```text
Δ ≈ A×r
```

但真实增长量：

```text
略小于 A×r
```

因此估算时要知道：

```text
方向是偏大的
```

---

# 16. 平均数增长率近似

精确：

```text
g = (a-b)/(1+b)
```

如果：

```text
b 很小
```

则：

```text
g ≈ a-b
```

但如果选项接近：

```text
必须除以 1+b
```

---

# 17. 隔年增长率近似

精确：

```text
R = r1+r2+r1r2
```

若：

```text
r1、r2都很小
```

则：

```text
R ≈ r1+r2
```

但若增速达到：

```text
10%以上
```

乘积项通常不能忽略。

---

# 18. 年均增长率估算

公式：

```text
末/初 = (1+r)^n
```

不建议考场直接开根号。

正确操作：

```text
① 算末期/初期倍数
② 看选项
③ 试乘 (1+r)^n
④ 哪个最接近选哪个
```

---

# 19. 二项式近似

当 `r` 较小时：

```text
(1+r)^n ≈ 1+nr
```

因此：

```text
年均增长率
≈ 累计增长率/n
```

仅用于快速定位选项。

---

# 20. 典型题型模型一：求基期量

## 触发词

```text
上年
去年
上一时期
基期
某年前
```

## 已知

```text
现期量 A
增长率 r
```

## 模板

增长：

```text
基期 = A/(1+r)
```

下降：

```text
基期 = A/(1-r)
```

## 速算优先级

```text
百化分
→ 截位直除
→ 放缩
→ 精算
```

## 易错

不要写：

```text
A×(1-r)
```

---

# 21. 模型二：基期量大小比较

题目：

> 上年哪个地区数量最多？

给的是：

```text
各地区现期量 + 增速
```

比较：

```text
A/(1+r)
```

### 快速判断

若：

```text
A1明显大于A2
且
r1与r2接近
```

则通常不用精算。

如果：

```text
现期量一大一小
增速一高一低
```

才精细比较。

---

# 22. 模型三：求增长量

## 触发词

```text
增加了多少
同比增加多少
比上年多多少
增量
```

## 模板

已知现期与增速：

```text
Δ = A×r/(1+r)
```

下降：

```text
D = A×r/(1-r)
```

## 速算

优先：

```text
百化分
```

其次：

```text
A×r 后修正
```

---

# 23. 模型四：增长量比较

题目：

> 哪个增长量最大？

不要只比较：

```text
增长率
```

必须比较：

```text
A×r/(1+r)
```

### 快速判定

#### 情况1

```text
现期量更大
增长率也更大
```

则：

```text
增长量一定更大
```

直接选。

#### 情况2

```text
现期量更小
增长率也更小
```

则：

```text
增长量一定更小
```

直接排除。

#### 情况3

一大一小：

```text
需要估算
```

---

# 24. 模型五：求增长率

## 触发词

```text
增长百分之多少
增长率
增速
同比增幅
```

如果已知：

```text
现期 A
基期 B
```

则：

```text
r = (A-B)/B
```

如果已知：

```text
现期 A
增长量 Δ
```

则：

```text
r = Δ/(A-Δ)
```

---

# 25. 模型六：增长率比较

题目：

> 哪个增长最快？

比较：

```text
增长率
```

不是：

```text
增长量
```

### 典型错误

一个地区：

```text
增长量最大
```

不代表：

```text
增长率最大
```

# 26. 模型七：现期比重

## 触发词

```text
占
占比
比重
比例
构成
```

## 模板

```text
比重 = 部分/整体
```

### 题干翻译

```text
A占B的比重
```

立刻写：

```text
A/B
```

---

# 27. 模型八：基期比重

## 触发词

```text
上年占比
去年比重
上一时期占……
```

## 已知

```text
现期部分 A
现期整体 B
部分增速 a
整体增速 b
```

## 模板

```text
基期比重
= A/B × (1+b)/(1+a)
```

## 考场口诀

```text
现期比重
乘下
除上
```

---

# 28. 模型九：判断比重上升下降

题目：

> 与上年相比，占比提高还是下降？

无需计算。

比较：

```text
部分增速 a
整体增速 b
```

```text
a>b → 上升
a<b → 下降
a=b → 不变
```

---

# 29. 模型十：两期比重差

## 触发词

```text
占比较上年提高多少个百分点
比重变化多少
占比下降几个百分点
```

## 模板

```text
现期比重 - 基期比重
= A/B × (a-b)/(1+a)
```

## 第一步

先判断：

```text
a-b
```

确定上升还是下降。

## 第二步

再估算绝对值。

---

# 30. 两期比重差快速排除

由于：

```text
现期比重 < 100%
```

通常：

```text
比重变化百分点
<
|a-b|对应的百分点
```

例如：

```text
部分增速20%
整体增速10%
```

比重变化一般：

```text
小于10个百分点
```

若选项：

```text
A. 2个百分点
B. 5个百分点
C. 8个百分点
D. 12个百分点
```

直接排除：

```text
D
```

---

# 31. 模型十一：现期平均数

## 触发词

```text
平均
人均
户均
每家
每人
单位面积
每辆
每公里
```

## 模板

```text
平均数 = 总量/份数
```

例如：

```text
人均GDP = GDP/人口

每家企业收入 = 总收入/企业数

单位面积产量 = 总产量/面积
```

---

# 32. 模型十二：基期平均数

已知：

```text
现期总量 A
总量增速 a
现期份数 B
份数增速 b
```

则：

```text
基期平均数
= A/B × (1+b)/(1+a)
```

和基期比重公式完全相同。

---

# 33. 模型十三：判断平均数升降

题目：

> 人均收入同比上升还是下降？

只比较：

```text
收入增速
人口增速
```

如果：

```text
收入增速 > 人口增速
```

则：

```text
人均收入上升
```

---

# 34. 模型十四：平均数增长率

## 模板

```text
平均数增长率
= (a-b)/(1+b)
```

## 口诀

```text
上减下
除以下加一
```

其中：

```text
上 = 分子增速
下 = 分母增速
```

---

# 35. 模型十五：平均数增长量

```text
平均数增长量
= 现期平均数 × (a-b)/(1+a)
```

即：

```text
A/B × (a-b)/(1+a)
```

注意和增长率公式区分：

```text
增长率 → 除1+b
增长量 → 除1+a
```

---

# 36. 模型十六：倍数

题目：

> A是B的多少倍？

```text
A/B
```

题目：

> A比B多几倍？

```text
A/B - 1
```

---

# 37. “倍数”秒判

例如：

```text
A = 240
B = 80
```

```text
A是B的3倍
A比B多2倍
A比B多200%
```

这三句话要彻底区分。

---

# 38. 模型十七：基期倍数

如果：

```text
A现/B现
```

且增速：

```text
a、b
```

则基期倍数：

```text
A/B × (1+b)/(1+a)
```

与：

```text
基期比重
基期平均数
```

同一公式。

---

# 39. 模型十八：倍数增长率

```text
倍数增长率
= (a-b)/(1+b)
```

本质仍然是：

```text
分子/分母型指标增长率
```

---

# 40. 模型十九：隔年增长率

## 触发词

```text
比两年前
两年累计
相较前两年
两年间增长
```

若：

```text
今年同比 r2
去年同比 r1
```

则：

```text
R = r1+r2+r1r2
```

---

# 41. 隔年增长一增一降

直接带正负号。

例如：

```text
去年 +20%
今年 -10%
```

```text
R
= 20%-10%-2%
= 8%
```

不要把：

```text
20%-10%=10%
```

当答案。

---

# 42. 模型二十：隔年基期量

先算：

```text
R = r1+r2+r1r2
```

再：

```text
两年前 = A/(1+R)
```

---

# 43. 模型二十一：隔年增长量

```text
Δ两年
= A×R/(1+R)
```

其中：

```text
R = r1+r2+r1r2
```

---

# 44. 模型二十二：年均增长率

## 触发词

```text
年均增长
年平均增速
年均增速
平均每年增长百分之多少
```

## 模板

```text
r = (末/初)^(1/n)-1
```

---

# 45. 年均增长率考场做法

不要真开根。

例如：

```text
2020年 = 100
2025年 = 161
```

增长次数：

```text
5
```

因为：

```text
1.1^5 ≈ 1.61
```

所以：

```text
年均约10%
```

---

# 46. 模型二十三：年均增长量

题目：

> 平均每年增加多少万吨？

公式：

```text
(末期量-初期量)/(末年-初年)
```

看到单位是：

```text
万吨
亿元
万人
```

通常就是：

```text
年均增长量
```

---

# 47. 年均增长率与年均增长量区别

### 问百分比

```text
年均增长率
```

### 问绝对量

```text
年均增长量
```

# 48. 模型二十四：混合增长率范围

题目给：

```text
A部分增长5%
B部分增长15%
```

总体增长率一定：

```text
5% < 总体 < 15%
```

不需要计算。

---

# 49. 模型二十五：混合增长率靠近原则

如果：

```text
A基期量远大于B
```

总体增长率会：

```text
更靠近A的增长率
```

---

# 50. 模型二十六：十字交叉

若：

```text
A增速 = r1
B增速 = r2
总体增速 = r
```

且：

```text
r1<r<r2
```

则：

```text
A基期量/B基期量
= (r2-r)/(r-r1)
```

---

# 51. 十字交叉图

```text
       r1       r2
         \     /
          \   /
            r
          /   \
         /     \

A基期 : B基期
=
(r2-r) : (r-r1)
```

---

# 52. 模型二十七：已知现期量的混合增长

如果给：

```text
A现期量、A增速
B现期量、B增速
```

必须先求：

```text
A基期 = A现/(1+a)
B基期 = B现/(1+b)
```

再加权。

不能直接按：

```text
现期量
```

做权重。

---

# 53. 模型二十八：拉动增长率

## 触发词

```text
拉动……增长
拉动总体增长多少个百分点
对总体增长的拉动
```

## 模板

```text
部分增长量 / 整体基期量
```

---

# 54. 拉动题固定流程

```text
① 求部分增长量
② 求整体基期量
③ 相除
```

如果题目已经给了：

```text
部分增长量
整体基期量
```

直接相除。

---

# 55. 模型二十九：贡献率

## 触发词

```text
贡献率
对增长的贡献
增长贡献
```

## 模板

```text
部分增长量 / 整体增长量
```

---

# 56. 拉动与贡献秒区分

```text
拉动 → 除整体基期量
贡献 → 除整体增长量
```

口诀：

```text
拉动看“率”
贡献看“增量”
```

# 57. 模型三十：由拉动求贡献

```text
贡献率
= 部分拉动增长率 / 整体增长率
```

例如：

```text
某产业拉动GDP增长2个百分点
GDP增长5%
```

则贡献率：

```text
2%/5% = 40%
```

> 顺差比上年扩大多少？

再：

# 64. 模型三十七：排序题

题目：

> 下列地区按……从高到低排列正确的是？

## 固定流程

```text
① 先看数量级
② 再找明显最大/最小
③ 排除错误选项
④ 最后只比较临界两个
```

千万不要：

```text
四个全部精算
```

# 65. 模型三十八：增长量排序

比较：

```text
A×r/(1+r)
```

### 双大原则

若某项：

```text
现期量更大
且
增长率更大
```

则增长量一定更大。

可以直接形成大小关系。

---

# 66. 模型三十九：基期量排序

比较：

```text
A/(1+r)
```

### 快速比较

如果：

```text
现期量差距大
增速差距小
```

通常由现期量决定。

如果：

```text
现期量接近
```

增长率越高：

```text
基期量越小
```

# 76. 题型模型：增长率与百分点

如果：

```text
去年增长率10%
今年增长率15%
```

题目问：

> 增速提高多少个百分点？

```text
15%-10%=5个百分点
```

题目问：

> 增速提高百分之多少？

```text
(15%-10%)/10%=50%
```

# 77. 题型模型：降幅收窄

例如：

```text
去年 -15%
今年 -8%
```

则：

```text
降幅收窄7个百分点
```

# 78. 题型模型：由负转正

```text
去年 -5%
今年 +7%
```

增速提高：

```text
7%-(-5%)
= 12个百分点
```

# 79. 题型模型：翻番

```text
翻1番 = 原来的2倍
翻2番 = 原来的4倍
翻3番 = 原来的8倍
```

增长率分别：

```text
100%
300%
700%
```

# 80. 题型模型：先涨后跌

先涨 `a`，再跌 `b`：

```text
最终倍率
= (1+a)(1-b)
```

最终增长率：

```text
a-b-ab
```

---

# 81. 同幅涨跌

先涨 `r` 再跌 `r`：

```text
最终变化率 = -r²
```

例如：

```text
+20%
再-20%
```

最终：

```text
-4%
```

---

# 82. 下降后恢复原值

先下降：

```text
r
```

恢复原值需要增长：

```text
r/(1-r)
```

例如：

```text
跌20%
```

需要：

```text
涨25%
```

---

# 83. 上涨后恢复原值

先增长：

```text
r
```

回到原值需要下降：

```text
r/(1+r)
```

例如：

```text
涨25%
```

只需：

```text
跌20%
```

### 同比

### 环比

# 85. 累计同比

例如：

```text
2026年1—6月同比增长
```

基期：

```text

```

不是：

```text
2026年上半年与2025年全年
```

# 86. 题型模型：部分增长量求总体增长量

若总体：

```text
T = A+B+C
```

则：

```text
ΔT = ΔA+ΔB+ΔC
```

因此：

```text
未知部分增长量
= 总体增长量
- 其他部分增长量
```

---

# 87. 题型模型：其他部分

如果：

```text
总量 = T
A部分 = A
```

则：

```text
其他 = T-A
```

若求其他占比：

```text
1-A/T
```

---

# 88. 题型模型：两部分占比差

如果：

```text
A占比 = w1
B占比 = w2
```

则：

```text
A-B占总体的比重差
= w1-w2
```

若总量为 `T`：

```text
A-B数量差
= T(w1-w2)
```

---

# 89. 题型模型：部分占剩余部分

已知：

```text
A占总体 = w
```

则：

```text
A / 其余
= w/(1-w)
```

# 90. 题型模型：人均变化

例如：

```text
GDP增长10%
人口增长2%
```

人均GDP增长率：

```text
(10%-2%)/(1+2%)
≈ 7.84%
```

不是：

```text
8%
```

若选项差距大：

```text
可近似8%
```

# 91. 题型模型：单位面积产量

```text
亩产
= 总产量/面积
```

若：

```text
产量增长 a
面积增长 b
```

亩产增长率：

```text
(a-b)/(1+b)
```

# 92. 题型模型：每家企业营业收入

```text
平均营业收入
= 总营业收入/企业数
```

增长率：

```text
(营业收入增速-企业数增速)/(1+企业数增速)
```

# 93. 题型模型：劳动生产率

```text

= 产出/就业人数
```

若资料明确给定相应口径，则按：

```text
分子/分母
```

模型处理。

# 94. 题型模型：人口占比

```text
某年龄人口占比
= 某年龄人口/总人口
```

判断比重升降：

```text
该年龄人口增速
vs
总人口增速
```

# 95. 题型模型：产业占GDP比重

```text
产业增加值/GDP
```

判断比重变化：

```text
产业增速
vs
GDP增速
```

无需计算。

# 96. 题型模型：增长贡献判断

如果：

```text
某部分增长率高
```

不代表贡献率一定高。

贡献率还取决于：

```text
该部分基期规模
```

必须看：

```text
增长量
```

---

# 97. 题型模型：比较拉动能力

比较：

```text
部分增长量 / 整体基期量
```

如果所有部分属于同一个整体：

```text
整体基期量相同
```

则只需要比较：

```text
各部分增长量
```

---

# 98. 题型模型：贡献率比较

如果所有部分对应同一整体：

```text
整体增长量相同
```

所以贡献率大小只看：

```text
部分增长量大小
```

---

# 99. 题型模型：混合增速反推基期量比

已知：

```text
低增速 r1
高增速 r2
总体 r
```

十字：

```text
低速部分基期量
:
高速部分基期量

=
(r2-r)
:
(r-r1)
```

---

# 100. 题型模型：混合增速找大主体

若总体增速：

```text
非常接近某部分增速
```

则该部分通常：

```text
基期量占比更大
```

# 101. 题型模型：排名变化

若问：

> 某指标排名较上年上升几位？

必须分别求：

```text
今年排名
去年排名
```

再：

```text
去年排名 - 今年排名
```

注意：

```text
名次数字越小，排名越高
```

---

# 102. 题型模型：超过某阈值的个数

例如：

> 增速超过10%的地区有几个？

先不要精算所有地区。

直接扫：

```text
明显>10%
明显<10%
临界项再算
```

---

# 103. 题型模型：高于平均水平的个数

先求总体平均：

```text
总量/个数
```

再逐项与平均值比较。

如果数据很多：

```text
先用明显大/小排除
```

---

# 104. 题型模型：中位数

先排序。

若数据数为奇数：

```text
最中间一个
```

若为偶数：

```text
中间两个的平均
```

资料分析偶尔会涉及，别和平均数混淆。

---

# 105. 题型模型：增长率超过总体

例如：

> 有几个行业增速高于总体？

只需比较：

```text
各行业增速
vs
总体增速
```

不需要计算行业占比。

---

# 106. 题型模型：占比超过某值

例如：

> 占比超过20%的有几个？

如果整体相同：

```text
部分 > 整体×20%
```

可先算：

```text
整体的1/5
```

然后直接比较部分量。

比分别做除法更快。

---

# 107. 题型模型：平均数超过某值

例如：

> 人均超过5万元的地区有几个？

比较：

```text
总量/人数 > 5
```

等价：

```text
总量 > 5×人数
```

避免逐个做除法。

---

# 108. 除法比较转乘法

若要判断：

```text
A/B > k？
```

可改写：

```text
A > kB？
```

这是资料分析非常重要的提速技巧。

---

# 109. 比重阈值题

判断：

```text
A/B > 30%
```

不用除。

比较：

```text
A > 0.3B
```

如果：

```text
30% = 3/10
```

可比较：

```text
10A > 3B
```

---

# 110. 增长率阈值题

判断：

```text
(A-B)/B > 10%
```

可变：

```text
A-B > 0.1B
```

即：

```text
A > 1.1B
```

---

# 111. 倍数阈值题

判断：

```text
A是B的3倍以上
```

直接：

```text
A ≥ 3B
```

不做除法。

---

# 112. 增长量阈值题

若增长率相同：

```text
增长量 ∝ 基期量
```

若现期量和增长率都大：

```text
增长量必大
```

优先定性。

---

# 113. 比值型指标统一模型

所有下面题型：

- 比重
- 平均数
- 倍数
- 人均
- 每户
- 单位面积
- 单位车辆
- 每家企业

全部统一成：

```text
X = A/B
```

只需要记三个公式：

```text
【基期】
X0 = X1×(1+b)/(1+a)

【增长率】
g = (a-b)/(1+b)

【增长量】
X1-X0 = X1×(a-b)/(1+a)
```

# 122. 单题时间控制

### 读取型

```text

```

### 简单计算型

```text
40～60秒
```

### 中等计算型

```text
60～90秒
```

### 超复杂计算

如果：

```text
90秒仍无清晰路径
```

优先跳过，最后处理。

```text

```

# 124. 资料分析高频错误分类

## A类：审题错误

- 时间看错
- 同比环比混
- 主体看错
- 问增长量却算增长率

## B类：公式错误

- 基期量乘 `(1-r)`
- 增长量直接 `A×r`
- 比重差用 `a-b`
- 平均数增长率漏分母

## C类：计算错误

- 百分数没化小数
- 小数点错误
- 单位没统一

## D类：策略错误

- 选项差很大还精算
- 判断题四项全算
- 能排除却硬算

# 137. 高频“看到就秒反应”清单

```text
看到“去年”
→ A/(1+r)

看到“增加多少”
→ Ar/(1+r)

看到“占”
→ 部分/整体

看到“去年占比”
→ 现期比重×(1+整体增速)/(1+部分增速)

看到“占比上升下降”
→ 比部分增速和整体增速

看到“占比提高几个百分点”
→ 现期比重×(a-b)/(1+a)

看到“人均”
→ 总量/人数

看到“人均增速”
→ (总量增速-人数增速)/(1+人数增速)

看到“两年增长”
→ r1+r2+r1r2

看到“两部分+总体增速”
→ 混合增长

看到“拉动”
→ 部分增长量/整体基期

看到“贡献”
→ 部分增长量/整体增长量

看到“顺差”
→ 出口-进口

看到“百分点”
→ 百分率直接作差
```

# 147. 典型错误示范：比重变化


# 148. 典型错误示范：平均数增长率


错误：

```text
人均收入增长5%
```

精确：


# 149. 典型错误示范：混合增长

```text

B增长15%
```

错误：

```text
总体一定增长10%
```

只有：

```text
A、B基期量相同
```

时才是10%。

# 150. 资料分析最终“肌肉记忆表”

```text
基期：
现 ÷ (1+r)

增量：
现 × r ÷ (1+r)

比重：
部分 ÷ 整体

基期比重：
现期比重 × (1+整体增速)/(1+部分增速)

比重变化：
看部分增速 - 整体增速

比重差：
现期比重 × (部分增速-整体增速)/(1+部分增速)

平均：
总量 ÷ 份数

平均增速：
(总量增速-份数增速)/(1+份数增速)

倍数：
A/B

多几倍：
A/B-1

隔年：
r1+r2+r1r2

年均率：
(末/初)^(1/n)-1

年均量：
(末-初)/年份差

混合：
介于两部分之间，靠近基期量大者

拉动：
部分增长量/整体基期

贡献：
部分增长量/整体增长量
```

# 153. 最终训练目标

资料分析真正的熟练标准不是：

```text
“我知道公式”
```

而是：

```text
看到“去年”
不用想就写 A/(1+r)

看到“增长多少”
不用想就写 Ar/(1+r)

看到“占比升降”
不用算就比较两个增速

看到“人均增长率”
不用想就写 (a-b)/(1+b)

看到“两年增长”
不用想就写 r1+r2+r1r2

看到“两部分+总体”
第一反应就是混合增长

看到“拉动”
绝不和贡献率混淆
```

最终做到：

```text
识别题型 5秒
决定算法 5秒
计算只做必要部分
```

这才是国考 / 辽宁省考资料分析稳定提速的核心。
