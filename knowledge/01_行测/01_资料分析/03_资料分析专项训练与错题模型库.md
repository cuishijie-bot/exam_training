# 1. 错题复盘总规则

每道错题只记录 5 件事：

```text
1. 题型是什么
2. 触发词是什么
3. 正确公式是什么
4. 最快解法是什么
5. 我为什么错
```

不要抄整道题。

---

# 2. 错因编码

统一使用：

```text
T = 时间错误
U = 单位错误
F = 公式错误
D = 数据定位错误
C = 计算错误
S = 速算策略错误
R = 阅读理解错误
M = 模型识别错误
P = 百分数/百分点错误
B = 倍数表述错误
```

例：

```text
F-基期量公式写成 A×(1-r)

M-看到“人均增长率”没有识别为分子/分母增长模型

S-选项差距很大仍精算

P-把“提高5个百分点”写成“提高5%”
```

# 4. 专项训练二：基期量比较

## 题4

某年四地区粮食产量及同比增速如下：

| 地区 | 现期产量 | 增速 |
|---|---:|---:|
| 甲 | 620 | 10% |
| 乙 | 600 | 5% |
| 丙 | 580 | -2% |
| 丁 | 570 | 1% |

上年产量最大的是：

A. 甲  
B. 乙  
C. 丙  
D. 丁

### 解题模型

比较：

```text
现期/(1+r)
```

估算：

```text
甲 ≈ 620/1.10 ≈ 564
乙 ≈ 600/1.05 ≈ 571
丙 ≈ 580/0.98 ≈ 592
丁 ≈ 570/1.01 ≈ 564
```

### 答案

```text
C
```

### 高频陷阱

```text
现期最大 ≠ 基期最大
```

# 34. 专项训练三十二：综合判断题策略

## 原创材料

某省 2025 年：

```text
GDP：20,000亿元，同比增长5%
第一产业：2,000亿元，同比增长3%
第二产业：8,000亿元，同比增长6%
第三产业：10,000亿元，同比增长5%
```

判断下列说法：

A. 第一产业占 GDP 比重同比上升  
B. 第二产业占 GDP 比重同比上升  
C. 第三产业占 GDP 比重同比下降  
D. 三次产业增速均高于 GDP

### 秒判

第一产业：

```text
3% < 5%
→ 比重下降
```

第二产业：

```text
6% > 5%
→ 比重上升
```

第三产业：

```text
5%=5%
→ 比重不变
```

### 答案

```text
B
```

### 训练意义

整题：

```text
0次除法
```

# 46. 错题模型库：基期量错题模板

```text
【触发词】
去年 / 上年 / 基期

【正确模型】
A/(1+r)

【下降】
A/(1-r)

【常见错法】
A×(1-r)

【下次条件反射】
看到“去年” → 先写除法
```

---

# 47. 错题模型库：增长量错题模板

```text
【触发词】
增加多少

【正确模型】
Ar/(1+r)

【下降】
Ar/(1-r)

【常见错法】
A×r

【下次条件反射】
增长率给的是相对于基期，不是现期
```

---

# 48. 错题模型库：比重错题模板

```text
【触发词】
占、占比、比重

【模型】
部分/整体

【比重升降】
比较部分增速与整体增速

【常见错法】
分子分母反
```

---

# 49. 错题模型库：两期比重差

```text
【触发词】
占比较上年提高/下降几个百分点

【公式】
现期比重×(a-b)/(1+a)

【先做】
先判断a-b正负

【常见错法】
直接用a-b当比重变化
```

---

# 50. 错题模型库：平均数增长率

```text
【触发词】
人均同比
平均每家同比
单位面积产量增长

【模型】
(a-b)/(1+b)

【口诀】
上减下，除以下加一

【常见错法】
只算a-b
```

---

# 51. 错题模型库：倍数

```text
【是几倍】
A/B

【多几倍】
A/B-1

【多百分之多少】
(A-B)/B
```

# 52. 错题模型库：隔年增长

```text
【触发词】
两年前 / 两年累计

【公式】
r1+r2+r1r2

【常见错法】
只相加
```

# 53. 错题模型库：混合增长

```text
【触发词】
两个部分 + 总体

【第一步】
总体增速一定在两个部分之间

【第二步】
靠近基期量大的部分

【问比例】
十字交叉
```

# 54. 错题模型库：拉动贡献

```text
拉动：
部分增长量/整体基期量

贡献：
部分增长量/整体增长量
```

口诀：

```text
拉动除基期
贡献除增量
```

# 55. 错题模型库：百分点

```text
两个百分率直接相减

相对变化

```
