# 2. 母题 01｜已知现期 + 增长率，求基期

## 典型题干

```text
2025年某指标为A，同比增长r%，问2024年约为多少？
```

## 触发词

```text
去年
上年
基期
上一时期
```

## 5秒识别

```text
现期 + 增长率 → 求基期
```

## 标准公式

增长：

```text
B = A/(1+r)
```

下降：

```text
B = A/(1-r)
```

## 最快算法

优先级：

```text
百化分
→ 截位直除
→ 放缩
→ 精算
```

## 典型变式

- 同比增长改成同比下降
- 年度改成月度
- 问“上年同期”
- 问“基期排名”

## 干扰项设计

常见错误选项来自：

```text
A×(1-r)
A×r
A/(1-r)   ← 增长时故意写错方向
```

# 3. 母题 02｜已知基期 + 增长率，求现期

## 典型题干

```text
上年为B，本年同比增长r%，问本年约为多少？
```

## 识别

```text
基期 + 增长率 → 现期
```

## 公式

```text
A = B(1+r)
```

下降：

```text
A = B(1-r)
```

## 最快算法

直接乘。

若：

```text
r=20%
```

可：

```text
B + B/5
```

# 4. 母题 03｜已知现期 + 增长率，求增长量

## 典型题干

```text
本年为A，同比增长r%，比上年增加多少？
```

## 触发词

```text
增加多少
同比增加
增长量
比上年多多少
```

## 公式

```text
Δ = Ar/(1+r)
```

下降：

```text
D = Ar/(1-r)
```

## 最快算法

如果：

```text
r=1/n
```

则：

```text
增长量 = A/(n+1)
```

## 干扰项

最常见：

```text
A×r
```

# 5. 母题 04｜已知现期 + 增长量，求增长率

## 典型题干

```text
本年A，比上年增加Δ，问同比增长约多少？
```

## 识别

先求：

```text
基期 = A-Δ
```

再：

```text
r = Δ/(A-Δ)
```

## 干扰项

常见错误：

```text
Δ/A
```

---

# 6. 母题 05｜已知现期和基期，求增长率

## 典型题干

```text
上年B，本年A，增长百分之多少？
```

## 公式

```text
r = (A-B)/B
```

## 速算

可改写：

```text
A/B - 1
```

如果判断：

```text
是否超过20%
```

直接比较：

```text
A > 1.2B？
```

# 7. 母题 06｜增长量大小比较

## 典型题干

```text
下列地区中，同比增长量最大的是？
```

材料通常给：

```text
现期量 + 增速
```

## 本质

比较：

```text
Ar/(1+r)
```

## 5秒判断

### 双大

如果某项：

```text
现期量更大
且增速更大
```

增长量必更大。

### 双小

```text
现期量更小
且增速更小
```

增长量必更小。

### 一大一小

再估算。

## 高频陷阱

```text
增速最大 ≠ 增长量最大
```

# 8. 母题 07｜基期量大小比较

## 题干

```text
上年哪个地区数量最大？
```

材料给：

```text
现期量 + 增速
```

## 本质

比较：

```text
A/(1+r)
```

## 快速判断

- 现期差很大，增速接近 → 看现期
- 现期接近 → 增速越大，基期越小

# 9. 母题 08｜增速变化（百分点）

## 典型题干

```text
本年增速为a%，比上年提高/回落b个百分点
```

## 固定关系

提高：

```text
上年增速 = a-b
```

回落：

```text
上年增速 = a+b
```

## 负增速也一样

例如：

```text
今年-2%
比去年提高5个百分点
```

上年：

```text
-7%
```

# 10. 母题 09｜两年累计增长率

## 题干

```text
今年同比r2，去年同比r1，今年比两年前增长多少？
```

## 公式

```text
R = r1+r2+r1r2
```

## 变式

- 两年都增长
- 一增一降
- 连续下降
- 求两年前基期量
- 求两年增长量

## 高频陷阱

```text
只相加
```

---

# 11. 母题 10｜多期累计增长率

## 题干

```text
连续三年增速分别为……
```

## 公式

```text
R = (1+r1)(1+r2)(1+r3)-1
```

## 快速方法

如果各增速很小且选项差大：

```text
可先粗略相加
```

但最终要注意乘积项。

# 12. 母题 11｜年均增长率

## 题干

```text
2020—2025年年均增长率约为多少？
```

## 公式

```text
末 = 初(1+r)^n
```

## 考场打法

不建议开根。

优先：

```text
① 算末/初
② 看选项
③ 试选项
```

## 高频陷阱

```text
n = 年份差
```

通常不是年份个数。


## 公式

```text
(末-初)/(末年-初年)
```


# 17. 母题 16｜基期比重

## 典型题干

```text
现期部分A，现期整体B；
部分增速a，整体增速b；
问上年占比。
```

## 公式

```text
W0 = A/B × (1+b)/(1+a)
```

## 口诀

```text
现期比重
乘整体
除部分
```

## 干扰项

经常把：

```text
(1+a)/(1+b)
```

反过来。

---

# 18. 母题 17｜判断比重升降

## 题干

```text
与上年相比，占比上升还是下降？
```

## 秒杀

比较：

```text
部分增速a
整体增速b
```

```text
a>b → 上升
a<b → 下降
a=b → 不变
```

## 特殊注意

负数也按大小比较：

```text
-3% > -8%
```

所以部分下降更慢：

```text
比重上升
```

# 19. 母题 18｜两期比重差

## 题干

```text
占比较上年提高/下降多少个百分点？
```

## 公式

```text
W1-W0
= A/B × (a-b)/(1+a)
```

## 做题顺序

```text
① 先看a-b确定方向
② 再估算大小
```

## 高频陷阱

```text
直接用a-b
```


# 30. 母题 29｜比值型指标万能模型

只要题目可写成：

```text
X = A/B
```

设：

```text
A增速=a
B增速=b
```

统一：

```text
基期：
X0=X1×(1+b)/(1+a)

增长率：
g=(a-b)/(1+b)

变化量：
X1-X0=X1×(a-b)/(1+a)
```

## 适用

- 比重
- 平均数
- 倍数
- 人均
- 户均
- 单位面积
- 每家企业
- 每辆车
- 每万人
- 各类“单位量”

这是资料分析最重要的“母模型”。

# 31. 母题 30｜混合增长率范围

```text
乙增长r2

```

## 秒杀

```text
总体增长率一定在r1和r2之间
```


# 33. 母题 32｜十字交叉求基期量比

## 题干

```text
甲增速r1
乙增速r2
总体增速r
问甲乙基期量之比
```

若：

```text
r1<r<r2
```

则：

```text
甲基期 : 乙基期
= (r2-r):(r-r1)
```

## 口诀

```text
低速配对面距离
高速配对面距离
```

# 40. 母题 39｜顺差 / 逆差变化

## 题干

```text
顺差比上年扩大多少？
```

## 流程

```text
① 求现期差额
② 求基期出口
③ 求基期进口
④ 求基期差额
⑤ 两期作差
```

## 高频陷阱

不能只比较：

```text
出口增速
进口增速
```

就直接得出精确扩大值。

# 71. 母题 70｜未知部分增长量

# 97. 母题体系的核心

真正需要牢牢记住的不是 70 个编号。

而是 8 个核心母模型：

```text
1. 现期 = 基期(1+r)

2. 增长量 = Ar/(1+r)

3. 比重/平均/倍数 = A/B

4. 基期比值 = 现期比值×(1+b)/(1+a)

5. 比值增长率 = (a-b)/(1+b)

6. 比值变化量 = 现期比值×(a-b)/(1+a)

7. 隔年 = r1+r2+r1r2

8. 混合 = 基期量加权平均
```

其他母题基本都是：

```text
这8个模型的变式
```
