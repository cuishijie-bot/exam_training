# 国考 / 辽宁省考完整版知识库｜资料分析

> 定位：国考、辽宁省考资料分析 **公式总库 + 识别词 + 速算方法 + 易错点 + 做题流程**。  
> 用法：**先看问题 → 判断题型 → 找数据 → 套公式 → 估算 → 对选项**。  
> 原则：资料分析不是“精算比赛”，而是“识别公式 + 控制精度 + 快速比较”。

---

# 0. 一页公式总表

## 0.1 基本符号

设：

- 基期量：`B`
- 现期量：`A`
- 增长率：`r`
- 增长量：`Δ`
- 部分现期量：`A`
- 整体现期量：`B`
- 部分增长率：`a`
- 整体增长率：`b`

最核心关系：

```text
现期量 = 基期量 × (1 + 增长率)

A = B × (1+r)
```

因此：

```text
基期量 = A / (1+r)

增长量 = A - B
       = B × r
       = A × r / (1+r)

增长率 = 增长量 / 基期量
       = (现期量 - 基期量) / 基期量
       = Δ / (A-Δ)
```

---

## 0.2 下降情形

若题目说“下降 r%”，把 `r` 看作正数下降率：

```text
现期量 = 基期量 × (1-r)

基期量 = 现期量 / (1-r)

减少量 = 基期量 × r
       = 现期量 × r / (1-r)
```

### 方向判断

- 增长：基期量 `<` 现期量
- 下降：基期量 `>` 现期量
- 增长时：增长量 `< 现期量 × r`
- 下降时：减少量 `> 现期量 × r`

---

## 0.3 比重 / 平均数 / 倍数通用公式

现期比值：

```text
现期比值 = A / B
```

若分子增长率为 `a`，分母增长率为 `b`：

```text
基期比值
= A/B × (1+b)/(1+a)
```

比值增长率：

```text
比值增长率
= (a-b)/(1+b)
```

现期比值与基期比值之差：

```text
现期比值 - 基期比值
= A/B × (a-b)/(1+a)
```

这三个公式同时适用于：

- 比重
- 平均数
- 倍数
- 人均量
- 单位面积产量
- 每家企业产值
- 每辆车运输量
- 每万人拥有量
- 任何“分子 ÷ 分母”的指标

---

## 0.4 隔年增长率

连续两期增长率分别为 `r1、r2`：

```text
隔年增长率 R
= (1+r1)(1+r2)-1
= r1+r2+r1×r2
```

对应：

```text
隔年基期量 = 现期量 / (1+R)

隔年增长量 = 现期量 × R / (1+R)
```

---

## 0.5 年均增长率

初期量 `A0`，末期量 `An`，增长次数为 `n`：

```text
An = A0 × (1+r)^n

r = (An/A0)^(1/n) - 1
```

---

## 0.6 年均增长量

```text
年均增长量
= (末期量 - 初期量) / 年份差
```

---

## 0.7 拉动增长率

```text
某部分拉动整体增长
= 某部分增长量 / 整体基期量
```

---

## 0.8 贡献率

```text
某部分增长贡献率
= 某部分增长量 / 整体增长量
```

关系：

```text
某部分贡献率
= 某部分拉动增长率 / 整体增长率
```

---

## 0.9 混合增长率

总体由若干部分组成：

```text
总体增长率
= Σ(各部分基期量 × 各部分增长率)
  / Σ各部分基期量
```

所以：

```text
总体增长率一定处于各部分增长率之间
```

且更靠近：

```text
基期量更大的那一部分增长率
```

两个部分时，若：

```text
r1 < r < r2
```

则十字交叉：

```text
基期量1 / 基期量2
= (r2-r) / (r-r1)
```

# 1. 基期量、现期量

## 1.1 识别词

看到这些词先判断时间：

### 现期

- 今年
- 本年
- 本期
- 本月
- 本季度
- 2026 年相对 2025 年中的 2026 年
- “截至某年”
- “目前”

### 基期

- 去年
- 上年
- 上期
- 上月
- 上季度
- 前一年
- “相比于某年”中的被比较年份

---

## 1.2 已知基期量和增长率，求现期量

```text
现期量 = 基期量 × (1+r)
```

例如：

```text
2025年产量 100
2026年增长 20%

2026年 = 100 × 1.2 = 120
```

---

## 1.3 已知现期量和增长率，求基期量

```text
基期量 = 现期量 / (1+r)
```

例如：

```text
2026年产量 120
同比增长20%

2025年 = 120 / 1.2 = 100
```

---

## 1.4 下降时求基期量

```text
基期量 = 现期量 / (1-r)
```

例如：

```text
今年90
同比下降10%

去年 = 90 / 0.9 = 100
```

---

## 1.5 高频错误

错误：

```text
现期量 × (1-r)
```

来求“增长前”的基期量。

增长 20% 后得到 120：

```text
120 × 80% = 96
```

并不是原来的 100。

正确：

```text
120 / 1.2 = 100
```

---

# 2. 增长率

## 2.1 基本公式

```text
增长率
= 增长量 / 基期量
= (现期量 - 基期量) / 基期量
```

---

## 2.2 已知现期量和增长量

由于：

```text
基期量 = 现期量 - 增长量
```

所以：

```text
增长率
= 增长量 / (现期量 - 增长量)
```

即：

```text
r = Δ / (A-Δ)
```

---

## 2.3 下降率

```text
下降率
= 减少量 / 基期量
```

注意：

```text
下降率 ≠ 减少量 / 现期量
```

---

## 2.4 增速提高 / 回落

若：

```text
去年增长率 = 10%
今年增长率 = 15%
```

则：

```text
增速提高 5 个百分点
```

不是：

```text
提高 50%
```

如果题目真的问：

> 增速提高了百分之多少

才计算：

```text
(15%-10%) / 10% = 50%
```

---

## 2.5 降幅扩大 / 收窄

例如：

```text
去年下降 15%
今年下降 8%
```

说明：

```text
降幅收窄 7 个百分点
```

如果：

```text
去年下降 8%
今年下降 15%
```

则：

```text
降幅扩大 7 个百分点
```

---

## 2.6 由负转正 / 由正转负

例如：

```text
去年增长率 -5%
今年增长率 +8%
```

增速变化：

```text
8% - (-5%) = 13个百分点
```

---

# 3. 增长量

## 3.1 基本公式

```text
增长量 = 现期量 - 基期量
```

---

## 3.2 已知基期量和增长率

```text
增长量 = 基期量 × r
```

---

## 3.3 已知现期量和增长率

```text
增长量
= 现期量 × r/(1+r)
```

即：

```text
Δ = A × r/(1+r)
```

---

## 3.4 下降时减少量

```text
减少量
= 现期量 × r/(1-r)
```

---

## 3.5 百化分秒算增长量

如果增长率：

```text
r = 1/n
```

则：

```text
增长量
= A × (1/n) / (1+1/n)
= A/(n+1)
```

### 常见

```text
增长 50% = 1/2 → 增长量 = A/3

增长 33.3% ≈ 1/3 → 增长量 = A/4

增长 25% = 1/4 → 增长量 = A/5

增长 20% = 1/5 → 增长量 = A/6

增长 16.7% ≈ 1/6 → 增长量 = A/7

增长 12.5% = 1/8 → 增长量 = A/9

增长 10% = 1/10 → 增长量 = A/11
```

---

## 3.6 下降时百化分

若：

```text
下降率 r = 1/n
```

则：

```text
减少量
= A × (1/n)/(1-1/n)
= A/(n-1)
```

例如：

```text
下降20% = 1/5

减少量 = A/4
```

---

## 3.7 增长量大小比较

精确比较：

```text
增长量 = A × r/(1+r)
```

### 快速判断

如果两个对象：

- 现期量差不多：增长率大的，增长量通常更大
- 增长率差不多：现期量大的，增长量通常更大
- 两者一大一小：必须比较 `A × r/(1+r)`

### 正增长时的估算

因为：

```text
r/(1+r) < r
```

所以：

```text
增长量 < A × r
```

---

# 4. 增长率与倍数的互换

## 4.1 现期是基期的多少倍

```text
现期 / 基期 = 1+r
```

例如：

```text
增长50%
```

表示：

```text
现期 = 基期的1.5倍
```

---

## 4.2 增长100%

```text
现期 = 基期 × 2
```

即：

```text
翻一番
```

---

## 4.3 翻番

```text
翻一番 = 变为原来的2倍 = 增长100%

翻两番 = 变为原来的4倍 = 增长300%

翻三番 = 变为原来的8倍 = 增长700%
```

一般：

```text
翻n番 = 原来的2^n倍
```

增长率：

```text
2^n - 1
```

---

# 5. 比重

## 5.1 基本公式

```text
比重 = 部分 / 整体
```

---

## 5.2 已知整体和比重，求部分

```text
部分 = 整体 × 比重
```

---

## 5.3 已知部分和比重，求整体

```text
整体 = 部分 / 比重
```

---

## 5.4 基期比重

现期：

```text
部分 = A
整体 = B
部分增速 = a
整体增速 = b
```

则：

```text
基期部分 = A/(1+a)

基期整体 = B/(1+b)
```

因此：

```text
基期比重
= A/B × (1+b)/(1+a)
```

---

## 5.5 判断比重上升还是下降

只比较：

```text
部分增速 a
整体增速 b
```

### 结论

```text
a > b → 比重上升

a = b → 比重不变

a < b → 比重下降
```

无需计算比重。

---

## 5.6 两期比重差

```text
现期比重 - 基期比重
= A/B × (a-b)/(1+a)
```

### 使用场景

题目问：

- 比上年提高多少个百分点
- 比重上升多少个百分点
- 占比较去年变化多少

---

## 5.7 比重差方向

公式：

```text
A/B × (a-b)/(1+a)
```

其中：

```text
A/B > 0
1+a > 0
```

所以正负只看：

```text
a-b
```

因此先判断方向，再估算大小。

---

## 5.8 比重变化量上界

在常见正增长情形下：

```text
两期比重差
= 现期比重 × (a-b)/(1+a)
```

由于：

```text
现期比重 < 1
```

所以比重变化的百分点通常明显小于 `|a-b|`。

可用于排除离谱选项。

---

## 5.9 求基期部分量

如果已知：

- 现期整体 `B`
- 现期比重 `w`
- 部分增长率 `a`

则现期部分：

```text
A = B × w
```

基期部分：

```text
A0 = B × w / (1+a)
```

---

# 6. 百分数与百分点

## 6.1 百分数

表示比例本身或相对变化：

```text
增长20%
占比30%
同比下降8%
```

---

## 6.2 百分点

用于两个百分数直接做差：

```text
今年占比25%
去年占比20%

提高 = 5个百分点
```

---

## 6.3 典型陷阱

```text
20% → 25%
```

两种说法：

```text
提高5个百分点

相对增长25%
```

因为：

```text
(25%-20%)/20% = 25%
```

---

# 7. 平均数

## 7.1 基本公式

```text
平均数 = 总量 / 份数
```

常见：

- 人均收入
- 户均收入
- 每家企业产值
- 单位面积产量
- 每辆车货运量
- 平均价格
- 平均工资
- 每万人拥有量

---

## 7.2 基期平均数

设：

```text
现期总量 = A
现期份数 = B
总量增速 = a
份数增速 = b
```

则：

```text
基期平均数
= A/B × (1+b)/(1+a)
```

---

## 7.3 平均数增长率

```text
平均数增长率
= (a-b)/(1+b)
```

### 推导

```text
现期平均数 / 基期平均数
= (1+a)/(1+b)
```

所以：

```text
增长率
= (1+a)/(1+b)-1
= (a-b)/(1+b)
```

---

## 7.4 判断平均数升降

只看：

```text
a 与 b
```

```text
a > b → 平均数上升

a = b → 平均数不变

a < b → 平均数下降
```

---

## 7.5 平均数增长量

```text
现期平均数 - 基期平均数
= A/B × (a-b)/(1+a)
```

注意：

- “平均数增长率”分母是 `1+b`
- “平均数增长量”公式中分母是 `1+a`

不要混淆。

---

# 8. 倍数

## 8.1 A 是 B 的几倍

```text
A/B
```

例如：

```text
300 / 100 = 3
```

所以：

```text
A 是 B 的3倍
```

---

## 8.2 A 比 B 多几倍

```text
(A-B)/B
= A/B - 1
```

例如：

```text
300比100多几倍

= 300/100 - 1
= 2倍
```

---

## 8.3 A 比 B 多百分之多少

与“多几倍”本质相同：

```text
(A-B)/B × 100%
```

---

## 8.4 基期倍数

现期：

```text
A/B
```

A 增速为 `a`，B 增速为 `b`：

```text
基期倍数
= A/B × (1+b)/(1+a)
```

---

## 8.5 倍数增长率

```text
倍数增长率
= (a-b)/(1+b)
```

与平均数增长率完全同构。

---

# 9. 比重、平均数、倍数“三胞胎”

只要题目本质是：

```text
分子 / 分母
```

就可统一使用下面三条：

## 9.1 基期比值

```text
基期比值
= 现期比值 × (1+分母增速)/(1+分子增速)
```

---

## 9.2 比值增长率

```text
比值增长率
= (分子增速 - 分母增速)/(1+分母增速)
```

---

## 9.3 比值变化量

```text
现期比值 - 基期比值
= 现期比值
× (分子增速 - 分母增速)
÷ (1+分子增速)
```

### 记忆

```text
基期比值：乘“下/上”

增长率：差 / 1+下

变化量：现期比值 × 差 / 1+上
```

其中：

```text
上 = 分子增速
下 = 分母增速
```

---

# 10. 隔年增长率

## 10.1 公式

连续两年：

```text
第一年增长率 = r1
第二年增长率 = r2
```

则两年累计：

```text
R = r1+r2+r1×r2
```

---

## 10.2 本质

```text
1+R
= (1+r1)(1+r2)
```

---

## 10.3 一增一降

仍然直接代符号。

例如：

```text
第一年增长20%
第二年下降10%

R
= 20%-10%+20%×(-10%)
= 8%
```

---

## 10.4 连续下降

例如：

```text
连续两年均下降10%
```

不能说总共下降20%。

正确：

```text
(1-10%)² - 1
= -19%
```

即累计下降19%。

---

## 10.5 隔年基期量

若现期量为 `A`：

```text
隔年基期量
= A / [(1+r1)(1+r2)]
= A/(1+R)
```

---

## 10.6 隔年增长量

```text
隔年增长量
= A × R/(1+R)
```

---

# 11. 多期累计增长率

如果连续 `n` 期增长率分别为：

```text
r1, r2, ..., rn
```

则：

```text
累计增长率
= (1+r1)(1+r2)...(1+rn)-1
```

不是简单：

```text
r1+r2+...+rn
```

除非题目明确允许近似且各增长率都很小。

---

# 12. 年均增长率

## 12.1 公式

```text
末期量
= 初期量 × (1+r)^n
```

所以：

```text
r
= (末期量/初期量)^(1/n)-1
```

---

## 12.2 n 是增长次数

例如：

```text
2020 → 2025
```

正常首末期比较：

```text
n = 2025-2020 = 5
```

不是6。

---

## 12.3 选项估算

如果选项给：

```text
8%
10%
12%
14%
```

不用真开根号。

分别估：

```text
(1+r)^n
```

看哪个最接近：

```text
末期量 / 初期量
```

---

## 12.4 小增长率近似

当 `r` 较小：

```text
(1+r)^n
≈ 1+nr
```

因此：

```text
年均增长率
≈ 累计增长率 / n
```

只适合：

- 增速较小
- 选项差距较大
- 快速排除

精确计算仍用幂公式。

---

# 13. 年均增长量

## 13.1 公式

```text
年均增长量
= (末期量 - 初期量)/(末年-初年)
```

例如：

```text
2020年100
2025年150
```

年均增长量：

```text
(150-100)/(2025-2020)
= 10
```

---

## 13.2 与年均增长率区分

### 年均增长量

单位仍是：

```text
万吨、亿元、万人……
```

### 年均增长率

单位是：

```text
%
```

---

# 14. 混合增长率

## 14.1 基本结论

总体由多个部分组成。

如果各部分增长率：

```text
r1, r2, ...
```

总体增长率：

```text
r
```

那么：

```text
min(r1,r2,...) ≤ r ≤ max(r1,r2,...)
```

通常严格在中间。

---

## 14.2 精确公式

以两个部分为例：

```text
基期量分别为 B1、B2
增长率分别为 r1、r2
```

则总体增长率：

```text
r
= (B1×r1 + B2×r2)/(B1+B2)
```

即：

```text
以基期量为权重的加权平均数
```

---

## 14.3 靠近原则

总体增速更靠近：

```text
基期量更大的部分增速
```

注意不是默认靠近：

```text
现期量更大的部分
```

---

## 14.4 十字交叉法

若：

```text
r1 < r < r2
```

则：

```text
B1/B2
= (r2-r)/(r-r1)
```

### 口诀

```text
低速对应“总体到高速的距离”
高速对应“总体到低速的距离”
```

---

## 14.5 已知现期量时的精确总体增长率

若只给各部分：

```text
现期量 A1、A2
增长率 r1、r2
```

先求基期：

```text
B1 = A1/(1+r1)
B2 = A2/(1+r2)
```

再：

```text
总体增长率
= (B1r1+B2r2)/(B1+B2)
```

也可写成：

```text
[ A1×r1/(1+r1) + A2×r2/(1+r2) ]
/
[ A1/(1+r1) + A2/(1+r2) ]
```

---

# 15. 拉动增长率

## 15.1 公式

```text
某部分拉动整体增长
= 某部分增长量 / 整体基期量
```

---

## 15.2 解释

它回答的是：

> 整体增长了这么多，其中某部分让整体增长率增加了多少。

---

## 15.3 各部分拉动之和

如果总体由若干互斥部分组成：

```text
整体增长率
= 各部分拉动增长率之和
```

---

## 15.4 常见错误

错误：

```text
部分增长量 / 整体增长量
```

这是：

```text
贡献率
```

不是拉动增长率。

---

# 16. 贡献率

## 16.1 公式

```text
贡献率
= 某部分增长量 / 整体增长量
```

---

## 16.2 关系式

由于：

```text
部分拉动
= 部分增长量 / 整体基期量

整体增长率
= 整体增长量 / 整体基期量
```

所以：

```text
贡献率
= 部分拉动 / 整体增长率
```

---

## 16.3 贡献率可以超过100%

例如：

- A 部分大幅增长
- B 部分下降
- 总体仅小幅增长

此时：

```text
A的增长量 > 总体增长量
```

所以：

```text
A贡献率 > 100%
```

完全可能。

---

## 16.4 贡献率也可能为负

如果某部分下降，而总体增长：

```text
部分增长量 < 0
```

则：

```text
贡献率 < 0
```

说明该部分拖累总体增长。

---

# 17. 增长贡献量与拉动的转换

若已知：

```text
整体基期量 = B
某部分拉动 = p
```

则某部分增长量：

```text
部分增长量 = B × p
```

若已知：

```text
整体增长量 = Δ
贡献率 = c
```

则：

```text
部分增长量 = Δ × c
```

# 19. 百化分在基期量中的应用

如果：

```text
增长率 r = 1/n
```

则：

```text
基期量
= A/(1+1/n)
= A×n/(n+1)
```

例如增长25%：

```text
r = 1/4

基期量
= A×4/5
```

---

## 19.1 下降时

若：

```text
下降率 = 1/n
```

则：

```text
基期量
= A/(1-1/n)
= A×n/(n-1)
```

例如下降20%：

```text
基期量 = A×5/4
```

# 20. 截位直除

## 20.1 核心原则

```text
选项差距越大，截位越狠
选项差距越小，保留位数越多
```

---

## 20.2 示例

```text
123456 / 456789
```

可先估：

```text
123 / 457
```

如果选项差距很大：

```text
12 / 46
```

也足够。

---

## 20.3 适用题型

- 比重
- 平均数
- 倍数
- 基期量
- 增长率
- 人均量
- 单位量

# 21. 分数比较

## 21.1 同分母

```text
分子大 → 分数大
```

---

## 21.2 同分子

```text
分母小 → 分数大
```

---

## 21.3 一大一小

若：

```text
A/B 与 C/D
```

可交叉相乘：

```text
比较 A×D 与 C×B
```

---

## 21.4 分子分母同时变大

不要凭感觉。

可：

- 截位直除
- 交叉相乘
- 差分法

---

# 22. 差分法

适用于两个分数非常接近：

```text
A/B
C/D
```

且：

```text
A > C
B > D
```

取差分数：

```text
(A-C)/(B-D)
```

将差分数与其中一个原分数比较，可辅助判断大小。

考试中不必机械使用；只有分数接近、交叉乘法很麻烦时使用。

---

# 23. 化同法

如果若干分数的：

- 分母接近
- 分子有明显倍数
- 可通过简单放缩变成相同量级

优先化成同分母或同分子比较。

目标不是精算，而是：

```text
快速找到大小关系
```

---

# 24. 放缩法

例如：

```text
A / (1+r)
```

若 `r > 0`：

```text
A/(1+r) < A
```

若：

```text
r = 10%左右
```

则基期大约：

```text
A的9成左右
```

---

## 24.1 增长量放缩

增长时：

```text
增长量 = A×r/(1+r)
```

所以：

```text
增长量 < A×r
```

---

## 24.2 下降量放缩

下降时：

```text
减少量 = A×r/(1-r)
```

所以：

```text
减少量 > A×r
```

---

# 25. 估算精度规则

## 25.1 选项差距 > 10%

通常：

```text
保留前2位有效数字
```

即可。

---

## 25.2 选项差距约 5%

建议：

```text
保留3位有效数字
```

---

## 25.3 选项非常接近

- 减少截位
- 尽量使用精确公式
- 必要时交叉相乘
- 注意单位

---

# 26. 单位换算

资料分析最容易白送分，也最容易白丢分。

常见：

```text
1万 = 10^4
1亿 = 10^8
1亿 = 10000万
1万亿 = 10^12
```

面积、重量等：

```text
1吨 = 1000千克
1千克 = 1000克
```

题目前一定确认：

- 万
- 亿
- 万亿
- 人
- 万人
- 平方米
- 公顷
- 万吨

---

# 27. 顺差、逆差

## 27.1 贸易总额

```text
进出口总额
= 出口额 + 进口额
```

---

## 27.2 顺差

```text
贸易顺差
= 出口额 - 进口额
```

前提：

```text
出口 > 进口
```

---

## 27.3 逆差

```text
贸易逆差
= 进口额 - 出口额
```

前提：

```text
进口 > 出口
```

---

## 27.4 已知总额和顺差

```text
出口 + 进口 = 总额
出口 - 进口 = 顺差
```

所以：

```text
出口 = (总额 + 顺差)/2

进口 = (总额 - 顺差)/2
```

---

## 27.5 已知总额和逆差

```text
进口 = (总额 + 逆差)/2

出口 = (总额 - 逆差)/2
```

---

# 28. 增长量之和 / 差

若：

```text
总体 = 部分1 + 部分2 + ...
```

则：

```text
总体增长量
= 各部分增长量之和
```

因此：

```text
未知部分增长量
= 总体增长量 - 已知部分增长量
```

这是贡献率、拉动增长率、混合增长题的基础。

---

# 29. 部分与整体的基期关系

若现期：

```text
总体 = A+B
```

但 A、B 增速不同：

```text
a ≠ b
```

则基期总体必须：

```text
A/(1+a) + B/(1+b)
```

不能直接：

```text
(A+B)/(1+某个随意增速)
```

除非题目已经给出总体增长率。

---

# 30. 比值变化的万能模型

只要指标可写成：

```text
X = 分子 / 分母
```

设：

```text
分子增长率 = a
分母增长率 = b
```

则：

```text
X现 / X基
= (1+a)/(1+b)
```

所以：

```text
X的增长率
= (a-b)/(1+b)
```

### 直接判断

```text
a > b → X增加
a < b → X下降
a = b → X不变
```

这一个模型可以解决大量：

- 平均数变化
- 倍数变化
- 人均量变化
- 单位面积产量变化
- 每家企业营收变化
- 单车运量变化

---

# 31. 现期值与基期值的差

若某个“比值型指标”现期为：

```text
X = A/B
```

分子增速：

```text
a
```

分母增速：

```text
b
```

则：

```text
X现 - X基
= X现 × (a-b)/(1+a)
```

这个公式非常重要。

对应：

- 两期比重差
- 平均数增长量
- 倍数差
- 人均量增加值

---

# 32. 平均数与比重的速判

题目如果只问：

> 比上年提高还是下降？

不要计算。

只比较：

```text
分子增速 与 分母增速
```

例如：

### 人均收入

```text
收入增速 > 人数增速
→ 人均收入上升
```

### 某产业占GDP比重

```text
产业增速 > GDP增速
→ 比重上升
```

---

# 33. 现期比重与基期比重大小比较

基期比重：

```text
W0
= W1 × (1+b)/(1+a)
```

若：

```text
a > b
```

则：

```text
(1+b)/(1+a) < 1
```

所以：

```text
W0 < W1
```

即比重上升。

---

# 34. 增长率反推

已知：

```text
现期量 A
增长量 Δ
```

直接：

```text
r = Δ/(A-Δ)
```

如果下降：

```text
现期量 A
减少量 D
```

基期：

```text
A+D
```

下降率：

```text
D/(A+D)
```

---

# 35. 预测量

如果当前量：

```text
A
```

预计下一期增长：

```text
r
```

则：

```text
下一期 = A(1+r)
```

连续 n 期：

```text
未来量 = A(1+r)^n
```

下降则：

```text
未来量 = A(1-r)^n
```

---

# 36. “至少 / 至多”与选项边界

资料分析中看到：

- 至少
- 至多
- 超过
- 不超过
- 不低于
- 不高于

要特别注意边界。

```text
至少 = ≥
至多 = ≤
超过 = >
不超过 = ≤
不低于 = ≥
不高于 = ≤
```

# 37. 排序题

## 37.1 先看数量级

例如：

```text
万
亿
万人
```

先统一单位。

## 37.2 再比较首位

若差距明显，不必算完整。

## 37.3 比较增长量时

不要只比增长率。

必须看：

```text
A×r/(1+r)
```

# 38. “最接近”题

最接近题一般允许：

- 截位
- 四舍五入
- 百化分
- 放缩

不要把时间耗在小数点后三四位。

---

# 39. “约为”题

“约为”意味着：

```text
估算优先
```

先用：

- 百化分
- 截位直除
- 放缩
- 分数比较

---

# 40. “超过 / 不足”型百分比

A 比 B 高多少：

```text
(A-B)/B
```

A 比 B 低多少：

```text
(B-A)/B
```

注意基准都是：

```text
“比”字后面的对象
```

---

# 41. 两个比例之差

若题目问：

```text
甲占比 - 乙占比
```

若两者分母相同：

```text
(甲部分-乙部分)/整体
```

可先做分子差，再除整体。

比分别算两个百分数更快。

---

# 42. 部分占剩余部分的比重

若：

```text
A占总体比重 = w
```

则其余部分：

```text
1-w
```

A 占“其余部分”的倍数：

```text
w/(1-w)
```

---

# 43. 已知部分占比求另一部分

若总体只有 A、B 两部分：

```text
A比重 = w
```

则：

```text
B比重 = 1-w
```

A/B：

```text
w/(1-w)
```

B/A：

```text
(1-w)/w
```

---

# 44. 增长率差与比值增长率不要混淆

例如：

```text
收入增长10%
人口增长5%
```

人均收入增长率不是：

```text
10%-5%=5%
```

精确是：

```text
(10%-5%)/(1+5%)
≈ 4.76%
```

只有估算时才可近似：

```text
≈ 5%
```

---

# 45. 基期比重不能简单用现期比重减增速差

错误：

```text
基期比重
= 现期比重 - (a-b)
```

正确：

```text
基期比重
= 现期比重 × (1+b)/(1+a)
```

---

# 46. 公式中的增长率必须化成小数参与普通乘除

例如：

```text
20% = 0.2
```

不是：

```text
20
```

但做百分数加减时：

```text
20% + 5% = 25%
```

可直接保留百分号。

## 47.2 环比

与紧邻上一统计周期比较。

# 55. 资料分析常见陷阱总表

## 55.1 基期量

错误：

```text
A×(1-r)
```

正确：

```text
A/(1+r)
```

---

## 55.2 增长量

错误：

```text
A×r
```

把现期量直接乘增长率。

正确：

```text
A×r/(1+r)
```

---

## 55.3 比重差

错误单位：

```text
%
```

通常应答：

```text
百分点
```

---

## 55.4 平均数增长率

错误：

```text
a-b
```

精确：

```text
(a-b)/(1+b)
```

---

## 55.5 A比B多几倍

错误：

```text
A/B
```

正确：

```text
A/B - 1
```

---

## 55.6 拉动与贡献

```text
拉动：部分增长量 / 整体基期量

贡献：部分增长量 / 整体增长量
```

---

## 55.7 混合增长率

错误：

```text
(r1+r2)/2
```

除非两部分基期量完全相等。

正确：

```text
基期量加权平均
```

---

## 55.8 年均增长次数

错误：

```text
年份个数
```

通常：

```text
增长次数 = 末年-初年
```

# 57. 不建议先通读整篇材料

资料分析材料通常信息很多。

先通读会导致：

- 记不住
- 浪费时间
- 数据互相干扰

优先：

```text
问题 → 材料定位
```

# 58. 每题计算前“四检查”

在落笔算之前，强制检查：

```text
① 时间对不对？
② 单位对不对？
③ 分子分母有没有反？
④ 问的是量、率、比重还是百分点？
```

这四项能减少大量低级错误。

# 60. 高频公式记忆口诀

## 60.1 基期

```text
基期 = 现期 ÷ 1加增长率
```

---

## 60.2 增量

```text
增量 = 现期 × 增长率 ÷ 1加增长率
```

---

## 60.3 基期比值

```text
现期比值 × 下增速因子 ÷ 上增速因子
```

即：

```text
A/B × (1+b)/(1+a)
```

---

## 60.4 比值增长率

```text
上减下，除以下加一
```

即：

```text
(a-b)/(1+b)
```

---

## 60.5 比值变化量

```text
现期比值 × 上减下 ÷ 上加一
```

即：

```text
A/B × (a-b)/(1+a)
```

---

## 60.6 隔年

```text
隔年 = 两率相加 + 两率相乘
```

---

## 60.7 拉动贡献

```text
拉动除基期
贡献除增量
```

# 61. 资料分析完整公式速查卡

```text
【现期量】
A = B(1+r)

【基期量】
B = A/(1+r)

【下降基期】
B = A/(1-r)

【增长量】
Δ = A-B
Δ = Br
Δ = Ar/(1+r)

【下降量】
D = Ar/(1-r)

【增长率】
r = Δ/B
r = (A-B)/B
r = Δ/(A-Δ)

【比重】
w = 部分/整体

【基期比重】
w0 = A/B × (1+b)/(1+a)

【比重升降】
a>b 上升
a<b 下降

【两期比重差】
w1-w0 = A/B × (a-b)/(1+a)

【平均数】
M = 总量/份数

【基期平均数】
M0 = A/B × (1+b)/(1+a)

【平均数增长率】
g = (a-b)/(1+b)

【平均数增长量】
M1-M0 = A/B × (a-b)/(1+a)

【倍数】
A是B的几倍 = A/B
A比B多几倍 = A/B-1

【基期倍数】
K0 = A/B × (1+b)/(1+a)

【倍数增长率】
g = (a-b)/(1+b)

【隔年增长率】
R = r1+r2+r1r2

【多期累计】
R = ∏(1+ri)-1

【年均增长率】
r = (末期/初期)^(1/n)-1

【年均增长量】
Δavg = (末期-初期)/(末年-初年)

【混合增长率】
r = Σ(Bi×ri)/ΣBi

【十字交叉】
B1/B2 = (r2-r)/(r-r1)

【拉动增长率】
p = 部分增长量/整体基期量

【贡献率】
c = 部分增长量/整体增长量

【贡献与拉动】
c = p/整体增长率

【顺差】
出口-进口

【逆差】
进口-出口
```

# 62. 高频识别词 → 公式映射

| 题干关键词 | 第一反应 |
|---|---|
| 去年、上年、基期 | `A/(1+r)` |
| 比去年增加多少 | 增长量 |
| 同比增长百分之多少 | 增长率 |
| 占、占比、比重 | 部分/整体 |
| 去年占比 | 基期比重 |
| 占比提高多少 | 两期比重差 |
| 平均、人均、户均、每 | 总量/份数 |
| 平均数增长率 | `(a-b)/(1+b)` |
| 是……的几倍 | `A/B` |
| 比……多几倍 | `A/B-1` |
| 两年累计增长 | `r1+r2+r1r2` |
| 年均增长率 | `(末/初)^(1/n)-1` |
| 年均增加 | `(末-初)/年份差` |
| 拉动增长 | 部分增长量/整体基期 |
| 贡献率 | 部分增长量/整体增长量 |
| 总体由两个部分组成 | 混合增长 |
| 提高几个百分点 | 两个百分率直接相减 |
| 顺差 | 出口-进口 |
| 逆差 | 进口-出口 |

# 63. 高频特殊结论

## 63.1 增长后恢复原值所需下降率

先增长 `r`，要回到原值：

```text
下降率 = r/(1+r)
```

例如先涨25%：

```text
25%/125% = 20%
```

所以：

```text
涨25%后，只需跌20%即可回原值
```

---

## 63.2 下降后恢复原值所需增长率

先下降 `r`，要回到原值：

```text
增长率 = r/(1-r)
```

例如先跌20%：

```text
20%/80% = 25%
```

所以：

```text
跌20%后，需要涨25%才能回原值
```

---

## 63.3 先涨后跌同样百分比不会回原值

例如：

```text
100 → +20% → 120
120 → -20% → 96
```

最终比原来：

```text
下降4%
```

一般：

```text
先涨r再跌r
最终变化率 = -r²
```

# 64. 复合变化

先增长 `a`，再增长 `b`：

```text
总变化率
= (1+a)(1+b)-1
= a+b+ab
```

先增长 `a`，再下降 `b`：

```text
总变化率
= (1+a)(1-b)-1
= a-b-ab
```

先下降 `a`，再增长 `b`：

```text
总变化率
= (1-a)(1+b)-1
= b-a-ab
```

# 67. 最终做题口令

每一道资料分析题都按下面顺序：

```text
问什么？
↓
哪一年？
↓
谁是分子？
↓
谁是分母？
↓
属于量、率、比重、平均数还是倍数？
↓
公式是什么？
↓
能不能判断？
↓
能不能估算？
↓
最后再算。
```

> 资料分析稳定提速的核心不是学更多复杂计算，而是把题目快速翻译成固定公式。
