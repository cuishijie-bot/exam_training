# 2. 8 个核心母模型

## ① 现期与基期

```text
现期 = 基期×(1+r)

基期 = 现期/(1+r)
```

下降：

```text
基期 = 现期/(1-r)
```

---

## ② 增长量

增长：

```text
增长量
= 现期×r/(1+r)
```

下降：

```text
减少量
= 现期×r/(1-r)
```

---

## ③ 比重 / 平均 / 倍数

```text
比值 = A/B
```

---

## ④ 基期比值

```text
基期比值
= 现期比值×(1+b)/(1+a)
```

其中：

```text
a = 分子增速
b = 分母增速
```

口诀：

```text
现期比值
乘下
除上
```

---

## ⑤ 比值增长率

```text
g = (a-b)/(1+b)
```

口诀：

```text
上减下
除以下加一
```

---

## ⑥ 比值变化量

```text
现期比值 - 基期比值
= 现期比值×(a-b)/(1+a)
```

口诀：

```text
现期比值
乘上减下
除以上加一
```

---

## ⑦ 隔年增长率

```text
R = r1+r2+r1r2
```

口诀：

```text
两率相加
别忘相乘
```

---

## ⑧ 混合增长率

```text
总体增长率
= 各部分基期量加权平均
```

必有：

```text
总体增速介于各部分增速之间
```

并：

```text
更靠近基期量大的部分
```

# 3. 资料分析核心公式一页版

```text
【现期量】
A = B(1+r)

【基期量】
B = A/(1+r)

【下降基期】
B = A/(1-r)

【增长量】
Δ = Ar/(1+r)

【下降量】
D = Ar/(1-r)

【增长率】
r = (A-B)/B
r = Δ/(A-Δ)

【比重】
部分/整体

【基期比重】
现期比重×(1+整体增速)/(1+部分增速)

【比重升降】
部分增速 > 整体增速 → 上升
部分增速 < 整体增速 → 下降

【两期比重差】
现期比重×(部分增速-整体增速)/(1+部分增速)

【平均数】
总量/份数

【基期平均数】
现期平均数×(1+份数增速)/(1+总量增速)

【平均数增长率】
(总量增速-份数增速)/(1+份数增速)

【平均数增长量】
现期平均数×(总量增速-份数增速)/(1+总量增速)

【倍数】
A是B的几倍 = A/B
A比B多几倍 = A/B-1

【隔年】
r1+r2+r1r2

【多期累计】
∏(1+r)-1

【年均增长率】
(末/初)^(1/n)-1

【年均增长量】
(末-初)/(末年-初年)

【混合增长】
介于各部分增速之间

【十字交叉】
低速部分:高速部分
=
(高速-总体):(总体-低速)

【拉动增长率】
部分增长量/整体基期量

【贡献率】
部分增长量/整体增长量

【贡献率与拉动】
贡献率
= 拉动增长率/整体增长率

【顺差】
出口-进口

【逆差】
进口-出口
```

# 4. 题干触发词速查

| 看到题干 | 第一反应 |
|---|---|
| 去年、上年、基期 | `A/(1+r)` |
| 比上年增加多少 | `Ar/(1+r)` |
| 同比增长百分之多少 | `(现-基)/基` |
| 占、占比、比重 | 部分/整体 |
| 去年占比 | 基期比重 |
| 占比上升/下降 | 比两个增速 |
| 占比提高几个百分点 | 两期比重差 |
| 人均、户均、平均、每 | 总量/份数 |
| 人均同比增长 | `(a-b)/(1+b)` |
| 是……的几倍 | `A/B` |
| 比……多几倍 | `A/B-1` |
| 两年前、两年累计 | `r1+r2+r1r2` |
| 年均增长率 | `(末/初)^(1/n)-1` |
| 平均每年增加多少 | 年均增长量 |
| 两部分+总体增速 | 混合增长 |
| 两部分量之比 | 十字交叉 |
| 拉动增长 | 部分增长量/整体基期 |
| 贡献率 | 部分增长量/整体增长量 |
| 提高几个百分点 | 百分率直接作差 |
| 顺差 | 出口-进口 |
| 逆差 | 进口-出口 |

# 6. 百化分秒杀增长量

若：

```text
r=1/n
```

则：

```text
增长量 = 现期/(n+1)
```

直接记：

```text
增长50%   → 现期/3
增长33.3% → 现期/4
增长25%   → 现期/5
增长20%   → 现期/6
增长16.7% → 现期/7
增长12.5% → 现期/9
增长10%   → 现期/11
```

---

# 7. 百化分秒杀基期量

若：

```text
增长率=1/n
```

则：

```text
基期
= 现期×n/(n+1)
```

例如：

```text
增长25%
→ 基期=现期×4/5

增长20%
→ 基期=现期×5/6

增长10%
→ 基期=现期×10/11
```

---

# 8. 下降百化分

若：

```text
下降率=1/n
```

则：

```text
基期 = 现期×n/(n-1)

减少量 = 现期/(n-1)
```

例如：

```text
下降20%=1/5

基期=现期×5/4
减少量=现期/4
```

# 9. 比重题速查

## 现期比重

```text
部分/整体
```

---

## 基期比重

```text
现期比重×(1+整体增速)/(1+部分增速)
```

---

## 判断升降

```text
部分增速 > 整体增速
→ 比重上升

部分增速 < 整体增速
→ 比重下降
```

---

## 变化几个百分点

```text
现期比重×(部分增速-整体增速)/(1+部分增速)
```

看到：

```text

户均

每人
平均
```

先：

```text
总量/份数
```

---

## 判断升降

```text
总量增速 > 份数增速
→ 平均数上升
```

---

## 平均数增长率

```text
(总量增速-份数增速)/(1+份数增速)
```

# 11. 倍数题速查

```text
A是B的几倍
= A/B

A比B多几倍
= A/B-1

A比B多百分之多少
= (A-B)/B
```

牢记：

```text
是几倍
≠
多几倍
```

---

# 12. 隔年题速查

```text
R = r1+r2+r1r2
```

一增一降：

```text
直接带正负号
```

例如：

```text
+20%
-10%
```

两年：

```text
20%-10%-2%
=8%
```

---

# 13. 年均题速查

## 年均增长率

```text
末/初 = (1+r)^n
```

考场：

```text
不要开根
优先代选项
```

---

## 增长次数

通常：

```text
n=末年-初年
```

例如：

```text
2020→2025
n=5
```

---

## 年均增长量

```text
(末-初)/(末年-初年)
```

---

# 14. 混合增长速查

两个部分：

```text
r1 < 总体r < r2
```

总体更靠近：

```text
基期量更大的部分
```

---

## 十字交叉

若：

```text
r1<r<r2
```

则：

```text
低速部分 : 高速部分
=
(r2-r):(r-r1)
```

---

# 15. 拉动 / 贡献速查

```text
拉动增长率
= 部分增长量/整体基期量

贡献率
= 部分增长量/整体增长量
```

口诀：

```text
拉动除基期
贡献除增量
```

---

# 16. 进出口速查

```text
进出口总额
= 出口+进口
```

顺差：

```text
出口-进口
```

逆差：

```text
进口-出口
```

---

## 已知总额 + 顺差

```text
出口=(总额+顺差)/2
进口=(总额-顺差)/2
```

---

## 已知总额 + 逆差

```text
进口=(总额+逆差)/2
出口=(总额-逆差)/2
```

---

# 17. 截位直除原则

```text
选项差距越大
截位越狠
```

一般：

```text
差距大 → 前2位
差距中 → 前3位
差距小 → 少截
```

---

# 18. 误差方向

```text
分子截小 + 分母截大
→ 结果偏小

分子截大 + 分母截小
→ 结果偏大
```

---

# 19. 放缩速查

增长时：

```text
基期 < 现期
```

且：

```text
增长量 < 现期×增长率
```

下降时：

```text
基期 > 现期
```

且：

```text
减少量 > 现期×下降率
```

---

# 20. 除法改乘法

判断：

```text
A/B > 20%
```

直接：

```text
A > B/5
```

判断：

```text
A/B > 25%
```

直接：

```text
A > B/4
```

判断：

```text
A/B > 10%
```

直接：

```text
A > B/10
```

# 21. 分数比较

比较：

```text
A/B
C/D
```

若接近：

```text
交叉相乘
```

比较：


# 24. 高频陷阱一页版

```text
□ 同比 ≠ 环比
□ 累计值 ≠ 单月值
□ 现期 ≠ 基期
□ 增长量 ≠ 增长率
□ 增长量 ≠ 现期×增长率
□ 下降量分母是1-r
□ 百分数 ≠ 百分点
□ 比重升降只比两个增速
□ 比重变化 ≠ 两增速之差
□ 平均数增长率 ≠ a-b
□ 是几倍 ≠ 多几倍
□ 隔年增长别忘r1r2
□ 年均增长次数看年份差
□ 混合权重看基期量
□ 总体增速在部分增速之间
□ 拉动 ≠ 贡献
□ 增速大 ≠ 增长量大
□ 总量大 ≠ 平均数大
□ 部分量大 ≠ 占比大
□ 亿元/万人 = 万元/人
```
