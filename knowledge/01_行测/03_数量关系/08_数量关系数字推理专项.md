# 1. 做题第一原则

不要一看到数列就：

```text
疯狂作差
```

先看：

```text
变化幅度
```

---

# 2. 第一眼判断

如果数列：

```text
增长很平稳
```

优先：

```text
作差
```

如果：

```text
成倍变化
```

优先：

```text
作商
```

如果：

```text
跳跃非常大
```

优先：

```text
幂次 / 乘法递推
```

如果：

```text
忽大忽小
```

优先：

```text
奇偶项拆分 / 分组
```

# 第一编 等差数列

# 3. 等差

```text
后一项 - 前一项
=
固定常数
```

例如：

```text
2，5，8，11，14
```

差：

```text
3，3，3，3
```

---

# 4. 变式

差本身不是常数，但：

```text
形成等差数列
```

例如：

```text
1，3，6，10，15
```

一阶差：

```text
2，3，4，5
```

---

# 5. 二阶差

例如：

```text
1，4，9，16，25
```

一阶差：

```text
3，5，7，9
```

二阶差：

```text
2，2，2
```

同时它也是：

```text
平方数列
```

---

# 第二编 等比数列

# 6. 等比

```text
后一项 ÷ 前一项
=
固定常数
```

例如：

```text
1，2，4，8，16
```

公比：

```text
2
```

---

# 7. 负数等比

例如：

```text
2，-4，8，-16
```

公比：

```text
-2
```

---

# 8. 小数/分数等比

不要因为形式复杂就放弃：

```text
1，1/2，1/4，1/8
```

仍是：

```text
×1/2
```

---

# 第三编 多级作差

# 9. 一阶差

优先适用于：

```text
相邻项变化较平稳
```

---

# 10. 二阶差

如果一阶差：

```text
仍有明显规律
```

继续：

```text
再作差
```

---

# 11. 三阶差

可以出现，但考试中：

```text
不要无止境作差
```

原则：

```text
最多做到能快速识别规律为止
```

---

# 12. 差为自然数

高频：

```text
1，2，3，4...
```

---

# 13. 差为奇数

```text
1，3，5，7...
```

常对应：

```text
平方数
```

---

# 14. 差为偶数

```text
2，4，6，8...
```

也很常见。

---

# 15. 差为质数

可能：

```text
2，3，5，7，11...
```

# 第四编 作商

# 16. 什么时候先作商

数列：

```text
2，6，18，54...
```

明显：

```text
×3
```

---

# 17. 商不是常数

若商为：

```text
2，3，4，5
```

则可能：

```text
依次×2、×3、×4、×5
```

---

# 18. 倍数+修正

高频模型：

```text
a(n+1) = k·a(n) ± c
```

---

# 19. 示例

```text
2，5，11，23，47
```

规律：

```text
×2 +1
```

---

# 20. 变化系数递增

例如：

```text
1，2，6，24，120
```

规律：

```text
×2
×3
×4
×5
```

---

# 第五编 递推数列

# 21. 和递推

```text
第三项
=
前两项和
```

典型：

```text
1，1，2，3，5，8
```

---

# 22. 前两项和±常数

```text
a(n)
=
a(n-1)+a(n-2)±c
```

---

# 23. 差递推

可能：

```text
第三项
=
第二项 - 第一项
```

---

# 24. 积递推

```text
第三项
=
前两项乘积
```

若增长极快：

```text
优先想乘法
```

---

# 25. 商递推

某项：

```text
= 前项 ÷ 前前项
```

较少见，但需知道。

---

# 26. 前两项组合

常见：

```text
和
差
积
倍数关系
```

# 第七编 分数数列

```text
先观察分子
再观察分母
```

# 35. 分子分母分别成规律

例如：

```text
1/2，2/3，3/4，4/5
```

# 36. 约分陷阱

```text
约掉
```

# 37. 反约分

例如：



# 38. 分数作商


# 第八编 奇偶项拆分

# 39. 触发条件

数列：

```text
整体看很乱
```

但：

```text
第1、3、5项
第2、4、6项
```

各自很顺。

---

# 40. 拆法

```text
奇数项：
1 → 3 → 5 → ...

偶数项：
2 → 4 → 6 → ...
```

---

# 41. 示例

```text
1，10，2，20，3，30，4，？
```

奇数项：

```text
1，2，3，4
```

偶数项：

```text
10，20，30，40
```

答案：

```text
40
```

---

# 42. 三组拆分

少数题可能：

```text
1、4、7
2、5、8
3、6、9
```

但只有在：

```text
两项拆分仍无规律
```

时再考虑。

# 第九编 两两分组

# 43. 触发

例如：

```text
2，4，3，9，4，16...
```

分组：

```text
(2,4)
(3,9)
(4,16)
```

关系：

```text
第二个 = 第一个平方
```

---

# 44. 组间也可变化

不要只看组内：

```text
还要看每组第一项是否有规律
```

# 第十四编 高频陷阱

# 61. 一上来连续作差

错误：

```text
所有数列都差差差
```

---

# 62. 只验证局部

规律必须：

```text
尽量解释全数列
```

---

# 63. 过度复杂

如果一个规律需要：

```text
很多人为参数
```

而另一个规律：

```text
简单统一
```

优先简单规律。

---

# 64. 只看绝对数差

可能实际：

```text
×倍数 ± 常数
```

---

# 65. 忽略负号

负号可能：

```text
交替
```

---

# 66. 忽略小数分数

可先：

```text
化成统一形式
```

---

# 67. 奇偶项没拆

整体杂乱：

```text
第一反应之一就是拆奇偶
```

---

# 68. 只找规律不看选项

选择题：

```text
选项本身可以帮助判断规律
```

# 第十九编 最终20条

```text
1. 数字推理先看增幅，不要机械作差
2. 平稳优先差
3. 倍数明显优先商
4. 跳跃大优先幂次和乘法递推
5. 一阶差无规律再看二阶差
6. 商也可能形成2、3、4、5等规律
7. 高频模型是×k±c
8. 前两项和是最常见递推之一
9. 平方1～20要熟
10. 立方1～10要熟
11. 幂次附近重点看±1、±2
12. 分数先拆分子分母
13. 小心约分把规律隐藏
14. 整体乱先拆奇偶
15. 成对明显就两两分组
16. 多位数怪异再看数位
17. 质数序列要熟
18. 一个规律必须尽量解释全部项
19. 简单统一规律优先于复杂拼凑
20. 30秒无明确方向先跳
```
