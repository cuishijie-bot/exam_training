# 1. 第一大类：方程法

## 什么时候用

看到：

```text
数量关系复杂
有“比……多/少”
有总量
有变化前后
```

可直接：

```text
设未知数
```

---

# 2. 一元一次方程

母式：

```text
ax+b=c
```

解：

```text
x=(c-b)/a
```

---

# 3. 二元方程

常见：

```text
x+y=A
ax+by=B
```

可用：

```text
代入
消元
```

---

# 4. 方程题原则

```text
未知数越少越好
```

优先设：

```text
最核心量
```

---

# 5. 高频陷阱

```text
设太多未知数
把“比”关系写反
忽略总量约束
```

---

# 6. 第二大类：不定方程

典型：

```text
ax+by=c
x、y为正整数
```

重点不是解唯一值，而是：

```text
找整数解
```

---

# 7. 不定方程技巧 1｜奇偶

例如：

```text
2x+3y=20
```

看：

```text
3y与20同奇偶
```

可快速判断：

```text
y为偶数
```

---

# 8. 不定方程技巧 2｜尾数

例如：

```text
5x+7y=41
```

看个位：

```text
5x个位只有0或5
```

可配合筛选。

---

# 9. 不定方程技巧 3｜代入选项

如果答案给：

```text
x+y
```

通常直接代入选项更快。

# 16. 第五大类：工程问题

核心公式：

```text
工作总量 = 工作效率 × 工作时间
```

即：

```text
W = v × t
```

---

# 17. 工程题最常用方法

如果给：

```text
甲单独a天
乙单独b天
```

建议赋：

```text
总工程量 = lcm(a,b)
```

# 18. 母题 01｜两人合作

甲：

```text
a天完成
```

乙：

```text
b天完成
```

合作效率：

```text
1/a + 1/b
```

合作时间：

```text
ab/(a+b)
```

---

# 19. 母题 02｜效率比

若：

```text
甲效率:乙效率 = 2:3
```

则同样工作量下：

```text
甲时间:乙时间 = 3:2
```

口诀：

```text
效率比和时间比反比
```

---

# 20. 母题 03｜先单干再合作

步骤：

```text
先算已完成工作量
→ 剩余工作量
→ 除以合作效率
```

---

# 21. 工程题高频陷阱

```text
效率直接相加时单位要一致
时间与效率是反比
中途加入/退出要分段
```

---

# 22. 第六大类：行程问题

核心：

```text
路程 = 速度 × 时间
```

即：

```text
S = vt
```

---

# 23. 相遇问题

两人相向而行：

```text
S = (v1+v2)t
```

---

# 24. 追及问题

同向：

```text
路程差 = (快速度-慢速度)t
```

---

# 25. 往返平均速度

若：

```text
去程速度v1
回程速度v2
路程相同
```

平均速度：

```text
2v1v2/(v1+v2)
```

不是：

```text
(v1+v2)/2
```

---

# 26. 流水行船

```text
顺水速度 = 船速 + 水速
逆水速度 = 船速 - 水速
```

---

# 27. 火车过桥

总路程：

```text
车长 + 桥长
```

过人/杆：

```text
只算车长
```

---

# 28. 环形运动

相遇：

```text
路程和 = 圈长
```

追及：

```text
路程差 = 圈长
```

---

# 29. 行程题高频陷阱

```text
平均速度不能直接平均
相遇看速度和
追及看速度差
火车过桥别漏车长
```

---

# 30. 第七大类：经济利润

核心公式：

```text
利润 = 售价 - 成本
```

```text
利润率 = 利润 / 成本
```

所以：

```text
售价 = 成本 × (1+利润率)
```

---

# 31. 折扣

```text
现价 = 原价 × 折扣
```

例如八折：

```text
×0.8
```

---

# 32. 母题｜先提价再打折

原价100：

```text
提价20%
→120

再打8折
→96
```

最终：

```text
比原价低4%
```

---

# 33. 利润题赋值

没给成本时：

```text
成本设100
```

最方便。

---

# 34. 利润题高频陷阱

```text
利润率分母是成本
不是售价
```

---

# 35. 第八大类：浓度问题

核心：

```text
溶质质量 = 溶液质量 × 浓度
```

---

# 36. 母题｜混合

两杯溶液：

```text
m1,c1
m2,c2
```

混合后浓度：

```text
(m1c1+m2c2)/(m1+m2)
```

---

# 37. 十字交叉法

两种浓度：

```text
高浓度H
低浓度L
目标浓度M
```

质量比：

```text
低浓度量 : 高浓度量
=
H-M : M-L
```

```text
溶质不变
溶液总量增加
浓度下降
```

---

# 39. 蒸发

```text
溶质不变
溶液总量减少
浓度上升
```

# 40. 第九大类：平均数

# 139. 最终20行极简版

```text
1. 工程：总量=效率×时间
2. 工程合作：效率相加
3. 行程：S=vt
4. 相遇用速度和
5. 追及用速度差
6. 等路程平均速度=2v1v2/(v1+v2)
7. 利润=售价-成本
8. 利润率=利润/成本
9. 浓度=溶质/溶液
10. 年龄差永远不变
11. 星期问题按7取余
12. 排列看顺序，组合不看顺序
13. 至少一次=1-一次都没有
14. 容斥=A+B-交集
15. 至少保证→最坏情况+1
16. 植树先数间隔再看端点
17. 牛吃草要算草的生长
18. 淘汰赛n支队=n-1场
19. 钟表相对速度=5.5°/分钟
20. 选项具体时优先代入
```
