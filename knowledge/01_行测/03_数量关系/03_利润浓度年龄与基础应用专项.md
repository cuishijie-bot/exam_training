# 1. 第一大类：经济利润

核心四量：

```text
成本
售价
利润
利润率
```

---

# 2. 利润公式

```text
利润 = 售价 - 成本
```

---

# 3. 利润率

```text
利润率 = 利润 / 成本
```

注意分母：

```text
成本
```

不是售价。

---

# 4. 售价公式

```text
售价 = 成本 × (1+利润率)
```

---

# 5. 成本公式

```text
成本 = 售价 / (1+利润率)
```

---

# 6. 母题 01｜成本100，利润率20%

```text
利润=20
售价=120
```

---

# 7. 利润题赋值法

若题目只给：

```text
利润率
折扣率
变化比例
```

第一反应：

```text
成本设100
```

---

# 8. 折扣

例如：

```text
八折
```

表示：

```text
售价 × 0.8
```

---

# 9. 母题 02｜原价200打八折

```text
现价=200×0.8=160
```

---

# 10. 提价

提价20%：

```text
新价=原价×1.2
```

---

# 11. 母题 03｜先提价20%再打八折

原价赋100：

```text
100×1.2×0.8
=96
```

最终：

```text
比原价低4%
```

---

# 12. 多次百分比变化

统一：

```text
最终值 = 原值 × 各变化系数连乘
```

例如：

```text
涨10%
再跌10%
```

```text
1.1×0.9=0.99
```

最终：

```text
下降1%
```

---

# 13. 高频陷阱：涨跌同百分比不能抵消

```text
+20%
-20%
```

结果：

```text
1.2×0.8=0.96
```

即：

```text
下降4%
```

# 18. 百分比赋值

若单价下降20%，销量上升50%。

原：

```text
单价100
销量100
销售额10000
```

新：

```text
80×150=12000
```

销售额：

```text
增长20%
```

```text

```

若题干另有定义：

```text
以题干为准
```

# 20. 高频利润陷阱

```text
□ 利润率分母是成本
□ 折扣是乘法
□ 多次涨跌用系数连乘
□ 单价变化不能单独判断总销售额
□ 总利润还要看销量
```

# 21. 第三大类：浓度问题

核心：

```text
浓度 = 溶质质量 / 溶液质量
```

---

# 22. 三量关系

```text
溶质 = 溶液 × 浓度
```

---

# 23. 浓度题最关键意识

先找：

```text
什么不变
```

常见：

```text
加水 → 溶质不变
蒸发水 → 溶质不变
混合 → 溶质相加
```

# 25. 第四大类：混合浓度

两杯：

```text
m1,c1
m2,c2
```

混合后：

```text
浓度
=
(m1c1+m2c2)/(m1+m2)
```


```text

```

# 27. 加权平均意识

混合浓度本质：

```text
按溶液质量加权平均
```

所以新浓度一定：

```text
介于两种原浓度之间
```

# 28. 第五大类：十字交叉法

适合：

```text

混成目标浓度

```

---

# 29. 十字交叉公式

高浓度：

```text
H
```

低浓度：

```text
L
```

目标：

```text
M
```

则：

```text
低浓度量 : 高浓度量
=
H-M : M-L
```

# 30. 母题 08｜20%和50%配成30%

```text

=

=

=

```

# 54. 加入一个新成员

原：

```text

平均A
```

```text

```



```text

```

```text
nA-(n-1)B
```

# 57. 加权平均

两组：

```text
n1,A
n2,B
```

整体平均：

```text
(n1A+n2B)/(n1+n2)
```

# 58. 平均数十字交叉


---

# 60. 母题 17｜每人5个差10，每人4个多8

设人数：

```text
n
```

总物品：

```text
5n-10
```

另一种：

```text
4n+8
```

所以：

```text
5n-10=4n+8
```

得：

```text
n=18
```

---

# 61. 盈亏快法

两种分法每人差：

```text
5-4=1
```

总量差：

```text
10+8=18
```

人数：

```text
18/1=18
```

---

# 62. 盈亏类型 1｜一盈一亏

```text
人数
=
(盈+亏)/(每人分配差)
```

---

# 63. 盈亏类型 2｜两次都盈

例如：

```text

每人4个剩40
```

```text
(40-20)/(5-4)=20
```

# 65. 第十三大类：鸡兔同笼

典型：


---

# 66. 方程法

鸡x兔y：

```text
x+y=H
2x+4y=F
```

---

# 67. 假设法

假设全是鸡：

```text
总脚=2H
```

实际多出：

```text
F-2H
```

每把一只鸡换成兔：

```text
多2只脚
```

所以：

```text
兔=(F-2H)/2
```

---

# 68. 鸡兔通用化

如果两类对象：

```text
每个贡献a和b
```

```text
N
```

总贡献：

```text
T
```

假设全是a类：

```text
b类数量
=
(T-aN)/(b-a)
```

# 116. 最终利润速查

```text
利润=售价-成本
利润率=利润/成本
售价=成本×(1+利润率)
折扣=原价×折扣系数
多次变化=系数连乘
```

---

# 117. 最终浓度速查

```text
浓度=溶质/溶液
溶质=溶液×浓度
混合=溶质相加
加水=溶质不变
蒸发=溶质不变
十字交叉=对角差配比
```

---

# 118. 最终年龄平均速查

```text
年龄差不变
年龄比会变
n人过x年
→ 总年龄+x×n

平均=总和/人数
总和=平均×人数
```

---

# 119. 最终基础应用速查

```text
盈亏
→ 两种分法列总量

鸡兔
→ 假设全一种

和差
→ (和±差)/2

方阵
→ 总数n²
→ 外层4n-4

整除
→ 先筛倍数

余数
→ 写N≡r(mod m)
```

# 120. 最终20行极简版

```text
1. 利润=售价-成本
2. 利润率=利润/成本
3. 百分比利润题常赋成本100
4. 多次涨跌用系数连乘
5. 浓度=溶质/溶液
6. 加水时溶质不变
7. 蒸发时溶质不变

9. 年龄差永远不变

15. 鸡兔题优先假设全一种

17. n×n方阵总人数=n²
```
