# 1. 第一大类：比例法

看到：

```text
A:B = m:n
```

第一反应：

```text
A=mk
B=nk
```

---

# 2. 母题 01｜总量已知

若：

```text
A:B=2:3
A+B=50
```

则：

```text
总份数=5
每份=10
A=20
B=30
```

---

# 3. 母题 02｜差值已知

若：

```text
A:B=5:3
A-B=20
```

比例差：

```text
2份=20
```

所以：

```text
1份=10
A=50
B=30
```

---

# 4. 母题 03｜比例和实际变化

若原来：

```text
男:女=3:2
```

后来增加：

```text
若干男生/女生
```

可设：

```text
男=3k
女=2k
```

再根据变化后比例列式。

---

# 5. 比例法最重要的意识

不要一上来设：

```text
男=x
女=y
```

如果比例已知：

```text
直接设3k、2k
```

未知数更少。

---

# 6. 反比关系

若总量一定：

```text
效率 × 时间 = 常数
```

因此：

```text
效率比 = 时间比的反比
```

---

# 7. 母题 04｜效率与时间反比

甲效率：

```text
2
```

乙效率：

```text
3
```

完成相同工作量：

```text
甲时间:乙时间=3:2
```

---

# 8. 行程中的反比

同一路程：

```text
速度 × 时间 = 常数
```

因此：

```text
速度比 = 时间比的反比
```

# 9. 第二大类：赋值法

## 什么时候优先赋值

看到：

```text
只给比例
只给效率关系
只给增长率
只给浓度比例
总量没有具体值
```

可以：

```text
人为设方便数字
```

---

# 10. 常用赋值 1｜设100

适合：

```text
百分比
利润率
浓度
增长变化
```

---

# 11. 常用赋值 2｜设最小公倍数

适合：

```text
工程时间
```

例如：

```text
甲10天
乙15天
```

赋总量：

```text
LCM(10,15)=30
```

则效率：

```text
甲=3/天
乙=2/天
```

---

# 12. 常用赋值 3｜按份数赋值

如果：

```text
A:B=3:5
```

直接：

```text
A=3
B=5
```

或：

```text
A=3k
B=5k
```

---

# 13. 赋值法判断标准

赋值后：

```text
不能破坏题干比例关系
```

最终求：

```text
比例/百分比
```

时最适合。

```text

```

```text

```


```text
时间减少20%
```

# 51. 第十四大类：追及问题

# 52. 追及公式

初始距离差：

```text
D
```

快慢速度：

```text
vf,vs
```

追及时间：

```text
t = D/(vf-vs)
```

---

# 53. 母题 17｜同地不同时出发

慢者先走：

```text
t0
```

领先距离：

```text

```

快者追及时间：

```text
vs×t0/(vf-vs)
```

# 54. 相遇 vs 追及

```text

```

# 115. 行程最终速查

```text
S=vt

相遇
→ v和

追及
→ v差

同路程平均速度
→ 2v1v2/(v1+v2)

流水：
顺=v船+v水
逆=v船-v水

过桥：
路程=车长+桥长

环形反向：
速度和×t=圈长

环形同向：
速度差×t=圈长
```

# 116. 最终20行极简版

```text
1. 比例先设份数
```
