

```text

```

# 59. 牛吃草基础公式

```text
原有草量
+
每天新增草量×天数
=
牛数×每牛每天吃草量×天数
```

---

# 60. 常用赋值

设：

```text
每头牛每天吃1份
```

则：

```text
牛数×天数
=
原草量 + 每天生长量×天数
```

---

# 61. 母题 15｜两组牛数据

若：

```text
10头牛吃20天
15头牛吃10天
```

设原草W，日长g：

```text
10×20 = W+20g
15×10 = W+10g
```

两式相减：

```text
50 = 10g
g=5
```

再求W。

---

# 62. 牛吃草解题顺序

```text
① 设每牛每天吃1
② 写两组方程
③ 相减求生长量
④ 回代求原草
⑤ 再求目标
```

---

# 65. 母题 16｜3空瓶换1瓶

有10空瓶：

第一轮：

```text
10→换3瓶，余1空
```

喝完：

```text
得到3空
```

现有：

```text
4空
```

再换：

```text
1瓶，余1空
```

喝完后：

```text
2空
```

不能继续。

总换：

```text
4瓶
```

---

# 66. 兑换净消耗思想

如果：

```text
k空瓶换1瓶
```

喝完后返1空瓶。

所以每换1瓶：

```text
净消耗k-1个空瓶
```

这是快速思路。
