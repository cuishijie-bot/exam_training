# 第一编 GDP / CPI / PPI

# 1. GDP

GDP：

```text
国内生产总值
```

核心：

```text
一个国家或地区
所有常住单位
在一定时期内
生产活动的最终成果
```

---

# 2. GDP三关键词

```text
一定时期
境内/常住单位
最终成果
```

---

# 3. GDP不是

```text
财富存量
```

而是：

```text
一定时期的生产成果
```

---

# 4. GDP不重复计算

核心：

```text
最终产品和服务
```

避免：

```text
中间产品重复计算
```

---

# 5. GDP三种核算视角

```text
生产法
收入法
支出法
```

---

# 6. 支出法常见表达

```text
消费
+
投资
+
政府购买
+
净出口
```

简化常见：

```text
C + I + G + (X-M)
```

---

# 7. 名义GDP

按：

```text
当期价格
```

计算。

---

# 8. 实际GDP

通过：

```text
剔除价格变动影响
```

反映实际产出变化。

---

# 9. GDP增长 ≠ 居民收入等比例增长

GDP是：

```text
宏观生产指标
```

不是：

```text
居民收入指标
```

---

# 10. CPI

```text
居民消费价格指数
```

---

# 11. CPI反映

```text
居民消费商品和服务
价格水平总体变动
```

---

# 12. CPI侧重

```text
消费端
```

---

# 13. CPI不等于

严格意义上的：

```text
整个社会通货膨胀率
```

但可：

```text
在一定程度上反映通胀/通缩趋势
```

---

# 14. PPI

我国常考：

```text
工业生产者出厂价格指数
```

---

# 15. PPI反映

```text
工业企业产品
第一次出售时
出厂价格总体变化
```

---

# 16. PPI侧重

```text
生产端
```

---

# 17. CPI vs PPI

```text
CPI
→ 居民消费端

PPI
→ 工业生产端
```

---

# 18. 三指标总辨析

```text
GDP
→ 经济总产出

CPI
→ 消费价格

PPI
→ 工业生产价格
```

---

# 19. 高频陷阱

错误：

```text
PPI直接反映居民消费价格
```

# 第二编 通胀与通缩

# 20. 通货膨胀

一般理解：

```text
物价总水平持续上涨
货币购买力下降
```

---

# 21. 不是

```text
某一种商品涨价
```

就一定叫通胀。

---

# 22. 通货紧缩

一般表现：

```text
物价总水平持续下降
需求偏弱
经济活动可能趋弱
```

---

# 23. 通胀与现金

若通胀上升：

```text
现金实际购买力下降
```

---

# 24. 通胀与固定利率债务

其他条件不变：

```text
通常有利于债务人
不利于债权人
```

因为：

```text
偿还货币实际价值下降
```

---

# 25. 通缩风险

可能导致：

```text
消费者推迟消费
企业收入利润承压
实际债务负担上升
```

---

# 第五编 利率

# 44. 名义利率

```text
利率
```

---

# 45. 实际利率

近似：

```text

≈
名义利率 - 通胀率
```

---

# 46. 利率上升

一般：

```text
储蓄吸引力上升
贷款成本上升
投资消费可能受抑制
```

---

# 47. 利率下降

一般：

```text
贷款成本下降
投资消费可能增强
```

---

# 第六编 汇率

# 48. 汇率

```text
两种货币之间兑换比率
```

---

# 49. 本币升值

一般：

```text
进口商品相对便宜
出境消费成本下降
出口价格竞争力可能下降
```

---

# 50. 本币贬值

一般：

```text
进口成本上升
出口价格竞争力可能增强
```

---

# 51. 注意

出口变化还受到：

```text
国外需求
成本
产业竞争力
贸易政策
```

等影响。

不能：

```text
简单绝对化
```

---

# 52. 汇率题口诀

```text
本币升
→ 买外货更便宜

本币贬
→ 外国买本国产品相对更便宜
```

---

# 第三十八编 考场最终40条

```text
1. GDP看总产出，CPI看居民消费价格，PPI看工业生产价格
2. CPI不能严格等同整个社会通胀率
3. 通胀通常意味着货币购买力下降
4. 税收政府支出属财政政策，利率准备金公开市场属货币政策
5. 降息降准一般偏宽松
6. 央行公开市场买入一般投放流动性
7. 本币升值通常有利进口、可能削弱出口价格竞争力
8. 机会成本是放弃的最佳替代选择价值
9. 沉没成本已发生且无法收回
10. 公共物品具有非竞争性、非排他性
11. 逆向选择偏交易前，道德风险偏交易后
12. 惯性是性质不是力，主要与质量有关
13. 压强等于压力除以受力面积
14. 高压锅气压高、沸点高
15. 真空不能传播声音
16. 音调主要看频率，响度与振幅等相关
17. 影子是直线传播，镜子是反射，筷子弯是折射
18. 近视通常用凹透镜
19. 电器短路可能导致大电流和火灾
20. 物理变化没有新物质，化学变化产生新物质
21. CO无色无味有毒，干冰是固态CO2
22. 小苏打是碳酸氢钠，苏打是碳酸钠
23. 生石灰氧化钙，熟石灰氢氧化钙
24. 病毒没有细胞结构
25. 红细胞运氧、白细胞免疫、血小板凝血
26. 肺动脉不等于含氧高，肺静脉不等于含氧低
27. 抗生素不能简单治疗病毒感染
28. 维生素D与骨骼钙磷代谢相关
29. 1 Byte = 8 bit
30. CPU重运算控制，GPU擅长并行

32. HTTPS主要保障传输加密认证，不保证网页内容真实

39. 嫦娥六号是世界首次月球背面采样返回
```
