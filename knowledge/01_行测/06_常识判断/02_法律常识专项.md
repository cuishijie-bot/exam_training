# 32. 民事权利能力

```text
一律平等
```

---

# 33. 胎儿利益保护

涉及：

```text
遗产继承
接受赠与
```

等胎儿利益保护时：

```text
胎儿视为具有民事权利能力
```

但：

```text
娩出时为死体

```

# 34. 完全民事行为能力

一般：

```text
18周岁以上成年人
```

---

# 35. 特殊完全行为能力

```text
16周岁以上不满18周岁
以自己的劳动收入为主要生活来源
```

视为：

```text
完全民事行为能力人
```

# 36. 限制民事行为能力

```text
8周岁以上不满18周岁的未成年人
```

# 37. 限制行为能力人可独立实施

```text
纯获利益的民事法律行为

与其年龄、智力相适应的民事法律行为
```

其他：

```text
需法定代理人代理
或同意、追认
```

# 38. 无民事行为能力

```text
不满8周岁的未成年人
```

# 39. 成年人也可能无行为能力

# 40. 成年人也可能限制行为能力

# 第四编 民法典｜民事法律行为

# 47. 民事法律行为有效一般条件

常见：

```text
行为人具有相应民事行为能力

意思表示真实

不违反法律、行政法规强制性规定

不违背公序良俗
```

---

# 48. 无效法律行为

典型：

```text
无民事行为能力人实施的民事法律行为

行为人与相对人恶意串通
损害他人合法权益

违反法律行政法规强制性规定且导致无效

违背公序良俗
```

---

# 49. 可撤销行为常见

```text
重大误解

欺诈

胁迫

显失公平
```

---

# 50. 无效 vs 可撤销

```text
无效
→ 自始没有法律约束力

可撤销
→ 撤销前原则上有效
```

# 65. 要约

```text
希望和他人订立合同的意思表示
```

要求内容通常：

```text
具体确定
```


# 66. 要约邀请

```text

招标公告
招股说明书
```

```text
要约邀请
```

```text

也可能构成要约
```

```text

```

---

# 86. 法定继承第一顺序

```text
配偶

```

---

# 87. 第二顺序

```text
兄弟姐妹
祖父母
外祖父母
```

---

# 88. 第一顺序存在

原则：

```text
第二顺序不继承
```

---

# 89. 代位继承

高频：

```text
被继承人的子女先于被继承人死亡
```

由其：

```text
晚辈直系血亲
```

代位继承。

民法典还扩大了：

```text
兄弟姐妹先于被继承人死亡时
其子女可依法代位
```

---

# 90. 受遗赠人

知道受遗赠后：

```text
60日内
```

作出：

```text
接受或放弃表示
```

到期未表示：

```text
视为放弃
```

---

# 91. 继承人放弃继承

应在：

```text
遗产处理前
```

以：

```text
书面形式
```

作出。

没有表示：

```text
视为接受继承
```

---

# 92. 继承权丧失

典型：

```text
故意杀害被继承人

为争夺遗产杀害其他继承人

遗弃被继承人或虐待情节严重

严重伪造篡改隐匿销毁遗嘱

严重欺诈胁迫妨碍设立变更撤回遗嘱
```

# 99. 罪刑法定

```text

```

---

# 100. 犯罪主观方面

```text

```

---

# 101. 意外事件

行为造成损害，

但：

```text
不是出于故意或过失
而是不能抗拒或不能预见原因
```

