# Codex 检索规则｜exam_traning

## 0. 核心规则

Codex不得一次读取整个知识库。

必须：

```text
先判断任务
→ 查总索引
→ 只读相关文件
→ 完成任务
```

---

# 1. 初始化

进入 exam_traning 后优先读取：

```text
knowledge/00_总索引.md
knowledge/README_知识库使用指南.md
knowledge/Codex检索规则.md
```

---

# 2. 用户发一道题时

执行：

```text
① 判断科目
② 判断子题型
③ 在总索引定位文件
④ 读取最相关专项
⑤ 必要时读取母题错题库
⑥ 解题
⑦ 输出错因和下次触发
```

---

# 3. 不得执行

```text
为一道资料分析题读取全部行测文件
为一道逻辑题读取全部判断推理
为一道申论小题读取全部申论库
```

# 11. 错题输出格式

每次错题统一输出：

```text
【科目】
【题型】
【母题】
【我的错误步骤】
【错因代码】
【正确触发】
【最短解法】
【D1】
【D3变式方向】
```

---

# 12. GUESS / SLOW

即使答对：

```text
猜对
→ GUESS

明显超时
→ SLOW
```

两者都进入复盘。

---

# 13. 动态知识

读到：

```text
UPDATE
```

若用户要求当前最新版：

```text
必须核对最新官方来源
不能直接按旧文件回答
```

---

# 14. 生成训练

优先依据：

```text
最近错因Top3
+
母题弱项
```

不要随机生成大量无关冷门题。
