# 公考知识库总索引

本索引仅收录 `knowledge/` 当前正式模块中的真实文件，不将 `99_归档/` 作为日常检索入口。

用途标记：

- 学习：系统学习知识、方法与题型模型
- 查题：定位题型、母题或解题模型
- 错题：复盘错误、归纳陷阱与映射母题
- 考前：考场前快速回看

默认读取顺序：总索引 → 对应模块完整版或专项 → 母题/错题库 → 必要时考场速查。禁止无目的扫描整个知识库。

## 三、检索边界

- 题目讲解、知识点查询、错题分析：先在本索引定位模块，再读取对应专项或母题/错题库。
- 高频考点复习：优先读取对应模块完整版，必要时进入专项。
- 考场速查：只读取对应模块的考场速查文件。
- 辽宁申论：优先进入 `02_申论/02_辽宁专项/`；涉及国考与辽宁分类分级时读取通用申论中的分类分级专项。
- `99_归档/` 中的旧版本、重复文件和待确认文件不作为默认知识来源。
