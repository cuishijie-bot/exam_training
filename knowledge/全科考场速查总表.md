# 1. 资料分析

```text
基期量 = 现期/(1+r)

增长率 = 增长量/基期

增长量 = 现期×r/(1+r)

比重 = 部分/整体

基期比重
= 现期比重×(1+整体增速)/(1+部分增速)

比重升降：
部分增速 > 整体增速
→ 上升

平均数 = 总量/份数

平均数增长率
= (a-b)/(1+b)

隔年增长
= r1+r2+r1r2

拉动增长
= 部分增长量/整体基期

贡献率
= 部分增长量/整体增长量
```

口诀：

```text
去年基期
增长多少量
增长百分比率
占比看部分整体
```
