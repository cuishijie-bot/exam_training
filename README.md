# 公务员考试训练管理系统

行测 + 申论的低摩擦训练与记录系统。当前以连续训练为第一KPI，不设硬性周总题量。

## 1. 日常流程

1. 晚间完成当天训练后发送“训练结算”，只报告真实完成的数据。
2. 系统更新当天日志、统计和必要的错题记录。
3. 系统在同一次结算后直接生成次日 `TODAY.md`。
4. 第二天早晨不重新生成计划，直接按 `TODAY.md` 执行完整去程公交包。
5. 返程按预列公交包执行，公交期间无需切回Codex发送“下一组”。
6. 晚间只做一个主训练项目，一般2×5题起步；第1组完成后自行决定是否做第2组。
7. 实际情况变化时发送“改B日”或“按C日”。

当前强度：A日30～45分钟，B日20～30分钟，C日10～15分钟；状态好可选45～60分钟，但不主动加量。

## 2. TODAY模板

```markdown
# TODAY — YYYY-MM-DD 周X

- 计划状态：A日 / B日 / C日
- 当前阶段：7天低摩擦恢复期

## 今日行测主项

- 模块：资料分析
- 参考量：2×5题

## 今日申论

- 无正式训练

## 去程公交包

1. 判断推理 1×5题
2. D1/D3/D7到期错题 1题（无到期内容则常识速查1组）

## 返程公交包

1. 言语理解 1×5题
2. 今日错题候选回看 1题

## 晚间单一主训练

- 资料分析 2×5题
- 先完成第1组；完成后根据当时状态自行决定是否做第2组

## 技术训练 / 错题

- 优先复盘1题；只有确实值得长期保存才增加到2～3题

## 今日标准完成线

- 去程或返程公交包至少完成1项
- 晚间主项先完成第1组；第2组按当时状态决定
- 目标总计约30～45分钟，不为凑时长追加高负荷模块

## 今日最低完成线

- 以下只选1项，10～15分钟：行测1×5题 / 错题1题 / 申论审题1题并列3点 / 材料小段提炼3点

## 状态好可选延伸

- 仅在有余力时增加1个低负荷任务，总时长不超过45～60分钟

## 训练结果

- 实际完成：
- 正确数：
- 总用时：
- 状态：
```

具体日期按周循环选择模块。申论正式日可把申论设为唯一晚间主项，不再叠加高负荷行测。

## 3. 公交包模板

```markdown
## 去程公交包

1. [低负荷模块] 1×5题
2. [已有错题 / 常识 / 公式 / knowledge定点速查] 1项

## 返程公交包

1. [低负荷模块] 1×5题
2. [错题回看 / 申论材料找点 / D1-D3-D7复习] 1项
```

公交包规则：

- 去程、返程一次性写全任务、数量和顺序。
- 不写“下一组”“同上”“到时再定”。
- 不安排大量资料分析计算、复杂数量关系或持续纸笔任务。
- `knowledge/` 只做定点速查；需要具体内容时先通过 `knowledge/00_总索引.md` 定位，不扫描整个知识库。
- 公交期间不需要汇报，晚间统一结算。

## 4. 晚间结算流程

发送示例：

```text
训练结算：
去程判断5题，对4
返程言语5题，对3
晚间资料分析完成1组，5题，对4
错题复盘1题，值得保存
总训练32分钟
状态一般
```

系统随后：

1. 更新当天 `logs/YYYY-MM-DD.md`。
2. 更新 `stats/training.csv`，缺失数据留空，不猜测。
3. 优先保存1道真正有价值的错题，确有必要才增加到2～3道。
4. 输出最多3条复盘，并判定完成、部分完成或最低训练完成。
5. 当天未完成任务直接结束，不补课、不顺延。
6. 直接生成次日 `TODAY.md`，包含完整去程包、返程包和晚间单一主项。

常用指令：

```text
改B日
```

```text
按C日
```

```text
生成明日计划
```

```text
执行周复盘
```

恢复期结束后，只根据连续7天真实数据决定是否调整训练量。
